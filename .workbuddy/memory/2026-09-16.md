## 用户对上一轮方法的反驳（方法已升级，重要）

- 用户原话：「但是这个无法证明，没有一个明确的方向啊，不好去做呀。只能说要么能证明，要么能证伪，无法证明，这太宽泛了吧。」
- **反驳成立。** 上一轮给的"夹不死就造反例"仍把判断留给学生，等于"能证就证、证不了就证伪"——不是判据。
- **通用教训**：给方法时不能停在"看能不能夹死"，必须给出**"看什么 → 直接得结论"的检索指令**；凡是需要学生自己"试一下"的步骤都不算方法。
- **升级后的机械判据（只看不算），按题形分两类：**

  **题型一 · 题里有第二个向量组且已知一组的秩**（如 01-006）
  - 探针 1（看方向）：选项里找「**已知无关的那组**可由**待判的那组**表示」→ 有则**充分**（span(α)⊆span(β) ⟹ m ≤ r(β) ≤ m）。方向反了 → 只有上界 → **不充分**。
  - 探针 2（看它要秩还是要位置）：题设只锁**秩**、没锁**张成空间的位置**。故：要"张成同一个空间 / 互相可表示"（位置）→ **不必要**；要"同型同秩"（秩）→ **充要**（＝答案）。
  - 一句话：**题设给的是秩，答案也只能是秩；凡把结论升级成"空间位置关系"的，一律不必要。**

  **题型二 · 只有一个向量组，问哪些是无关的充要/充分条件**（如 01-003、01-004）
  - 无关的定义＝「**每一个**向量都不能被**其余全部**表示」。干扰项都在**两条正交的降级轴**上做手脚：
    - 轴 1：被查范围（每一个 → 某一个）
    - 轴 2：参照系大小（其余 s−1 个 → 1 个 → 0 个）
  - **机械动作**：圈出每个选项的量词与参照系，两句都拉满才是答案；出现「**存在**」二字基本可当场划掉。
  - 003 对照：(A) 参照系缩到空（只要非零）·(B) 参照系缩到 1 个（只看两两）·(C) 被查范围缩到某一个 ·(D) 两句都满 ✓

- **反例不必"找"，与走样方式一一对应，照着填即可**：
  - 参照系缩到空 → 两个成比例的非零向量
  - 参照系缩到 1 个 → 三个向量，其中一个等于另两个之和
  - 被查范围缩到某一个 → 一对成比例 + 一个与它们独立的
  - 要求"位置关系" → 另取一个同维数、不同方向的子空间
- 落笔动作序列（给学生版）：① 圈出已知哪组无关、几个向量、有没有第二个组；② 单组型→划量词与参照系，双组型→在选项旁画箭头标方向；③ 画完/划完答案已在纸上，只剩补一句反例。
