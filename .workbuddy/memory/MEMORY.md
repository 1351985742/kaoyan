## 小节刷题文件的固定开头（用户明确要求）
每份小节刷题文件的**最开头**必须先放一段「做题路径导览」：用连贯的行动序列带用户把整条路走一遍，**再**放 Section Start Card 的字段清单。
- 理由：字段清单是静态速查表，导览是动态流程；先有流程感，字段才挂得住。
- 导览结构（用户两次纠偏后定型）：**一句话纲领 → 先分主路/岔路 → 第一层（一个二分问题，下位手段显式标为同层）→ 第二层（唯一动作 + 捷径附注）→ 岔路 → 收尾句**。
- 顶部纲领句必须能一句话拎起整节，往下每层只回答纲领里的某一段。
- **落位（2026-09-16 定）**：Obsidian题库 的题型文件里插在 `- 题量：\`N\`` 元数据行之后、`## 做前总览` 之前，标题写作 `## 做题路径导览｜先把这一节的路走一遍`。已落实：`02 线性代数/03 向量/03 线性相关与无关/` 下 01–05 五个文件。
- 该题库的题块标题层级是 `## NNN.`（不是 `#### NNN.`）；统计题块用 `^## [0-9]{3}\.`。

## 题库内「前置知识未学」的暂缓标记约定（2026-09-16 定）
- **判据看题面**：只判断「没有该前置知识，题面读不读得懂」，不看解析。
- **两档标记**：`> [!todo]- 待学标记｜涉及 X，先跳过`（题面直接依赖）／`> [!info]- 待学标记｜学完 X 后回看`（题面自足，但本质属该体系）。
- **落位（重要）**：插在**分组标题（`### 锚点题` / `### 变式题` / `### 同构确认`）之后、`## NNN.` 题头之前**——也就是留在题块外部。绝不插进题块内部，否则会破坏「题面 → 解析 → 勘误 → 走法 → `^q-` 锚点」的元素顺序。
- 配套两处：`### 建议练习顺序` 块内加内链清单行（`[[#题头|编号]]`）；上一级 `00 做前总览` 里加汇总表 + 影响统计（先跳过几题、实际可做几题）。
- **易误判**：题面里的 $\lambda_i$ 可能是线性组合系数而非特征值；幂零链 $A^m\alpha=0$、正交补/基础解系类都不依赖特征值；「$A\alpha$ 与 $\alpha$ 线性相关」是特征向量定义式但用比坐标可解，属软档。

## 用脚本批量改写 md 文件后的强制校验项
任何用脚本批量改写的题库 / 笔记 md，改完必须四项全查：
1. **文件第一行**（标题是否完好）—— 本次事故就是只查统计数、没查头部，标题被污染后好几轮才发现
2. 元数据字段（分类ID / 分类路径 / 题量）
3. 题块数（`#### NNN.` 计数）
4. 块锚点数（`^q-` 计数）
5. **块内元素顺序**（题面 → 解析 → 勘误 → 走法 → `^q-` 锚点）—— 事故二：切分正则漏了 `### 锚点 N` 这一级，导致追加内容错位
6. **抽查实际渲染**：至少 `awk` 打印两个完整题块（含勘误的必查），确认 callout 没被拆散

## 切分 md 题块时的两个坑
- **切分正则要覆盖所有层级标题**。只按 `^#### NNN\.` 切分，中间的 `### 锚点 N · XXX` 会被算进上一题的块体，往块尾追加的内容就落到锚点标题之后了。
- **`(?:\n> ?[^\n]*)*` 这类续行分组允许匹配 0 次**，配上非贪婪 `.*?` 会让整个 group 退化成只匹配首行开头十几个字符（实测把 `> [!warning]-` 与正文拆成两半）。匹配引用块续行要用 `[^\n]*` 先吃掉整行。
- **最后一道题的块体会一直延伸到文件末尾**，往它尾部追加内容会插到收尾章节之后（实测多出一份重复题块）。拼接前先把尾部章节切出来单独处理。

## 整理结构时的层次纪律
- **不要把不同层次的东西并列。** 用户两次指出同一病根：先说"分太细、过拟合"，后说"没有提纲挈领感"。根因都是把「上位二分」与「下位手段」压在同一层。
- 正确做法：每个上层只留**一个判断问题**；下层的多个手段要显式标注"这是同一层的东西"。
- 「捷径 / 特例」必须降级为附注，不能与「通用主路」并列。例：等比截断是降次的捷径，不是与配凑并列的第二种方法。
