# 004｜ID 969｜倍角降幂开方绝对值与分段常数连续拼接复盘

本条为普通题目复盘。原题库路径：高等数学 / 一元积分 / 不定积分 / 求 f(x) 或不定积分；P3 拼接分段原函数，锚点题。

### 原始题目

880 综合填空 6（题目ID：`969`，题号：`004`）

已知 $f'(x) = \sqrt{1-\cos 2x}, x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right], f(0)=0$，则 $f(x) = \_\_\_\_$

---

### 我的真实过程

- **学生初次作答**：“这题不会是因为忘了公式是什么了？倍角公式。”
- **失误还原**：未能将 $1 - \cos 2x$ 瞬间转化为正弦平方，导致在脱根号第一步卡壳。
- **底层公式盲区**：
  $$\cos 2x = 1 - 2\sin^2 x \iff 1 - \cos 2x = 2\sin^2 x$$
  $$\cos 2x = 2\cos^2 x - 1 \iff 1 + \cos 2x = 2\cos^2 x$$

---

### 状态—路径切片

- **$S_0$（初始状态）**：含根号平方式的导函数，带初值 $f(0)=0$。
- **第一动作**：
  $$f'(x) = \sqrt{2\sin^2 x} = \sqrt{2}|\sin x|$$
  （严防漏掉绝对值！）。
- **中间状态（依零点拆段）**：
  * $x \in [0, \pi/2]$ 时，$f'(x) = \sqrt{2}\sin x \implies f(x) = -\sqrt{2}\cos x + C_1$
  * $x \in [-\pi/2, 0)$ 时，$f'(x) = -\sqrt{2}\sin x \implies f(x) = \sqrt{2}\cos x + C_2$
- **常数锁定**：
  * 初值 $f(0) = 0 \implies -\sqrt{2} + C_1 = 0 \implies C_1 = \sqrt{2}$
  * 连续性（可导函数必连续）：$\lim_{x\to 0^-} f(x) = \sqrt{2} + C_2 = 0 \implies C_2 = -\sqrt{2}$
- **落点**：
  $$f(x) = \begin{cases} \sqrt{2}(1 - \cos x), & 0 \le x \le \frac{\pi}{2} \\ \sqrt{2}(\cos x - 1), & -\frac{\pi}{2} \le x < 0 \end{cases}$$

---

### 下次触发规则

> [!IMPORTANT]
> 看到 $\sqrt{1 \pm \cos 2x}$，秒出倍角降幂：$1-\cos 2x = 2\sin^2 x$；**开方必带绝对值，分段求积分设独立常数 $C_1, C_2$，靠接点连续性与初值锁定**！
