# 方法专题｜定积分比大小全景心法（认知困惑复盘、3秒分流决策树与实战手法总览）

> **统领法则**：定积分比大小的本质是“定积分 = 底座（区间） $\times$ 平均高度（被积函数）”。
> 告别“手段过载与选择瘫痪”，看清题面特征，走唯一确定性的 3 秒分流决策树。

---

## 一、真实认知困惑复盘（Cognitive Bottleneck）

### 1. 学生的真实卡点与痛点
在做定积分比大小题时，极易陷入**“手段过载综合征（Tool Overload）”**：
- 脑子里同时漂浮着：放缩法、函数图形、切线割线、凹凸性、移项求导、基准借桥……
- 拿到一道题时，不知道该派哪个工具上场，产生严重的决策瘫痪：
  *“到底要不要放缩？什么时候放缩？什么时候看图形？什么时候切线割线？什么时候移项求导？”*
- 甚至误以为要对复杂的整体组合式（如 $\frac{\sin ax}{\sin x}$）求二阶导看凹凸性，导致畏难不前。

### 2. 困惑的底层根源
- **误将“不同维度的工具”当成了“同一层级的并列选项”**。
- 事实上，“切线、割线、凹凸性”是数学原理与几何直觉，“移项作差求导”是代数落地执行动作，而“放缩”只在特定题型下触发。它们根本不是随时在脑子里打架的选项，而是有着**严格、非黑即白的题面触发条件**。

## 三、路线 A 唯一实操正统：初中移项去分母 ➔ 作差求导（通杀 80% 题目）

当选项没有具体数字 1 时，**大脑彻底关闭“放缩、切线、凹凸性”等一切花哨概念**，只执行三步流水线：

1. **第一步（去分母）**：带着分母求导是找虐，初中生移项去分母：
   - 要比 $\frac{\sin ax}{\sin x}$ 与 $a$ ➔ 改比 $\sin ax$ 与 $a\sin x$；
   - 要比 $\frac{x}{2}$ 与 $\ln(1+x)$ ➔ 改比 $x$ 与 $2\ln(1+x)$。
2. **第二步（设函数）**：作差设辅助函数，标出起点 0：
   $$F(x) = \sin ax - a\sin x \quad (F(0) = 0)$$
3. **第三步（求一阶导）**：求一次导数看正负，初等单调性直接落地：
   $$F'(x) = a(\cos ax - \cos x) > 0 \quad (\text{因 } ax < x \text{ 且余弦在第一象限单减})$$
   $F(0)=0$ 且单调递增 $\implies F(x) > 0 \implies \frac{\sin ax}{\sin x} > a$。
   **三行草稿纸完事，稳准狠。**

## 四、路线 B 精准放缩狙击：端点最值与区间长“天平对消律”

只有在**“积不出来、选项有 1、区间长度带有 $\pi$”**时，放缩才是唯一解法：

### 1. 核心铁律
> **被积函数小于 1 $\neq$ 积分小于 1！** 必须严格乘以区间长度 $(b-a)$。

### 2. 双向天平对消模型
- **区间 $[0, \frac{\pi}{2}]$（长度 $\frac{\pi}{2} > 1$）**：
  粗放放缩 $\frac{\sin x}{x} < 1 \implies I_1 < 1.57$（太松，废了！）。
  **必须找下界**：$\frac{\sin x}{x}$ 单减，右端点极小值是 $\frac{\sin(\pi/2)}{\pi/2} = \frac{2}{\pi}$。
  $$\text{极小值 } \frac{2}{\pi} \times \text{区间长 } \frac{\pi}{2} = \mathbf{1} \implies \mathbf{I_1 > 1} \quad (\#023 \text{ 选 B})$$
- **区间 $[0, \frac{\pi}{4}]$（长度 $\frac{\pi}{4} < 1$）**：
  **必须找上界**：$\frac{\tan x}{x}$ 单增，右端点极大值是 $\frac{\tan(\pi/4)}{\pi/4} = \frac{4}{\pi}$。
  $$\text{极大值 } \frac{4}{\pi} \times \text{区间长 } \frac{\pi}{4} = \mathbf{1} \implies \mathbf{I_1 < 1} \quad (\#001 \text{ 选 B})$$

## 五、考研三大基础切线不等式链（几何本源，无需死记）

所有放缩落点，均来自函数与其在原点的切线位置关系：

| 不等式链 | 原点切线方程 | 曲线与切线位置 | 核心考场不等式 |
| :--- | :---: | :---: | :--- |
| **指数链** | $y = 1 + x$ | 曲线在切线**上方**（碗形 $\cup$） | $e^x \ge 1 + x \implies \frac{e^x}{1+x} > 1$ |
| **对数链** | $y = x$ | 曲线在切线**下方**（伞形 $\cap$） | $\frac{x}{1+x} < \ln(1+x) < x$ |
| **三角链** | $y = x$ | 正弦在下方，正切在上方 | $\frac{2}{\pi}x \le \sin x < x < \tan x$ |

## 六、宏观统领：三维控制论与均值高度律

1. **三维控制论**：
   - **坐标域维**：同区间直接比；对称区间换元拉齐；包含区间除以底座比平均高度。
   - **运算传递维**：复合函数链式法则 $(+)\times(-) = (-)$ **单调性保真**（#022 选 C）；乘积函数求导加法正负相消 **单调性毁灭**（#022 排除 A）。
   - **基准锚定维**：不同形式借助公共桥梁（$x$、1、$\frac{1}{2}$）穿透。
2. **均值高度律（破交叉项 $b\int_0^a f$ vs $a\int_0^b f$）**：
   同除以 $ab$，看平均高度 $\bar{y} = \frac{1}{L}\int f$。单减函数后段更矮拖累整体均值，故前段均值必大于全段均值（#019 选 A）。
