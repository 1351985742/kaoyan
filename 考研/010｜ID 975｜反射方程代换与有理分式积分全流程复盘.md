# 010｜ID 975｜反射方程代换与有理分式积分全流程复盘

本条为普通题目复盘。原题库路径：高等数学 / 一元积分 / 不定积分 / 求 f(x) 或不定积分；P4 反射方程联立，锚点题（同构题 013｜ID 978）。

### 原始题目

25 版 1000 第九章强化 4（题目ID：`975`，题号：`010`；同构题：880 综合填空 2 · ID 978）

设函数 $f(x)$ 满足方程：
$$x f(x) + f(1-x) = x^{2}$$
求不定积分 $\int f(x) \, dx$。

---

### 我的真实过程

- **学生初次作答**：“这个路径P4，我确实是没想到能够直接做复杂的代换。”
- **失误还原**：看到未知函数既有 $f(x)$ 又有 $f(1-x)$，尝试直接求导或分离变量受阻，没有意识到自变量对偶关系 $x \leftrightarrow 1-x$ 具备自闭性。
- **底层认知**：方程中出现对称型变量对偶 $f(x)$ 与 $f(a-x)$ 时，必须立即通过对偶变量代换引入第 2 个方程组成闭合方程组。

---

### 状态—路径切片

- **$S_0$（初始状态）**：含对偶变量 $f(x)$ 与 $f(1-x)$ 的单方程。
- **$G$（目标状态）**：解出显式 $f(x)$ 并求出原函数。
- **第一动作**：
  将原方程全体 $x$ 替换为 $1-x$：
  $$(1-x)f(1-x) + f(x) = (1-x)^2 = x^2 - 2x + 1$$
- **中间状态**：
  消去 $f(1-x)$ 解出：
  $$f(x) = \frac{x^3 - 2x + 1}{x^2 - x + 1}$$
  （分母 $(x-\frac{1}{2})^2 + \frac{3}{4} > 0$ 恒无零点，全实数域安全）。
- **落点**：
  多项式长除拆真分式：$f(x) = x + 1 - \frac{2x}{x^2 - x + 1}$。
  配导数拆项：
  $$\frac{2x}{x^2 - x + 1} = \frac{(2x-1) + 1}{x^2 - x + 1} = \frac{2x-1}{x^2 - x + 1} + \frac{1}{(x-\frac{1}{2})^2 + \frac{3}{4}}$$
  逐项积分落地：
  $$\int f(x)dx = \frac{1}{2}x^2 + x - \ln(x^2-x+1) - \frac{2}{\sqrt{3}}\arctan\left(\frac{2x-1}{\sqrt{3}}\right) + C$$

---

### 下次触发规则

> [!IMPORTANT]
> 看到方程中同时出现 $f(x)$ 与 $f(a-x)$（或 $f(-x)$、$f(1/x)$），**立即用对应对称变量代换写出第 2 个伴随方程，二元一次消元出 $f(x)$**！
