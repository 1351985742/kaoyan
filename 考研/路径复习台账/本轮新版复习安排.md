# 本轮新版复习安排

用户要求提高题目压缩效率，不能按约 1.6 条题库记录对应一次反馈推进。一周总预算，使用新版 10 个主题组、80 条练习路径；按目录顺序一条路径一批，已反馈题通过原题 ID 对照旧台账。

选题默认每条路径 1–2 道代表题，存在实际不同的关键结构或用户明确困难时可增加；极简单或已充分回顾的路径可少于 1 道新题。每条路径在后台检查其全部题目的覆盖关系，明确哪些结构可以合并、哪些仍有必要回访；同题、同构、题型标签或 Agent 的归类都不是学生已经掌握的证据。80–160 道新题仅是预算规划，并非完成保证；实际题数取决于路径差异、既有证据和剩余时间。

每批一次发齐，不泄露解法。多数题口述关键计算路径；明确的非常规中间处理结合已有证据选择性关注。当前无纸笔，所需手算暂存，不因未手算否定口述路径通过。按学生实际反馈逐题标记路径和真正关键的中间处理，写台账并回读；结束后总结路径，整体复习结束后总回顾。12 条待核题不作为正常独立训练。
