## q1881｜原解析的临界参数有误

题面：x > 0 时，kx + 1/x² = 1 恰有一个解。原解析把正的临界值写成 2/∛4，不能成立。

当 k ≤ 0，左侧严格下降并与 1 恰交一次；当 k > 0，恰有一个解的临界情形满足同时等于 1 且导数为零：k = 2/x³，3/x² = 1，故 x = √3、k = 2/(3√3)。正确结论：k ≤ 0 或 k = 2/(3√3)。题目本身可用，评价时使用上述校正，不套用原解析。

## q1746｜正确选项可用，但原解析的一处反例不成立

原解析用常函数反驳“偶函数在 0 处取得极值”。按通常非严格极值定义，常函数每点均为极值点，故此反例不恰当。可用 f(0)=0，x≠0 时 f(x)=x² sin(1/x²)：它是偶函数，在 0 的每个邻域既有正值也有负值，因此 0 不为极值点。其余选项仍需按各自条件判断。

## q1336 / q4098｜同题源版本目标阶次不一致

两处都标注 26 版 660 第 154 题，一元微分的 q1336 要求 f'''(0)，极限章 q4098 要求 f''(0)。两种写法对应不同的数学问题和答案，不能未经查原题就认定二者完全相同。选题暂用 q1337；若之后使用任一版本，应明确题面并核原题。
