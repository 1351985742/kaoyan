# 二阶常系数线性方程｜学习笔记

记录日期：2026-11-02。用户要求记录此前讲过的判断逻辑；这是教学笔记，不表示已通过独立练习。

## 一、先确定齐次通解

对 y″+py′+qy=f(x)，先看对应齐次方程 y″+py′+qy=0，写特征方程 r²+pr+q=0。

- 两个不同实根 r₁、r₂：y_h=C₁e^(r₁x)+C₂e^(r₂x)。
- 二重实根 r：y_h=(C₁+C₂x)e^(rx)。
- 共轭复根 α±βi：y_h=e^(αx)(C₁cosβx+C₂sinβx)。

## 二、右端决定非齐次特解的试探

- 右端为多项式 Pₘ(x)：先设完整 m 次多项式 Qₘ(x)。
- 右端为 e^(αx)Pₘ(x)：先设 e^(αx)Qₘ(x)。
- 右端含正弦或余弦：通常同时设 A cosβx+B sinβx；若乘指数或多项式，按相应形式配指数和待定多项式。
- 上述为初步试探，代回原方程确定系数；并非所有右端都可用有限项待定系数法处理。

## 三、与齐次解重复时补乘 x 的幂

- 对 e^(αx)Pₘ(x)，检查 α 在特征方程中是否是根：不是根乘 x⁰，单根乘 x，二重根乘 x²。普通多项式对应 α=0。
- 对 e^(αx)(多项式×cosβx + 多项式×sinβx)，检查 α±βi 的相应根重数；重复则乘对应的 x 幂。
- 例：y″−2y′+y=eˣ，特征方程 (r−1)²=0，因 1 是二重根，特解试 y_p=Ax²eˣ，代回得 A=1/2。通解 y=(C₁+C₂x)eˣ+(1/2)x²eˣ。

## 四、完整流程和边界

标准化并区分齐次与非齐次 → 写特征方程并得齐次通解 → 根据右端试设特解 → 判断特征根重数并按需乘 x 的幂 → 代回原方程确定待定系数 → 齐次通解加一个非齐次特解 → 用初值确定 C₁、C₂。找不到初等原函数或右端超出待定系数法适用范围时，不强套本表。
