# q3913｜调和和的 n 次根

- 题目：求 [1+1/2+…+1/n]^(1/n) 的极限。
- 用户：“也是化成指对形式，是否也能直接凑出定义式？”
- 评价：取对数是有效入口；能否直接用积分定义不确定。关键是控制整个和式的增长，而不必将其强行化为常规定积分和。
- 讲解：记 Hₙ 为括号中的和，1≤Hₙ≤n，于是 1≤Hₙ^(1/n)≤n^(1/n)→1，结果为 1。等价地 0≤ln Hₙ/n≤ln n/n→0。若写成积分和需注意 1/x 在 0 处无界，不能直接按连续函数的标准黎曼和套用。
- 状态：解释后待独立检验；本地记录，Notion 待同步。
- 后续用户补充：“这些感觉可能能想到，但有可能想不到。”表示对界的独立提取没有把握，不等于确认不会；回顾时检查能否主动找到粗界，不强制完整手算。
