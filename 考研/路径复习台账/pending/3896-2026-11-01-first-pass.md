# q3896｜n 项乘积开 n 次方

- 题目：求 [(n+1)(n+2)…(2n)]^(1/n)/n 的极限。
- 用户：“分子上先把N^N给提出来。里面就是1+2/N这样的表述了。然后上面是化成指对形式……凑成……积分定义式。”
- 评价：主线正确，先提 n 的 n 次方，取对数把乘积变为平均和，再转积分；积分计算及最终结果未展示，不推断不会。
- 复核：ln 结果趋于 ∫₀¹ln(1+x)dx=2ln2−1，极限 4/e。普通路径步骤已预测，未提出具体计算困难，不单列强制补算。
- 后续用户追问：“根号里面得提出来一个 n……提出来的 n 跑哪去了？”需展开 n 个因子各提 n 得 nⁿ，开 n 次方得 n，与原分母 n 约去；属于这一题具体计算连接点有疑惑，不推断整体路线有误。
