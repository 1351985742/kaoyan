# 线性代数第三批学习断点与错题记录（待核对原逐题复盘并同步）

记录日期：2026-11-08。
背景：学生对第三批 5 题的真实作答反馈暴露出了严重的解法缺失、依赖死算、定义提取不全以及遗忘，**全部 5 题均未能独立完整做出，绝不能认定掌握，属于严重薄弱项**。

## 逐题真实断点与原始反馈

1. **q107 · 2019 数二真题（代数余子式求和 001）**
   - **学生原始反馈**：“第1题是不是最直接的把代数余子式拿出来，然后去做？”
   - **真实掌握状态**：**不会巧妙路径，只能盲目硬算**。完全没有看出 $A_{11} - A_{12}$ 的系数 $(1, -1, 0, 0)$ 正好是原矩阵第一行元素本身，未识别出该式就是 $|A|$ 自身按首行展开。
   - **主要断点**：代数余子式线性组合的整体识别能力缺失。
   - **后续回访要求**：重新测试非首行余子式求和（需真正替换行的题），检验是否能构造辅助行列式。

2. **q119 · 2024 数三真题（余子式相关信息定参 001）**
   - **学生原始反馈**：“第2题有什么简便方法吗？在我看来好像只能去硬算。”
   - **真实掌握状态**：**完全不会定参技巧，处于硬算停滞状态**。完全无法将 $-M_{21} + M_{22} - M_{23} = 0$ 转化为代数余子式 $A_{21} + A_{22} + A_{23} = 0$，更不知道构造第 2 行为 $(1,1,1)$ 的辅助行列式秒解 $b=a+1$。
   - **主要断点**：余子式与代数余子式符号转化、辅助行列式构造定参机制完全不熟。
   - **后续回访要求**：重新独立作答 2024 数三真题，检验辅助行列式能否独立列出。

3. **q121 · 2021 数二三真题（确定多项式系数 001）**
   - **学生原始反馈**：“要是要求每一行只能选一个的话，好像组合只能是，第一行选第4个，第二行选第2个，第三行选第3个，第四行选第1个。剩下的也有可能是我没看出来，我不是很确定。”
   - **真实掌握状态**：**不完整，遗漏关键项，判定不稳**。仅找到了 $(4,2,3,1)$ 项，遗漏了 $(2,1,3,4)$ 项，无法确定最终系数（$-5$）。
   - **主要断点**：多项式行列式按定义排列表达式不完备，缺乏求导法等交叉验证手段。
   - **后续回访要求**：安排确定 $x^k$ 次方系数的代表题，独立找全所有非零项。

4. **q126 · 1999 数二真题（根的个数 001）**
   - **学生原始反馈**：“第2、3、4行全部减一下第1行...只留个第1行和第2行。但是这时候好像是不是有些不对了？4行里面有两个空行。”
   - **真实掌握状态**：**对行列式退化为 0 的含义极其不自信，未能理解本质**。不仅没有一眼看出第 1 列和第 3 列完全相同，而且消出行全为 0 之后反而怀疑自己算错了，未能得出“$f(x) \equiv 0$ 故有无穷多个根”的结论。
   - **主要断点**：观察相同列的能力缺失；行列式全 0 行与恒等式的逻辑联系不牢。
   - **后续回访要求**：重新给出含参行列式求根题，检验因式分解与相同列识别。

5. **q128 · 姜晓千基础例题（Cramer 法则 001）**
   - **学生原始反馈**：“第5题，这个好像是范德蒙德行列式。具体的解法我有点忘了。”
   - **真实掌握状态**：**完全遗忘，无法作答**。只认得名字，不知道克拉默法则的唯一解条件，更不会利用特解观察法秒杀。
   - **主要断点**：克拉默法则适用条件及解的判定完全遗忘。
   - **后续回访要求**：重新回测克拉默法则非零解与唯一解的综合应用题。
