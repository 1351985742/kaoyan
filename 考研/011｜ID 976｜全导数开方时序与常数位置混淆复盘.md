# 011｜ID 976｜全导数开方时序与常数位置混淆复盘

本条为普通题目复盘。原题库路径：高等数学 / 一元积分 / 不定积分 / 求 f(x) 或不定积分；P5 原函数乘导数，锚点题。

### 原始题目

25 版 1000 第九章强化 14（题目ID：`976`，题号：`011`）

设 $F(x) > 0$ 为 $\mathbb{R}$ 上的连续可导函数，$F(0) = \sqrt{\pi}$，且满足：
$$F(x) F'(x) = \frac{\cos x}{2 \sin^{2} x + \cos^{2} x}$$
求 $F(x)$。

---

### 我的真实过程

- **学生初次作答**：“哎呦，我把常数放在根号外边了。”
- **失误还原**：在求出右侧不定积分 $2\arctan(\sin x)$ 之后，潜意识以为先对等式两边开方得到 $F(x) = \sqrt{2\arctan(\sin x)}$，最后再外挂一个积分常数 $+ C$（或直接加上初值 $\sqrt{\pi}$），变成了 $F(x) = \sqrt{2\arctan(\sin x)} + \sqrt{\pi}$。
- **底层认知漏洞**：混淆了微分方程中**通解常数的生成时序**：
  1. $2F(x)F'(x) = [F^2(x)]'$，积分直接产生的对象是 $F^2(x)$，常数 $+C$ 必须绑在 $F^2(x)$ 这一层；
  2. 只有在常数 $C=\pi$ 被初值锁定之后，才能两边整体开方！

---

### 状态—路径切片

- **$S_0$（初始状态）**：含乘积 $F(x)F'(x)$ 的微分等式，带初值 $F(0)=\sqrt{\pi}$。
- **$G$（目标状态）**：锁定原函数 $F(x) = \sqrt{2\arctan(\sin x) + \pi}$。
- **强信号**：$F(x)F'(x) \implies \frac{1}{2}[F^2(x)]'$；分母 $2\sin^2 x + \cos^2 x = 1+\sin^2 x$。
- **第一动作**：
  两端同乘 2 积分：
  $$F^2(x) = \int \frac{2\cos x}{1+\sin^2 x} dx = 2\arctan(\sin x) + C$$
- **常数锁定**：
  代入 $x=0, F(0)=\sqrt{\pi} \implies \pi = 2\arctan(0) + C \implies C = \pi$。
- **落点**：
  已知 $F(x) > 0$，整体开平方：$F(x) = \sqrt{2\arctan(\sin x) + \pi}$。

---

### 诊断校准

- **主要失效层**：**计算失误 / 符号时序错位**。
- **专家视角**：此类微分方程题，常数漏开方或外挂常数是考生失分率超 40% 的高发陷阱。

---

### 下次触发规则

> [!IMPORTANT]
> 看到 $2FF'$ 或 $yy'$，求出的积分对象是 $F^2$（或 $y^2$），**常数必须牢牢绑在 $F^2=g(x)+C$ 这一层**；代入初值定好 $C$ 后，再执行开平方！
