# 方法专题｜三角同角平方恒等式与微分配对秒推图谱

- **专题归属**：考研数学一 · 三角函数积分变形底座
- **痛点诊断**：经常搞混 $\sec^2 x$ 与 $\tan^2 x$、$\csc^2 x$ 与 $\cot^2 x$ 的加减常数关系，导致凑微分时卡壳。

---

## 一、三秒推导法（考场上 1 秒写出，永不再记混）

不要死记，只从小学就会的这一条出发：
$$\sin^2 x + \cos^2 x = 1$$

### 1. 两边同时除以 $\cos^2 x$（导出正切-正割组）：
$$\frac{\sin^2 x}{\cos^2 x} + \frac{\cos^2 x}{\cos^2 x} = \frac{1}{\cos^2 x}$$

$$\mathbf{1 + \tan^2 x = \sec^2 x}$$
- 变形式：$\tan^2 x = \sec^2 x - 1$
- 极速记忆法：“**小弟（tan）加 1 变大哥（sec）**”。

### 2. 两边同时除以 $\sin^2 x$（导出余切-余割组）：
$$\frac{\sin^2 x}{\sin^2 x} + \frac{\cos^2 x}{\sin^2 x} = \frac{1}{\sin^2 x}$$

$$\mathbf{1 + \cot^2 x = \csc^2 x}$$
- 变形式：$\cot^2 x = \csc^2 x - 1$
- 极速记忆法：“**带 co 的跟带 co 的在一起，小弟（cot）加 1 变大哥（csc）**”。

---

## 二、三角微分“天生一对”镜像表（必须刻在脑子里）

| 正组（无负号） | 余组（必带负号） |
| :--- | :--- |
| **$(\tan x)' = \sec^2 x$**<br>$\implies \sec^2 x \, dx = \mathbf{d(\tan x)}$ | **$(\cot x)' = -\csc^2 x$**<br>$\implies \csc^2 x \, dx = \mathbf{-d(\cot x)}$ |
| **$(\sec x)' = \sec x \tan x$**<br>$\implies \sec x \tan x \, dx = \mathbf{d(\sec x)}$ | **$(\csc x)' = -\csc x \cot x$**<br>$\implies \csc x \cot x \, dx = \mathbf{-d(\csc x)}$ |

---

## 三、实战反射动作

### 1. 看到偶数次幂（$\sec^4 x$ 或 $\csc^4 x$）：
- 拆出一个平方送进 $d$：$\sec^2 x dx = d(\tan x)$（或 $\csc^2 x dx = -d(\cot x)$）；
- 剩下的平方用 $1+\tan^2 x$（或 $1+\cot^2 x$）换掉，**纯多项式积分秒杀**。

### 2. 看到奇数次幂（$\sec^3 x$ 或 $\csc^3 x$）：
- 拆出一个平方送进 $d$ 做分部积分；
- 剩下的积分用 $\tan^2 x = \sec^2 x - 1$（或 $\cot^2 x = \csc^2 x - 1$）拆开；
- **移项自循环除以 2 落地**。
