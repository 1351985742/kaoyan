# 方法专题｜积分三大定理概念秒杀律（有界可积门槛、达布定理排查与变限升阶折角）

- **所属模块**：高等数学 / 一元函数积分学 / 积分概念题 / 积分三大定理
- **核心痛点**：
  1. 混淆“定积分存在（可积）”与“原函数存在”：可积只要【有界+有限个间断点】，根本不需要原函数！
  2. 误以为原函数必须能用初等函数算出来，或误把“被积函数在某点不可导”当成“没有原函数”（找原函数是往上积分磨皮，只需连续即可！）。
  3. 概念题中看到 $\sec x$ 等三角函数误以为要算积分，忽略了只需看左右极限判跳跃间断。
- **沉淀日期**：2026-10-23

## 一、可积性 vs 原函数存在性（极度清晰对照）

| 考察维度 | 定积分存在（黎曼可积） | 原函数存在（导函数存在） |
| :--- | :--- | :--- |
| **定义本质** | 有限和式的极限 $\lim \sum f(\xi_i)\Delta x_i$ 是否收敛为一个有限常数 | 是否存在可导的 $F(x)$，使得 $F'(x) = f(x)$ 处处成立 |
| **门槛高低** | **门槛极低！** | **门槛极高！** |
| **充分条件** | 在闭区间 $[a,b]$ 上**【有界 + 只有有限个间断点】必可积！**（哪怕间断点是跳跃、可去、振荡，全都能积！） | 在区间上**【连续】必有原函数！** |
| **致命死穴** | **无界必不可积！**（必要条件是有界） | **有第一类间断点（跳跃/可去）必无原函数！**（达布导数介值定理一票否决） |
| **反例武器** | 符号函数 $\operatorname{sgn}(x)$：在 $[-1, 1]$ 上有界且仅 1 个间断点 $\implies$ **可积！但有跳跃间断 $\implies$ 绝无原函数！** |

## 二、变上限积分 $F(x) = \int_a^x f(t)dt$ 的升阶折角律

1. **连续性保底**：
   只要被积函数 $f(t)$ 有界可积，$F(x)$ 在全区间上**100% 连续**，绝无间断点！
2. **导数看左右极限**：
   $$F'_-(x_0) = f(x_0^-), \quad F'_+(x_0) = f(x_0^+)$$
   - 若 $f(x_0^-) \neq f(x_0^+)$（$f$ 在 $x_0$ 是跳跃间断点） $\implies$ $F(x)$ 在 $x_0$ 处**连续但不可导（折角尖点）**！
   - 若要 $F(x)$ 在 $x_0$ 处可导 $\iff$ 左右极限必须焊死相等：$f(x_0^-) = f(x_0^+)$。

## 三、原函数存在性的两大思维盲区与经典双胞胎模型

### 1. 两大致命认知误区
- **误区一：执念于“必须能用初等函数解析式算出来”**  
  存在原函数 $\neq$ 原函数是初等函数。比如 $e^{-x^2}$ 的原函数不是初等函数，但它连续，原函数客观存在！考研问“是否存在原函数”，只看它**是否连续（或满足达布定理）**，绝不看能否积出解析式。
- **误区二：把“自身不可导”误判为“没有原函数”**  
  **求原函数是“往上走”（积分升级，平滑磨皮）！** 被积函数哪怕在某点不可导（有折角尖点），只要它没有断开（**处处连续**），它的原函数就必定存在！

### 2. 经典双胞胎模型（考研必背对比）

```
【弟弟】g(x) = x · sin(1/x) (x≠0), g(0) = 0
  ├─ 连续性：x→0 时，无穷小 × 有界 = 0 = g(0) ──【在 x=0 处连续！】
  ├─ 可导性：差商 sin(1/x) 振荡不存在 ─────────【在 x=0 处不可导！】
  └─ 原函数：因为处处连续 ───────────────────────【必存在原函数！】G(x) = ∫[0,x] t sin(1/t) dt

【哥哥】F(x) = x² · sin(1/x) (x≠0), F(0) = 0
  ├─ 可导性：在 x=0 处可导且 F'(0) = 0
  └─ 导函数：f(x) = F'(x) = 2x sin(1/x) - cos(1/x) 在 0 处是【第二类振荡间断点】！
     ★ 核心反例地位：f(x) 虽然在 0 处不连续（振荡），但它偏偏【存在原函数 F(x)】！
```

## 四、常用正割/正切导数与积分速查

- **导数**：
  $$(\sec x)' = \sec x \tan x$$
  $$(\tan x)' = \sec^2 x$$
- **积分**：
  $$\int \sec x dx = \ln |\sec x + \tan x| + C$$
  $$\int \sec^2 x dx = \tan x + C$$
  $$\int \tan x dx = -\ln |\cos x| + C = \ln |\sec x| + C$$
