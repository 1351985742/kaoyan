# 方法专题｜多元函数偏积分、待定函数与原函数恢复律

> 适用范围：高等数学 · 多元微分学 · 已知偏导数/全微分/偏导关系式恢复多元原函数（全 21 题矩阵全景沉淀）。

---

## 一、 核心底座：为什么多元偏积分的常数不能写成数字 $C$？

- **一元微积分**：只有自变量 $x$，导数为零的唯一可能就是纯常数，故 $\int g(x)\,\mathrm{d}x = G(x) + C$。
- **多元微积分**：对 $x$ 求偏导时，**纯含 $y$ 的任意表达式（如 $y^2, \sin y, e^y$）均被视作常数，导数恒等于 $0$**！
- **信息守恒律**：逆向偏积分时，积分项必然保留沿未积变量方向的任意分布：
  $$\int g(x, y) \mathrm{d}x = G(x, y) + \mathbf{\varphi(y)}$$
  $$\int g(x, y) \mathrm{d}y = G(x, y) + \mathbf{\psi(x)}$$

---

## 二、 常规基础流水线：二阶混合/同变量偏导逐次偏积分

### 1. 混合偏导（如 $\frac{\partial^2 z}{\partial x \partial y} = x+y$）
- **操作流水线**：
  1. 对 $y$ 偏积分 $\to$ 补一元待定函数 $\varphi(x)$；
  2. 对 $x$ 偏积分 $\to$ 再补一元待定函数 $\psi(y)$；
  3. 骨架：$z(x,y) = \text{双重积分项} + \Phi(x) + \psi(y)$；
  4. 利用给定的边界 $z(x,0)$ 与 $z(0,y)$，在零点联立方程相加减，求出待定和 $\Phi(x) + \psi(y)$。
- **代表题**：25版 660 第 96 题 `[ID 2644]`、900 数二 B 类 22 `[ID 2646]`。

### 2. 同变量高阶偏导（如 $f_{yy}'' = 2$）
- 两次积分**全是对 $y$ 积**，待定函数全都是关于 $x$ 的函数：
  $f_y' = 2y + G(x) \xrightarrow{\text{代边界}} G(x) = x \implies f = y^2 + xy + H(x) \xrightarrow{\text{代边界}} H(x) = 1$。
- **代表题**：880 综合填空 1 `[ID 2643]`。

### 路径四：全微分相容性确定系数（1000 基础 10 · [ID 2653]）

* **题型特征**：给出 $Q(x,y) = \frac{x}{y^2}$，若 $P(x,y)\mathrm{d}x + Q(x,y)\mathrm{d}y$ 是某函数的全微分，求 $P(x,y)$。
* **破局公理**：全微分存在的充要条件（单连通域上）即混合偏导对称性（格林无旋场条件）：
  \[
  \mathbf{\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}}
  \]
* **慢动作推演**：
  1. 求 $\frac{\partial Q}{\partial x} = \frac{\partial}{\partial x}\left(\frac{x}{y^2}\right) = \frac{1}{y^2}$；
  2. 建立方程：$\frac{\partial P}{\partial y} = \frac{1}{y^2}$；
  3. 对 $y$ 偏积分恢复 $P$ 的骨架：$P(x,y) = \int \frac{1}{y^2}\mathrm{d}y = \mathbf{-\frac{1}{y} + \varphi(x)}$；
  4. 对照选项，选项 B 为 $x^2 - \frac{1}{y}$，恰好满足（其中 $\varphi(x) = x^2$）！秒选 B！

---

### 路径五：固定单变量降维解一元 ODE（2009 北京大学生竞赛题 · [ID 2660]）

* **题型特征**：条件给出 $f_x'(x,y) = -f(x,y)$，$\frac{f_y'(0,y)}{f(0,y)} = \cot y$，且 $f(0, \pi/2) = 1$。
* **考场地位**：⭐⭐⭐⭐⭐（考研大题 10~12 分压轴高频题型！“多元微分 + 微分方程”跨章大综合）。
* **破局心智**：**把 $y$ 锁死当常数，它就是高数上一元微分方程 $y' = -y$！**
* **慢动作推演**：
  1. **第一步（降维解 $x$）**：  
     $\frac{f_x'}{f} = -1 \implies \ln|f| = -x + \ln|C(y)| \implies \mathbf{f(x,y) = C(y)e^{-x}}$；
  2. **第二步（代入切片 $x=0$）**：  
     $f(0,y) = C(y)e^0 = C(y)$，因此 $f_y'(0,y) = C'(y)$；
  3. **第三步（解 $y$ 的微分方程）**：  
     代入已知条件：$\frac{C'(y)}{C(y)} = \cot y = \frac{\cos y}{\sin y} \implies \ln|C(y)| = \ln|\sin y| + \ln|A| \implies \mathbf{C(y) = A\sin y}$；
  4. **第四步（定初值）**：  
     $f(0, \pi/2) = A\sin(\pi/2) = 1 \implies A = 1 \implies C(y) = \sin y$；
  5. **拼装收工**：$\mathbf{f(x,y) = e^{-x}\sin y}$。

---

### 路径六：坐标转轴双偏导合体偏积分（25版 660 第 90 题 · [ID 2661]）

* **题型特征**：已知双偏导之和 $\frac{\partial f}{\partial u} + \frac{\partial f}{\partial v} = (u+v)e^v$，且 $f(0,v) = (v-2)e^v$，求 $f(x, x+y)$。
* **破局心智**：**不要去解偏微分方程！求什么就令什么为新函数 $g(x,y)$，链式求导后双偏导必定自动合并为一个单偏导！**
* **慢动作推演**：
  1. **令新函数**：令 $\mathbf{g(x,y) = f(x, x+y)}$（即 $u=x, v=x+y$）；
  2. **链式求导（见证合体）**：  
     \[
     \frac{\partial g}{\partial x} = \frac{\partial f}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial f}{\partial v}\frac{\partial v}{\partial x} = f_u' \cdot 1 + f_v' \cdot 1 = \mathbf{f_u' + f_v'}
     \]
     双偏导之和完美合体为单一偏导 $\frac{\partial g}{\partial x}$！
  3. **代入已知右侧**：  
     $\frac{\partial g}{\partial x} = (u+v)e^v = (x + x + y)e^{x+y} = \mathbf{(2x+y)e^{x+y}}$；
  4. **对 $x$ 偏积分（分部积分）**：  
     $g(x,y) = \int (2x+y)\mathrm{d}(e^{x+y}) = (2x+y-2)e^{x+y} + C(y)$；
  5. **代入边界定 $C(y)$**：  
     $g(0,y) = f(0,y) = (y-2)e^y \implies (y-2)e^y + C(y) = (y-2)e^y \implies C(y) = 0$；
  6. **结果**：$\mathbf{f(x, x+y) = (2x+y-2)e^{x+y}}$。

### 路径七：复杂隐变量导数公因式清零消项（880 基础解答 11 · [ID 2662]）

* **题型特征**：$z = \frac{u}{y} + e^{-ux} + f(u)$，其中 $u(x,y)$ 满足 $xe^{-ux} - f'(u) = \frac{1}{y}$，且 $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial y}$，求 $u(x,y)$。
* **破局心智**：**大胆展开并提取公因式，考官给的约束条件必定是那把让未知导数括号严格等于 0 的定点爆破钥匙！**
* **慢动作推演**：
  1. **求 $z_x'$ 并提取 $u_x'$**：  
     $\frac{\partial z}{\partial x} = -ue^{-ux} + \mathbf{\left[\frac{1}{y} - xe^{-ux} + f'(u)\right]} u_x'$；
  2. **定点爆破**：  
     由已知 $xe^{-ux} - f'(u) = \frac{1}{y} \implies \left[\frac{1}{y} - xe^{-ux} + f'(u)\right] = 0$！  
     导数项瞬间蒸发：$\mathbf{\frac{\partial z}{\partial x} = -ue^{-ux}}$；
  3. **同理求 $z_y'$**：  
     $\frac{\partial z}{\partial y} = -\frac{u}{y^2} + \left[\dots\right]u_y' = \mathbf{-\frac{u}{y^2}}$；
  4. **联立方程解 $u$**：  
     $-ue^{-ux} = -\frac{u}{y^2} \implies e^{-ux} = y^{-2} \implies -ux = -2\ln y \implies \mathbf{u(x,y) = \frac{2\ln y}{x}}$。
