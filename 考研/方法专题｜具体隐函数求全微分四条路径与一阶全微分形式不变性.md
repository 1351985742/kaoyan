# 方法专题｜具体隐函数求全微分四条路径与一阶全微分形式不变性

> 适用范围：高等数学 · 多元微分学 · 具体隐函数求全微分、复合全微分、抽象约束对称消项。

---

## 一、 核心心法：什么是“两边求微分”？（形式不变性真相）

传统做法对 $F(x, y, z) = 0$：
1. 把 $y$ 当常数，对 $x$ 求偏导解出 $\frac{\partial z}{\partial x}$；
2. 把 $x$ 当常数，对 $y$ 求偏导解出 $\frac{\partial z}{\partial y}$；
3. 拼装 $\mathrm{d}z = \frac{\partial z}{\partial x}\mathrm{d}x + \frac{\partial z}{\partial y}\mathrm{d}y$。

### 为什么可以直接两边同时求微分？
数学底层证明：
把对 $x$ 求偏导的式子乘以 $\mathrm{d}x$，对 $y$ 求偏导的式子乘以 $\mathrm{d}y$，两式相加：
\[
\left(F_x + F_z \frac{\partial z}{\partial x}\right)\mathrm{d}x + \left(F_y + F_z \frac{\partial z}{\partial y}\right)\mathrm{d}y = 0
\]
\[
F_x\,\mathrm{d}x + F_y\,\mathrm{d}y + F_z \underbrace{\left(\frac{\partial z}{\partial x}\mathrm{d}x + \frac{\partial z}{\partial y}\mathrm{d}y\right)}_{\text{严格定义就是 } \mathrm{d}z} = 0 \implies \mathbf{F_x\,\mathrm{d}x + F_y\,\mathrm{d}y + F_z\,\mathrm{d}z = 0}
\]

> **黄金心智模型（全员独立，一视同仁）**：
> 在对一阶微分操作时，**假定 $x, y, z$ 全是完全独立的自变量**，所有项轮流求微挂标签！
> 等所有 $\mathrm{d}x, \mathrm{d}y, \mathrm{d}z$ 列齐后，在最后一步才把 $\mathrm{d}z$ 当作未知数移项解出！

## 二、 4 大基础运算法则

1. **加减法**：$\mathrm{d}(u \pm v) = \mathrm{d}u \pm \mathrm{d}v$
2. **乘法法则（轮流当主角）**：
   - 二元乘积：$\mathrm{d}(xy) = y\,\mathrm{d}x + x\,\mathrm{d}y$
   - 三元乘积：$\mathrm{d}(xyz) = (yz)\,\mathrm{d}x + (xz)\,\mathrm{d}y + (xy)\,\mathrm{d}z$
3. **除法法则**：$\mathrm{d}\left(\frac{u}{v}\right) = \frac{v\,\mathrm{d}u - u\,\mathrm{d}v}{v^2}$
4. **复合函数与变限积分（剥洋葱）**：
   - $\mathrm{d}(e^{2yz}) = e^{2yz} \cdot 2(z\,\mathrm{d}y + y\,\mathrm{d}z)$
   - $\mathrm{d}\left(\int_a^{u} g(t)\mathrm{d}t\right) = g(u) \cdot \mathbf{\mathrm{d}u}$
   - 抽象复合：$\mathrm{d}[F(u, v)] = F_1'\,\mathbf{\mathrm{d}u} + F_2'\,\mathbf{\mathrm{d}v}$

## 三、 具体隐函数求全微分 4 条路径全景

### 路径一：一个代数隐式方程直接两边求微分解 $\mathrm{d}z$（P1）
* **特征**：纯代数方程 $F(x,y,z)=0$，求在指定点处的 $\mathrm{d}z$。
* **代表题**：26版 660 第 93 题 `[ID 2629]`
  - 方程：$x^2 + y^2 + z^2 = 3$，求 $\left. \mathrm{d}z \right|_{(1,1,1)}$。
  - 动作：两边全员求微：$2x\,\mathrm{d}x + 2y\,\mathrm{d}y + 2z\,\mathrm{d}z = 0$。
  - 代入点 $(1,1,1) \implies 2\mathrm{d}x + 2\mathrm{d}y + 2\mathrm{d}z = 0 \implies \mathbf{\mathrm{d}z = -\mathrm{d}x - \mathrm{d}y}$。

---

### 路径二：积分约束的整体微分（P2）
* **特征**：方程含变限积分 $\int_a^u g(t)\mathrm{d}t$。
* **代表题 1**：26版 1000 强化 14 `[ID 2632]`
  - 方程：$\sin(x-y) + \int_1^z e^{-t^2}\mathrm{d}t = 0$，求 $\left. \mathrm{d}z \right|_{(0,0)}$。
  - 动作：令 $x=y=0 \implies z=1$。两边求微：$\cos(x-y)(\mathrm{d}x - \mathrm{d}y) + e^{-z^2}\mathrm{d}z = 0$。
  - 代入 $(0,0,1) \implies (\mathrm{d}x - \mathrm{d}y) + e^{-1}\mathrm{d}z = 0 \implies \mathbf{\mathrm{d}z = -e\,\mathrm{d}x + e\,\mathrm{d}y}$。
* **代表题 2**：26版 660 第 98 题 `[ID 2631]`
  - 方程：$x + y + z = \int_0^{xyz} e^{-t^2}\mathrm{d}t$，求 $\mathrm{d}z$。
  - 动作：$\mathrm{d}x + \mathrm{d}y + \mathrm{d}z = e^{-(xyz)^2}(yz\mathrm{d}x + xz\mathrm{d}y + xy\mathrm{d}z)$，直接合并移项。

---

### 路径三：隐式变量嵌入外层全微分（P3）
* **特征**：外层定义 $u = f(x, y, z)$，内层 $z(x,y)$ 满足隐式方程，求 $\mathrm{d}u$。
* **代表题**：2002 数三真题 `[ID 2633]`
  - 方程：$u = f(x, y, z)$，内层满足 $xe^x - ye^y = ze^z$。
  - 动作三步走：
    1. 外层立骨架：$\mathrm{d}u = f_1'\mathrm{d}x + f_2'\mathrm{d}y + f_3'\mathbf{\mathrm{d}z}$；
    2. 内层全员求微解 $\mathrm{d}z$：$(x+1)e^x\mathrm{d}x - (y+1)e^y\mathrm{d}y = (z+1)e^z\mathbf{\mathrm{d}z} \implies \mathrm{d}z = \frac{(x+1)e^x}{(z+1)e^z}\mathrm{d}x - \frac{(y+1)e^y}{(z+1)e^z}\mathrm{d}y$；
    3. 塞回骨架合并同类项收工。

---

### 路径四：抽象约束在对称点公因子约分消项（P4）
* **特征**：方程外层抽象 $F(u, v) = 0$，但在特定的对称点（如 $x=y=z=1$）求全微分。
* **代表题**：900 强化 24 `[ID 2636]`
  - 方程：$F\left(xyz, \sqrt{x^2+y^2+z^2}\right) = 0$，$z(1,1)=1$，$F_1' + \frac{1}{\sqrt{3}}F_2' \neq 0$。
  - 动作四步走：
    1. 外层求微立骨架：$F_1'\mathbf{\mathrm{d}u} + F_2'\mathbf{\mathrm{d}v} = 0$；
    2. 展开内层：$\mathrm{d}u = yz\mathrm{d}x+xz\mathrm{d}y+xy\mathrm{d}z$，$\mathrm{d}v = \frac{x\mathrm{d}x+y\mathrm{d}y+z\mathrm{d}z}{\sqrt{x^2+y^2+z^2}}$；
    3. 代入对称点 $(1,1,1)$：$\mathrm{d}u = (\mathrm{d}x+\mathrm{d}y+\mathrm{d}z)$，$\mathrm{d}v = \frac{1}{\sqrt{3}}(\mathrm{d}x+\mathrm{d}y+\mathrm{d}z)$；
    4. 提取公因式约分：$(F_1' + \frac{1}{\sqrt{3}}F_2')(\mathrm{d}x+\mathrm{d}y+\mathrm{d}z) = 0 \implies \mathbf{\mathrm{d}z = -\mathrm{d}x - \mathrm{d}y}$。

## 四、 边界警示

* **一阶全微分**：形式不变性 100% 成立，可大胆全员独立微分。
* **二阶微分 $\mathrm{d}^2 z$**：形式不变性失效！不可无脑当独立变量二次微分。
