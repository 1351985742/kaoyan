# 002｜ID 2213｜径向一阶主部圆锥尖点与系数清零可微门槛复盘

本条为普通题目复盘。原题库路径：高等数学 / 多元微分 / 重极限 / 已知重极限推导其他 / 已知重极限求偏导／判断可微／求全微分；P3 径向一阶项与可微门槛，锚点题。

---

### 原始题目

26 版 1000 题 第十三章 强化 4（题目ID：`2213`，题号：`002`）

若 $f(x,y)$ 在 $(0,0)$ 点的某个邻域内有定义，$f(0,0)=0$，且：
$$\lim_{(x,y)\to(0,0)}\frac{f(x,y)-\sqrt{x^{2}+y^{2}}}{\sqrt{x^{2}+y^{2}}}=a \quad (a \text{ 为常数})$$
(1) 讨论函数 $f(x, y)$ 在 $(0, 0)$ 点的连续性；  
(2) 当 $a$ 为何值时，函数 $f(x,y)$ 在 $(0,0)$ 点可微？并求 $\left.\mathrm{d}f\right|_{(0,0)}$。

---

### 我的真实过程

- **学生原话总结**：
  > “第一道题中，能看到 $\frac{f(x,y) - \sqrt{x^2+y^2}}{\sqrt{x^2+y^2}} = a$，然后 $\frac{f(x,y)}{\sqrt{x^2+y^2}}$ 就等于一个 $a+1$。那么在极限的这个语境下，这样的意义就在于，$f(x,y)$ 在 $(0,0)$ 处可以看成是 $(a+1)\sqrt{x^2+y^2}$，再加上一个高阶无穷小量 $o(\rho)$。前者就是所谓的主部。这样来看的话，对于这个式子求 $(0,0)$ 处的偏导，如果要让偏导存在的话，必须让 $a = -1$。”
- **卡点与认知突破**：
  起初学生困惑于“如何从一个比值极限推断未知函数的导数和微分”，未能主动激活“极限式 $\iff$ 局部展开代数式”的动态视角。在厘清“主部（起决定性作用的低阶项）”与“余项（相对于空间欧氏距离 $\rho$ 的高阶项）”的本质后，深刻理解了：径向圆锥项 $\sqrt{x^2+y^2}$ 在坐标轴上是带刺折线 $|x|$，偏导左右极限相反，必须靠系数清零（$a+1=0$）消灭尖点，才能越过可微门槛！

---

### 状态—路径切片

- **$S_0$（初始状态）**：二元函数在原点的无定形比值极限，分母为欧氏距离 $\rho = \sqrt{x^2+y^2}$。
- **$G$（目标状态）**：判定连续性；求可微时的参数 $a$ 与全微分 $\left.\mathrm{d}f\right|_{(0,0)}$。
- **强信号**：
  1. 分式结构：$\frac{f(x,y) - \rho}{\rho} \to a \implies \frac{f(x,y)}{\rho} \to a+1$；
  2. 几何特征：$\rho = \sqrt{x^2+y^2}$ 是圆锥面（尖点），不可微；
  3. 可微定义核心：增量必须是线性主部 $Ax + By$ 加上 $o(\rho)$。
- **候选工具**：无穷小展开式、轴向先代后求法、全微分定义式。
- **第一动作**：将重极限翻译为局部渐近展开式：
  $$f(x,y) = (a+1)\sqrt{x^2+y^2} + o(\rho)$$
- **中间状态**：
  1. 连续性：当 $\rho \to 0$ 时，$(a+1)\rho + o(\rho) \to 0 = f(0,0)$，无论 $a$ 是多少都连续；
  2. 轴向切片：令 $y=0$，$\rho = |x|$，$f(x,0) = (a+1)|x| + o(|x|)$。
     $$\lim_{x\to 0^+} \frac{f(x,0)}{x} = a+1, \quad \lim_{x\to 0^-} \frac{f(x,0)}{x} = -(a+1)$$
     两单侧极限相等 $\iff a+1 = -(a+1) \iff a = -1$。
- **落点**：当 $a=-1$ 时，径向尖点彻底消除，$f(x,y) = o(\rho) = 0\cdot x + 0\cdot y + o(\rho)$，可微且全微分为 0。

### 诊断校准

- **主要失效层**：**结构信号识别层（未将抽象极限主动转化为局部代数展开式）**。
- **归因**：传统做题习惯停留在“被动计算极限”，缺乏“拿到极限比值，立刻两边去分母，写出函数在邻域内的骨架代数式”的结构化思维。

---

### 出题专家视角

- **命题立意**：精准考察全微分“线性逼近”的几何本质，以及对不可导折线/圆锥尖点的代数控制。
- **陷阱设计**：很多考生只记得“极限存在通常挺平滑”，误以为只要 $a$ 是有限常数就都可导；或者在求偏导时试图用复合求导公式。出题人专门安排 $\sqrt{x^2+y^2}$，就是看考生能不能看破“非线性 1 阶项必然破坏偏导与可微性”的铁律。

### 考场标准解法

1. **解第 (1) 问**：
   由已知条件，记 $\rho = \sqrt{x^2+y^2}$，则存在无穷小量 $\alpha(x,y)$（当 $\rho \to 0$ 时 $\alpha \to 0$），使得：
   $$\frac{f(x,y) - \rho}{\rho} = a + \alpha(x,y)$$
   化简整理得：
   $$f(x,y) = (a+1)\rho + \alpha(x,y)\rho = (a+1)\sqrt{x^2+y^2} + o(\rho)$$
   当 $(x,y) \to (0,0)$ 时，$\rho \to 0$，故：
   $$\lim_{(x,y)\to(0,0)} f(x,y) = \lim_{\rho \to 0} [(a+1)\rho + o(\rho)] = 0 = f(0,0)$$
   因此，对任意常数 $a$，$f(x,y)$ 在 $(0,0)$ 点处恒连续。

2. **解第 (2) 问**：
   函数在 $(0,0)$ 可微的充要条件是存在常数 $A, B$，使得：
   $$f(x,y) - f(0,0) = Ax + By + o(\rho)$$
   代入展开式：$(a+1)\sqrt{x^2+y^2} + o(\rho) = Ax + By + o(\rho)$。
   若 $a+1 \neq 0$，沿 $x$ 轴考察偏导数：
   $$f_x'(0,0) = \lim_{x\to 0} \frac{f(x,0) - 0}{x} = \lim_{x\to 0} \frac{(a+1)|x| + o(|x|)}{x}$$
   当 $x\to 0^+$ 时极限为 $a+1$；当 $x\to 0^-$ 时极限为 $-(a+1)$。
   因为 $a+1 \neq 0$，左右极限不相等，故偏导数 $f_x'(0,0)$ 不存在，函数必不可微。
   若 $a = -1$，则 $a+1 = 0$，$f(x,y) = o(\rho)$。
   此时显然 $f_x'(0,0) = 0$，$f_y'(0,0) = 0$，且：
   $$\lim_{\rho \to 0} \frac{f(x,y) - 0 - (0\cdot x + 0\cdot y)}{\rho} = \lim_{\rho \to 0} \frac{o(\rho)}{\rho} = 0$$
   完全满足可微定义。
   故当且仅当 $a = -1$ 时，$f(x,y)$ 在 $(0,0)$ 点处可微，且 $\left.\mathrm{d}f\right|_{(0,0)} = 0$。

---

### 方法抽象与推广

- **题面信号**：已知在 $(x_0,y_0)$ 处的比值极限 $\lim \frac{f(x,y) - g(x,y)}{\rho^\alpha} = A$。
- **第一动作**：立刻去分母，写出局部渐近展开式：
  $$f(x,y) = g(x,y) + A\rho^\alpha + o(\rho^\alpha)$$
- **性质映射表**：
  - **连续性**：直接令 $\rho \to 0$，看点值是否相等；
  - **线性项 $Ax+By$**：提供偏导数 $f_x'=A, f_y'=B$ 与全微分 $\mathrm{d}f$；
  - **径向项 $\sqrt{x^2+y^2}$**：是圆锥尖点，系数不为 0 时必不可导、必不可微，**必须系数清零**！
  - **二次及更高阶项 $\rho^2$**：阶数比 $\rho$ 高，被 $\rho$ 压制，不破坏可微性。

> **遇到径向模长 $\sqrt{x^2+y^2}$ 别犹豫：带刺折线必不可导，除非系数清零（$a=-1$）！**

### 一句话沉淀

**径向项 $\sqrt{x^2+y^2}$ 是天然不可导圆锥尖点；重极限拆出局部主部后，偏导与可微唯一生路是主部系数清零（$a+1=0$）。**
