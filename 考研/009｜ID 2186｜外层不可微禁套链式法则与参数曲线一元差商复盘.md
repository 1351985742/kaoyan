# 009｜ID 2186｜外层不可微禁套链式法则与参数曲线一元差商复盘

本条为普通题目复盘。原题库路径：高等数学 / 多元微分 / 概念题 / 已知具体多元函数判断其他；P6 沿指定曲线求导，锚点题。

### 原始题目

姜晓千真题同源 150（重点）（题目ID：`2186`，题号：`9`）

设 $f(x,y)=\begin{cases}\dfrac{x^{2}y}{x^{2}+y^{2}},&(x,y)\neq(0,0),\\0,&(x,y)=(0,0),\end{cases}$ $z(t)=f(\mathrm{e}^{2t}-1,\arctan 3t)$，则 $z'(0)=$ ________.

---

### 我的真实过程

- **学生初次作答**：回答为 `0`。
- **真实运算路径**：
  直接套用了多元复合函数求导链式法则：
  $$z'(0) = f_x'(0,0)\cdot x'(0) + f_y'(0,0)\cdot y'(0)$$
  因为先代后求已知 $f_x'(0,0) = 0, f_y'(0,0) = 0$，而 $x'(0) = 2, y'(0) = 3$，故直接得出：
  $$z'(0) = 0 \cdot 2 + 0 \cdot 3 = 0$$
- **致命定理盲区**：
  **链式法则公式成立的严格前提，是外层函数 $f(x,y)$ 在对应点【可微】！**
  而本题中的 $f(x,y) = \frac{x^2 y}{x^2+y^2}$ 在点 $(0,0)$ 处**不可微**（极坐标净阶数 $3 - 2 - 1 = 0 \le 0$）。
  既然外层函数不可微，全微分链式法则的前提条件彻底不成立，直接套公式得出的 `0` 是完全非法的错误结论！

---

### 状态—路径切片

- **$S_0$（初始状态）**：已知外层二元分段函数在原点不可微，求复合曲线 $z(t) = f(x(t), y(t))$ 在 $t=0$ 处的导数 $z'(0)$。
- **$G$（目标状态）**：正确求出一元复合函数的导数值 $\frac{12}{13}$。
- **强信号**：外层函数是经典不可微反例 $x^2 y/(x^2+y^2)$，内层是平滑参数曲线。
- **候选工具**：链式法则（已失效，禁用！）、一元导数定义式（唯一合法武器）。
- **第一动作**：严禁套公式，直接把参数曲线 $x(t) \sim 2t, y(t) \sim 3t$ 代回 $f(x,y)$ 表达式中，写一元差商极限。
- **中间状态**：
  $$z(t) \sim \frac{(2t)^2(3t)}{(2t)^2+(3t)^2} = \frac{12t^3}{13t^2} = \frac{12}{13}t$$
- **落点**：$z'(0) = \lim_{t\to 0}\frac{z(t)-0}{t} = \frac{12}{13}$。

### 考场首选解法（一元导数定义直通车）

1. **审题定性**：
   外层函数 $f(x,y) = \frac{x^2 y}{x^2+y^2}$ 在 $(0,0)$ 处不可微，**链式法则失效，严禁套用**！

2. **回归一元导数定义**：
   由一元函数导数定义：
   $$z'(0) = \lim_{t\to 0}\frac{z(t) - z(0)}{t} = \lim_{t\to 0}\frac{f(\mathrm{e}^{2t}-1, \arctan 3t) - 0}{t}$$

3. **等价无穷小代换与化简**：
   当 $t\to 0$ 时，$\mathrm{e}^{2t}-1 \sim 2t$，$\arctan 3t \sim 3t$。
   代入分子表达式：
   $$z'(0) = \lim_{t\to 0}\frac{\frac{(2t)^2 \cdot 3t}{(2t)^2 + (3t)^2}}{t} = \lim_{t\to 0}\frac{\frac{12t^3}{13t^2}}{t} = \lim_{t\to 0}\frac{\frac{12}{13}t}{t} = \frac{12}{13}$$

---

### 方法抽象与推广：复合函数求导的“可微性门槛定律”

- **题面信号**：已知 $z(t) = f(x(t), y(t))$，求复合曲线导数 $z'(t_0)$。
- **决策决策树**：
  1. **检查外层函数在对应点是否可微**：
     - **若外层可微**：放心套用全微分链式法则 $\frac{\mathrm{d}z}{\mathrm{d}t} = f_x' x' + f_y' y'$。
     - **若外层不可微（或可微性未知/为分段函数）**：**严禁使用链式法则！**
  2. **万能兜底武器（降落伞）**：
     直接将参数曲线代入外层函数，化为一元函数 $z(t)$，用一元差商极限 $\lim_{t\to t_0}\frac{z(t)-z(t_0)}{t-t_0}$ 求解！无论外层可微与否，此法恒成立！
