# 方法专题｜有理式代数变形四武器与积分降解心法

- **专题归属**：考研数学一 · 不定积分与定积分计算底座
- **核心定位**：解决“微积分入口判断正确、换元/分部逻辑顺畅，但最后卡死在纯代数分式化简”的通病。

---

## 诊断：为什么会觉得“有理式变形经验不足”？

在做考研积分时，很多同学以为自己积分公式没背熟，其实真正的瓶颈是：
> **微积分思维是“降维”的（把根号、对数、反三角消掉），但降维之后留下的“有理分式（多项式比多项式）”，需要纯粹的中学代数变形能力来收尾。**

考研中遇到的有理分式，**95% 逃不出以下 4 种固定变形套路**。只要建立这 4 个肌肉反射，任何换元或分部后的落地点都能在 15 秒内拆解完毕。

---

## 武器一：【加一减一 / 分离常数】（专治同次与高次假分式）

### 1. 触发信号
- 分子的最高次数 $\ge$ 分母的最高次数（假分式）。
- 绝不能直接积，必须**先降次为“整式 + 真分式”**。

### 2. 核心手法
不必每次都列复杂的长除法，优先用**分子凑分母（加常数减常数）**：

#### ① 二次同次型（考研最高频）
- **母版**：$\frac{t^2}{t^2 + 1} = \frac{(t^2 + 1) - 1}{t^2 + 1} = 1 - \frac{1}{t^2 + 1}$
  $$\implies \int \frac{t^2}{t^2+1} dt = t - \arctan t + C$$
- **变式**：$\frac{t^2}{t^2 - 1} = \frac{(t^2 - 1) + 1}{t^2 - 1} = 1 + \frac{1}{t^2 - 1}$
  $$\implies \int \frac{t^2}{t^2-1} dt = t + \frac{1}{2}\ln\left|\frac{t-1}{t+1}\right| + C$$

#### ② 高次立方型（加一减一配合立方和差）
- **母版**：$\frac{x^3}{x+1} = \frac{(x^3+1) - 1}{x+1} = \frac{(x+1)(x^2-x+1) - 1}{x+1} = (x^2 - x + 1) - \frac{1}{x+1}$
  $$\implies \int \frac{x^3}{x+1} dx = \frac{1}{3}x^3 - \frac{1}{2}x^2 + x - \ln|x+1| + C$$

## 武器二：【两根之差造分子】（专治二次因式分母裂项）

### 1. 触发信号
- 分母可以因式分解为两个一次因式：$(t-a)(t-b)$。
- 分子为常数 1。

### 2. 核心公式与 5 秒现场还原
$$\frac{1}{(t-a)(t-b)} = \frac{1}{b-a} \cdot \frac{(t-a) - (t-b)}{(t-a)(t-b)} = \frac{1}{b-a} \left( \frac{1}{t-b} - \frac{1}{t-a} \right)$$

#### 考研必背双子星：
1. **平方差型**：
   $$\frac{1}{t^2 - 1} = \frac{1}{(t-1)(t+1)} = \frac{1}{2} \left( \frac{1}{t-1} - \frac{1}{t+1} \right)$$
   $$\int \frac{1}{t^2-1} dt = \frac{1}{2}\ln\left|\frac{t-1}{t+1}\right| + C$$
2. **相邻因式型**：
   $$\frac{1}{t(t+1)} = \frac{(t+1) - t}{t(t+1)} = \frac{1}{t} - \frac{1}{t+1}$$
   $$\int \frac{1}{t(t+1)} dt = \ln\left|\frac{t}{t+1}\right| + C$$

## 武器三：【分子匹配分母导数】（专治一次比二次）

### 1. 触发信号
- 分式形如 $\frac{Ax+B}{ax^2+bx+c}$。
- 分母不可分解（或配方为平方和），无法裂项。

### 2. 核心口诀：分子硬拆成【分母导数 + 修正余项】
令分子 $Ax+B = \frac{A}{2a}(2ax+b) + \left(B - \frac{Ab}{2a}\right)$。

#### 经典实战：
求 $\int \frac{x}{x^2 + 2x + 2} dx$：
1. 分母是 $x^2+2x+2$，它的导数是 **$2x+2$**；
2. 分子只有 $x$，硬凑导数：$x = \mathbf{\frac{1}{2}(2x+2) - 1}$；
3. 拆分为两项：
   $$\frac{x}{x^2+2x+2} = \frac{1}{2} \cdot \frac{2x+2}{x^2+2x+2} - \frac{1}{(x+1)^2 + 1}$$
4. 积分秒出：
   $$= \frac{1}{2}\ln(x^2+2x+2) - \arctan(x+1) + C$$

## 武器四：【遮盖法快速分解】（专治高次重因式部分分式）

### 1. 触发信号
- 分母包含一次因式与重因式，如 $\frac{P(x)}{(x-a)(x-b)}$ 或 $\frac{1}{(t-1)(t+1)^2}$。

### 2. 遮盖法（Heaviside 留数法）核心心法
> **口诀**：**“谁做分母让谁等于 0，用手指头物理遮住它，把根代入露出来的部分！”**

#### ① 标准一次因式示例（3 秒心算）：
求 $\frac{2x + 3}{(x - 1)(x + 2)} = \frac{A}{x - 1} + \frac{B}{x + 2}$：
- **求 $A$**：令 $x - 1 = 0 \implies x = 1$。遮住左边的 $(x-1)$，把 $x=1$ 代入剩余部分：
  $$A = \left. \frac{2x + 3}{x + 2} \right|_{x=1} = \frac{2(1) + 3}{1 + 2} = \mathbf{\frac{5}{3}}$$
- **求 $B$**：令 $x + 2 = 0 \implies x = -2$。遮住左边的 $(x+2)$，把 $x=-2$ 代入剩余部分：
  $$B = \left. \frac{2x + 3}{x - 1} \right|_{x=-2} = \frac{2(-2) + 3}{-2 - 1} = \frac{-1}{-3} = \mathbf{\frac{1}{3}}$$
- **数学本质**：两边同乘 $(x-1)$ 并令 $x=1$，其他待定项自带 $(x-1)$ 因子瞬间归零，只剩下 $A$。

#### ② 含有重因式时的进阶操作：
设待定形式为：
$$\frac{1}{(t-1)(t+1)^2} = \frac{A}{t-1} + \frac{B}{t+1} + \frac{C}{(t+1)^2}$$

- **求 $A$（单根因式）**：遮住左边的 $(t-1)$，代入 $t=1$：
  $$A = \left. \frac{1}{(t+1)^2} \right|_{t=1} = \frac{1}{(1+1)^2} = \mathbf{\frac{1}{4}}$$
- **求 $C$（最高次重因式）**：遮住左边的 $(t+1)^2$，代入 $t=-1$：
  $$C = \left. \frac{1}{t-1} \right|_{t=-1} = \frac{1}{-1-1} = \mathbf{-\frac{1}{2}}$$
- **求 $B$（中间次因式）**：令一个最简单的特殊值（如 $t=0$）代入两边：
  $$\frac{1}{(-1)(1)^2} = \frac{1/4}{-1} + \frac{B}{1} + \frac{-1/2}{(1)^2} \implies -1 = -\frac{1}{4} + B - \frac{1}{2} \implies B = \mathbf{-\frac{1}{4}}$$
- 整个分解在草稿纸上只需 15 秒，彻底告别繁琐的通分联立方程组！
