# 方法专题｜定积分几何意义（四形态凹凸切弦压制与总面积分割法则）

> **统领心法**：定积分比大小的几何精髓在于两件事：
> 1. **曲线弯曲决定高低**：一阶导定方向，二阶导定切弦位置，画出 4 种单调凹凸形态即可 3 秒秒杀大小；
> 2. **区域分割利用守恒**：两块面积比大小，永远优先算整块总面积 $S_{\text{总}}$，用 $S_B = S_{\text{总}} - S_A$ 免去一半复杂积分。

---

## 模块一：一阶导与二阶导组合的【四大经典曲线形态】（肌肉记忆图谱）

```
                     【曲线弯曲形态判定坐标系】
                                 |
         f'' > 0 (下凸/凹函数 ∪)   |   f'' < 0 (上凸/凸函数 ∩)
         切线在下方，弦线在上方     |   切线在上方，弦线在下方
  -------------------------------+-------------------------------
  f' > 0   形态 1：加速上升        |   形态 2：减速上升
  (递增)   典型：y = eˣ, y = x²    |   典型：y = ln x, y = √x
           切线 < 曲线 < 弦线      |   弦线 < 曲线 < 切线
  -------------------------------+-------------------------------
  f' < 0   形态 3：减速下降        |   形态 4：加速下降
  (递减)   典型：y = 1/x, y = e⁻ˣ  |   典型：y = -x² (x>0)
           切线 < 曲线 < 弦线      |   弦线 < 曲线 < 切线
```

### 1. 形态 1：$f'(x) > 0, f''(x) > 0$（增 + 下凸，火箭升空）
- **代表原型**：$y = e^x$ 或 $y = x^2 \,(x > 0)$
- **几何特征**：坡度越来越陡；
- **位置关系**：曲线**塌在弦线下方**，直边梯形比曲边梯形多出一块空间：
  $$\text{矩形（左端高）} < \text{曲边梯形（定积分 } \int_a^b f) < \text{直边梯形（弦线梯形）}$$

### 2. 形态 2：$f'(x) > 0, f''(x) < 0$（增 + 上凸，飞机爬升平缓，#008 原型）
- **代表原型**：$y = \ln x$ 或 $y = \sqrt{x}$
- **几何特征**：越走越平缓，像圆弧顶部；
- **位置关系**：曲线**拱在弦线上方**，曲边梯形反超直边梯形：
  $$\text{矩形 } S_3 = f(a)(b-a) < \text{直边梯形 } S_2 = \frac{f(a)+f(b)}{2}(b-a) < \text{曲边梯形 } S_1 = \int_a^b f(x)dx$$

### 3. 形态 3：$f'(x) < 0, f''(x) > 0$（减 + 下凸，滑梯出底，#007 原型）
- **代表原型**：$y = e^{-x}$ 或 $y = \frac{1}{x} \,(x > 0)$
- **几何特征**：下降得越来越缓，贴近水平渐近线；
- **位置关系**：曲线依然**塌在弦线下方**（只要 $f'' > 0$，弦线永远在上！）：
  $$\text{矩形（右端高） } N = f(1) < \text{曲边梯形 } M = \int_0^1 f(x)dx < \text{直边梯形 } P = \frac{f(0)+f(1)}{2}$$

### 4. 形态 4：$f'(x) < 0, f''(x) < 0$（减 + 上凸，悬崖跳水）
- **代表原型**：$y = -x^2 \,(x > 0)$
- **几何特征**：越降越陡峭；
- **位置关系**：曲线依然**拱在弦线上方**（只要 $f'' < 0$，曲线永远在上！）。

## 模块二：区域分割守恒律（第 6 题 #005 核心心法）

### 考场致命误区：
分别硬算 $S_A$ 和 $S_B$ 的定积分。因为 $S_B$ 通常边界不规则或需要分段，强算极耗费时间且极易算错。

### 破局核心：**“总面积减一块”**
1. **外轮廓总面积极其光滑**：
   抛物线 $y = x(b-x) = bx - x^2$ 与 $x$ 轴围成的抛物拱面积，属于标准闭合区：
   $$S_{\text{总}} = \int_0^b (bx - x^2)dx = \frac{b^3}{6}$$
2. **只算单交点的闭合块 $S_A$**：
   联立交点 $x = \frac{b}{\sqrt{2}}$，上曲线减下曲线：
   $$S_A = \int_0^{\frac{b}{\sqrt{2}}} (bx - \sqrt{2}x^2)dx = \frac{b^3}{4} - \frac{b^3}{6} = \frac{b^3}{12}$$
3. **利用守恒作差得出 $S_B$**：
   $$S_B = S_{\text{总}} - S_A = \frac{b^3}{6} - \frac{b^3}{12} = \frac{b^3}{12}$$
   瞬间秒出 $S_A = S_B$！根本不需要求 $S_B$ 的边界积分！

## 考场一句话速决口诀
- **见凹凸比梯形**：$f''>0$ 曲线塌在弦下（积分小于直边梯形）；$f''<0$ 曲线拱在弦上（积分大于直边梯形）。
- **见分割比面积**：严禁分别双积分，先求总轮廓面积 $S_{\text{总}}$，算出一块作差即定输赢。
