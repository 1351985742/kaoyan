# 方法专题｜定积分比大小（三维控制论、数值基准对消律与微观去分母求导）

> **统领法则**：定积分比大小的本质是“定积分 = 底座（区间） $\times$ 平均高度（被积函数）”。
> 宏观审题过三关（坐标域、运算传递、基准锚定）；微观实操只有唯一正统：**去分母 ➔ 作差设函数 ➔ 求一次导看正负**。

---

## 宏观架构：定积分比大小的“三维控制论”（统领全域）

面对两个定积分 $\int_A \text{式}_1$ 与 $\int_B \text{式}_2$，必须同时过三道检验关卡，任何一道卡壳都会导致无法比较：

```
                    定积分比大小的三道关卡
                              │
     ┌────────────────────────┼────────────────────────┐
     ▼                        ▼                        ▼
【1. 坐标域维度】        【2. 运算传递维度】       【3. 基准锚定维度】
 区间能不能对齐？        增减性能不能保真？       高低有没有参照物？
     │                        │                        │
• 同区间: 天生对齐        • 复合核: 链式乘法       • 同函数: 自带基准
• 对称区间: 换元对齐        保号，单调性不丢         (#016, #021)
• 包含区间: 均值化对齐      (#022-C)               • 异函数: 必须借桥
                          • 乘积核: 导数正负相抵     (如 #003 借 x,
                            单调性毁灭(#022-A)       #022-D 无法借桥)
```

## 核心心法一：运算维的生与死——复合保真 vs 乘积毁灭（解剖 #022 / ID 1143）

### 1. 结构特征
已知 $f'(x) > 0$（严格增），$g'(x) < 0$（严格减），区间为对称的 $[-1, 0]$ 与 $[0, 1]$。

### 2. 选项生死解剖
- **为什么 (C) $\int_{-1}^0 f[g(x)]dx > \int_0^1 f[g(x)]dx$ 绝对成立？（复合保真）**
  令 $F(x) = f[g(x)]$。由链式法则：
  $$F'(x) = f'[g(x)] \cdot g'(x) = (+) \times (-) = (-) < 0$$
  复合函数的求导运算具有**符号封闭性**！导数在全域 $[-1, 1]$ 恒负。
  因此 $F(x)$ 在整个 $[-1, 1]$ 上是**严格全局单调递减**的：
  - 在 $[-1, 0)$ 上，每一点的高度都高于 $F(0)$；
  - 在 $(0, 1]$ 上，每一点的高度都低于 $F(0)$；
  - 中间点 $F(0)$ 是一道铁闸门：
    $$\int_{-1}^0 F(x)dx > F(0) \cdot 1 > \int_0^1 F(x)dx$$

- **为什么 (A) $\int_{-1}^0 f(x)g(x)dx > \int_0^1 f(x)g(x)dx$ 必死？（乘积毁灭）**
  求导：$(fg)' = f'g + fg'$。
  加法破坏了单调性传递：第一项与第二项异号，且函数本身正负未给。
  **秒杀反例**：取 $f(x) = e^x > 0$（增），$g(x) = e^{-x} > 0$（减），则 $f(x)g(x) \equiv 1$。
  $\int_{-1}^0 1 dx = 1 = \int_0^1 1 dx$，大小严格相等，(A) 立即破产。

- **为什么 (D) $\int_{-1}^0 f[f(x)]dx > \int_0^1 g[g(x)]dx$ 必死？（缺乏基准）**
  左边由 $f$ 决定，右边由 $g$ 决定，两函数高度完全没有公共参照系。取 $f(x)=x$ 积分为负，取 $g(x)=-x+100$ 积分为几百，不可比。

## 核心心法二：均值高度律（解剖 #019 / ID 1140 交叉相乘型）

### 1. 结构特征
$0 < a < b < 1$，$f(x)$ 单调减少，$b\int_0^a f(x)dx$ 与 $a\int_0^b f(x)dx$ 比大小。

### 2. 物理与几何本质（除以底座看平均高度）
两边同除以 $ab > 0$：
$$\frac{1}{a}\int_0^a f(x)dx \quad \text{vs} \quad \frac{1}{b}\int_0^b f(x)dx$$
- $\bar{y}_{[0, a]} = \frac{1}{a}\int_0^a f(x)dx$ 是前段 $[0, a]$ 上的**平均高度**；
- $\bar{y}_{[0, b]} = \frac{1}{b}\int_0^b f(x)dx$ 是全段 $[0, b]$ 上的**平均高度**。

### 3. 单调性秒杀
因为 $f(x)$ **单调递减**，后段 $[a, b]$ 上的函数值全部更低，必然把全段平均值“拉低”！
$$\bar{y}_{[0, a]} > \bar{y}_{[0, b]} \iff b\int_0^a f(x)dx > a\int_0^b f(x)dx$$
结论 (B) 严格成立；题目选不正确的，故选 **(A)**！

## 核心心法三：可积数值基准的两大抓手（解剖 P2：#023、#001、#014、#024）

当选项要求与 **$1$** 或某个具体数比大小时，考场只有两大抓手：

### 1. 抓手一：端点极值与区间长度的天平对消律（破 #023、#001）
> **考场第一杀手陷阱**：“被积函数小于 1 $\neq$ 积分小于 1”！必须乘以区间长度！

- **$[0, \frac{\pi}{2}]$ 上比 1（#023 / #025 锚点）**：
  $I_1 = \int_0^{\pi/2} \frac{\sin x}{x} dx$。
  - 粗放放缩 $\frac{\sin x}{x} < 1 \implies I_1 < \frac{\pi}{2} \approx 1.57$（**失灵！无法断定是否小于 1**）。
  - **紧绷放缩（端点极小值）**：$\frac{\sin x}{x}$ 单减，右端点取到全区间最小值 $\frac{\sin(\pi/2)}{\pi/2} = \frac{2}{\pi}$。
    $$I_1 > \int_0^{\frac{\pi}{2}} \frac{2}{\pi} dx = \frac{2}{\pi} \times \frac{\pi}{2} = \mathbf{1} \implies I_1 > 1$$
  - 而 $\frac{x}{\sin x} > 1 \implies I_2 > \frac{\pi}{2} > 1$。
  - 最终次序：$1 < I_1 < I_2$（选 B）。

- **$[0, \frac{\pi}{4}]$ 上比 1（#001 变式）**：
  $I_1 = \int_0^{\pi/4} \frac{\tan x}{x} dx$。
  - **紧绷放缩（端点极大值）**：$\frac{\tan x}{x}$ 单增，右端点取到全区间最大值 $\frac{\tan(\pi/4)}{\pi/4} = \frac{4}{\pi}$。
    $$I_1 < \int_0^{\frac{\pi}{4}} \frac{4}{\pi} dx = \frac{4}{\pi} \times \frac{\pi}{4} = \mathbf{1} \implies I_1 < 1$$
  - 最终次序：$1 > I_1 > I_2$（选 B）。

### 2. 抓手二：把“1”伪装成定积分（破 #014、#024、#020）
- 在 $[0, \frac{\pi}{2}]$ 上，常数 1 天然等于两个最基础的正余弦积分：
  $$\mathbf{1 = \int_0^{\frac{\pi}{2}} \sin x dx = \int_0^{\frac{\pi}{2}} \cos x dx}$$
- 一旦把 1 还原为积分，降维为 P1 点态比较：
  - $\sin(\sin x) < \sin x \implies \int_0^{\pi/2} \sin(\sin x)dx < \int_0^{\pi/2} \sin x dx = 1$；
  - $\cos(\sin x) > \cos x \implies \int_0^{\pi/2} \cos(\sin x)dx > \int_0^{\pi/2} \cos x dx = 1$；
  - 立得 $I_1 < 1 < I_2$（#014 选 A；#024 换元后完全同构选 B）。
- 奇函数消零直接算出数值 $M = \int_{-1/2}^{1/2}(1 + \frac{x}{1+x^2})dx = 1$（#020 选 C）。

## 核心心法四：微观函数比大小的唯一实操正统——去分母作差求导（解剖 #005、#004）

考场切忌对复杂的组合分式去求二阶导看“整体凹凸性”，那会陷进不可计算的泥潭。

**考场唯一无脑、通用的三步实操流水线**：

```
                    比函数大小唯一流水线
                             │
            【第一步：初中移项去分母（卸掉除法负担）】
            要比 sin ax / sin x 与 a ➔ 改比 sin ax 与 a sin x
                             │
            【第二步：作差设辅助函数（标出起点 0）】
            令 F(x) = sin ax - a sin x  (F(0) = 0)
                             │
            【第三步：求一次一阶导数看正负】
            F'(x) = a(cos ax - cos x)
            因 ax < x 且 cos 单减 ➔ cos ax > cos x ➔ F'(x) > 0
            F 从 0 起增 ➔ F(x) > 0 ➔ sin ax / sin x > a
```

全过程草稿纸只需三行，没有任何记忆负担，稳杀一切初等分式比较！
