# 002｜ID 2226｜复合函数二阶偏导先代后求与AC-B²极值判定复盘

本条为普通题目复盘。原题库路径：高等数学 / 多元微分 / 重极限 / 已知重极限推导其他 / 已知重极限求多元复合函数极值；P3 先恢复局部信息再判极值，锚点题。

---

### 原始题目

姜晓千真题同源 150（重点）例 5.10（题目ID：`2226`，题号：`002`）

设 $f(x,y)$ 有二阶连续偏导数，且：
$$\lim_{\substack{x\to1\\ y\to0}}\frac{f(x,y)+x+y-1}{\sqrt{(x-1)^2+y^2}}=0$$
若 $g(x,y)=f(1+xy,\ x^2+y^2)$，
**证明**：$g(x,y)$ 在点 $(0,0)$ 处取得极值，并**判断是极大值还是极小值**。

---

### 我的真实过程

- **学生原话与顿悟**：
  > “又忘记能够直接把 $y=0$ 带入再求偏导了！”
- **卡点与破局**：
  传统求复合函数高阶偏导时，容易习惯性直接在任意点 $(x,y)$ 盲目套用全套链式求导法则，式子会迅速膨胀出外层函数的二阶未知项 $f_{11}'', f_{12}'', f_{22}''$。而题目仅通过重极限给出了外层函数在 $(1,0)$ 处的一阶信息，导致考生误以为“条件不足”而卡死。
  核心破局在于“**先代后求**”切片法则：求点 $(0,0)$ 的纯二阶偏导 $g_{xx}''$ 时，直接固定 $y=0$，将二元函数瞬间降维为一元切片函数 $g(x,0) = f(1, x^2)$，求导过程不仅大幅减熵，而且完全避开了外层二阶未知项，直接锁定 $A = -2, B = -1, C = -2$，带入 $AC - B^2 = 3 > 0, A < 0$ 瞬间完成极大值绝杀！

---

### 状态—路径切片

- **$S_0$（初始状态）**：外层函数 $f$ 给定点 $(1,0)$ 处的重极限；目标为内层复合函数 $g(x,y) = f(1+xy, x^2+y^2)$ 在原点的极值。
- **$G$（目标状态）**：求出 $g$ 在 $(0,0)$ 处的驻点与二阶导数矩阵，判定极值类型。
- **强信号**：
  1. 极限分母为距离 $\rho = \sqrt{(x-1)^2+y^2}$，分子为 $f(x,y) + (x-1) + y$；
  2. 内层结构：$u = 1+xy, v = x^2+y^2$，在 $(0,0)$ 处导数具有强对称性与零值优势。
- **候选工具**：重极限渐近展开（剥皮法）、复合函数链式法则、“先代后求”切片降维、二元极值充分条件（$AC-B^2$）。
- **第一动作**：从重极限提取外层一阶偏导数：
  $$f(x,y) = -(x-1) - y + o(\rho) \implies f(1,0)=0, \quad f_1'(1,0) = -1, \quad f_2'(1,0) = -1$$
- **中间状态**：
  1. 验证驻点：$g_x'(0,0) = 0, g_y'(0,0) = 0$；
  2. “先代后求”算 $A = g_{xx}''(0,0)$：令 $y=0 \implies g(x,0) = f(1, x^2) \implies g_x'(x,0) = 2x f_2'(1, x^2) \implies A = 2f_2'(1,0) = -2$；
  3. 对称性算 $C = g_{yy}''(0,0) = -2$；
  4. 算混合导 $B = g_{xy}''(0,0)$：$g_x'(0,y) = y f_1'(1, y^2) \implies B = f_1'(1,0) = -1$。
- **落点**：$AC - B^2 = (-2)(-2) - (-1)^2 = 3 > 0$，且 $A = -2 < 0$，极大值。

---

### 诊断校准

- **主要失效层**：**做题策略层（未在特定点求导时优先调用“先代后求”降维策略）**。
- **归因**：做题惯性为“先通式求导再代入特殊点”，面对复合函数多元二阶导时算量呈指数级上升；未能建立“求单点纯偏导，直接固定垂直轴为常数”的切片思维。

### 出题专家视角

- **命题立意**：将“重极限提取一阶全微分”与“复合函数二阶极值判别”融为一体，考查考生的综合分析与运算经济性。
- **陷阱设计**：故意不给 $f$ 的二阶偏导数，诱导考生在全量展开中因缺少 $f_{11}'', f_{22}''$ 的数值而自我怀疑，唯有领悟“求点导数可先代后求”的考生能平步青云。

### 考场标准解法

1. **提取外层偏导**：
   由 $\lim_{\substack{x\to1\\ y\to0}}\frac{f(x,y)+(x-1)+y}{\sqrt{(x-1)^2+y^2}}=0$，根据可微定义，有：
   $$f(x,y) - f(1,0) = -(x-1) - y + o(\rho)$$
   故 $f(1,0) = 0$，$f_1'(1,0) = -1$，$f_2'(1,0) = -1$。

2. **验证驻点**：
   $$g_x'(x,y) = y f_1'(1+xy, x^2+y^2) + 2x f_2'(1+xy, x^2+y^2)$$
   $$g_y'(x,y) = x f_1'(1+xy, x^2+y^2) + 2y f_2'(1+xy, x^2+y^2)$$
   代入 $(0,0)$ 得 $g_x'(0,0) = 0, g_y'(0,0) = 0$，故 $(0,0)$ 为驻点。

3. **先代后求二阶偏导**：
   - 令 $y=0$，$g(x,0) = f(1, x^2)$，则 $g_x'(x,0) = 2x f_2'(1, x^2)$。
     $$A = g_{xx}''(0,0) = \left.\frac{\mathrm{d}}{\mathrm{d}x}[2x f_2'(1, x^2)]\right|_{x=0} = 2 f_2'(1,0) = -2$$
   - 同理，由对称性，$C = g_{yy}''(0,0) = 2 f_2'(1,0) = -2$。
   - 对 $g_x'(x,y)$ 令 $x=0$，得 $g_x'(0,y) = y f_1'(1, y^2)$。
     $$B = g_{xy}''(0,0) = \left.\frac{\mathrm{d}}{\mathrm{d}y}[y f_1'(1, y^2)]\right|_{y=0} = f_1'(1,0) = -1$$

4. **极值判定**：
   $$AC - B^2 = (-2)(-2) - (-1)^2 = 3 > 0$$
   且 $A = -2 < 0$。
   故 $g(x,y)$ 在点 $(0,0)$ 处取得极大值，极大值为 $g(0,0) = f(1,0) = 0$。

---

### 方法抽象与推广

- **先代后求黄金律**：
  求多元复合函数在特定点 $(x_0,y_0)$ 处的纯偏导数 $\frac{\partial^2 g}{\partial x^2}(x_0,y_0)$ 时：
  **严禁直接求导函数！第一步必须令 $y = y_0$，将多变量立即收缩为一元函数 $g(x,y_0)$，再对其按一元函数求导两次！**
- 算量对比：直接求导需要展开 6~8 项，先代后求仅需 1 项！
