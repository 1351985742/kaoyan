# 001｜ID 2225｜多元交叉项阶数累加律与二次主部鞍点判非极值复盘

本条为普通题目复盘。原题库路径：高等数学 / 多元微分 / 重极限 / 已知重极限推导其他 / 已知重极限求多元复合函数极值；P2 二次主部变号或退化，锚点题。

---

### 原始题目

2003 数一（题目ID：`2225`，题号：`001`）

已知函数 $f(x,y)$ 在点 $(0,0)$ 的某个邻域内连续，且：
$$\lim_{\substack{x \to 0 \\ y \to 0}} \frac{f(x,y) - xy}{(x^2 + y^2)^2} = 1$$
则（$\quad$）
- **A**. 点 $(0,0)$ 不是 $f(x,y)$ 的极值点.
- **B**. 点 $(0,0)$ 是 $f(x,y)$ 的极大值点.
- **C**. 点 $(0,0)$ 是 $f(x,y)$ 的极小值点.
- **D**. 根据所给条件无法判别点 $(0,0)$ 是否为 $f(x,y)$ 的极值点.

---

### 我的真实过程

- **学生原话与深度思考**：
  > “你这些阶数我看不太懂……我想知道的是，x和y是两个变量，为什么阶数能像单变量一样累加？”
- **卡点与认知破局**：
  学生直击多元微积分的底层命脉——为什么不同变量的乘积项 $x^a y^b$ 可以把指数加起来（如 $xy$ 算 2 阶）？
  通过三大维度的深度解构，彻底完成了认知蜕变：
  1. **几何极坐标尺度（统一绝对标尺）**：点 $(x,y)\to(0,0)$ 逼近原点的真实度量是欧氏距离 $\rho = \sqrt{x^2+y^2}$。因 $x = \rho\cos\theta, y = \rho\sin\theta$，故 $x^a y^b = \rho^{a+b}(\cos^a\theta\sin^b\theta)$！每一个字母都携带一份距离因子 $\rho$，到原点的收缩快慢完全由 $\rho^{a+b}$ 决定，$xy$ 与 $x^2, y^2$ 拥有完全同阶的 2 阶衰减速度！
  2. **物理量纲视角（同类量级）**：若 $x, y$ 单位为米（$\text{m}$），则 $x^2, y^2, xy$ 单位皆为 $\text{m}^2$（面积），属同阶量级；而 $(x^2+y^2)^2$ 为 $\text{m}^4$。微观尺度下面积项（2阶）是绝对主导，高阶项无法改变其正负符号；
  3. **马鞍面鞍点判定**：主部 $xy$ 沿 $y=x$（第一象限）为正，沿 $y=-x$（第四象限）为负，邻域内有正有负，几何形态为双曲抛物面（马鞍面鞍点），断然否定极值！

### 状态—路径切片

- **$S_0$（初始状态）**：重极限给出了差值 $f(x,y)-xy$ 与距离四次方 $\rho^4$ 的渐近关系。
- **$G$（目标状态）**：断定点 $(0,0)$ 的极值性质，锁定选项 A。
- **强信号**：
  1. 分母是 4 次方项 $(x^2+y^2)^2$；分子减去的是 2 次方项 $xy$；
  2. $xy$ 是不定二次型，沿不同对角线正负相悖。
- **候选工具**：渐近局部展开、极坐标尺度分析、特定路径变号检验、特例代入法。
- **第一动作**：去分母写出局部展开式：
  $$f(x,y) = xy + (x^2+y^2)^2 + o(\rho^4)$$
- **中间状态**：确立 2 阶项 $xy$ 为支配主部，检验其在原点邻域内的符号分布：
  - 沿路径 $y = x$：$f(x,x) = x^2 + 4x^4 > 0 = f(0,0)$（比原点高，向上凸）；
  - 沿路径 $y = -x$：$f(x,-x) = -x^2 + 4x^4 = x^2(-1 + 4x^2) < 0 = f(0,0)$（比原点低，向下凹）。
- **落点**：既非最高峰亦非最低谷，必非极值点。选 A。

### 诊断校准

- **主要失效层**：**知识结构层（多元多项式齐次阶数累加的本质原理）**。
- **归因**：传统教学往往直接搬出阶数概念，未解释“以欧氏距离 $\rho$ 为统一标尺”的几何与物理本质，导致面对交叉乘积项 $xy$ 时无法确立其 2 阶支配地位。

- **命题立意**：考查考生对多元渐近展开中“低阶项主导局部符号”的理解，以及利用不定二次型反驳极值存在性的能力。
- **双生题联动设计（001 与 004 的鲜明对照）**：
  - **001 题（本题）**：主部为 $xy$（不定二次型），符号有正有负，**必非极值（选 A）**；
  - **004 题**：主部配成完全平方 $\frac{1}{2}(x+y)^2$（半正定退化），在直线 $y=-x$ 上主部为 0，符号受未知更高阶余项支配，**无法判断（选 D）**！

### 考场标准解法

由极限式 $\lim_{\substack{x\to0\\ y\to0}}\frac{f(x,y)-xy}{(x^2+y^2)^2} = 1$，且分母趋于 0，由连续性可得 $f(0,0) = 0$。  
由无穷小关系可知，在 $(0,0)$ 邻域内：
$$f(x,y) = xy + (x^2+y^2)^2 + o(\rho^4)$$
取特殊逼近路径：
1. 沿直线 $y = x$ 趋于 $(0,0)$：
   $$f(x,x) = x^2 + 4x^4 > 0 = f(0,0) \quad (x \neq 0)$$
2. 沿直线 $y = -x$ 趋于 $(0,0)$：
   $$f(x,-x) = -x^2 + 4x^4 = x^2(4x^2 - 1)$$
   当 $|x| < \frac{1}{2}$ 且 $x \neq 0$ 时，$4x^2 - 1 < 0$，故：
   $$f(x,-x) < 0 = f(0,0)$$
在点 $(0,0)$ 的任意充分小去心邻域内，既存在使 $f(x,y) > f(0,0)$ 的点，又存在使 $f(x,y) < f(0,0)$ 的点。  
因此点 $(0,0)$ 不是 $f(x,y)$ 的极值点。选 **A**。

---

### 方法抽象与推广

- **多元阶数累加律**：项 $x^a y^b$ 在原点微观下的收缩速率由 $\rho^{a+b}$ 唯一决定，其阶数为 $a+b$。
- **考场特例秒杀法**：若不想推导余项，直接取满足条件的简单具体函数：
  $$f(x,y) = xy + (x^2+y^2)^2$$
  带入 $y=x$ 得正，带入 $y=-x$ 得负，15 秒光速锁定选项 A！

### 下次触发规则

> **求极值遇到重极限：**
> 1. 先去分母，挑出**次数最低的多项式（主部）**；
> 2. 若主部为 $xy$ 或未退化不定式，直接沿 $y=\pm x$ 测变号，秒断**非极值**！
> 3. 若主部退化为完全平方 $(x+y)^2$，零方向上由余项定夺，警惕**无法判断**！

### 一句话沉淀

**$xy$ 本质携带距离因子的平方（$\rho^2$），二阶主部沿 $y=\pm x$ 符号相反成鞍点，必非极值。**
