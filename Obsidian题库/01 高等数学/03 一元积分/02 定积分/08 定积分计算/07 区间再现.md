## 001. 姜晓千强化例题（北京竞赛）

- 题目ID：`2001`
- 题号：`1`
- 题源：姜晓千强化例题（北京竞赛）
- 分类：高等数学 / 一元积分 / 定积分 / 定积分计算 / 区间再现
- 选做：否

计算定积分：
(1) $\int_{0}^{\frac{\pi}{2}}\frac{e^{\sin x}}{e^{\sin x}+e^{\cos x}}dx$；
(2) $\int_{0}^{\frac{\pi}{2}}\frac{1}{1+\left(\tan x\right)^{\sqrt{2}}}dx$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 对于(1)，令 $x=\frac{\pi}{2}-t$，则 $dx=-dt$，积分区间变为 $\frac{\pi}{2}$ 到 $0$，即 $\int_{0}^{\frac{\pi}{2}}\frac{e^{\sin x}}{e^{\sin x}+e^{\cos x}}dx = \int_{0}^{\frac{\pi}{2}}\frac{e^{\cos t}}{e^{\cos t}+e^{\sin t}}dt$。将原式记为 $I$，则有 $2I = \int_{0}^{\frac{\pi}{2}}\frac{e^{\sin x}+e^{\cos x}}{e^{\sin x}+e^{\cos x}}dx = \int_{0}^{\frac{\pi}{2}}1 dx = \frac{\pi}{2}$，故 $I = \frac{\pi}{4}$。
> 对于(2)，同理，令 $x=\frac{\pi}{2}-t$，可得 $\int_{0}^{\frac{\pi}{2}}\frac{1}{1+\left(\tan x\right)^{\sqrt{2}}}dx = \int_{0}^{\frac{\pi}{2}}\frac{1}{1+\left(\cot t\right)^{\sqrt{2}}}dt = \int_{0}^{\frac{\pi}{2}}\frac{\left(\tan t\right)^{\sqrt{2}}}{1+\left(\tan t\right)^{\sqrt{2}}}dt$。将原式记为 $J$，则有 $2J = \int_{0}^{\frac{\pi}{2}}\frac{1+\left(\tan t\right)^{\sqrt{2}}}{1+\left(\tan t\right)^{\sqrt{2}}}dt = \int_{0}^{\frac{\pi}{2}}1 dt = \frac{\pi}{2}$，故 $J = \frac{\pi}{4}$。

^q-2001

## 002. 姜晓千强化例题（专业数学）

- 题目ID：`2002`
- 题号：`2`
- 题源：姜晓千强化例题（专业数学）
- 分类：高等数学 / 一元积分 / 定积分 / 定积分计算 / 区间再现
- 选做：否

求 $\int_{0}^{\frac{\pi}{4}}\ln(1+\tan x)dx$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $x=\frac{\pi}{4}-t$，则 $dx=-dt$，积分区间变为 $\frac{\pi}{4}$ 到 $0$，即 $I = \int_{0}^{\frac{\pi}{4}} \ln(1 + \tan(\frac{\pi}{4} - t)) dt = \int_{0}^{\frac{\pi}{4}} \ln(1 + \frac{1 - \tan t}{1 + \tan t}) dt = \int_{0}^{\frac{\pi}{4}} \ln\frac{2}{1 + \tan t} dt = \frac{\pi}{4} \ln 2 - \int_{0}^{\frac{\pi}{4}} \ln(1 + \tan t) dt = \frac{\pi}{4} \ln 2 - I$。因此，$2I = \frac{\pi}{4} \ln 2$，解得 $I = \frac{\pi}{8} \ln 2$。

^q-2002

## 003. 24 版魔法练习册第九章 A 组 6-3

- 题目ID：`2003`
- 题号：`3`
- 题源：24 版魔法练习册第九章 A 组 6-3
- 分类：高等数学 / 一元积分 / 定积分 / 定积分计算 / 区间再现
- 选做：否

计算 $\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\frac{3\mathrm{e}^{x}\sin^{2}x}{1+\mathrm{e}^{x}}\mathrm{d}x$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $x=-t$，则 $dx=-dt$，积分区间变为 $\frac{\pi}{2}$ 到 $-\frac{\pi}{2}$，即 $\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\frac{3\mathrm{e}^{x}\sin^{2}x}{1+\mathrm{e}^{x}}\mathrm{d}x = 3\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\frac{\mathrm{e}^{-t}\sin^{2}t}{1+\mathrm{e}^{-t}}\mathrm{d}t = 3\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\frac{\sin^{2}t}{1+\mathrm{e}^{t}}\mathrm{d}t$。将原式记为 $I$，则有 $2I = 3\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\frac{\mathrm{e}^{x}\sin^{2}x}{1+\mathrm{e}^{x}}dx + 3\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\frac{\sin^{2}x}{1+\mathrm{e}^{x}}dx = 3\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\sin^{2}x dx = 3 \cdot \frac{1}{2} \cdot \pi = \frac{3\pi}{2}$，故 $I = \frac{3\pi}{4}$。

^q-2003

## 004. 24 版魔法练习册第九章 A 组 6-4

- 题目ID：`2004`
- 题号：`4`
- 题源：24 版魔法练习册第九章 A 组 6-4
- 分类：高等数学 / 一元积分 / 定积分 / 定积分计算 / 区间再现
- 选做：否

计算 $\int_{0}^{1}\frac{x}{\mathrm{e}^{x}+\mathrm{e}^{1-x}}\mathrm{d}x$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $1-x=t$，则 $dx=-dt$，积分区间变为 $1$ 到 $0$，即 $\int_{0}^{1}\frac{x}{\mathrm{e}^{x}+\mathrm{e}^{1-x}}\mathrm{d}x = \int_{0}^{1}\frac{1-t}{\mathrm{e}^{1-t}+\mathrm{e}^{t}}\mathrm{d}t = \int_{0}^{1}\frac{1}{\mathrm{e}^{t}+\mathrm{e}^{1-t}}\mathrm{d}t - \int_{0}^{1}\frac{t}{\mathrm{e}^{t}+\mathrm{e}^{1-t}}\mathrm{d}t$。将原式记为 $I$，则有 $2I = \int_{0}^{1}\frac{1}{\mathrm{e}^{t}+\mathrm{e}^{1-t}}\mathrm{d}t$。因此，$I = \frac{1}{2}\int_{0}^{1}\frac{\mathrm{d}t}{\mathrm{e}^{t}+\mathrm{e}^{1-t}} = \frac{1}{2}\int_{0}^{1}\frac{\mathrm{d}(\mathrm{e}^{t})}{\mathrm{e}^{2t}+\mathrm{e}} = \frac{1}{2\sqrt{\mathrm{e}}}\arctan\frac{\mathrm{e}^{t}}{\sqrt{\mathrm{e}}}\bigg|_{0}^{1} = \frac{1}{2\sqrt{\mathrm{e}}}\left(\arctan\sqrt{\mathrm{e}}-\arctan\frac{1}{\sqrt{\mathrm{e}}}\right)$。

^q-2004

## 005. 900 第三章数二 B 类 40

- 题目ID：`2005`
- 题号：`5`
- 题源：900 第三章数二 B 类 40
- 分类：高等数学 / 一元积分 / 定积分 / 定积分计算 / 区间再现
- 选做：否

求 $\int_{0}^{\pi}\frac{x}{2+\sin x}dx$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $t=\pi-x$，则 $dx=-dt$，积分区间变为 $\pi$ 到 $0$，即 $\int_{0}^{\pi}\frac{x}{2+\sin x}dx = \int_{0}^{\pi}\frac{\pi-t}{2+\sin(\pi-t)}dt = \int_{0}^{\pi}\frac{\pi-x}{2+\sin x}dx$。将原式记为 $I$，则有 $2I = \pi\int_{0}^{\pi}\frac{1}{2+\sin x}dx$。因此，$I = \frac{\pi}{2}\int_{0}^{\pi}\frac{1}{2+\sin x}dx = \frac{\pi}{2}\left(\int_{0}^{\frac{\pi}{2}}\frac{1}{2+\sin x}dx + \int_{\frac{\pi}{2}}^{\pi}\frac{1}{2+\sin x}dx\right)$。对第二个积分令 $x=\pi-t$，可得 $\int_{\frac{\pi}{2}}^{\pi}\frac{1}{2+\sin x}dx = \int_{0}^{\frac{\pi}{2}}\frac{1}{2+\sin t}dt$。于是 $I = \pi\int_{0}^{\frac{\pi}{2}}\frac{1}{2+\sin x}dx$。利用万能公式或变形，令 $u=\tan\frac{x}{2}$，则 $\sin x = \frac{2u}{1+u^2}$，$dx = \frac{2}{1+u^2}du$，积分变为 $\pi\int_{0}^{1}\frac{1}{2+\frac{2u}{1+u^2}} \cdot \frac{2}{1+u^2} du = \pi\int_{0}^{1}\frac{1}{u^2+u+1} du = \frac{2\pi}{\sqrt{3}}\arctan\frac{2u+1}{\sqrt{3}}\bigg|_{0}^{1} = \frac{2\pi}{\sqrt{3}}\left(\arctan\sqrt{3}-\arctan\frac{1}{\sqrt{3}}\right) = \frac{2\pi}{\sqrt{3}}\left(\frac{\pi}{3}-\frac{\pi}{6}\right) = \frac{\sqrt{3}\pi^{2}}{9}$。

^q-2005

## 路径 P2｜整周期积分与平移

触发规则：积分区间长为周期或整数倍 → 化到一个周期，检查周期平均值。

## 006. 880 综合解答 27

- 题目ID：`2006`
- 题号：`6`
- 题源：880 综合解答 27
- 分类：高等数学 / 一元积分 / 定积分 / 定积分计算 / 区间再现
- 选做：否

设 $f(x)$ 在 $(-\infty, +\infty)$ 内连续，且满足 $f(x+T) = f(x)$，$T > 0$，$f(-x) = f(x)$。
（I）证明：$\int_{0}^{nT}xf(x)dx=\frac{n^{2}T}{2}\int_{0}^{T}f(x)dx$（$n$为正整数）；
（Ⅱ）计算 $I=\int_{0}^{n\pi}x\left|\cos x\right|\mathrm{d}x$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> （I）证明：令 $x=nT-t$，则 $dx=-dt$，积分区间变为 $nT$ 到 $0$，即 $\int_{0}^{nT}xf(x)dx = \int_{0}^{nT}(nT-t)f(nT-t)dt = nT\int_{0}^{nT}f(t)dt - \int_{0}^{nT}tf(t)dt$。移项得 $2\int_{0}^{nT}xf(x)dx = nT\int_{0}^{nT}f(x)dx$，即 $\int_{0}^{nT}xf(x)dx = \frac{nT}{2}\int_{0}^{nT}f(x)dx$。由于 $f(x+T)=f(x)$，故 $\int_{0}^{nT}f(x)dx = n\int_{0}^{T}f(x)dx$，代入即得 $\int_{0}^{nT}xf(x)dx = \frac{n^{2}T}{2}\int_{0}^{T}f(x)dx$。
> （Ⅱ）计算：取 $f(x)=|\cos x|$，$T=\pi$，则 $f(x+\pi)=|\cos(x+\pi)|=|\cos x|=f(x)$，且 $f(-x)=|\cos(-x)|=|\cos x|=f(x)$，满足条件。由（I）结论，$I = \int_{0}^{n\pi}x|\cos x|dx = \frac{n^{2}\pi}{2}\int_{0}^{\pi}|\cos x|dx = \frac{n^{2}\pi}{2}\left[\int_{0}^{\frac{\pi}{2}}\cos x dx + \int_{\frac{\pi}{2}}^{\pi}(-\cos x) dx\right] = \frac{n^{2}\pi}{2} \cdot 2 = n^{2}\pi$。

^q-2006
