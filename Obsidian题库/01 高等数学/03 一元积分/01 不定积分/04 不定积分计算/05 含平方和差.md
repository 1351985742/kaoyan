## 001. 2003 数二

- 题目ID：`1052`
- 题号：`1`
- 题源：2003 数二
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 含平方和差
- 选做：否

计算不定积分 $\int \frac{xe^{\arctan x}}{(1+x^2)^{3/2}} dx$.

> [!success]- 答案解析
> **答案**
>
> $\frac{(x-1) e^{\arctan x}}{2\sqrt{1+x^2}}+C$
>
> **解析**
>
> 方法一：令 $x = \tan t$，则 $dx = \sec^2 t\, dt$，$\sqrt{1+x^2} = \sec t$，$\arctan x = t$。原式化为 $\int \frac{\tan t \cdot e^t}{\sec^3 t} \cdot \sec^2 t\, dt = \int e^t \sin t\, dt$。利用分部积分 $\int e^t \sin t\, dt = \frac{e^t}{2}(\sin t - \cos t) + C = \frac{(x-1) e^{\arctan x}}{2\sqrt{1+x^2}} + C$。
> 方法二：直接分部积分 $I = \int \frac{x e^{\arctan x}}{\sqrt{1+x^2}}\, d(\arctan x) = \frac{x}{\sqrt{1+x^2}} e^{\arctan x} - \int e^{\arctan x} \frac{dx}{(1+x^2)^{3/2}}$，移项解得 $I = \frac{(x-1) e^{\arctan x}}{2\sqrt{1+x^2}} + C$。

## 002. 1992 数二；880 基础解答 2-3

- 题目ID：`1053`
- 题号：`2`
- 题源：1992 数二；880 基础解答 2-3
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 含平方和差
- 选做：否

$\int\frac{x^3}{\sqrt{1+x^2}}~d x$

> [!success]- 答案解析
> **答案**
>
> $\frac{1}{3}(1+x^2)^{\frac{3}{2}} - \sqrt{1+x^2} + C$
>
> **解析**
>
> 方法一：凑微分 $\int\frac{x^3}{\sqrt{1+x^2}}~d x = \frac{1}{2}\int\frac{x^2}{\sqrt{1+x^2}}~d(x^2+1)$。令 $u=x^2+1$，则 $x^2=u-1$，原式 $= \frac{1}{2}\int\frac{u-1}{\sqrt{u}}\, du = \frac{1}{2}\int (\sqrt{u} - \frac{1}{\sqrt{u}}) du = \frac{1}{3}u^{\frac{3}{2}} - \sqrt{u} + C = \frac{1}{3}(1+x^2)^{\frac{3}{2}} - \sqrt{1+x^2} + C$。
> 方法二：令 $x = \tan t$，则 $dx = \sec^2 t\, dt$，$\sqrt{1+x^2} = \sec t$。原式 $= \int \frac{\tan^3 t}{\sec t} \sec^2 t\, dt = \int \tan^3 t \sec t\, dt = \int (\sec^2 t - 1)\sec t \tan t\, dt = \int (\sec^3 t \tan t - \sec t \tan t) dt$。凑微分即得。

## 003. 24 版0.1w 第九章 A 组 2-6

- 题目ID：`1054`
- 题号：`3`
- 题源：24 版0.1w 第九章 A 组 2-6
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 含平方和差
- 选做：否

$\int\frac{x^3}{\sqrt{1-x^2}}~d x$

> [!success]- 答案解析
> **答案**
>
> $-\frac{1}{3}(1-x^2)^{\frac{3}{2}} + \sqrt{1-x^2} + C$ 或 $\frac{1}{3}(1-x^2)^{\frac{3}{2}} - (1-x^2)^{\frac{1}{2}} + C$
>
> **解析**
>
> 方法一：凑微分 $\int\frac{x^3}{\sqrt{1-x^2}}~d x = -\frac{1}{2}\int\frac{x^2}{\sqrt{1-x^2}}~d(1-x^2)$。令 $u=1-x^2$，则 $x^2=1-u$，原式 $= -\frac{1}{2}\int\frac{1-u}{\sqrt{u}}\, du = -\frac{1}{2}\int (u^{-1/2} - u^{1/2}) du = -(\sqrt{u} - \frac{1}{3}u^{3/2}) + C = -\sqrt{1-x^2} + \frac{1}{3}(1-x^2)^{\frac{3}{2}} + C$。
> 方法二：令 $x = \sin t$，则 $dx = \cos t\, dt$，$\sqrt{1-x^2} = \cos t$。原式 $= \int \frac{\sin^3 t}{\cos t} \cos t\, dt = \int \sin^3 t\, dt = \int (1-\cos^2 t) \sin t\, dt$。令 $u=\cos t$，则 $du = -\sin t\, dt$，原式 $= -\int (1-u^2) du = -u + \frac{1}{3}u^3 + C = -\cos t + \frac{1}{3}\cos^3 t + C$。回代得 $=\frac{1}{3}(1-x^2)^{\frac{3}{2}} - \sqrt{1-x^2} + C$。

^q-1054

## 004. 2001 数二；880 基础解答 2-4

- 题目ID：`1055`
- 题号：`4`
- 题源：2001 数二；880 基础解答 2-4
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 含平方和差
- 选做：否

计算积分 $\int\frac{d x}{\left(2 x^2+1\right)\sqrt{x^2+1}}$

> [!success]- 答案解析
> **答案**
>
> $\frac{1}{\sqrt{2}}\arctan\left(\frac{x}{\sqrt{2}\sqrt{x^2+1}}\right) + C$
>
> **解析**
>
> 令 $x = \tan t$，则 $dx = \sec^2 t\, dt$，$\sqrt{x^2+1} = \sec t$。原式 $= \int \frac{\sec^2 t\, dt}{(2\tan^2 t + 1) \sec t} = \int \frac{\sec t\, dt}{2\tan^2 t + 1}$。因为 $\sec^2 t = 1+\tan^2 t$，可化为 $\int \frac{\cos t\, dt}{2\sin^2 t + \cos^2 t} = \int \frac{\cos t\, dt}{\sin^2 t + 1}$。令 $u = \sin t$，则 $du = \cos t\, dt$，原式 $= \int \frac{du}{u^2+1} = \arctan u + C_1 = \arctan(\sin t) + C_1$。由于 $\sin t = \frac{x}{\sqrt{x^2+1}}$，故结果为 $\arctan\left(\frac{x}{\sqrt{x^2+1}}\right) + C_1$。亦可进一步化为 $\frac{1}{\sqrt{2}}\arctan\left(\frac{x}{\sqrt{2}\sqrt{x^2+1}}\right) + C$。

^q-1055

## 005. 900 第三章数二 A 类 78

- 题目ID：`1056`
- 题号：`5`
- 题源：900 第三章数二 A 类 78
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 含平方和差
- 选做：否

求 $\int\frac{dx}{\left(x^2-3\right)\sqrt{x^2+1}}$

> [!success]- 答案解析
> **答案**
>
> $\frac{1}{4\sqrt{3}}\ln\left|\frac{2x-\sqrt{3(x^2+1)}}{2x+\sqrt{3(x^2+1)}}\right|+C$
>
> **解析**
>
> 令 $x = \tan t$，$dx = \sec^2 t\, dt$，$\sqrt{x^2+1} = \sec t$。原式 $= \int \frac{\sec^2 t\, dt}{(\tan^2 t - 3) \sec t} = \int \frac{\sec t\, dt}{\tan^2 t - 3}$。分子分母同除以 $\cos^2 t$，得 $\int \frac{\cos t\, dt}{\sin^2 t - 3\cos^2 t} = \int \frac{\cos t\, dt}{4\sin^2 t - 3}$。令 $u = \sin t$，$du = \cos t\, dt$，则 $= \int \frac{du}{4u^2 - 3}$。利用部分分式分解 $\frac{1}{4u^2-3} = \frac{1}{4\sqrt{3}}\left(\frac{1}{2u-\sqrt{3}} - \frac{1}{2u+\sqrt{3}}\right)$，积分得 $\frac{1}{4\sqrt{3}}\ln\left|\frac{2u-\sqrt{3}}{2u+\sqrt{3}}\right|+C$。回代 $u = \sin t = \frac{x}{\sqrt{x^2+1}}$，并化简得最终结果。

## 006. 900 第三章数二 A 类 77

- 题目ID：`1057`
- 题号：`6`
- 题源：900 第三章数二 A 类 77
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 含平方和差
- 选做：否

求 $\int\frac{5}{3 x+\sqrt{1-x^2}}~d x$

> [!success]- 答案解析
> **答案**
>
> $\frac{1}{2}\arcsin x+\frac{3}{2}\ln\left|3x+\sqrt{1-x^2}\right|+C$
>
> **解析**
>
> 令 $x = \sin t$，$dx = \cos t\, dt$，$\sqrt{1-x^2} = \cos t$。原式 $\xrightarrow{x=\sin t} \int\frac{5\cos t\, dt}{3\sin t + \cos t}$。被积函数可拆分为 $\frac{5\cos t}{3\sin t+\cos t} = \frac{1}{2} \cdot \frac{(3\sin t+\cos t) + 3(3\cos t - \sin t)}{3\sin t+\cos t} = \frac{1}{2} + \frac{3}{2} \cdot \frac{3\cos t - \sin t}{3\sin t+\cos t}$。而后 $\int \frac{3\cos t - \sin t}{3\sin t+\cos t} dt = \ln|3\sin t + \cos t|$。所以积分结果为 $\frac{1}{2}t + \frac{3}{2}\ln|3\sin t+\cos t| + C$，回代 $t = \arcsin x$，$\cos t = \sqrt{1-x^2}$，即得。

^q-1057

## 007. 900 第三章数二 A 类 27

- 题目ID：`1058`
- 题号：`7`
- 题源：900 第三章数二 A 类 27
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 含平方和差
- 选做：否

$\int\frac{\ln\left(1-x^2\right)}{2 x^2\sqrt{1-x^2}}~d x$

> [!success]- 答案解析
> **答案**
>
> $-\frac{\sqrt{1-x^2}}{2x}\ln(1-x^2)-\arcsin x+C$
>
> **解析**
>
> 令 $x = \sin t$，$dx = \cos t\, dt$，$\sqrt{1-x^2} = \cos t$。原式 $= \int \frac{\ln(\cos^2 t)}{2\sin^2 t \cos t} \cdot \cos t\, dt = \int \frac{2\ln(\cos t)}{2\sin^2 t} dt = \int \frac{\ln(\cos t)}{\sin^2 t} dt$。利用分部积分：$\int \ln(\cos t)\, d(-\cot t) = -\cot t \ln(\cos t) + \int \cot t \cdot (-\sin t/\cos t) dt = -\cot t \ln(\cos t) - \int dt = -\cot t \ln(\cos t) - t + C$。回代 $\cot t = \frac{\sqrt{1-x^2}}{x}$，$\ln(\cos t) = \ln\sqrt{1-x^2} = \frac{1}{2}\ln(1-x^2)$，$t = \arcsin x$，即得结果。

^q-1058
