## 001. 2016 数一、二

- 题目ID：`1059`
- 题号：`1`
- 题源：2016 数一、二
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 求分段函数的不定积分（求分段函数的原函数）
- 选做：否

设 $f(x)=\begin{cases} 2(x-1), & x<1 \\ \ln x, & x \ge 1 \end{cases}$, 则 $f(x)$ 的一个原函数是（ ）。

> [!success]- 答案解析
> **答案**
>
> $F(x)=\begin{cases} (x-1)^2, & x<1 \\ x(\ln x - 1) + 1, & x \ge 1 \end{cases}$
>
> **解析**
>
> 当 $x < 1$ 时，$F(x)=\int 2(x-1) dx = (x-1)^2 + C_1$。当 $x \ge 1$ 时，$F(x)=\int \ln x dx = x(\ln x - 1) + C_2$。由原函数可导（从而连续），有 $\lim_{x \to 1^{-}} F(x) = \lim_{x \to 1^{+}} F(x)$，即 $(1-1)^2 + C_1 = 1\cdot (\ln 1 - 1) + C_2$，得 $C_1 = -1 + C_2$。令 $C_2 = 0$，则 $C_1 = -1$，可得 $F(x)=\begin{cases} (x-1)^2 - 1, & x < 1 \\ x(\ln x - 1), & x \ge 1 \end{cases}$。选项C给的形式与此等价，可验证 $F(x)=\begin{cases} (x-1)^2, & x<1 \\ x(\ln x - 1) + 1, & x \ge 1 \end{cases}$。

## 002. 880 综合填空 1

- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 求分段函数的不定积分（求分段函数的原函数）
- 选做：否

$f(x) = \max\{1, x^2\}$ 在 $(-\infty, +\infty)$ 内满足 $F(0)=1$ 的一个原函数为（ ）。

> [!success]- 答案解析
> **答案**
>
> $F(x)=\begin{cases} \frac{1}{3}x^3 + \frac{1}{3}, & x < -1 \\ x + 1, & -1 \le x \le 1 \\ \frac{1}{3}x^3 + \frac{5}{3}, & x > 1 \end{cases}$
>
> **解析**
>
> 首先写出 $f(x) = \max\{1, x^2\} = \begin{cases} x^2, & x \le -1 \text{ 或 } x \ge 1 \\ 1, & -1 < x < 1 \end{cases}$。分段积分：当 $x < -1$ 时，$F(x) = \int x^2 dx = \frac{1}{3}x^3 + C_1$；当 $-1 \le x \le 1$ 时，$F(x) = \int 1 dx = x + C_2$；当 $x > 1$ 时，$F(x) = \int x^2 dx = \frac{1}{3}x^3 + C_3$。由 $F(0)=1$ 得 $0 + C_2 = 1$，即 $C_2 = 1$。再由 $F(x)$ 在 $x = -1$ 和 $x = 1$ 处连续：$\lim_{x \to -1^{-}} F(x) = \lim_{x \to -1^{+}} F(x)$，得 $-\frac{1}{3} + C_1 = -1 + 1 = 0$，故 $C_1 = \frac{1}{3}$。$\lim_{x \to 1^{-}} F(x) = \lim_{x \to 1^{+}} F(x)$，得 $1 + 1 = 2 = \frac{1}{3} + C_3$，故 $C_3 = \frac{5}{3}$。因此所求原函数为 $F(x)=\begin{cases} \frac{1}{3}x^3 + \frac{1}{3}, & x < -1 \\ x + 1, & -1 \le x \le 1 \\ \frac{1}{3}x^3 + \frac{5}{3}, & x > 1 \end{cases}$。

## 003. 24版 0.1w 第八章 A 组 10

- 选做：否

$\int e^{-|x|}~dx$ = （ ）。

> [!success]- 答案解析
> **答案**
>
> $F(x) = \begin{cases} -e^{-x} + C, & x \ge 0 \\ e^{x} - 2 + C, & x < 0 \end{cases}$
>
> **解析**
>
> $e^{-|x|} = \begin{cases} e^{-x}, & x \ge 0 \\ e^{x}, & x < 0 \end{cases}$。分段积分：$F(x) = \begin{cases} \int e^{-x} dx = -e^{-x} + C_1, & x \ge 0 \\ \int e^{x} dx = e^{x} + C_2, & x < 0 \end{cases}$。由于 $e^{-|x|}$ 连续，其原函数 $F(x)$ 必连续，所以在 $x=0$ 处有 $\lim_{x \to 0^{-}} F(x) = \lim_{x \to 0^{+}} F(x)$，即 $e^{0} + C_2 = 1 + C_2 = -e^{0} + C_1 = -1 + C_1$，解得 $C_1 = C_2 + 2$。令 $C = C_1$，则 $C_2 = C - 2$。代入即得 $F(x) = \begin{cases} -e^{-x} + C, & x \ge 0 \\ e^{x} + (C - 2), & x < 0 \end{cases}$。

## 004. 900 第三章数二 A 类 83

- 题目ID：`1062`
- 题号：`4`
- 题源：900 第三章数二 A 类 83
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 求分段函数的不定积分（求分段函数的原函数）
- 选做：否

求 $\int\max\{x^2, x+2\}~dx$。

> [!success]- 答案解析
> **答案**
>
> $F(x) = \begin{cases} \frac{x^3}{3} + C, & x \le -1 \\ \frac{x^2}{2} + 2x + \frac{7}{6} + C, & -1 < x < 2 \\ \frac{x^3}{3} + \frac{9}{2} + C, & x \ge 2 \end{cases}$
>
> **解析**
>
> 先确定 $\max\{x^2, x+2\}$ 的分段点。令 $f(x)=x^2 - (x+2) = x^2 - x - 2 = (x+1)(x-2)$。当 $x \le -1$ 或 $x \ge 2$ 时，$f(x) \ge 0$，故 $\max = x^2$；当 $-1 < x < 2$ 时，$f(x) < 0$，故 $\max = x+2$。\newline 分段积分：$F(x) = \begin{cases} \int x^2 dx = \frac{x^3}{3} + C_1, & x \le -1 \\ \int (x+2) dx = \frac{x^2}{2} + 2x + C_2, & -1 < x < 2 \\ \int x^2 dx = \frac{x^3}{3} + C_3, & x \ge 2 \end{cases}$。\newline 由 $F(x)$ 在 $x=-1$ 和 $x=2$ 处的连续性建立方程：\newline $\lim_{x \to -1^{-}} F(x) = -\frac{1}{3} + C_1 = \lim_{x \to -1^{+}} F(x) = \frac{1}{2} - 2 + C_2 = -\frac{3}{2} + C_2$，得 $C_1 - C_2 = -\frac{7}{6}$。\newline $\lim_{x \to 2^{-}} F(x) = 2 + 4 + C_2 = 6 + C_2 = \lim_{x \to 2^{+}} F(x) = \frac{8}{3} + C_3$，得 $C_3 - C_2 = 6 - \frac{8}{3} = \frac{10}{3}$。\newline 设 $C = C_1$，解得 $C_2 = C + \frac{7}{6}$，$C_3 = C_2 + \frac{10}{3} = C + \frac{7}{6} + \frac{20}{6} = C + \frac{27}{6} = C + \frac{9}{2}$。代入即得最终结果。

## 005. 25版 660数一二三第 55题

- 题目ID：`1063`
- 题号：`5`
- 题源：25版 660数一二三第 55题
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 求分段函数的不定积分（求分段函数的原函数）
- 选做：否

设 $f(x) = \begin{cases} \sin x + 1, & x > 0 \\ \frac{1}{1+x^2}, & x \le 0 \end{cases}$，则 $f(x)$ 的所有原函数为（ ）。

> [!success]- 答案解析
> **答案**
>
> $$
> F(x) = \begin{cases} -\cos x + x + C + 1, & x > 0 \\ \arctan x + C, & x \le 0 \end{cases}
> $$
>
> **解析**
>
> 这是一个非常典型的分段函数求原函数的问题。在考研数学中，处理这类问题的核心关键点在于：**原函数在整个定义域内必须是连续的**。我们需要利用这一点来确定分段点两边积分常数之间的关系。
>
> 以下是详细的求解步骤：
>
> ### 第一步：分别求各分段区间的原函数
>
> 对于 $x > 0$ 的区间，对 $f(x)$ 进行不定积分：
>
> $$
> F_1(x) = \int (\sin x + 1) \mathrm{d}x = -\cos x + x + C_1
> $$
>
> 对于 $x \le 0$ 的区间，对 $f(x)$ 进行不定积分：
>
> $$
> F_2(x) = \int \frac{1}{1+x^2} \mathrm{d}x = \arctan x + C_2
> $$
>
> 此时，原函数的形式可以初步写为：
>
> $$
> F(x) = \begin{cases} -\cos x + x + C_1, & x > 0 \\ \arctan x + C_2, & x \le 0 \end{cases}
> $$
>
> 这里 $C_1$ 和 $C_2$ 是两个尚未确定关系的常数。
>
> ### 第二步：利用原函数的连续性寻找常数关系
>
> 根据原函数的性质，如果 $F(x)$ 是 $f(x)$ 的原函数（即 $F'(x) = f(x)$），那么 $F(x)$ 在整个实数域上必须是可导的，而**可导必连续**。因此，$F(x)$ 在分段点 $x = 0$ 处必须连续。
>
> 这要求 $F(x)$ 在 $x \to 0^+$ 和 $x \to 0^-$ 时的极限相等，并且等于该点的函数值 $F(0)$：
>
> $$
> \lim_{x \to 0^+} F(x) = \lim_{x \to 0^-} F(x) = F(0)
> $$
>
> 分别计算左右极限：
> * **右极限**：$\lim_{x \to 0^+} F_1(x) = \lim_{x \to 0^+} (-\cos x + x + C_1) = -\cos(0) + 0 + C_1 = -1 + C_1$
> * **左极限及函数值**：$\lim_{x \to 0^-} F_2(x) = \lim_{x \to 0^-} (\arctan x + C_2) = \arctan(0) + C_2 = C_2$
>
> 要使 $F(x)$ 在 $x = 0$ 处连续，必须满足：
>
> $$
> -1 + C_1 = C_2
> $$
>
> 由此可以解出两个常数的关系：
>
> $$
> C_1 = C_2 + 1
> $$
>
> ### 第三步：写出最终的所有原函数
>
> 为了表达式简洁，我们通常用一个统一的常数 $C$ 来表示。
> 令 $C_2 = C$，则 $C_1 = C + 1$。
>
> 将它们代入初步构造的 $F(x)$ 中，即可得到 $f(x)$ 的所有原函数：
>
> $$
> F(x) = \begin{cases} -\cos x + x + C + 1, & x > 0 \\ \arctan x + C, & x \le 0 \end{cases}
> $$
>
> （其中 $C$ 为任意常数）
>
> ---

## 006. 24版 0.1w 第九章 A 组 3

- 题目ID：`1064`
- 题号：`6`
- 题源：24版 0.1w 第九章 A 组 3
- 分类：高等数学 / 一元积分 / 不定积分 / 不定积分计算 / 求分段函数的不定积分（求分段函数的原函数）
- 选做：否

设 $f'(\ln x) = \begin{cases} 1, & 0 < x \le 1 \\ x, & x > 1 \end{cases}$，且 $f(0) = 0$，求 $f(x)$。

> [!success]- 答案解析
> **答案**
>
> $f(x) = \begin{cases} x, & x \le 0 \\ e^x - 1, & x > 0 \end{cases}$
>
> **解析**
>
> 令 $t = \ln x$，则 $x = e^t$。当 $0 < x \le 1$ 时，即 $t \le 0$，有 $f'(t) = 1$，积分得 $f(t) = t + C_1, (t \le 0)$。当 $x > 1$ 时，即 $t > 0$，有 $f'(t) = x = e^t$，积分得 $f(t) = e^t + C_2, (t > 0)$。已知 $f(0) = 0$，且 $f(x)$ 在 $t=0$ (即 $x=0$)处应连续（因 $f'(x)$ 存在）。由于 $f'(t)$ 在 $t=0$ 两侧的极限都是1，所以 $f$ 在 $t=0$ 处可导，进而连续。由 $\lim_{t \to 0^{-}} f(t) = \lim_{t \to 0^{-}} (t + C_1) = C_1 = f(0) = 0$，得 $C_1 = 0$。由 $\lim_{t \to 0^{+}} f(t) = \lim_{t \to 0^{+}} (e^t + C_2) = 1 + C_2$，与 $f(0)=0$ 连续，得 $1 + C_2 = 0$，故 $C_2 = -1$。因此 $f(x) = \begin{cases} x, & x \le 0 \\ e^x - 1, & x > 0 \end{cases}$。
