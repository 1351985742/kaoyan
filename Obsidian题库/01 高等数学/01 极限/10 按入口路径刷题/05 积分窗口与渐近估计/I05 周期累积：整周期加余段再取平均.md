- 题目ID：`3755`
- 题号：`4`
- 题源：880 第三章基础填空 10
- 分类：高等数学 / 极限 / 极限 / 极限计算 / 函数极限 / 含变限积分的极限 / x 趋于∞ / 被积函数为周期函数
- 选做：否

极限 $\lim_{x\to+\infty}\frac{\int_{0}^{x}\left|\sin t\right|\mathrm{d}t}{x}=$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 解 $\left|\sin t\right|$ 以 $\pi$ 为周期，它在每个周期上的积分相等，且 $\int_{0}^{\pi}\left|\sin t\right|\mathrm{d}t=2.$ 故当 $n\pi\leqslant x\leqslant(n+1)\pi$时，有 
>
> $$
> 2n=\int_{0}^{n\pi}\mid\sin t\mid\mathrm{d}t\leqslant\int_{0}^{x}\mid\sin t\mid\mathrm{d}t\leqslant\int_{0}^{(n+1)\pi}\mid\sin t\mid\mathrm{d}t\leqslant2(n+1),
> $$
>
>  从而 
>
> $$
> \frac{2n}{(n+1)\pi}\leqslant\frac{\int_{0}^{x}\mid\sin t\mid\mathrm{d}t}{x}\leqslant\frac{2(n+1)}{n\pi}.
> $$
>
>  令上式 $n \rightarrow \infty$，有 
>
> $$
> \lim_{x\to+\infty}\frac{\int_{0}^{x}\left|\sin t\right|\mathrm{d}t}{x}=\frac{2}{\pi}.
> $$

### 变式题 · q3752 · 原题 001

[原题源：2000 数二](../../02%20%E6%9E%81%E9%99%90/02%20%E6%9E%81%E9%99%90%E8%AE%A1%E7%AE%97/01%20%E5%87%BD%E6%95%B0%E6%9E%81%E9%99%90/10%20%E5%90%AB%E5%8F%98%E9%99%90%E7%A7%AF%E5%88%86%E7%9A%84%E6%9E%81%E9%99%90/02%20x%20%E8%B6%8B%E4%BA%8E%E2%88%9E/01%20%E8%A2%AB%E7%A7%AF%E5%87%BD%E6%95%B0%E4%B8%BA%E5%91%A8%E6%9C%9F%E5%87%BD%E6%95%B0.md#^q-3752)

- 题目ID：`3752`
- 题号：`1`
- 题源：2000 数二
- 分类：高等数学 / 极限 / 极限 / 极限计算 / 函数极限 / 含变限积分的极限 / x 趋于∞ / 被积函数为周期函数
- 选做：否

设函数 $S(x) = \int_{0}^{x} |\cos t| \, dt$。
（1）当 $n$ 为正整数，且 $n\pi \leq x < (n+1)\pi$ 时，证明： $2n \leq S(x) < 2(n+1)$。
（2）求 $\lim_{x\to+\infty}\frac{S(x)}{x}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> （1）由于 $|\cos x| \geq 0$，当 $n\pi \leqslant x < (n+1)\pi$ 时，有 $\int_{0}^{n\pi} |\cos x| dx \leqslant S(x) < \int_{0}^{(n+1)\pi} |\cos x| dx$。因为 $|\cos x|$ 是以 $\pi$ 为周期的函数，所以 $\int_{0}^{n\pi} |\cos x| dx = n\int_{0}^{\pi} |\cos x| dx = 2n$，$\int_{0}^{(n+1)\pi} |\cos x| dx = 2(n+1)$。于是 $2n \leqslant S(x) < 2(n+1)$，得证。
> （2）当 $n\pi \leqslant x < (n+1)\pi$ 时，有 $2n \leqslant S(x) < 2(n+1)$，从而 $\frac{2n}{x} < \frac{S(x)}{x} < \frac{2(n+1)}{x}$。进一步放缩得 $\frac{2n}{(n+1)\pi} < \frac{S(x)}{x} < \frac{2(n+1)}{n\pi}$。两边取极限，$\lim_{n\to\infty}\frac{2n}{(n+1)\pi} = \frac{2}{\pi}$，$\lim_{n\to\infty}\frac{2(n+1)}{n\pi} = \frac{2}{\pi}$。由夹逼准则，$\lim_{x\to+\infty}\frac{S(x)}{x} = \frac{2}{\pi}$。

### 变式题 · q3753 · 原题 002

[原题源：姜晓千真题同源 150](../../02%20%E6%9E%81%E9%99%90/02%20%E6%9E%81%E9%99%90%E8%AE%A1%E7%AE%97/01%20%E5%87%BD%E6%95%B0%E6%9E%81%E9%99%90/10%20%E5%90%AB%E5%8F%98%E9%99%90%E7%A7%AF%E5%88%86%E7%9A%84%E6%9E%81%E9%99%90/02%20x%20%E8%B6%8B%E4%BA%8E%E2%88%9E/01%20%E8%A2%AB%E7%A7%AF%E5%87%BD%E6%95%B0%E4%B8%BA%E5%91%A8%E6%9C%9F%E5%87%BD%E6%95%B0.md#^q-3753)

- 题目ID：`3753`

- 分类：高等数学 / 极限 / 极限 / 极限计算 / 函数极限 / 含变限积分的极限 / x 趋于∞ / 被积函数为周期函数
- 选做：否

（1）设 $f(x)$ 为以 $T$ 为周期的非负可积函数，且 $\int_{0}^{T} f(x) \, dx = a$，证明： $\lim_{x \to +\infty} \frac{1}{x} \int_{0}^{x} f(t) \, dt = \frac{a}{T}$。
（2）设 $f(x)=x-[x]$，其中 $[x]$ 表示不超过 $x$ 的最大整数，求极限 $\lim_{x\to+\infty}\frac{1}{x}\int_{0}^{x}f(t)dt$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> （1）当 $nT \leqslant x < (n+1)T$ 时，有 $\frac{na}{(n+1)T} = \frac{1}{(n+1)T}\int_{0}^{nT}f(x)dx \leqslant \frac{1}{x}\int_{0}^{x}f(t)dt \leqslant \frac{1}{nT}\int_{0}^{(n+1)T}f(x)dx = \frac{(n+1)a}{nT}$。取极限，$\lim_{n\to\infty}\frac{na}{(n+1)T} = \lim_{n\to\infty}\frac{(n+1)a}{nT} = \frac{a}{T}$，由夹逼准则得 $\lim_{x\to+\infty}\frac{1}{x}\int_{0}^{x}f(t)dt = \frac{a}{T}$。
> （2）$f(x)=x-[x]$ 是以 $1$ 为周期的非负可积函数，且 $\int_{0}^{1}f(x)dx = \int_{0}^{1}(x-[x])dx = \int_{0}^{1}xdx = \frac{1}{2}$。由（1）得 $\lim_{x\to+\infty}\frac{1}{x}\int_{0}^{x}f(t)dt = \frac{1}{2}$。

> **答案**

>
> **解析**
>

数列极限 $\lim_{n\to\infty}\frac{\int_{0}^{n\pi}\left|\sin x\right|dx}{(n+1)\pi}=$

#### 选项

A. 0
B. 不存在
C. $\frac{2}{\pi}$
D. $\frac{1}{\pi}$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> $$
> \begin{aligned}&\lim_{n\rightarrow\infty}\frac{\int_{0}^{n\pi}\left|\sin x\right|dx}{(n+1)\pi}\\ &=\lim_{n\rightarrow\infty}\frac{n\int_{0}^{\pi}\left|\sin x\right|dx}{(n+1)\pi}\\&=\frac{\int_{0}^{\pi}\left|\sin x\right|dx}{\pi}\cdot\lim_{n\rightarrow\infty}\frac{n}{(n+1)}\\&=\frac{2}{\pi}\cdot\lim_{n\rightarrow\infty}\frac{n}{(n+1)}=\frac{2}{\pi}.\end{aligned}
> $$
