- 选做：否

证明： $\lim_{n\to\infty}\sqrt[n]{a_{1}^{n}+a_{2}^{n}+\cdots+a_{k}^{n}}=\max\left\{a_{1},a_{2},\cdots,a_{k}\right\}\left(a_{i}>0,i=1,2,\cdots,k\right)$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $\max\{a_{1}, a_{2}, \cdots, a_{k}\} = a$，则 $a=\sqrt[n]{a^{n}}\leqslant\sqrt[n]{a_{1}^{n}+a_{2}^{n}+\cdots+a_{k}^{n}}\leqslant\sqrt[n]{ka^{n}}$。而 $\lim_{n\to\infty}\sqrt[n]{ka^{n}}=\lim_{n\to\infty}a\sqrt[n]{k}=a$，故由夹逼准则，知 $\lim_{n\to\infty}\sqrt[n]{a_{1}^{n}+a_{2}^{n}+\cdots+a_{k}^{n}}=\max\{a_{1},a_{2},\cdots,a_{k}\}$。

## 003. 880 第一章 综合填空 7

- 题目ID：`3906`
- 题号：`3`
- 题源：880 第一章 综合填空 7
- 分类：高等数学 / 极限 / 极限 / 极限计算 / 数列极限 / n 项数列极限计算 / n 次根号下 n 次方的和
- 选做：否

设 $0 < a_{1} < a_{2}$，则 $\lim_{n \to \infty} \left( a_{1}^{-n} + a_{2}^{-n} \right)^{\frac{1}{n}} =$ ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由 $0<a_{1}<a_{2}$，有 $\lim_{n\to\infty}(a_{1}^{-n}+a_{2}^{-n})^{\frac{1}{n}}=\lim_{n\to\infty}a_{1}^{-1}\left[1+\left(\frac{a_{1}}{a_{2}}\right)^{n}\right]^{\frac{1}{n}}=a_{1}^{-1}$。注：这类问题也可利用以下结论：$\lim_{n\to\infty}\sqrt[n]{a_{1}^{n}+a_{2}^{n}+\cdots+a_{k}^{n}}=\max_{1\leq i\leq k}\{a_{i}\}(a_{i}>0,i=1,2,\cdots,k)$。由 $0 < a_{1} < a_{2}$，可知 $\frac{1}{a_{1}} > \frac{1}{a_{2}}$，故 $\lim_{n\to\infty}(a_{1}^{-n}+a_{2}^{-n})^{\frac{1}{n}}=\lim_{n\to\infty}\sqrt[n]{\left(\frac{1}{a_{1}}\right)^{n}+\left(\frac{1}{a_{2}}\right)^{n}}=\frac{1}{a_{1}}$。本题也可利用夹逼准则求解，由 $0<a_{1}<a_{2}$，可知 $\frac{1}{a_{1}}>\frac{1}{a_{2}}$，故 $\frac{1}{a_{1}}=\sqrt[n]{\left(\frac{1}{a_{1}}\right)^{n}}<\sqrt[n]{\left(\frac{1}{a_{1}}\right)^{n}+\left(\frac{1}{a_{2}}\right)^{n}}<\sqrt[n]{2\left(\frac{1}{a_{1}}\right)^{n}}=\frac{\sqrt[n]{2}}{a_{1}}$。由于 $\lim_{n\to\infty}\sqrt[n]{2}=1$，故 $\lim_{n\to\infty}(a_{1}^{-n}+a_{2}^{-n})^{\frac{1}{n}}=\frac{1}{a_{1}}$。
