## 001. 2001 数一

- 题目ID：`2524`
- 题号：`1`
- 题源：2001 数一
- 分类：高等数学 / 多元微分 / 偏导数 / 多元复合函数求偏导 / f(u,v) / f 套 f
- 选做：否

设函数 $z = f(x, y)$ 在点 $(1, 1)$ 处可微，且 $f(1, 1) = 1$， $\left. \frac{\partial f}{\partial x} \right|_{(1,1)} = 2$， $\left. \frac{\partial f}{\partial y} \right|_{(1,1)} = 3$， $\varphi(x) = f[x, f(x, x)]$。求 $\left. \frac{\mathrm{d}}{\mathrm{d}x} \varphi^{3}(x) \right|_{(x=1)}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 第一步：求出 $\frac{\mathrm{d}\varphi(x)}{\mathrm{d}x}\bigg|_{x=1}$。 $\varphi(x)=f(x,\ f(x,\ x))$。 $\frac{\mathrm{d}\varphi(x)}{\mathrm{d}x} = f_{1}^{\prime}(x,\ f(x,\ x)) + f_{2}^{\prime}(x, f(x, x))\left[f_{1}^{\prime}(x, x) + f_{2}^{\prime}(x, x)\right]$。 $\varphi(1) = f(1, f(1, 1)) = f(1, 1) = 1$。所以 $\left.\frac{\mathrm{d}\varphi(x)}{\mathrm{d}x}\right|_{x=1} = f_{1}^{\prime}(1, f(1, 1)) + f_{2}^{\prime}(1, f(1, 1)) [f_{1}^{\prime}(1, 1) + f_{2}^{\prime}(1, 1)] = f_{1}^{\prime}(1, 1) + f_{2}^{\prime}(1, 1) [f_{1}^{\prime}(1, 1) + f_{2}^{\prime}(1, 1)] = 2 + 3 \cdot (2 + 3) = 17$。第二步：求出 $\frac{\mathrm{d}[\varphi(x)]^{3}}{\mathrm{d}x}\bigg|_{x=1}$。 $\frac{\mathrm{d}}{\mathrm{d}x}[\varphi(x)]^{3}=3[\varphi(x)]^{2}\frac{\mathrm{d}\varphi(x)}{\mathrm{d}x}$。代入 x = 1 后，得出： $\left.\frac{\mathrm{d}}{\mathrm{d}x}[\varphi(x)]^{3}\right|_{x=1} =3[\varphi(1)]^{2}\cdot\left.\frac{\mathrm{d}\varphi(x)}{\mathrm{d}x}\right|_{x=1}=3\cdot1\cdot17 =51$。

## 003. 25版660数一二三第92题

- 分类：高等数学 / 多元微分 / 偏导数 / 多元复合函数求偏导 / f(u,v) / f 套 f

> **答案**
>
> 无
>
> **解析**
>
> 对 $z = f(x + y, f(x, y))$ 两端关于 x 求偏导数得 $\frac{\partial z}{\partial x}=f_{1}^{\prime}(x+y,f(x,y))+f_{2}^{\prime}(x+y,f(x,y))\cdot f_{1}^{\prime}(x,y)$。继续对上式两端关于 y 求偏导数得 $\frac{\partial^{2}z}{\partial x\partial y}=f_{11}^{\prime \prime}(x+y,f(x,y))+f_{12}^{\prime \prime}(x+y,f(x,y))f_{2}^{\prime}(x,y)+\left[f_{21}^{\prime \prime}(x+y,f(x,y))+f_{22}^{\prime \prime}(x+y,f(x,y))f_{2}^{\prime}(x,y)\right]f_{1}^{\prime}(x,y)+f_{2}^{\prime}(x+y,f(x,y))f_{12}^{\prime \prime}(x,y)$。由极值的必要条件可知 $f_{1}^{\prime}(1,1)=f_{2}^{\prime}(1,1)=0$。将 $f(1,1)=2,f_{1}^{\prime}(1,1)=f_{2}^{\prime}(1,1)=0$代入上式可得 $\left.\frac{\partial^{2}z}{\partial x\partial y}\right|_{(1,1)}=f_{11}^{\prime\prime}(2,2)+f_{2}^{\prime}(2,2)f_{12}^{\prime\prime}(1,1)$。

B. $2f_{uv}^{\prime\prime}(1,1)$

>

> **解析**
>
