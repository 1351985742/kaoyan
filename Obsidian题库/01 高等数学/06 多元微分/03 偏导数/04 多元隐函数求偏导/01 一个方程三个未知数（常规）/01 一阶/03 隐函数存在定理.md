## 002. 900 第四章数二 A 类 14

- 题目ID：`2578`
- 题号：`2`
- 题源：900 第四章数二 A 类 14
- 分类：高等数学 / 多元微分 / 偏导数 / 多元隐函数求偏导 / 一个方程三个未知数（常规） / 一阶 / 隐函数存在定理
- 选做：否

设有三元方程 $x\arctan x + \frac{\ln x}{\ln y} + ze^{\sin z} = \frac{\pi}{4}$，根据隐函数存在定理，存在点 $(1, e, 0)$ 的一个邻域，在此邻域内该方程（）

### 选项

A. 只能确定一个具有连续偏导数的隐函数 $z = z(x, y)$.
B. 可确定两个具有连续偏导数的隐函数 $y = y(x, z)$ 和 $z = z(x, y)$.
C. 可确定两个具有连续偏导数的隐函数 $x = x(y, z)$ 和 $z = z(x, y)$.
D. 可确定两个具有连续偏导数的隐函数 $x = x(y, z)$ 和 $y = y(x, z)$.

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 记 $F(x,y,z) = x\arctan x + \frac{\ln x}{\ln y} + z\mathrm{e}^{\sin z} - \frac{\pi}{4}$. 点 $(1,e,0)$ 满足方程 $F(x,y,z) = 0$.
> $F_{x}^{\prime}=\frac{x}{1+x^{2}}+\arctan x+\frac{1}{x\ln y},F_{y}^{\prime}=-\frac{\ln x}{(\ln y)^{2}}\cdot\frac{1}{y},F_{z}^{\prime}=\mathrm{e}^{\sin z}+z\cos z\mathrm{e}^{\sin z},F_{x}^{\prime},F_{y}^{\prime},F_{z}^{\prime}$ 在点 $(1,e,0)$ 附近都连续.
> 由于 $F_{x}^{\prime}(1,e,0)=\frac{3}{2}+\frac{\pi}{4},F_{y}^{\prime}(1,e,0)=0,F_{z}^{\prime}(1,e,0)=1$ ，故由隐函数存在定理可知，原方程可确定两个具有连续偏导数的隐函数 $x=x(y,z)$ 和 $z=z(x,y)$ 。应选 C.

## 003. 26版1000第十三章强化47

- 题目ID：`2579`
- 题号：`3`
- 题源：26版1000第十三章强化47
- 分类：高等数学 / 多元微分 / 偏导数 / 多元隐函数求偏导 / 一个方程三个未知数（常规） / 一阶 / 隐函数存在定理
- 选做：否

设函数 $f(x, y)$ 在点 (0,1) 的某邻域内一阶偏导数连续， $f(0,1) = 0$， $f_{y}^{'}(0,1) = 1$，则 $f\left(x, \int_{1}^{x} \ln x \, dx \right) = 0$.

### 选项

A. 在点 (0,1) 附近可确定 $t = t(x)$，且 $t'(0) = -f_{x}^{'}(0,1)$
B. 在点 (0,1) 附近可确定 $t = t(x)$，且 $t'(0) = -1$
C. 在点 (0,e) 附近可确定 $t = t(x)$，且 $t'(0) = -f_{x}^{'}(0,1)$
D. 在点 (0,e) 附近可确定 $t = t(x)$，且 $t'(0) = -1$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 记 $g(x) = \int_{1}^{x} \ln x \, dx$，则 $g(0) = \int_{1}^{0} \ln x \, dx = -\int_{0}^{1} \ln x \, dx = 1$。令 $F(x, t) = f(x, t)$，则方程 $f\left(x, \int_{1}^{x} \ln x \, dx \right) = 0$ 在点 $(0,1)$ 处满足 $F(0,1)=f(0,1)=0$，且 $F_t'(0,1)=f_y'(0,1)=1 \neq 0$。由隐函数存在定理，在点 $(0,1)$ 附近可确定隐函数 $t = t(x)$，满足 $t(0)=1$。对 $F(x, t(x)) = 0$ 两边关于 $x$ 求导得 $f_x' + f_y' \cdot t'(x) = 0$，代入 $x=0, t(0)=1$ 得 $f_x'(0,1) + 1 \cdot t'(0) = 0$，故 $t'(0) = -f_x'(0,1)$。因此选项A正确。
