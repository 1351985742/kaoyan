# 多元微分｜做前总览

**先用 16 道代表题检查主线，再按不会的路径补题。** 这 16 道是入口诊断，不能替代全部考点覆盖；不要求一次做完。做得顺的题可以口述第一步与关键条件后跳过，做不顺的再进入对应文件。

本章共 **54 个题目文件、395 道题目记录**。保留原目录、文件名、题号、题目 ID、块锚点和原答案解析；各文件内按路径聚拢，再排锚点、变式、同构确认。

逐文件标注为：**130 道本页锚点、195 道变式、62 道同构确认、8 道待核**。这里的锚点是本文件的代表题，同一路径可能在不同文件反复出现，不能把 130 当成必须重学的方法数。变式也不默认全部必做。

## 先建立这条主线

概念与重极限 → 偏导／可微与全微分 → 复合、隐式求导 → 梯度与二阶导 → 无约束、条件、闭域最值。偏积分是从导数信息反推函数的一条支路。

| 阶段 | 已有路径如何复用 | 真正增加的动作 |
|---|---|---|
| 重极限 → 可微 | 都要控制任意趋近方向 | 可微先减线性主部，再把余项除以距离 |
| 一阶 → 二阶复合求导 | 继续使用同一依赖关系 | 系数也求导，补内层二阶项 |
| 显式 → 隐式求导 | 仍用乘积和链式法则 | 把未知偏导收集成线性方程；核隐函数分母 |
| 单方程 → 方程组 | 每条约束整体求导 | 明确独立变量，同时解多个未知导数 |
| 偏导 → 全微分 | 使用同一梯度 | 特殊点须先证明可微；不能仅凭偏导存在 |
| 已知函数 → 已知偏导／微分 | 后半段极值判别不变 | 先恢复函数；只问点或类型时有时可直接用梯度 |
| 显式极值 → 隐式极值 | 驻点与二阶型仍是核心 | 候选点同时满足原约束，且核局部分支 |
| 无约束 → 条件极值 | 都先找候选再判断 | 梯度为零改为可行方向上的变化为零 |
| 局部极值 → 闭域最值 | 内部沿用驻点路径 | 增加每段边界、端点和统一比较 |

## 时间有限时的走法

- 每次留出一小段时间收尾。例如 40 分钟：5 分钟看入口，25 分钟做 2–3 道，10 分钟归纳卡点；按计算长度减少题数。
- 锚点独立做对、能说清适用条件：该路径暂过，只选还没见过的关键变式。同构确认后置。
- 锚点会想但算错：只补对应计算；锚点第一步想不到：展开启动卡，重做本题，再选一个近变式。
- 定义域、分段点、隐变量依赖、退化参数、二阶判别为零、闭域边界：这些改变判断步骤的变式优先，单纯换表达式靠后。
- 16 道完成后仍需按考试范围补含参／变限积分求导、嵌套复合、隐函数存在条件、坐标变换及双约束等分支。它们都在下方原路径中，不因精简而删除。
- 题面有疑点的 8 道先跳过。整理完成只意味着导航和分层完成，不等于已经掌握。
