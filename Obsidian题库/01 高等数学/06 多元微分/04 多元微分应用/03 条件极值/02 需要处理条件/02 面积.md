## 001. 1988 数二

- 题目ID：`2748`
- 题号：`1`
- 题源：1988 数二
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 需要处理条件 / 面积
- 选做：否

将长为 $a$ 的铁丝切成两段，一段围成正方形，另一段围成圆形，问这两段铁丝各长为多少时，正方形与圆形的面积之和为最小。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设圆形的周长为 $x$，则正方形的周长为 $a - x$。圆的面积为 $A_1 = \pi \left( \frac{x}{2\pi} \right)^2 = \frac{x^{2}}{4\pi}$，正方形的面积为 $A_2 = \left( \frac{a - x}{4} \right)^2 = \frac{a^{2}-2ax+x^{2}}{16}$。则面积之和 $A = \frac{x^{2}}{4\pi} + \frac{x^{2}}{16} - \frac{a}{8}x + \frac{a^{2}}{16}$。求导得 $A^{\prime} = \frac{x}{2\pi} + \frac{x}{8} - \frac{a}{8} = \frac{x(4+\pi)-a\pi}{8\pi}$。令 $A' = 0$，得 $x = \frac{\pi a}{4 + \pi}$。二阶导 $A^{\prime \prime} = \frac{1}{2\pi} + \frac{1}{8} > 0$，故 $A$ 在 $x = \frac{\pi a}{4 + \pi}$ 处取极小值，且为最小值。此时正方形周长为 $a - x = \frac{4a}{4+\pi}$。综上所述：当圆的周长为 $\frac{\pi a}{4+\pi}$，正方形的周长为 $\frac{4a}{4+\pi}$ 时，两面积之和最小。

## 002. 2018数一二三

- 题目ID：`2749`
- 题号：`2`
- 题源：2018数一二三
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 需要处理条件 / 面积
- 选做：否

将长为 $2m$ 的铁丝分成三段，依次围成圆、正方形与正三角形。三个图形的面积之和是否存在最小值？若存在，求出最小值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设围成圆、正方形、正三角形的铁丝长度分别为 $x$，$y$，$z$，则 $x + y + z = 2$。圆的半径为 $\frac{x}{2\pi}$，面积为 $\frac{x^{2}}{4\pi}$；正方形的边长为 $\frac{y}{4}$，面积为 $\frac{y^{2}}{16}$；正三角形的边长为 $\frac{z}{3}$，面积为 $\frac{\sqrt{3}}{4} \left( \frac{z}{3} \right)^{2} = \frac{\sqrt{3}}{36} z^{2}$。总面积 $S = \frac{x^{2}}{4\pi} + \frac{y^{2}}{16} + \frac{\sqrt{3}}{36} z^{2}$，约束条件为 $x + y + z = 2$。利用拉格朗日乘数法求条件极值，可判断最小值是否存在并求解。

## 003. 26版1000第十三章强化31

- 题目ID：`2750`
- 题号：`3`
- 题源：26版1000第十三章强化31
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 需要处理条件 / 面积
- 选做：否

求曲线 $x^{2}-xy+y^{2}=1(x>0,y>0)$ 上的一点 P，使该点处的切线与 x 轴，y 轴所围面积最小.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 将方程 $x^{2}-xy+y^{2}=1$ 两边对 x 求导得，$2x-y-xy^{\prime}+2y\cdot y^{\prime}=0$，则 $y^{\prime}=\frac{y-2x}{2y-x}$，即切线方程为 $Y-y=\frac{y-2x}{2y-x}(X-x)$。令 Y = 0，则其在 x 轴上的截距为 $X = x - \frac{y(2y - x)}{y - 2x}$；令 X = 0，则其在 y 轴上的截距为 $Y = y - \frac{x(y - 2x)}{2y - x}$。故所求面积为 $S=\frac{1}{2}XY=\frac{2}{(y-2x)(x-2y)}$。由于 $x^{2}-xy+y^{2}=1$，即求 $(y-2x)(x-2y)$ 在约束条件 $x^{2}-xy+y^{2}=1(x>0,y>0)$ 下的最值。构造拉格朗日函数 $F(x,y,\lambda)=(y-2x)(x-2y)+\lambda(x^{2}-xy+y^{2}-1)$，令 $\begin{cases}F_{x}^{\prime}=5y-4x+\lambda(2x-y)=0,\\F_{y}^{\prime}=5x-4y+\lambda(2y-x)=0,\\F_{\lambda}^{\prime}=x^{2}-xy+y^{2}-1=0,\end{cases}$ 解得 x = y = 1，故 $S_{\min} = \frac{2}{|(-1) \cdot (-1)} = 2$，即点 P 坐标为 $(1, 1)$.

## 004. 880 第四章基础解答 9

- 题目ID：`2751`
- 题号：`4`
- 题源：880 第四章基础解答 9
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 需要处理条件 / 面积
- 选做：否

在第一象限内，过曲线 $3x^{2}+2xy+3y^{2}=a$ 上任一点作其切线，切线与两坐标轴所围成的三角形面积的最小值为 $\frac{1}{4}$，求a的值.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设第一象限内，曲线上任一点为 $P(x, y)$。方程 $3x^{2} + 2xy + 3y^{2} = a$ 两边同时对 x 求导，解得 $y' = -\frac{3x + y}{x + 3y}$。则过点 P 的切线方程为 $Y-y=-\frac{3x+y}{x+3y}(X-x)$。切线与两个坐标轴的截距分别为 $x + \frac{x + 3y}{3x + y}$ 和 $y + \frac{3x + y}{x + 3y}$。三角形的面积为 $S=\frac{1}{2}\Big(x+\frac{x+3y}{3x+y}y\Big)\Big(y+\frac{3x+y}{x+3y}x\Big)=\frac{1}{2}\bullet\frac{a^{2}}{a+8xy}$（这里利用了 $3x^{2}+2xy+3y^{2}=a$）。由已知 a > 0，只需求 xy 在条件 $3x^{2} + 2xy + 3y^{2} = a$ 下的最大值。令 $L = xy + \lambda(3x^{2} + 2xy + 3y^{2} - a)$，则 $\begin{cases}L_{x}^{\prime}=y+6\lambda x+2\lambda y=0,\\L_{y}^{\prime}=x+2\lambda x+6\lambda y=0,\\L_{\lambda}^{\prime}=3x^{2}+2xy+3y^{2}-a=0.\end{cases}$ 解上方程组，得 $x = y = \frac{\sqrt{2a}}{4}$，故 $S_{\min}=\frac{1}{2}\bullet\frac{a^{2}}{a+8\bullet\frac{\sqrt{2a}}{4}\bullet\frac{\sqrt{2a}}{4}}=\frac{1}{4}$，解得a=1。

## 005. 姜晓千真题同源 150（重点）

- 题目ID：`2752`
- 题号：`5`
- 题源：姜晓千真题同源 150（重点）
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 需要处理条件 / 面积
- 选做：否

设 a, b 满足 $\int_{a}^{b}|x|\mathrm{d}x=\frac{1}{2}(a\leqslant0\leqslant b)$，求曲线 $y=x^{2}+ax$ 与直线 y=bx 所围区域的面积的最值.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由 $\int_{a}^{b}\left|x\right|\mathrm{d}x=\int_{a}^{0}-x\mathrm{d}x+\int_{0}^{b}x\mathrm{d}x=\frac{1}{2}(a^{2}+b^{2})=\frac{1}{2}$，得 $a^{2}+b^{2}=1\left(a\leqslant0\leqslant b\right)$。曲线 $y=x^{2}+ax$ 与直线 y=bx 所围区域的面积为 $A=\int_{0}^{b-a}\left(bx-x^{2}-ax\right)\mathrm{d}x=\frac{1}{6}\left(b-a\right)^{3}$。方法一：令 $L(a,b,\lambda)=\frac{1}{6}(b-a)^{3}+\lambda(a^{2}+b^{2}-1)$，解 $\begin{cases}L_{a}^{\prime}=-\frac{1}{2}\left(b-a\right)^{2}+2\lambda a=0,\\L_{b}^{\prime}=\frac{1}{2}\left(b-a\right)^{2}+2\lambda b=0,\\L_{\lambda}^{\prime}=a^{2}+b^{2}-1=0,\end{cases}\Leftrightarrow\begin{cases}L_{a}^{\prime}=-1+2\lambda a=0&\begin{array}{c}b\\b\neq0\end{array}\\L_{b}^{\prime}=+2\lambda b=0&L_{\lambda}^{\prime}=a^{2}+b^{2}-1=0\end{cases}$ 消去 $\lambda$，得 $\left\{\begin{aligned}a&=-\frac{\sqrt{2}}{2},\\ b&=\frac{\sqrt{2}}{2}.\end{aligned}\right.$ 又因为 $A\left(-\frac{\sqrt{2}}{2},\frac{\sqrt{2}}{2}\right)=\frac{\sqrt{2}}{3}$， $A(-1,0)=A(0,1)=\frac{1}{6}$，故 A 的最大值为 $\frac{\sqrt{2}}{3}$，最小值为 $\frac{1}{6}$。方法二：令 $a = \cos \theta, b = \sin \theta, \theta \in \left[\frac{\pi}{2}, \pi\right]$，则 $A=\frac{1}{6}\left(\sin\theta-\cos\theta\right)^{3}=\frac{\sqrt{2}}{3}\sin^{3}\left(\theta-\frac{\pi}{4}\right)$，故 A 的最大值为 $\frac{\sqrt{2}}{3}$，最小值为 $\frac{1}{6}$。

^q-2752
