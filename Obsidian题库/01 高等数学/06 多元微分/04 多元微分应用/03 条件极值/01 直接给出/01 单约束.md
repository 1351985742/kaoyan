## 001. 2006 数一二三

- 题目ID：`2731`
- 题号：`1`
- 题源：2006 数一二三
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 直接给出 / 单约束
- 选做：否

设 $f(x,y)$ 与 $\varphi(x,y)$ 均为可微函数，且 $\varphi_{y}^{\prime}(x,y)\neq0$。已知 $\left(x_{0},y_{0}\right)$ 是 $f(x,y)$ 在约束条件 $\varphi(x,y)=0$ 下的一个极值点，下列选项正确的是（）

### 选项

A. 若 $f_{x}^{\prime}(x_{0},y_{0})=0$，则 $f_{y}^{\prime}(x_{0},y_{0})=0$
B. 若 $f_{x}^{\prime}(x_{0},y_{0})=0$，则 $f_{y}^{\prime}(x_{0},y_{0})\neq0$
C. 若 $f_{x}^{\prime}(x_{0},y_{0})\neq0$，则 $f_{y}^{\prime}(x_{0},y_{0})=0$
D. 若 $f_{x}^{\prime}(x_{0},y_{0})\neq0$，则 $f_{y}^{\prime}(x_{0},y_{0})\neq0$

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 根据拉格朗日乘数法，设 $L(x,y,\lambda) = f(x,y) + \lambda \varphi(x,y)$。在极值点 $(x_0, y_0)$ 处，有 $L_x^{\prime} = f_x^{\prime}(x_0, y_0) + \lambda \varphi_x^{\prime}(x_0, y_0) = 0$ 和 $L_y^{\prime} = f_y^{\prime}(x_0, y_0) + \lambda \varphi_y^{\prime}(x_0, y_0) = 0$。已知 $\varphi_y^{\prime}(x_0, y_0) \neq 0$，因此 $\lambda = -\frac{f_y^{\prime}(x_0, y_0)}{\varphi_y^{\prime}(x_0, y_0)}$。代入第一个方程得 $f_x^{\prime}(x_0, y_0) - \frac{f_y^{\prime}(x_0, y_0)}{\varphi_y^{\prime}(x_0, y_0)} \varphi_x^{\prime}(x_0, y_0) = 0$。由此可知，$f_x^{\prime}(x_0, y_0)$ 和 $f_y^{\prime}(x_0, y_0)$ 不能同时为零，除非 $\varphi_x^{\prime}(x_0, y_0) = 0$，但题目未给出此条件。因此，若 $f_x^{\prime}(x_0, y_0) = 0$，则必有 $f_y^{\prime}(x_0, y_0) = 0$（因为 $\varphi_y^{\prime} \neq 0$，且 $\lambda$ 可能非零，但方程要求 $f_y^{\prime}$ 必须为零才能使 $\lambda$ 为零，否则方程不成立）。反之，若 $f_x^{\prime}(x_0, y_0) \neq 0$，则 $f_y^{\prime}(x_0, y_0)$ 不一定为零。但根据选项，正确的关系是：若 $f_x^{\prime}(x_0, y_0) = 0$，则 $f_y^{\prime}(x_0, y_0) = 0$。因此正确答案应为 A。

## 002. 2010 数三

- 题目ID：`2732`
- 题号：`2`
- 题源：2010 数三
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 直接给出 / 单约束
- 选做：否

求函数 $u = xy + 2yz$ 在约束条件 $x^{2} + y^{2} + z^{2} = 10$ 下的最大值和最小值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $L(x,y,z,\lambda)=xy+2yz+\lambda(x^{2}+y^{2}+z^{2}-10)$。求偏导并令为零： 
>
> $$
> \begin{cases} L_x^{\prime} = y + 2\lambda x = 0 \\ L_y^{\prime} = x + 2z + 2\lambda y = 0 \\ L_z^{\prime} = 2y + 2\lambda z = 0 \\ L_{\lambda}^{\prime} = x^{2} + y^{2} + z^{2} - 10 = 0 \end{cases}
> $$
>
>  解方程组得驻点：$A(1,\sqrt{5},2)$，$B(-1,\sqrt{5},-2)$，$C(1,-\sqrt{5},2)$，$D(-1,-\sqrt{5},-2)$，$E(2\sqrt{2},0,-\sqrt{2})$，$F(-2\sqrt{2},0,\sqrt{2})$。计算函数值：$u(A)=u(D)=5\sqrt{5}$，$u(B)=u(C)=-5\sqrt{5}$，$u(E)=u(F)=0$。比较得最大值为 $5\sqrt{5}$，最小值为 $-5\sqrt{5}$。

## 003. 900 第四章数二 A 类 42

- 题目ID：`2733`
- 题号：`3`
- 题源：900 第四章数二 A 类 42
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 直接给出 / 单约束
- 选做：否

求函数 $f(x,y)=3x^{2}+3y^{2}-7xy$ 在约束条件 $x^{2}+y^{2}-xy=9$ 下的最大值和最小值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 建立拉格朗日函数 $L(x,y,\lambda)=3x^{2}+3y^{2}-7xy+\lambda(x^{2}+y^{2}-xy-9)$。求偏导并令为零： 
>
> $$
> \begin{cases} L_x^{\prime} = 6x - 7y + \lambda(2x - y) = 0 \\ L_y^{\prime} = 6y - 7x + \lambda(2y - x) = 0 \\ L_{\lambda}^{\prime} = x^{2} + y^{2} - xy - 9 = 0 \end{cases}
> $$
>
>  (1)式 + (2)式得 $(\lambda - 1)(x + y) = 0$，因此 $\lambda = 1$ 或 $y = -x$。若 $\lambda = 1$，由 $6x - 7y + \lambda(2x - y) = 0$ 得 $x = y$，代入约束得 $x = y = \pm 3$。若 $y = -x$，代入约束得 $x = \pm \sqrt{3}, y = \mp \sqrt{3}$。可能的极值点：$M_{1}(3,3)$，$M_{2}(-3,-3)$，$M_{3}(\sqrt{3},-\sqrt{3})$，$M_{4}(-\sqrt{3},\sqrt{3})$。计算得 $f(3,3)=f(-3,-3)=-9$，$f(\sqrt{3},-\sqrt{3})=f(-\sqrt{3},\sqrt{3})=39$。比较得最大值为 39，最小值为 -9。

## 004. 900 第四章数二 B 类 32

- 题目ID：`2734`
- 题号：`4`
- 题源：900 第四章数二 B 类 32
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 直接给出 / 单约束
- 选做：否

设函数 $f(x,y,z)=\frac{1}{3}x^{3}+y^{2}-2\ln z$，求该函数在条件 $x^{2}+2y^{2}+z^{2}=3$ 下的最小值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 建立拉格朗日函数 $L\left(x,y,z,\lambda\right)=\frac{1}{3}x^{3}+y^{2}-2\ln z+\lambda\left(x^{2}+2y^{2}+z^{2}-3\right)$。求偏导并令为零： 
>
> $$
> \begin{cases} L_{x}^{\prime} = x^{2} + 2\lambda x = x(x+2\lambda) = 0 \\ L_{y}^{\prime} = 2y + 4\lambda y = 2y(1+2\lambda) = 0 \\ L_{z}^{\prime} = -\frac{2}{z} + 2\lambda z = 0 \\ L_{\lambda}^{\prime} = x^{2} + 2y^{2} + z^{2} - 3 = 0 \end{cases}
> $$
>
>  由(3)式得 $\lambda z^{2}=1$，故 $\lambda=\frac{1}{z^{2}}>0$，进而 $1+2\lambda>0$，由(2)式得 $y=0$。由(4)式得 $x^{2}+z^{2}=3$。（i）若 $x = 0$，则 $z^{2} = 3, \lambda = \frac{1}{3}$，得 $f(0,0, \sqrt{3}) = -2 \ln \sqrt{3} = -\ln 3$。（Ⅱ）若 $x \neq 0$，由(1)式得 $x = -2\lambda$，即 $\lambda = -\frac{x}{2}$。代入 $\lambda z^{2} = 1$ 得 $xz^{2} = -2$，结合 $x^{2}+z^{2}=3$ 得 $x(3 - x^{2}) = -2$，整理得 $x^{3} - 3x - 2 = 0$。因式分解为 $(x - 2)(x + 1)^{2} = 0$，根为 $x = 2$ 或 $x = -1$。当 $x = 2$ 时，$\lambda = -1 < 0$，舍去。当 $x = -1$ 时，$y = 0, z = \sqrt{2}$，$f(-1, 0, \sqrt{2}) = -\frac{1}{3} - 2\ln\sqrt{2} = -\frac{1}{3} - \ln 2$。比较 $-\frac{1}{3}-\ln2$ 和 $-\ln3$：计算 $-\frac{1}{3}-\ln2+\ln3 = \ln\frac{3}{2}-\frac{1}{3} = \frac{1}{3}\left[\ln\left(\frac{3}{2}\right)^{3}-1\right] = \frac{1}{3}\left(\ln\frac{27}{8}-1\right)$。由于 $\frac{27}{8}>3>\mathrm{e}$，故 $\ln\frac{27}{8}>1$，因此 $-\frac{1}{3}-\ln2 > -\ln3$。所以最小值为 $-\ln 3$。

## 008. 900 第四章数二 B 类 33

- 题目ID：`2738`
- 题号：`8`
- 题源：900 第四章数二 B 类 33
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 直接给出 / 单约束

某行星上的磁场强度为 $M(x,y,z)=6x-y^{2}+xz+50$ ，行星表面的点 $(x,y,z)$ 满足方程 $x^{2}+y^{2}+z^{2}=20$ 。科学家欲在该行星表面磁场强度最小处架设一台天文望远镜进行探测，求该望远镜的选址坐标 $(x_{0},y_{0},z_{0})$ 。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 目标函数为 $M(x,y,z)=6x-y^{2}+xz+50$，约束条件为 $x^{2}+y^{2}+z^{2}=20$。建立拉格朗日函数 $L(x,y,z,\lambda)=6x-y^{2}+xz+50+\lambda(x^{2}+y^{2}+z^{2}-20)$，求该函数关于各个变量的偏导数，并令其为零。 
>
> $$
> \begin{align*}\begin{aligned}L^{\prime}_x&=6+z+2\lambda x=0,\end{aligned}\end{align*}
> $$
>
>  
>
> $$
> \begin{aligned}\left|L_{y}^{\prime}\right.&=-\left.2y+2\lambda y=0\right.,\end{aligned}
> $$
>
>  
>
> $$
> \left|L_{z}^{\prime}=x+2\lambda z=0,\right.
> $$
>
>  
>
> $$
> \begin{align*}\begin{aligned}L^{\prime}_{\lambda}&=x^{2}+y^{2}+z^{2}-20=0.\end{aligned}\end{align*}
> $$
>
>  (1) 式 $x - (3)$ 式 x 得 $6z + z^{2} - x^{2} = 0$。由(2)式可得 $(2\lambda-2)y=0$。从而 $\lambda=1$ 或 y=0。下面分情况讨论。（i）若 y = 0，则代入（4）式并与 $6z + z^{2} - x^{2} = 0$ 联立可得 $\left\{\begin{aligned}x^{2} + z^{2} &= 20, \\ 6z + z^{2} - x^{2} &= 0.\end{aligned}\right.$ 消去 x 并整理可得 $z^{2} + 3z - 10 = 0$。解得 z = 2 或 z = -5。当 z = 2 时， $x = \pm 4$。但是当 z = -5 时， $z^{2} > 20$，方程组无解。于是，情况（i）有两组解 $\left\{\begin{aligned}x &= 4, \\ y &= 0, \\ z &= 2.\end{aligned}\right.$  $\left\{\begin{aligned}x &= -4, \\ y &= 0, \\ z &= 2.\end{aligned}\right.$ (ii) 若 $\lambda = 1$，则代入(1)式和(3)式，并联立可得 $\left\{\begin{aligned}6 + z + 2x &= 0, \\ x + 2z &= 0.\end{aligned}\right.$ 解得 $\left\{\begin{aligned}x &= -4, \\ z &= 2.\end{aligned}\right.$ 代入(4)式可得 y = 0。此解与情况（i）的一组解重合。因此，由拉格朗日乘数法可得两个可能的极值点： $(4,0,2)$ 和 $(-4,0,2)$。 $M(4,0,2)=24+8+50=82,\quad M(-4,0,2)=-24-8+50=18$。 $M(-4,0,2)<M(4,0,2)$。综上所述，望远镜的选址坐标 $(x_{0},y_{0},z_{0})$ 为 $(-4,0,2)$。

## 007. 26版1000第十三章强化34

- 题目ID：`2737`
- 题号：`7`
- 题源：26版1000第十三章强化34
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 直接给出 / 单约束
- 选做：否

设函数 $f(x,y)$ 具有二阶连续偏导数，且满足 $f(x,0)=x^{2}$， $f_{y}^{\prime}(x,0)=\sqrt{2}x$， $f_{yy}^{\prime\prime}(x,y)=4$，求 $f(x,y)$ 在约束条件 $x^{2}+2y^{2}=4$ 下的最大值与最小值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由 $f_{yy}''(x,y)=4$，两边对y积分，得 $f_{y}^{\prime}(x,y)=4y+\varphi(x)$，上式两边再对 y 积分，得 $f(x,y)=2y^{2}+\varphi(x)y+\psi(x)$。由条件 $f(x,0)=x^{2}$， $f_{y}^{\prime}(x,0)=\sqrt{2}x$，得 $\varphi(x)=\sqrt{2}x$， $\psi(x)=x^{2}$，故 $f(x,y)=2y^{2}+\sqrt{2}xy+x^{2}$。令 $L(x,y,\lambda)=x^{2}+\sqrt{2}xy+2y^{2}+\lambda(x^{2}+2y^{2}-4)$，由 
>
> $$
> \begin{cases}L_{x}^{\prime}=2x+\sqrt{2}y+2\lambda x=0,\\L_{y}^{\prime}=\sqrt{2}x+4y+4\lambda y=0,\\L_{\lambda}^{\prime}=x^{2}+2y^{2}-4=0,\end{cases}
> $$
>
>  解得驻点 $(\sqrt{2},1)$， $(\sqrt{2},-1)$， $(- \sqrt{2},1)$， $(- \sqrt{2},-1)$。由于 $f(\sqrt{2},1)=6, f(\sqrt{2},-1)=2, f(-\sqrt{2},1)=2, f(-\sqrt{2},-1)=6$ ，故 $f(x,y)$ 在约束条件 $x^{2}+2y^{2}=4$ 下的最大值为 $f(\sqrt{2},1)=f(-\sqrt{2},-1)=6$ ，最小值为 $f(\sqrt{2},-1)=f(-\sqrt{2},1)=2$。

## 006. 26版660数一二三第251题

- 题目ID：`2736`
- 题号：`6`
- 题源：26版660数一二三第251题
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 直接给出 / 单约束
- 选做：否

设有三个正数 x, y, z 满足 $x + y + z = a$，其中 a > 0 为常数，又 xyz $\leqslant$ b，则 b 的最小取值是

### 选项

A. $\frac{a^{3}}{21}$
B. $\frac{a^{3}}{18}$
C. $\frac{a^{3}}{9}$
D. $\frac{a^{3}}{27}$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 此问题归结为求函数 $u=xyz\left(x>0,y>0,z>0\right)$ 在条件 $x + y + z = a$ 下的最大值。方法 1 用拉格朗日乘数法。令 $F(x,y,z,\lambda)=xyz+\lambda(x+y+z-a)$ 解方程组 
>
> $$
> \begin{cases}\frac{\partial F}{\partial x}=yz+\lambda=0\\\frac{\partial F}{\partial y}=xz+\lambda=0\\\frac{\partial F}{\partial z}=xy+\lambda=0\\\frac{\partial F}{\partial\lambda}=x+y+z-a=0\end{cases}
> $$
>
>  用 x, y, z 分别乘第一、二、三个方程得 x = y = z，再代入最后一个方程式得 $x=y=z=\frac{a}{3}$。由题意最大值一定存在，因此当 $x = y = z = \frac{a}{3}$ 时 u 取最大值 $\left(\frac{a}{3}\right)^{3} = \frac{a^{3}}{27}$。方法 2 化为简单最值问题。从条件 $x + y + z = a$ 中解得 z = a - x - y，代入 u = xyz 得 $u = xy(a - x - y)$，转化为求函数 $u = xy(a - x - y)$ 在开区域 $D=\left\{(x,y)\mid x>0,y>0,x+y<a\right\}$ 中的最大值。这个最大值一定存在，它在 D 内的驻点达到。令 
>
> $$
> \begin{cases}\frac{\partial u}{\partial x}=y(a-x-y)-xy=0\\\frac{\partial u}{\partial y}=x(a-x-y)-xy=0\end{cases}\Rightarrow\begin{cases}x=y\\2x+y=a\end{cases}
> $$
>
>  解得 $x=\frac{a}{3},y=\frac{a}{3}$ 即 $\left(\frac{a}{3},\frac{a}{3}\right)$ 是唯一驻点，也就是最大值点。因此u的最大值是 $u=\frac{a}{3}\cdot\frac{a}{3}\left(a-\frac{a}{3}-\frac{a}{3}\right)=\frac{a^{3}}{27}$。

## 005. 26版1000第十三章强化30

- 题目ID：`2735`
- 题号：`5`
- 题源：26版1000第十三章强化30
- 分类：高等数学 / 多元微分 / 多元微分应用 / 条件极值 / 直接给出 / 单约束
- 选做：否

求函数 $u = \sqrt{x^{2} + y^{2} + z^{2}}$ 在约束条件 $x + 2y = 1$ 与 $x^{2} + 2y^{2} + z^{2} = 1$ 下的最值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由题意可转化为求 $x^{2}+y^{2}+z^{2}$ 在约束条件下的最值。作拉格朗日函数 
>
> $$
> F(x,y,z,\lambda,\mu)=x^{2}+y^{2}+z^{2}+\lambda(x+2y-1)+\mu(x^{2}+2y^{2}+z^{2}-1),
> $$
>
>  则令 
>
> $$
> \begin{cases}F_{x}^{\prime}=2x+\lambda+2\mu x=0,\\F_{y}^{\prime}=2y+2\lambda+4\mu y=0,\\F_{z}^{\prime}=2z+2\mu z=0,\\F_{\lambda}^{\prime}=x+2y-1=0,\\F_{\mu}^{\prime}=x^{2}+2y^{2}+z^{2}-1=0\end{cases}
> $$
>
>  解方程组得 $(x_{1},y_{1},z_{1})=\left(-\frac{1}{3},\frac{2}{3},0\right),\left(x_{2},y_{2},z_{2}\right)=(1,0,0)$，分别计算目标函数值，有 
>
> $$
> u\left(-\frac{1}{3},\frac{2}{3},0\right)=\frac{\sqrt{5}}{3},u(1,0,0)=1,
> $$
>
>  故所求最大值为1，最小值为 $\frac{\sqrt{5}}{3}$。
