## ID 4436：旧答案C应为D

在原方程的正规区间x≠0上，令 $u=e^xv$，代回得到

$$v''-\frac1xv'=0,\qquad v=C_1+C_2x^2.$$

因此非零解空间为 $u=e^x(C_1+C_2x^2)$。取 $u=e^x$，则 $x^2u$ 仍是解，排除“一定不是”；取 $u=x^2e^x$，则 $x^2u=x^4e^x$ 不是解，排除“一定是”。任意非零 $u$ 乘 $e^x$ 后成为 $e^{2x}$ 乘非零二次多项式，不能再属于原解空间，故选D。旧解析只有推断字母，不能作为依据。

## ID 4703：未给初值，不能套用4702的唯一解

由全微分相容性，只能推出

$$tf''(t)-2f'(t)=2t.$$

在各正规区间t≠0上通解为

$$f(t)=\frac{C_1}{3}t^3-t^2+C_2.$$

原题未给 $f(1)=f'(1)=1$，旧解析中两条件来自相邻4702，不能移植。若f在含0的区间二阶连续，可用该正则性讨论跨0连接；一旦要跨不同区域，还需核对常数是否应一致。

导数为 $f'(t)=t(C_1t-2)$。若0在定义域内，则0处二阶导数为−2，是极大值点，极大值为C₂；若C₁≠0且2/C₁在定义域内，则该点为极小值点，极小值为 $C_2-4/(3C_1^2)$。C₁=0时只有定义域允许的0处极大值。不能在未给定义域时擅删0，也不能声称唯一的极值数值。

## ID 4702：t的范围影响极值结论

给定初值得到 $f(t)=t^3-t^2+1$，但t=y/x；题面只写“x>0的平面区域”，并未明确y>0。若区域使t取全实数，则0处极大值1与2/3处极小值23/27都应计入；若只允许t>0才排除0。原解析将0直接判为不在定义域缺少题面依据。训练按实际区域注明两种范围，不能照抄排除。

## ID 4528：选项残缺，使用完整同题4529

4528只保留了A选项，解析为空。差解为4x（差的正负不影响p），在x≠0有 $p=-1/x$，代回得到 $q=x-1/x$，故 $p+q=(x^2-2)/x$。题干可作求值训练；不根据残缺选项判字母。完整同题4529可用于选项训练，两条只算一份迁移证据。

## ID 4571：先固定量词

原题“解在全实轴有界”按通常意图理解为“所有解有界”，才对应原选C。若只是存在一个解，零解对任意a、b都成立，无法推出参数条件。全实轴所有解有界要求模态不含增长指数，也不含重零根的x项，得到a=0、b>0；不能遗漏量词后机械记忆。

## ID 4421：两个解须给出非零差方向

表达 $y_1+C(y_1-y_2)$ 覆盖一阶非齐次通解，前提是两解不同。题面“有两个的解”转写不完整；练习按不同特解的常规意图处理，同时保留此条件。若两解相同，该表达式只有一个特解。
