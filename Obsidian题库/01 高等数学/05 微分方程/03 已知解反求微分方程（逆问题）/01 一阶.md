## 001. 1995 数二

- 题目ID：`4524`
- 题号：`1`
- 题源：1995 数二
- 分类：高等数学 / 微分方程 / 已知解反求微分方程（逆问题） / 一阶
- 选做：否

设 $y = e^x$ 是微分方程 $xy' + p(x)y = x$ 的一个解，求此微分方程满足条件 $y|_{x=\ln 2} = 0$ 的特解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 第一步：得到非齐次线性微分方程。将 $y = e^{x}$ 代入 $xy' + p(x)y = x$ 可得， $xe^{x}+p(x)e^{x}=x$，解得 $p(x)=\frac{x-xe^{x}}{e^{x}}=x(e^{-x}-1)$. 于是原方程为 $xy' + x(e^{-x} - 1)y = x$，方程两端同时除以 x 可得， $y^{\prime}+(e^{-x}-1)y=1.$ 第二步：求解通解。运用一阶非齐次线性微分方程的公式可得，通解为 $y = e^{x}+Ce^{x+e^{-x}}$，其中 C 为待定常数. 第三步：求特解。将 $x = \ln 2$，y = 0 代入 $y = e^{x} + C e^{x + e^{-x}}$ 可得 $0 = e^{\ln 2} + C e^{\ln 2 + e^{-\ln 2}} = 2 + C e^{\ln 2 + \frac{1}{2}}$，解得 $C = -e^{-\frac{1}{2}}$. 因此，所求特解为 $y = e^{x} - e^{x + e^{-x} - \frac{1}{2}}$.

## 003. 2003 数二

- 题目ID：`4526`
- 题号：`3`
- 题源：2003 数二
- 分类：高等数学 / 微分方程 / 已知解反求微分方程（逆问题） / 一阶
- 选做：否

已知 $\frac{x}{\ln x}$是微分方程 $y'=\frac{y}{x}+\varphi\left(\frac{x}{y}\right)$的解，则 $\varphi\left(\frac{x}{y}\right)$的表达式为（）.

### 选项

A. $-\frac{y^{2}}{x^{2}}$
B. $\frac{y^{2}}{x^{2}}$
C. $-\frac{x^{2}}{y^{2}}$
D. $\frac{x^{2}}{y^{2}}$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 由 $y = \frac{x}{\ln x}$ 得 $y' = \frac{\ln x - 1}{\ln^{2} x}$，代入微分方程， $\frac{y}{x}=\frac{\frac{x}{\ln x}}{x}=\frac{1}{\ln x}$，有 $\frac{\ln x-1}{\ln^{2}x}=\frac{1}{\ln x}+\varphi\left(\frac{x}{y}\right)$，于是得 $\varphi\left(\frac{x}{y}\right)=\frac{\ln x-1}{\ln^{2}x}-\frac{1}{\ln x} = -\frac{1}{\ln^{2}x} = -\frac{y^{2}}{x^{2}}$. 故选(A).

^q-4526

## 002. 880 第六章基础选择 2

- 题目ID：`4525`
- 题号：`2`
- 题源：880 第六章基础选择 2
- 分类：高等数学 / 微分方程 / 已知解反求微分方程（逆问题） / 一阶
- 选做：否

设 $y' + P(x)y = 0$ 的一个特解为 $y = \cos 2x$，则该方程满足 $y(0) = 2$ 的特解为（）.

### 选项

A. $2\cos x$
B. $2\cos2x$
C. $\cos 2x$
D. $\cos 2x + 1$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 解 将 $y = \cos 2x$ 代入 $y' + P(x)y = 0$，解得 $P(x) = 2\tan 2x$，故 $y' + (2\tan 2x)y = 0$. 解此一阶线性齐次微分方程，得 $y = C e^{-\int P(x)dx} = C e^{-\int 2\tan 2x dx} = C \cos 2x.$ 由 $y(0)=2$ , 得 C=2 , 故 $y=2\cos2x$ ，选项 B 正确.

> [!success]- 答案解析

>
> **解析**
>
> 设原方程为 $y^{\prime}+p(x)y=q(x)$，则其对应的一阶齐次线性微分方程为 $y^{\prime}+p(x)y=0$。记 $y_{1}=x^{2}-e^{x}$，$y_{2}=x^{2}$，则 $y_{2}-y_{1}=e^{x}$是原方程对应的一阶齐次线性微分方程的解。将 $y=e^{x}$代入，可得 $p(x)=-1$。再将 $y = x^{2}$ 代入 $y' - y = q(x)$，得 $q(x) = 2x - x^{2}$。因此，原方程为 $y' - y = 2x - x^{2}$。

若 $y=\left(1+x^{2}\right)^{2}-\sqrt{1+x^{2}},y=\left(1+x^{2}\right)^{2}+\sqrt{1+x^{2}}$ 是微分方程 $y^{\prime}+p(x)y=q(x)$ 的两个解，则 $q(x)=$ （ ）

### 选项

A. $3x(1+x^{2})$
B. $-3x(1+x^{2})$
C. $\frac{x}{1+x^{2}}$
D. $-\frac{x}{1+x^{2}}$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 解 令 $y_{1}=(1+x^{2})^{2}-\sqrt{1+x^{2}},y_{2}=(1+x^{2})^{2}+\sqrt{1+x^{2}}$ 。由于 $y_{1},y_{2}$ 均是微分方程 $y^{\prime}+p(x)y=q(x)$ 的解，故 $y_{2}-y_{1}=2\sqrt{1+x^{2}}$ 是对应的齐次线性方程 $y^{\prime}+p(x)y=0$ 的解。将解代入方程中得到 $\frac{2x}{\sqrt{1+x^{2}}}+2p(x)\sqrt{1+x^{2}}=0,$ 从而 $p(x) = -\frac{x}{1 + x^{2}}.$ 由于 $y_{1}, y_{2}$ 是微分方程 $y' + p(x)y = q(x)$ 的解，故 $\frac{y_{1} + y_{2}}{2} = (1 + x^{2})^{2}$ 也是该微分方程的解。将解代入方程中得到 $4x\left(1+x^{2}\right)-\frac{x}{1+x^{2}}\cdot\left(1+x^{2}\right)^{2}=q(x),$ 即 $q(x) = 3x(1 + x^{2})$. 应选 A.

## 006. 900 第六章数二 A 类 1

- 题目ID：`4529`
- 题号：`6`
- 题源：900 第六章数二 A 类 1
- 分类：高等数学 / 微分方程 / 已知解反求微分方程（逆问题） / 一阶
- 选做：否

若 $y_{1}=(x-1)^{2}, y_{2}=(x+1)^{2}$ 是微分方程 $y' + p(x)y = q(x)$ 的两个解，则 $p(x) + q(x) = (\quad)$

### 选项

A. $\frac{x^{2}-1}{x}$
B. $\frac{x^{2}-2}{x}$
C. $\frac{1-x^{2}}{x}$
D. $\frac{2-x^{2}}{x}$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 由于 $y_{1}, y_{2}$ 均是微分方程 $y' + p(x)y = q(x)$ 的解，故 $y_{2} - y_{1} = 4x$ 是对应的齐次线性方程 $y' + p(x)y = 0$ 的解。将解代入方程中得到 $4 + 4xp(x) = 0$，从而 $p(x) = -\frac{1}{x}$。由于 $y_{1}, y_{2}$ 是微分方程 $y' + p(x)y = q(x)$ 的解，故 $\frac{y_{1} + y_{2}}{2} = 1 + x^{2}$ 也是该微分方程的解。将解代入方程中得到 $2x - \frac{1 + x^{2}}{x} = q(x)$，即 $q(x) = \frac{x^{2} - 1}{x}$。因此，$p(x)+q(x)=-\frac{1}{x}+\frac{x^{2}-1}{x}=\frac{x^{2}-2}{x}$。应选 B。

## 010. 900 第六章数二 A 类 4

- 题目ID：`4533`
- 题号：`10`
- 题源：900 第六章数二 A 类 4
- 分类：高等数学 / 微分方程 / 已知解反求微分方程（逆问题） / 一阶
- 选做：否

设 $C$ 为任意常数，则以 $x = y^{2}(C - 2\ln|y|)$ 为通解的一阶微分方程为（）

### 选项

A. $y'=\frac{y}{x-y^{2}}$
B. $y'=\frac{y}{2x-y^{2}}$
C. $y'=\frac{y}{x-2y^{2}}$
D. $y'=\frac{y}{2(x-y^{2})}$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 由 $x = y^{2}(C - 2\ln|y|)$ 可得 $\frac{x}{y^{2}} = C - 2\ln|y|$。对该式两端同时关于 $x$ 求导可得 $\frac{1}{y^{2}} - \frac{2xy'}{y^{3}} = -\frac{2y'}{y}$。整理可得 $\frac{1}{y^{2}}=\frac{1}{y^{3}}(2x-2y^{2})y'$。进一步可得 $y'=\frac{y}{2(x-y^{2})}$。因此，应选D。

## 011. 880 第六章综合选择 3

- 题目ID：`4534`
- 题号：`11`
- 题源：880 第六章综合选择 3
- 分类：高等数学 / 微分方程 / 已知解反求微分方程（逆问题） / 一阶
- 选做：否

设 $C$ 为任意常数，则以 $y=e^{Cx+x^{2}}$ 为通解的一阶微分方程为（）。

### 选项

A. $xy' - y \ln y = x^{2} y$
B. $xy' + y \ln y = xy^{2}$
C. $xy' - y \ln y^{2} = xy$
D. $xy' + y \ln y = xy$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 由 $y = e^{Cx + x^{2}}$，有 $\ln y = x^{2} + Cx$，即 $\frac{\ln y}{x} - x = C$，两边同时对 $x$ 求导，得 $\frac{\frac{x}{y}\cdot y^{\prime}-\ln y}{x^{2}}-1=0$，化简得 $xy' - y \ln y = x^{2}y$，选项 A 正确。

^q-4534
