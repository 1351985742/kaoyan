## 001. 26 版 660 数三第 217 题

- 题目ID：`4607`
- 题号：`1`
- 题源：26 版 660 数三第 217 题
- 分类：高等数学 / 微分方程 / 处理微分方程解 / 微分方程解的定积分（应用）
- 选做：否

设微分方程 $(1+x^{2})y' - 2xy = x$ 满足 $y(0)=1$ 的特解是 $y^{*}(x)$，则 $\int_{0}^{1} y^{*}(x) dx =$

### 选项

A. $\frac{3}{2}$
B. $\frac{1}{2}$
C. $-\frac{1}{2}$
D. $-\frac{3}{2}$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 这是一阶线性微分方程，标准形式是 $y' - \frac{2x}{1 + x^{2}}y = \frac{x}{1 + x^{2}}$。用 $\mu(x) = \mathrm{e}^{-\int \frac{2x}{1+x^{2}} dx} = \frac{1}{1+x^{2}}$ 同乘方程两端即得 $\frac{y'}{1+x^{2}} - \frac{2x}{(1+x^{2})^{2}}y = \frac{x}{(1+x^{2})^{2}}$，即 $\left(\frac{y}{1+x^{2}}\right)' = \frac{x}{(1+x^{2})^{2}}$。积分并用 $y^{*}(0)=1$ 求出特解 $y^{*}(x)$：$\int_{0}^{x} \left(\frac{y^{*}}{1+x^{2}}\right)' dx = \int_{0}^{x} \frac{x}{(1+x^{2})^{2}} dx$，得 $\frac{y^{*}(x)}{1+x^{2}} - 1 = -\frac{1}{2}\frac{1}{1+x^{2}} + \frac{1}{2}$。于是所求特解 $y^{*}(x) = \frac{3}{2}(1+x^{2}) - \frac{1}{2} = 1 + \frac{3}{2}x^{2}$。求定积分可得 $\int_{0}^{1} y^{*}(x) dx = \int_{0}^{1} (1 + \frac{3}{2}x^{2}) dx = 1 + \frac{1}{2} = \frac{3}{2}$。故应选(A)。

^q-4607

## 003. 26 版 1000 第十五章基础 11

- 题目ID：`4609`
- 题号：`3`
- 题源：26 版 1000 第十五章基础 11
- 分类：高等数学 / 微分方程 / 处理微分方程解 / 微分方程解的定积分（应用）
- 选做：否

设函数 $y = y(x)$ 是微分方程 $2xy' - 4y = 2\ln x - 1$ 满足条件 $y(1) = \frac{1}{4}$ 的解，求曲线 $y = y(x)$ 在 $[1, e]$ 上的平均值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 整理题干方程，得 $y' - \frac{2}{x}y = \frac{2\ln x - 1}{2x}$，由一阶非齐次线性微分方程的通解公式，得 $y(x) = \mathrm{e}^{\int \frac{2}{x} dx} \left( \int \frac{2\ln x - 1}{2x} \mathrm{e}^{-\int \frac{2}{x} dx} dx + C \right) = x^{2} \left( \int \frac{2\ln x - 1}{2x^{3}} dx + C \right) = -\frac{1}{2}\ln x + Cx^{2}$。代入 $y(1) = \frac{1}{4}$，得 $C = \frac{1}{4}$，所以 $y = -\frac{1}{2}\ln x + \frac{1}{4}x^{2}$。由 $\int_{1}^{e} y(x) dx = \int_{1}^{e} \left( -\frac{1}{2}\ln x + \frac{1}{4}x^{2} \right) dx = \frac{e^{3} - 7}{12}$，得平均值为 $\frac{e^{3} - 7}{12(e-1)}$。

## 002. 880 第六章综合解答 12

- 题目ID：`4608`
- 题号：`2`
- 题源：880 第六章综合解答 12
- 分类：高等数学 / 微分方程 / 处理微分方程解 / 微分方程解的定积分（应用）
- 选做：否

设 $f(x)$ 满足 $f'(x) = \frac{1}{x}f(x) + x\cos x (x>0)$，且 $\lim_{x\to0^{+}}\frac{f(x)}{x} = 0$。
(I) 求 $f(x)$ 的表达式；
(II) 若 $y = f(x)$ 在 $[0, n\pi]$ 上与 x 轴所围图形的面积为 $A_{n} (n=1,2,\cdots)$，求 $\lim_{n\to\infty}\frac{A_{n}}{(n+1)^2}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> (I) 由已知，$f'(x) - \frac{1}{x} f(x) = x \cos x (x > 0)$，解一阶线性微分方程，有 $f(x) = \mathrm{e}^{\int \frac{1}{x} dx} \left( \int x\cos x \cdot \mathrm{e}^{-\int \frac{1}{x} dx} dx + C \right) = x \left( \int x\cos x \cdot x^{-1} dx + C \right) = x(\sin x + C)$。由 $\lim_{x\to0^{+}}\frac{f(x)}{x} = \lim_{x\to0^{+}}\frac{x(\sin x + C)}{x} = C = 0$，知 $f(x) = x\sin x$。
> (Ⅱ) 依题设，有 $A_{n} = \int_{0}^{n\pi} | f(x) | dx = \int_{0}^{n\pi} x |\sin x| dx$。通过变量代换 $x = n\pi - t$，可得 $\int_{0}^{n\pi} x |\sin x| dx = \frac{n\pi}{2} \int_{0}^{n\pi} |\sin x| dx$。因 $|\sin x|$ 以 $\pi$ 为周期，所以 $\int_{0}^{n\pi} x |\sin x| dx = \frac{n\pi}{2} \cdot n \int_{0}^{\pi} \sin x dx = n^{2}\pi$。故 $\lim_{n\to\infty}\frac{A_n}{(n+1)^2} = \lim_{n\to\infty}\frac{n^2\pi}{(n+1)^2} = \pi$。

^q-4608

## 004. 26 版 660 数一二三第 219 题

- 题目ID：`4610`
- 题号：`4`
- 题源：26 版 660 数一二三第 219 题
- 分类：高等数学 / 微分方程 / 处理微分方程解 / 微分方程解的定积分（应用）
- 选做：否

设函数 $f(x)$ 满足 $xf'(x) - 2f(x) = -4x$，且由曲线 $y = f(x)$ 与直线 x = 1 以及 x 轴所围成的平面图形绕 x 轴旋转一周所得旋转体的体积最小，则 $f(x) =$

### 选项

A. $5x^{2} - 4x$
B. $4x - 5x^{2} - 2$
C. $5x^{2} - 4x - 2$
D. $4x - 5x^{2}$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 一阶线性微分方程 $xy' - 2y = -4x$ 可化为标准形式 $y' - \frac{2}{x}y = -4$，方程两边同乘 $\mathrm{e}^{\int -\frac{2}{x} dx} = \frac{1}{x^{2}}$ 得 $\left(\frac{y}{x^{2}}\right)' = -\frac{4}{x^{2}}$，积分得 $\frac{y}{x^{2}} = \frac{4}{x} + C$，于是得通解为 $y = Cx^{2} + 4x$。由于对任何常数 C 都有 $y(0) = 0$，从而由曲线 $y = Cx^{2} + 4x$ 与直线 x = 1 以及 x 轴所围成的平面图形绕 x 轴旋转一周所得旋转体的体积 $V(C) = \pi \int_{0}^{1} y^{2} dx = \pi \int_{0}^{1} (Cx^{2} + 4x)^{2} dx = \pi \left( \frac{C^{2}}{5} + 2C + \frac{16}{3} \right)$。由于 $V'(C) = \pi \left( \frac{2C}{5} + 2 \right)$，当 $C < -5$ 时 $V'(C) < 0$，当 $C = -5$ 时 $V'(C) = 0$，当 $C > -5$ 时 $V'(C) > 0$，可见当 $C = -5$ 时 $V(C)$ 最小，即函数 $f(x) = 4x - 5x^{2}$。

^q-4610
