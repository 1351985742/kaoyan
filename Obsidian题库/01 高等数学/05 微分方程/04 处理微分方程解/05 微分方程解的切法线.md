## 001. 2021 数二

- 题目ID：`4601`
- 题号：`1`
- 题源：2021 数二

- 选做：否

设 $y = y(x) (x > 0)$ 满足微分方程 $xy' - 6y = -6$，且满足 $y(\sqrt{3}) = 10$，
(I) 求 $y(x)$；
（Ⅱ）设 P 为曲线 $y = y(x)$ 上的一点，曲线 $y = y(x)$ 在点 P 的法线在 y 轴上的截距为 $I_{p}$，为使 $I_{p}$ 最小，求 P 的坐标。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> （Ⅰ）整理 $xy' - 6y = -6$ 得，$y' - \frac{6y}{x} = -\frac{6}{x}$。由求解公式，可得通解 $y = e^{\int\frac{6}{x}dx}\left[\int\left(-\frac{6}{x}\right)\cdot e^{-\int\frac{6}{x}dx}dx + C\right] = x^{6}\left[\int(-6)x^{-7}dx + C\right] = Cx^{6} + 1$。代入 $y(\sqrt{3}) = 10$，得 $10 = 1 + C(\sqrt{3})^{6}$，即 $10 = 1 + 27C$，解得 $C = \frac{1}{3}$。因此，$y(x) = \frac{x^{6}}{3} + 1, x > 0$。
> （Ⅱ）曲线 $y = \frac{x^{6}}{3} + 1$ 上点 $P(x, y)$ 处的切线斜率为 $2x^{5}$，法线斜率为 $-\frac{1}{2x^{5}}$。法线方程为 $Y - y = -\frac{1}{2x^{5}}(X - x)$。令 $X = 0$，得截距 $I_{P}(x) = y + \frac{1}{2x^{4}} = \frac{x^{6}}{3} + \frac{1}{2x^{4}} + 1$。求导 $I_{P}'(x) = 2x^{5} - 2x^{-5} = \frac{2(x^{10} - 1)}{x^{5}}$。令 $I_{P}'(x) = 0$，得 $x = 1$。当 $0 < x < 1$ 时，$I_{P}'(x) < 0$，$I_{P}(x)$ 单调减少；当 $x > 1$ 时，$I_{P}'(x) > 0$，$I_{P}(x)$ 单调增加。故 $I_{P}(1)$ 为最小值，$I_{P}(1) = \frac{1}{3} + \frac{1}{2} + 1 = \frac{11}{6}$。对应 $y = \frac{1^{6}}{3} + 1 = \frac{4}{3}$。因此，当 $x = 1, y = \frac{4}{3}$ 时，$I_{p}(x)$ 有最小值 $\frac{11}{6}$。
