## 001. 880 第六章基础解答 11

- 题目ID：`4602`
- 题号：`1`
- 题源：880 第六章基础解答 11
- 分类：高等数学 / 微分方程 / 处理微分方程解 / 微分方程解的最值
- 选做：否

设 $f(x)$ 满足 $xf'(x) - 3f(x) = 2x, f(1) = \frac{1}{3}k - 1, k > 0$。
(I) 求 $f(x)$ 的表达式；
（Ⅱ）求 $f(x)$ 在 $x \in \left[0, \frac{1}{k}\right]$ 上的最小值与最大值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> （Ⅰ）方程 $xf'(x) - 3f(x) = 2x$ 变形为 $f'(x) - \frac{3}{x}f(x) = 2$，其通解为 $f(x) = e^{\int\frac{3}{x}dx}\left(\int2e^{-\int\frac{3}{x}dx}dx + C\right) = Cx^{3} - x$。由 $f(1) = \frac{1}{3}k - 1$，得 $C = \frac{1}{3}k$，故 $f(x) = \frac{1}{3}kx^{3} - x$。
> （Ⅱ）令 $f'(x) = kx^{2} - 1 = 0$，得驻点 $x = \sqrt{\frac{1}{k}}$。
> 当 $0 < k < 1$ 时，$\sqrt{\frac{1}{k}} < \frac{1}{k}$，即 $\sqrt{\frac{1}{k}} \in \left(0, \frac{1}{k}\right)$。当 $x \in \left[0, \sqrt{\frac{1}{k}}\right)$ 时，$f'(x) < 0$；当 $x \in \left(\sqrt{\frac{1}{k}}, \frac{1}{k}\right]$ 时，$f'(x) > 0$。故 $f\left(\sqrt{\frac{1}{k}}\right)$ 是唯一的极小值，也是最小值，最小值为 $f\left(\sqrt{\frac{1}{k}}\right) = -\frac{2}{3}\sqrt{\frac{1}{k}}$。
> 当 $0 < k < \frac{1}{3}$ 时，$f(0) = 0, f\left(\frac{1}{k}\right) = \frac{1 - 3k}{3k^{2}} > 0 = f(0)$，此时 $f\left(\frac{1}{k}\right)$ 是最大值。
> 当 $\frac{1}{3} < k < 1$ 时，$f\left(\frac{1}{k}\right) < 0 = f(0)$，此时 $f(0)$ 是最大值。
> 当 $k = \frac{1}{3}$ 时，$f(0) = 0$ 与 $f\left(\frac{1}{k}\right) = \frac{1}{3k^{2}} - \frac{1}{k}$ 均为最大值。
> 当 $k \geqslant 1$ 时，$\sqrt{\frac{1}{k}} \geqslant \frac{1}{k}$，且 $f'(x) = kx^{2} - 1 \leqslant 0, x \in \left[0, \frac{1}{k}\right]$。此时 $f(x)$ 在 $\left[0, \frac{1}{k}\right]$ 上单调减少，故 $f(0) = 0$ 是最大值，$f\left(\frac{1}{k}\right) = \frac{1 - 3k}{3k^{2}}$ 是最小值。

## 002. 26 版 1000 第十五章强化 16

- 题目ID：`4603`
- 题号：`2`
- 题源：26 版 1000 第十五章强化 16
- 分类：高等数学 / 微分方程 / 处理微分方程解 / 微分方程解的最值
- 选做：否

已知函数 $y = y(x)$ 满足 $x(\ln x - 1)y'(x) + (3 - \ln x^{2})y(x) = 0, x > e$，且 $y(e^{2}) = \frac{e^{4}}{2}$，求 $y = y(x)$ 的最小值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 将方程变形为 $\frac{dy}{dx} = \frac{2\ln x - 3}{x(\ln x - 1)}y$，分离变量得 $\frac{1}{y}dy = \frac{2\ln x - 3}{x(\ln x - 1)}dx$。两边积分得 $\int\frac{1}{y}dy = \int\frac{2\ln x - 3}{x(\ln x - 1)}dx$，即 $\ln|y| = \int\frac{2\ln x - 3}{\ln x - 1}d(\ln x)$，计算得 $\ln|y| = 2\ln x - \ln(\ln x - 1) + C$。代入 $y(e^{2}) = \frac{e^{4}}{2}$，得 $C = -\ln 2$，故 $y = \frac{x^{2}}{2(\ln x - 1)}$。求导 $y' = \frac{x(2\ln x - 3)}{2(\ln x - 1)^{2}}$。令 $y' = 0$ 得 $x = e^{\frac{3}{2}}$。当 $e < x < e^{\frac{3}{2}}$ 时，$y' < 0$，y 单调递减；当 $x > e^{\frac{3}{2}}$ 时，$y' > 0$，y 单调递增，故 $y(e^{\frac{3}{2}}) = e^{3}$ 为最小值。

^q-4603

## 003. 26 版 1000 第十五章强化 17

- 题目ID：`4604`
- 题号：`3`
- 题源：26 版 1000 第十五章强化 17
- 分类：高等数学 / 微分方程 / 处理微分方程解 / 微分方程解的最值
- 选做：否

设 $y = y(x)$ 满足 $y' + 2(\ln x + 1)y = 0, y(1) = 1$，则 $y(x)$ 在 $(0,1]$ 上的最大值为 ___。

> [!success]- 答案解析
> **答案**
>
> e^{\frac{2}{e}}
>
> **解析**
>
> 已知 $y' + 2(\ln x + 1)y = 0$，则 $\frac{dy}{dx} = -2(\ln x + 1)y$，分离变量得 $-\frac{1}{2y}dy = (\ln x + 1)dx$。两边积分得 $-\frac{1}{2}\ln y = x\ln x + \ln C_{0} = \ln(x^{x} \cdot C_{0})$，解得 $y^{-\frac{1}{2}} = C_{0} \cdot x^{x}$。由 $y(1) = 1$，得 $C_{0} = 1$，即 $y = x^{-2x}$。令 $y' = -2(\ln x + 1)x^{-2x} = 0$，得 $x = e^{-1}$。当 $0 < x < e^{-1}$ 时，$y' > 0$；当 $e^{-1} < x \leqslant 1$ 时，$y' < 0$，故 $y_{\max} = x^{-2x}\bigg|_{x = e^{-1}} = (e^{-1})^{-2e^{-1}} = e^{\frac{2}{e}}$。

^q-4604

## 004. 26 版 1000 第十五章强化 19

- 题目ID：`4605`
- 题号：`4`
- 题源：26 版 1000 第十五章强化 19
- 分类：高等数学 / 微分方程 / 处理微分方程解 / 微分方程解的最值
- 选做：否

当 $x > 0$ 时，函数 $f(x)$ 满足关系式 $x^{2}f'(x) + (-1 + \ln x)f(x) = 0$，且 $f(1) = 1$，则 $f(x)$ 的最大值为 ( ).

### 选项

A. $e^{-e}$
B. $e^{e}$
C. $e^{-\frac{1}{e}}$
D. $e^{\frac{1}{e}}$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 设 $y = f(x)$，则有 $x^{2}y' = (1 - \ln x)y$，即 $\frac{1 - \ln x}{x^{2}} \mathrm{d}x = \frac{\mathrm{d}y}{y}$，两边同时积分，得 
>
> $$
> \ln y=\frac{\ln x}{x}+\ln C=\ln C x^{\frac{1}{x}},
> $$
>
>  所以 $y = f(x) = C x^{\frac{1}{x}}$。令 $x=1$，则 $f(1)=C=1$，所以 
>
> $$
> f(x)=x^{\frac{1}{x}},f^{\prime}(x)=\frac{x^{\frac{1}{x}}(1-\ln x)}{x^{2}},
> $$
>
>  令 $f'(x)=0$，得 $x=e$，易知 $f(e)$ 为极大值，即最大值，此时 $f(e)=e^{\frac{1}{e}}$。

^q-4605
