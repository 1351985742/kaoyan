# 一侧为 x 分之 y 的函数（齐次方程） 题目

- 分类ID：`796`
- 分类路径：高等数学 / 微分方程 / 解微分方程 / 一阶 / 基本类型 / 一侧为 x 分之 y 的函数（齐次方程）
- 题量：`2`

## 001. 2007 数三

- 题目ID：`4443`
- 题号：`1`
- 题源：2007 数三
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 基本类型 / 一侧为 x 分之 y 的函数（齐次方程）
- 选做：否

微分方程 $\frac{dy}{dx}=\frac{y}{x}-\frac{1}{2}\left(\frac{y}{x}\right)^{3}$ 满足 $y\big|_{x=1}=1$ 的特解为 $y=$___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $u = \frac{y}{x}$，则 $y = xu$，有 $dy = \mathrm{d}(ux) = x \, \mathrm{d}u + u \, \mathrm{d}x$，$\Rightarrow \quad \frac{dy}{dx} = u + x \frac{du}{dx}$。于是原式变为：$x \frac{\mathrm{d}u}{\mathrm{d}x} + u = u - \frac{1}{2}u^3$，即 $x \frac{\mathrm{d}u}{\mathrm{d}x} = -\frac{1}{2}u^3$。由上式得：$-2\frac{1}{u^3} \, \mathrm{d}u = \frac{1}{x} \, \mathrm{d}x$。取积分得：$\int -2\frac{1}{u^3} \, \mathrm{d}u = \int \frac{1}{x} \, \mathrm{d}x$，$\frac{1}{u^2} = \ln |x| + C$。代入初始条件 $y|_{x=1}=1$，即 $u|_{x=1}=1$，得 $1 = \ln 1 + C$，故 $C = 1$。于是 $\frac{1}{u^2} = \ln |x| + 1$，即 $u^2 = \frac{1}{\ln |x| + 1}$。由于 $x=1>0$，取 $u = \frac{y}{x} = \frac{1}{\sqrt{\ln x + 1}}$，所以特解为 $y = \frac{x}{\sqrt{\ln x + 1}}$。

## 002. 880 第六章基础填空 3

- 题目ID：`4444`
- 题号：`2`
- 题源：880 第六章基础填空 3
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 基本类型 / 一侧为 x 分之 y 的函数（齐次方程）
- 选做：否

求微分方程 $y' = \frac{y}{x} + \tan \frac{y}{x}$ 满足 $y(1) = \frac{\pi}{6}$ 的特解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程为齐次微分方程，令 $u = \frac{y}{x}$，即 $y = ux$，则 $\frac{dy}{dx} = u + x \cdot \frac{du}{dx} = u + \tan u$。分离变量得 $\cot u \, du = \frac{dx}{x}$，积分得 $\ln |\sin u| = \ln |x| + C_1$，故 $\sin u = \pm e^{C_1} \cdot x = Cx (C \neq 0)$，即 $\sin \frac{y}{x} = Cx (C \neq 0)$。又 $y = 0$ 也是原方程的解，故常数也可以为零，则原方程的通解为 $\sin \frac{y}{x} = Cx$（$C$ 为任意常数）。由 $y(1) = \frac{\pi}{6}$，得 $C = \frac{1}{2}$，故所求特解为 $\sin \frac{y}{x} = \frac{1}{2}x$。

^q-4444
