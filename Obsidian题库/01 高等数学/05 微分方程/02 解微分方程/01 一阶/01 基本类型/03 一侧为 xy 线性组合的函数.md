## 001. 姜晓千基础例题（重点）

- 题目ID：`4445`
- 题号：`1`
- 题源：姜晓千基础例题（重点）
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 基本类型 / 一侧为 xy 线性组合的函数
- 选做：否

求微分方程 $y' = \cos(x + y)$ 的通解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $x + y = u$，则 $1 + \frac{dy}{dx} = \frac{du}{dx} = 1 + \cos u$，即 $\frac{du}{dx} = \cos u$。分离变量得 $\frac{du}{1 + \cos u} = dx$，积分得 $\int \frac{du}{1 + \cos u} = x + C$。利用三角公式 $1 + \cos u = 2\cos^2 \frac{u}{2}$，有 $\int \frac{du}{2\cos^2 \frac{u}{2}} = \int \sec^2 \frac{u}{2} d\frac{u}{2} = \tan \frac{u}{2}$。故 $\tan \frac{u}{2} = x + C$，即 $\tan \frac{x + y}{2} = x + C$，解得 $y = 2\arctan(x + C) - x$。

## 002. 2024 数一二；1800（先于真题出现）

- 题目ID：`4446`
- 题号：`2`

- 选做：否

微分方程 $y' = \frac{1}{(x + y)^2}$ 满足条件 $y(1) = 0$ 的解为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 作变量替换 $x + y = u$，则 $1 + \frac{dy}{dx} = \frac{du}{dx}$。微分方程变为 $\frac{du}{dx} = \frac{1}{u^2} + 1$，即 $\frac{u^2}{1 + u^2} du = dx$。两边积分得 $u - \arctan u = x + C$。将 $x + y = u$ 代入，得 $x + y - \arctan(x + y) = x + C$，即 $y - \arctan(x + y) = C$。由 $y(1) = 0$ 得 $C = -\frac{\pi}{4}$，因此所求解为 $y - \arctan(x + y) + \frac{\pi}{4} = 0$。

## 003. 姜晓千真题同源 150（重点）

- 题目ID：`4447`
- 题号：`3`
- 题源：姜晓千真题同源 150（重点）

- 选做：否

求微分方程 $y' = (2x + y - 1)^2$ 的通解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $2x + y - 1 = u$，则 $\frac{du}{dx} = 2 + \frac{dy}{dx} = 2 + u^2$。分离变量得 $\int \frac{du}{2 + u^2} = \int dx$，即 $\frac{1}{\sqrt{2}} \arctan \frac{u}{\sqrt{2}} = x + C$。代入 $u = 2x + y - 1$，得 $\frac{1}{\sqrt{2}} \arctan \frac{2x + y - 1}{\sqrt{2}} = x + C$，故方程的通解为 $y = \sqrt{2} \tan \sqrt{2}(x + C) - 2x + 1$，其中 $C$ 为任意常数。

## 004. 1800 基础（重点）

- 题目ID：`4448`
- 题号：`4`
- 题源：1800 基础（重点）
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 基本类型 / 一侧为 xy 线性组合的函数
- 选做：否

求微分方程 $\frac{dy}{dx} = \frac{1}{2x + y}$ 的通解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方法一：令 $u = 2x + y$，则 $\frac{du}{dx} = 2 + \frac{dy}{dx}$，代入原方程得 $\frac{du}{dx} - 2 = \frac{1}{u}$，即 $\frac{du}{dx} = \frac{1 + 2u}{u}$。分离变量得 $\frac{u}{1 + 2u} du = dx$，积分得 $\frac{1}{2}u - \frac{1}{4} \ln |1 + 2u| = x + C$。代入 $u = 2x + y$，整理得 $\frac{1}{2}y - \frac{1}{4} \ln |1 + 4x + 2y| + C = 0$。
> 方法二：将方程改写为 $\frac{dx}{dy} - 2x = y$，这是一阶线性微分方程。通解公式得 $x = e^{2y} \left[ \int y e^{-2y} dy + C \right] = C e^{2y} - \frac{y}{2} - \frac{1}{4}$，其中 $C$ 为任意常数。
