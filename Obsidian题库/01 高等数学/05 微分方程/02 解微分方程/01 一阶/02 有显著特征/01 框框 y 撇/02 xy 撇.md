## 005. 1991 数二

- 题目ID：`4473`
- 题号：`5`
- 题源：1991 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 y 撇 / xy 撇
- 选做：否

求微分方程 $xy' + y = x e^{x}$ 满足 $y(1) = 1$ 的特解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方程两边除以 $x$ 得 $y' + \frac{1}{x}y = e^{x}$。由一阶线性微分方程通解公式 $y = e^{-\int \frac{1}{x} dx} \left[ \int e^{\int \frac{1}{x} dx} \cdot e^{x} \, dx + C \right] = e^{-\ln x} \left[ \int e^{\ln x} \cdot e^{x} \, dx + C \right] = \frac{1}{x} \left[ \int x e^{x} \, dx + C \right]$。计算 $\int x e^{x} \, dx = x e^{x} - \int e^{x} \, dx = (x-1)e^{x}$。故通解为 $y = \frac{1}{x} \left[ (x-1)e^{x} + C \right]$。代入 $y(1)=1$ 得 $1 = \frac{1}{1} \left[ (1-1)e^{1} + C \right] = C$，即 $C=1$。因此特解为 $y = \frac{1}{x} \left[ (x-1)e^{x} + 1 \right]$。

## 003. 1987 数二

- 题目ID：`4471`
- 题号：`3`
- 题源：1987 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 y 撇 / xy 撇
- 选做：否

求微分方程 $x \frac{dy}{dx} = x - y$ 满足条件 $y|_{x=\sqrt{2}} = 0$ 的特解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程化为 $\frac{dy}{dx} + \frac{1}{x}y = 1$，为一阶线性微分方程。由通解公式 $y = e^{-\int \frac{1}{x} dx} \left[ \int e^{\int \frac{1}{x} dx} \cdot 1 \, dx + C \right] = e^{-\ln x} \left[ \int e^{\ln x} \, dx + C \right] = \frac{1}{x} \left( \int x \, dx + C \right) = \frac{1}{x} \left( \frac{1}{2}x^{2} + C \right) = \frac{1}{2}x + \frac{C}{x}$。代入 $y(\sqrt{2}) = 0$ 得 $\frac{1}{2} \cdot \sqrt{2} + \frac{C}{\sqrt{2}} = 0$，解得 $C = -1$。故特解为 $y = \frac{1}{2}x - \frac{1}{x}$。

## 008. 2005 数三

- 题目ID：`4476`
- 题号：`8`

- 选做：否

微分方程 $xy' + y = 0$ 满足初始条件 $y(1) = 2$ 的特解为 ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方法一：化为标准形式 $y' + \frac{1}{x}y = 0$，为一阶线性齐次方程。通解公式 $y = e^{-\int \frac{1}{x} dx} \left[ \int 0 \cdot e^{\int \frac{1}{x} dx} dx + C \right] = e^{-\ln x} \cdot C = \frac{C}{x}$。代入 $y(1)=2$ 得 $2 = \frac{C}{1}$，故 $C=2$，特解为 $y = \frac{2}{x}$。方法二：注意到 $(xy)' = y + xy'$，原方程 $xy' + y = 0$ 即 $(xy)' = 0$，积分得 $xy = C$，即 $y = \frac{C}{x}$。代入 $y(1)=2$ 得 $C=2$，故 $y = \frac{2}{x}$。方法三：分离变量，方程写为 $x \frac{dy}{dx} = -y$，即 $\frac{dy}{y} = -\frac{dx}{x}$，积分得 $\ln |y| = -\ln |x| + \ln C_1$，整理得 $|y| = \frac{C_1}{|x|}$，即 $y = \frac{C}{x}$（$C$ 为任意常数，$C=0$ 时 $y \equiv 0$ 不符初始条件）。代入 $y(1)=2$ 得 $C=2$，故 $y = \frac{2}{x}$。

## 010. 2025 数三

- 题目ID：`4478`
- 题号：`10`
- 题源：2025 数三
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 y 撇 / xy 撇
- 选做：否

微分方程 $xy' - y + x^2 e^x = 0$ 满足条件 $y(1) = e$ 的解为 $y =$ ___

> [!success]- 答案解析
> **答案**
>
> $$
> 2ex - x e^x
> $$
>
> **解析**
>
> 这是一道典型的一阶线性常微分方程求解题。使用“凑微分法”可以得到非常简洁且严谨的推导过程。
>
> ### **第一步：整理方程并凑微分**
>
> 已知原方程为：
>
> $$
> xy' - y + x^2 e^x = 0
> $$
>
> 将其移项，把含有未知函数 $y$ 及其导数的项留在等式左边：
>
> $$
> xy' - y = -x^2 e^x
> $$
>
> 观察等式左边 $xy' - y$，这与商的求导公式 $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ 的分子结构非常相似。为了凑出全微分形式，我们将等式两边同时除以 $x^2$（由于初始条件在 $x=1$ 处，可隐含 $x \neq 0$）：
>
> $$
> \frac{xy' - y}{x^2} = -e^x
> $$
>
> 此时，等式左边恰好是函数 $\frac{y}{x}$ 的导数：
>
> $$
> \left(\frac{y}{x}\right)' = -e^x
> $$
>
> ### **第二步：两边积分求通解**
>
> 对上式两边同时关于 $x$ 进行不定积分：
>
> $$
> \int \left(\frac{y}{x}\right)' \mathrm{d}x = \int -e^x \mathrm{d}x
> $$
>
> 得到：
>
> $$
> \frac{y}{x} = -e^x + C
> $$
>
> *（其中 $C$ 为任意常数）*
>
> 将式子化简，解出 $y$ 得到该微分方程的通解：
>
> $$
> y = -x e^x + Cx
> $$
>
> ### **第三步：代入初始条件求特解**
>
> 已知初始条件为 $y(1) = e$，将其代入通解方程：
>
> $$
> e = -1 \cdot e^1 + C \cdot 1
> $$
>
> $$
> e = -e + C
> $$
>
> $$
> C = 2e
> $$
>
> 将 $C = 2e$ 代回通解方程中，即可得到满足条件的特解：
>
> $$
> y = -x e^x + 2ex
> $$
>
> ---
>
> **最终答案：**
>
> $$
> 2ex - x e^x
> $$

^q-4478

## 004. 1989 数二

- 题目ID：`4472`
- 题号：`4`
- 题源：1989 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 y 撇 / xy 撇
- 选做：否

求微分方程 $xy' + (1 - x)y = e^{2x} \, (0 < x < +\infty)$ 满足 $y(1) = 0$ 的特解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方程两边除以 $x$ 得 $y' + \frac{1 - x}{x}y = \frac{e^{2x}}{x}$。由一阶线性微分方程通解公式 $y = e^{-\int \frac{1-x}{x} dx} \left[ \int e^{\int \frac{1-x}{x} dx} \cdot \frac{e^{2x}}{x} \, dx + C \right]$。计算 $\int \frac{1-x}{x} dx = \int \left( \frac{1}{x} - 1 \right) dx = \ln x - x$，故 $e^{-\int \frac{1-x}{x} dx} = e^{-(\ln x - x)} = e^{-\ln x + x} = \frac{e^{x}}{x}$，$e^{\int \frac{1-x}{x} dx} = \frac{x}{e^{x}}$。代入得 $\int e^{\int \frac{1-x}{x} dx} \cdot \frac{e^{2x}}{x} \, dx = \int \frac{x}{e^{x}} \cdot \frac{e^{2x}}{x} \, dx = \int e^{x} \, dx = e^{x}$。因此通解为 $y = \frac{e^{x}}{x} (e^{x} + C) = \frac{C e^{x} + e^{2x}}{x}$。代入 $y(1)=0$ 得 $\frac{C e^{1} + e^{2}}{1} = 0$，解得 $C = -e$。故特解为 $y = \frac{e^{x}}{x} (e^{x} - e)$。

## 006. 2005 数一二

- 题目ID：`4474`
- 题号：`6`

微分方程 $xy' + 2y = x \ln x$ 满足 $y(1) = -\frac{1}{9}$ 的特解为 ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方程两边除以 $x$ 得 $y' + \frac{2}{x}y = \ln x$。由一阶线性微分方程通解公式 $y = e^{-\int \frac{2}{x} dx} \left[ \int e^{\int \frac{2}{x} dx} \cdot \ln x \, dx + C \right] = e^{-2\ln x} \left[ \int e^{2\ln x} \cdot \ln x \, dx + C \right] = \frac{1}{x^{2}} \left[ \int x^{2} \ln x \, dx + C \right]$。计算 $\int x^{2} \ln x \, dx = \frac{1}{3} x^{3} \ln x - \int \frac{1}{3} x^{3} \cdot \frac{1}{x} \, dx = \frac{1}{3} x^{3} \ln x - \frac{1}{9} x^{3}$。故通解为 $y = \frac{1}{x^{2}} \left[ \frac{1}{3} x^{3} \ln x - \frac{1}{9} x^{3} + C \right] = \frac{1}{3} x \ln x - \frac{1}{9} x + \frac{C}{x^{2}}$。代入 $y(1) = -\frac{1}{9}$ 得 $-\frac{1}{9} = \frac{1}{3} \cdot 1 \cdot \ln 1 - \frac{1}{9} \cdot 1 + \frac{C}{1^{2}} = 0 - \frac{1}{9} + C$，解得 $C = 0$。因此特解为 $y = \frac{1}{3} x \ln x - \frac{1}{9} x$。

## 012. 26 版 660 数一二三第 75 题

- 题目ID：`4480`
- 题号：`12`
- 题源：26 版 660 数一二三第 75 题
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 y 撇 / xy 撇
- 选做：否

方程 $xy' + 2y = \sin x$ 满足条件 $y\big|_{x=\pi} = \frac{1}{\pi}$ 的特解为 ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 将方程化为标准形式：$y' + \frac{2}{x} y = \frac{\sin x}{x}$。这是一阶线性微分方程，其中 $P(x) = \frac{2}{x}$，$Q(x) = \frac{\sin x}{x}$。通解公式为 $y = e^{-\int P(x) dx} \left[ \int Q(x) e^{\int P(x) dx} dx + C \right]$。计算得 $\int P(x) dx = \int \frac{2}{x} dx = 2 \ln x = \ln x^2$，故 $e^{-\int P(x) dx} = e^{-\ln x^2} = \frac{1}{x^2}$，$e^{\int P(x) dx} = e^{\ln x^2} = x^2$。于是 $y = \frac{1}{x^2} \left[ \int \frac{\sin x}{x} \cdot x^2 dx + C \right] = \frac{1}{x^2} \left[ \int x \sin x dx + C \right]$。利用分部积分计算 $\int x \sin x dx = -x \cos x + \sin x$。因此通解为 $y = \frac{1}{x^2} \left( -x \cos x + \sin x + C \right) = -\frac{\cos x}{x} + \frac{\sin x}{x^2} + \frac{C}{x^2}$。代入条件 $y(\pi) = \frac{1}{\pi}$：$\frac{1}{\pi} = -\frac{\cos \pi}{\pi} + \frac{\sin \pi}{\pi^2} + \frac{C}{\pi^2} = -\frac{(-1)}{\pi} + 0 + \frac{C}{\pi^2} = \frac{1}{\pi} + \frac{C}{\pi^2}$。解得 $\frac{C}{\pi^2} = 0$，即 $C = 0$。故特解为 $y = -\frac{\cos x}{x} + \frac{\sin x}{x^2}$。

> **解析**
>
> 第一步：将方程化为标准形式 $y' + \frac{2}{x}y = \ln x$，为一阶线性微分方程。通解公式为 $y = e^{-\int P(x)dx} \left[ \int e^{\int P(x)dx} Q(x) dx + C \right]$，其中 $P(x) = \frac{2}{x}$，$Q(x) = \ln x$。计算得 $e^{-\int \frac{2}{x} dx} = e^{-2 \ln x} = x^{-2} = \frac{1}{x^2}$，$e^{\int \frac{2}{x} dx} = x^2$。于是 $y = \frac{1}{x^2} \left[ \int x^2 \ln x dx + C \right]$。利用分部积分计算 $\int x^2 \ln x dx = \frac{1}{3} x^3 \ln x - \frac{1}{9} x^3$。因此通解为 $y(x) = \frac{1}{x^2} \left( \frac{1}{3} x^3 \ln x - \frac{1}{9} x^3 + C \right)$。第二步：代入初始条件 $y(1) = -\frac{1}{9}$，得 $-\frac{1}{9} = \frac{1}{1^2} \left( \frac{1}{3} \cdot 1^3 \cdot \ln 1 - \frac{1}{9} \cdot 1^3 + C \right)$，即 $-\frac{1}{9} = 0 - \frac{1}{9} + C$，解得 $C = 0$。故特解为 $y(x) = \frac{1}{x^2} \left( \frac{1}{3} x^3 \ln x - \frac{1}{9} x^3 \right) = \frac{1}{3} x \ln x - \frac{1}{9} x = \frac{1}{3} x \left( \ln x - \frac{1}{3} \right)$。

^q-4475

## 001. 2014 数一

- 题目ID：`4469`
- 题号：`1`
- 题源：2014 数一
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 y 撇 / xy 撇
- 选做：否

微分方程 $xy' + y(\ln x - \ln y) = 0$ 满足条件 $y(1) = e^{3}$ 的解为 $y =$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程可化为 $\frac{dy}{dx} = \frac{y}{x} \ln \frac{y}{x}$。令 $u = \frac{y}{x}$，则 $y = xu$，$\frac{dy}{dx} = u + x \frac{du}{dx}$。代入得 $u + x \frac{du}{dx} = u \ln u$，即 $x \frac{du}{dx} = u(\ln u - 1)$。分离变量得 $\int \frac{du}{u(\ln u - 1)} = \int \frac{dx}{x}$。积分得 $\ln |\ln u - 1| = \ln x + \ln C$，即 $\ln u - 1 = Cx$。代回 $u = \frac{y}{x}$ 得 $\ln \frac{y}{x} - 1 = Cx$，即 $\frac{y}{x} = e^{Cx+1}$，$y = x e^{Cx+1}$。代入 $y(1)=e^{3}$ 得 $e^{3} = 1 \cdot e^{C \cdot 1 + 1} = e^{C+1}$，故 $C+1=3$，$C=2$。因此特解为 $y = x e^{2x+1}$。

## 002. 900 第六章数二 A 类 13

- 题目ID：`4470`
- 题号：`2`

- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 y 撇 / xy 撇
- 选做：否

微分方程 $xy' + 2y(\ln x - \ln y) = 0$ 满足条件 $y(1) = 1$ 的特解为 $y =$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由题设知 $x > 0, y > 0$，原方程可化为 $y' = 2 \frac{y}{x} \ln \frac{y}{x}$。令 $u = \frac{y}{x}$，则 $y = xu$，$\frac{dy}{dx} = u + x \frac{du}{dx}$。代入得 $u + x \frac{du}{dx} = 2u \ln u$，即 $x \frac{du}{dx} = u(2\ln u - 1)$。分离变量得 $\frac{du}{u(2\ln u - 1)} = \frac{dx}{x}$，即 $\frac{d(2\ln u - 1)}{2\ln u - 1} = \frac{2dx}{x}$。积分得 $\ln |2\ln u - 1| = 2\ln x + C_1$，整理得 $2\ln u - 1 = Cx^{2}$，其中 $C = \pm e^{C_1}$。代回 $u = \frac{y}{x}$ 得 $2\ln \frac{y}{x} - 1 = Cx^{2}$。代入 $y(1)=1$ 得 $2\ln 1 - 1 = C \cdot 1^{2}$，即 $-1 = C$。故 $2\ln \frac{y}{x} - 1 = -x^{2}$，解得 $\ln \frac{y}{x} = \frac{1 - x^{2}}{2}$。因此特解为 $y = x e^{\frac{1 - x^{2}}{2}}$。

## 011. 26 版 660 数一二三第 74 题

- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 y 撇 / xy 撇
- 选做：否

方程 $xy' - x \sin\frac{y}{x} - y = 0$ 的通解为 ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程可写为 $y' - \sin\frac{y}{x} - \frac{y}{x} = 0$。令 $u = \frac{y}{x}$，则 $y = xu$，$y' = u + x u'$。代入方程得 $u + x u' - \sin u - u = 0$，即 $x u' = \sin u$。分离变量得 $\frac{du}{\sin u} = \frac{dx}{x}$。利用三角恒等式 $\sin u = 2 \sin\frac{u}{2} \cos\frac{u}{2}$，有 $\frac{du}{\sin u} = \frac{du}{2 \sin\frac{u}{2} \cos\frac{u}{2}} = \frac{d(\tan\frac{u}{2})}{\tan\frac{u}{2}}$。积分得 $\ln \left| \tan\frac{u}{2} \right| = \ln |x| + \ln C$，即 $\tan\frac{u}{2} = C x$。回代 $u = \frac{y}{x}$，得通解 $\tan\frac{y}{2x} = C x$。
