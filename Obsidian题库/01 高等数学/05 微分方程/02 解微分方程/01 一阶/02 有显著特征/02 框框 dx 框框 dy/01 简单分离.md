## 001. 1994 数二

- 题目ID：`4488`
- 题号：`1`
- 题源：1994 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 简单分离
- 选做：否

微分方程 $y \, dx + (x^{2} - 4x) \, dy = 0$ 的通解为 ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 分离变量得：$\frac{dy}{y} = \frac{dx}{4x - x^{2}}$。两边积分得：$\int \frac{dy}{y} = \int \frac{dx}{4x - x^{2}}$，即 $\ln|y| = \int \frac{dx}{x(4-x)}$。计算积分：$\int \frac{dx}{x(4-x)} = \int \left( \frac{A}{4-x} + \frac{B}{x} \right) dx$，其中 $A = B = \frac{1}{4}$。所以 $\int \frac{dx}{x(4-x)} = \frac{1}{4} \int \left( \frac{1}{4-x} + \frac{1}{x} \right) dx = \frac{1}{4} \left[ -\ln(4-x) + \ln x + \ln C \right] = \frac{1}{4} \ln \frac{Cx}{4-x}$。因此 $4\ln|y| = \ln \left| \frac{Cx}{4-x} \right|$，即 $y^{4} = \frac{Cx}{4-x}$。

## 002. 880 第六章基础填空 2

- 题目ID：`4489`
- 题号：`2`
- 题源：880 第六章基础填空 2
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 简单分离
- 选做：否

微分方程 $\left(1+y^{2}\right)\mathrm{d}x+(2x-1)y\mathrm{d}y=0$ 的通解为 ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程可化为可分离变量方程 $\frac{dx}{2x-1} + \frac{y\,dy}{1+y^{2}} = 0$。积分可得 $\frac{1}{2} \ln|2x-1| + \frac{1}{2} \ln(1+y^{2}) = \frac{1}{2} \ln C$，故通解为 $(2x-1)(1+y^{2}) = C$，其中 $C$ 为任意常数。

^q-4489

## 003. 900 第六章数二 A 类 12

- 题目ID：`4490`
- 题号：`3`
- 题源：900 第六章数二 A 类 12
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 简单分离
- 选做：否

微分方程 $y\mathrm{d}x + (16 - x^{2})\mathrm{d}y = 0$ 满足条件 $y(0) = 1$ 的特解为 $y = \_\_\_\_\_\_$.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 题设方程为可分离变量的微分方程。分离变量得 $\frac{dy}{y}=\frac{dx}{x^{2}-16}$。方程两端同时积分可得，$\int\frac{dy}{y}=\int\frac{dx}{x^{2}-16}$。进一步可得 
>
> $$
> \ln\left|y\right|=\int\frac{1}{\left(x-4\right)\left(x+4\right)}\mathrm{d}x=\frac{1}{8}\int\left(\frac{1}{x-4}-\frac{1}{x+4}\right)\mathrm{d}x=\frac{1}{8}\ln\left|\frac{x-4}{x+4}\right|+C,
> $$
>
>  其中 C 为任意常数。由(1)式可得 $y^{8}=e^{c}\left|\frac{x-4}{x+4}\right|$。代入 $y(0)=1$ 可得，$1=e^{c}\cdot1$，解得 C=0。又由于当 -4<x<4 时，$\left|\frac{x-4}{x+4}\right|=\frac{4-x}{x+4}$，故所求特解为 $y=\left(\frac{4-x}{x+4}\right)^{\frac{1}{8}}$。注：$y=\left|\frac{x-4}{x+4}\right|^{\frac{1}{x}}$ 在 $(-\infty,+\infty)$ 上存在间断点 x=-4 以及不可导点 x=4。当 x<-4 或 x≥4 时，$y=\left|\frac{x-4}{x+4}\right|^{\frac{1}{x}}=\left(\frac{x-4}{x+4}\right)^{\frac{1}{x}}$，与 $y=\left(\frac{4-x}{x+4}\right)^{\frac{1}{x}}$ 是不同的函数。所求特解为过点 $(0,1)$ 的一支，即 $y=\left(\frac{4-x}{x+4}\right)^{\frac{1}{x}}$。

^q-4490
