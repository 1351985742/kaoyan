## 001. 1999 数二; 26 版 660 数三第 589 题; 26 版 660 数二第 495 题

- 题目ID：`4502`
- 题号：`1`
- 题源：1999 数二; 26 版 660 数三第 589 题; 26 版 660 数二第 495 题
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 含根号下平方和
- 选做：否

求微分方程 $(y+\sqrt{x^{2}+y^{2}})dx-xdy=0(x>0)$ 满足初始条件 $y(1)=0$ 的解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程可化为 $\frac{d y}{d x}=\frac{y}{x}+\sqrt{1+\left(\frac{y}{x}\right)^{2}}$。令 $u = \frac{y}{x}$，则 $y = u x$，$\frac{d y}{d x} = u + x \frac{d u}{d x}$。代入得 $u + x\frac{d u}{d x} = u + \sqrt{1+u^{2}}$，即 $x\frac{d u}{d x} = \sqrt{1+u^{2}}$。分离变量得 $\int\frac{d u}{\sqrt{1+u^{2}}}=\int\frac{d x}{x}$，积分得 $\ln(u+\sqrt{1+u^{2}}) = \ln x + \ln C$，即 $u+\sqrt{1+u^{2}} = Cx$。代入 $u = \frac{y}{x}$ 得 $\frac{y}{x}+\sqrt{1+\left(\frac{y}{x}\right)^{2}} = Cx$，即 $y+\sqrt{x^{2}+y^{2}} = Cx^{2}$。利用初始条件 $y(1)=0$，得 $0+\sqrt{1+0} = C \cdot 1$，故 $C=1$。代入得 $y+\sqrt{x^{2}+y^{2}} = x^{2}$。移项平方整理得 $x^{4} - 2x^{2}y - x^{2} = 0$，结合 $x>0$ 及初始条件，解得特解为 $y = \frac{x^{2}-1}{2}$。

^q-4502

## 002. 900 第六章数二 A 类 14

- 题目ID：`4503`
- 题号：`2`
- 题源：900 第六章数二 A 类 14
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 含根号下平方和
- 选做：否

微分方程 $(\sqrt{x^{2}+y^{2}}-y)\mathrm{d}x+x\mathrm{d}y=0(x>0)$ 满足条件 $y(1)=0$ 的特解为 $y=$___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 将已知方程移项可得 $(\sqrt{x^{2}+y^{2}}-y)\mathrm{d}x=-x\mathrm{d}y$。于是，$\frac{\mathrm{d}y}{\mathrm{d}x}=\frac{y}{x}-\frac{\sqrt{x^{2}+y^{2}}}{x}=\frac{y}{x}-\sqrt{1+\left(\frac{y}{x}\right)^{2}}$。这是一个齐次方程。令 $u = \frac{y}{x}$，则 $y = u x$，$\frac{d y}{d x} = u + x \frac{d u}{d x}$。代入原方程可得 $u+x\frac{\mathrm{d}u}{\mathrm{d}x}=u-\sqrt{1+u^{2}}$。分离变量得 $-\frac{\mathrm{d}u}{\sqrt{1+u^{2}}}=\frac{\mathrm{d}x}{x}$。方程两端积分可得，$-\ln\left(\sqrt{1+u^{2}}+u\right)=\ln\left|x\right|+C$，即 $\frac{1}{\sqrt{1+u^{2}}+u}=Cx$，其中 C 为待定常数。由于当 $x=1$ 时，$y=0$，$u=0$，故 $C=1$。从而 $\frac{1}{\sqrt{1+u^{2}}+u}=x$，即 $x(\sqrt{1+u^{2}}+u)=1$。代入 $u=\frac{y}{x}$ 可得 $\sqrt{x^{2}+y^{2}}+y=1$。移项后两端平方，整理可得 $x^{2}+2y-1=0$，解得 $y=\frac{1-x^{2}}{2}$。因此，所求特解为 $y=\frac{1-x^{2}}{2}$。

^q-4503

> [!note]- 整理注｜ID 4504（做后或遇歧义时展开）
> 未限定 x>0，提取根式时 √(x²+y²)=|x|√(1+(y/x)²)，必须分 x>0 与 x<0。

## 003. 1996 数三

- 题目ID：`4504`
- 题号：`3`
- 题源：1996 数三
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 含根号下平方和
- 选做：否

求微分方程 $\frac{dy}{dx}=\frac{y-\sqrt{x^{2}+y^{2}}}{x}$ 的通解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $\frac{y}{x}=u$，则 $y=xu$，$\frac{dy}{dx}=u+x\frac{du}{dx}$。代入原方程得 $u+x\frac{du}{dx}=u-\sqrt{1+u^{2}}$，化简得 $\frac{du}{\sqrt{u^{2}+1}}=-\frac{dx}{x}$。积分得 $\ln(u+\sqrt{u^{2}+1})=\ln\frac{c}{x}$，即 $u+\sqrt{u^{2}+1}=\frac{c}{x}$。回代 $u=\frac{y}{x}$，得 $y+\sqrt{x^{2}+y^{2}}=c$（$x<0$ 时）。

^q-4504

> [!note]- 整理注｜ID 4505（做后或遇歧义时展开）
> 同样需明确不跨 x=0 的解区间，不能漏掉绝对值。

## 004. 880 第六章基础填空 4

- 题目ID：`4505`
- 题号：`4`
- 题源：880 第六章基础填空 4
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 含根号下平方和
- 选做：否

微分方程 $xy' = \sqrt{x^2 + y^2} + y$ 的通解为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方程变形为 $y' = \frac{\sqrt{x^{2} + y^{2}}}{x} + \frac{y}{x}$。当 $x>0$ 时，令 $\frac{y}{x}=u$，得 $\frac{du}{\sqrt{1+u^{2}}}=\frac{dx}{x}$，积分得 $y+\sqrt{x^{2}+y^{2}}=Cx^{2}$（$C>0$）。当 $x<0$ 时，类似可得 $-y+\sqrt{x^{2}+y^{2}}=C$（$C>0$）。

^q-4505
