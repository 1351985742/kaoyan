### 锚点题

## 001. 1993 数二

- 题目ID：`4496`
- 题号：`1`
- 题源：1993 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 一阶线性
- 选做：否

求微分方程 $(x^2 - 1)dy + (2xy - \cos x)dx = 0$ 满足初始条件 $y(0) = 1$ 的特解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程可化为 $\frac{dy}{dx}+\frac{2x}{x^{2}-1}y=\frac{\cos x}{x^{2}-1}$，为一阶线性微分方程。通解为 $y=\left[\int\frac{\cos x}{x^{2}-1}\mathrm{e}^{\int\frac{2x}{x^{2}-1}\mathrm{d}x}\mathrm{d}x+C\right]\mathrm{e}^{-\int\frac{2x}{x^{2}-1}\mathrm{d}x} = \left[\int\cos x\mathrm{d}x+C\right]\frac{1}{x^{2}-1} = \frac{\sin x+C}{x^{2}-1}$。代入 $y(0)=1$，得 $1=\frac{C}{-1}$，即 $C=-1$，故特解为 $y=\frac{\sin x-1}{x^{2}-1}$。

## 005. 2008 数二

- 题目ID：`4500`
- 题号：`5`
- 题源：2008 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 一阶线性
- 选做：否

微分方程 $(y+x^{2}e^{-x})dx-x dy=0$ 的通解是 $y=$___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 该微分方程可变形为 $\frac{dy}{dx} - \frac{1}{x}y = x e^{-x}$，这是一阶非齐次线性微分方程。通解公式为 $y = e^{\int -\frac{1}{x} dx} \left[ \int x e^{-x} \cdot e^{\int \frac{1}{x} dx} dx + C \right] = e^{-\ln|x|} \left[ \int x e^{-x} \cdot e^{\ln|x|} dx + C \right] = \frac{1}{|x|} \left[ \int x e^{-x} \cdot |x| dx + C \right]$。分情况讨论：当 $x>0$ 时，$y = \frac{1}{x} \left[ \int x^2 e^{-x} dx + C \right]$，计算积分 $\int x^2 e^{-x} dx = -e^{-x}(x^2+2x+2) + C_1$，代入得 $y = \frac{1}{x} \left[ -e^{-x}(x^2+2x+2) + C \right] = -e^{-x}(x+2+\frac{2}{x}) + \frac{C}{x}$。当 $x<0$ 时，$y = -\frac{1}{x} \left[ \int -x^2 e^{-x} dx + C \right] = \frac{1}{x} \left[ \int x^2 e^{-x} dx + C \right]$，积分结果相同，故通解形式一致。通常写为 $y = -e^{-x}(x+2+\frac{2}{x}) + \frac{C}{x}$，其中 $C$ 为任意常数。

^q-4500

## 006. 880 第六章基础填空 1

- 题目ID：`4501`
- 题号：`6`
- 题源：880 第六章基础填空 1
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 一阶线性
- 选做：否

微分方程 $(y - x\sin x)dx + xdy = 0$ 的通解为___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程变形为 $\frac{dy}{dx} + \frac{1}{x}y = \sin x$，为一阶线性微分方程，故通解为 
>
> $$
> \begin{aligned}y&=\mathrm{e}^{-\int P(x)\mathrm{d}x}\left[\int Q(x)\mathrm{e}^{\int P(x)\mathrm{d}x}\mathrm{d}x+C\right]=\mathrm{e}^{-\int\frac{1}{x}\mathrm{d}x}\left(\int\sin x\cdot\mathrm{e}^{\int\frac{1}{x}\mathrm{d}x}\mathrm{d}x+C\right)\\&=\mathrm{e}^{-\ln|x|}\left(\int\mathrm{e}^{\ln|x|}\sin x\mathrm{d}x+C\right)\\&=\frac{1}{x}\left(\int x\sin x\mathrm{d}x+C\right)=\frac{1}{x}(\sin x-x\cos x+C)(C \text{为任意常数}).\end{aligned}
> $$
>
>  注：① 若令 $P = y - x \sin x$， $Q = x$，则 $\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y} = 1$，所以该方程为全微分方程，故通解为 $\int_{0}^{x}P(x,0)\mathrm{d}x+\int_{0}^{y}Q(x,y)\mathrm{d}y=C$，即 $\int_{0}^{x}(0-x\sin x)\mathrm{d}x+\int_{0}^{y}x\mathrm{d}y=C$。故 $x \cos x - \sin x + xy = C$ 为通解。② $P(x,y)\mathrm{d}x+Q(x,y)\mathrm{d}y=0$，当 $\frac{\partial Q}{\partial x}=\frac{\partial P}{\partial y}$ 时，该方程为全微分方程，有通解公式 
>
> $$
> \int_{x_{0}}^{x}P(x,y_{0})\mathrm{d}x+\int_{y_{0}}^{y}Q(x,y)\mathrm{d}y=C.
> $$

^q-4501

## 路径 P2｜标准一阶线性式的积分因子

触发规则：y′+p(x)y=q(x) → 在合法区间标准化，乘 μ=e^(∫p)。

> [!tip]- 本路径边界与止损
> 先除最高阶系数可能漏奇点；常数在不同区间不自动相同。
> 若原式已有乘积导数，直接认出 μy，少做公式展开。

## 002. 1990 数二

- 题目ID：`4497`
- 题号：`2`
- 题源：1990 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 一阶线性
- 选做：否

求微分方程 $x \ln x \, \mathrm{d}y + (y - \ln x) \, \mathrm{d}x = 0$ 满足条件 $y|_{x=e} = 1$ 的特解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方程化为 $y'+\frac{1}{x\ln x}y=\frac{1}{x}$（$x \neq 1$）。通解为 $y=\mathrm{e}^{-\int\frac{1}{x\ln x}\mathrm{d}x}\left[C+\int\frac{1}{x}\mathrm{e}^{\int\frac{1}{x\ln x}\mathrm{d}x}\mathrm{d}x\right] = \frac{1}{\ln x}\left(C+\int\ln x \, d\ln x\right) = \frac{1}{\ln x}\left(C+\frac{1}{2}\ln^{2}x\right)$。代入 $x=e, y=1$，得 $1 = C + \frac{1}{2}$，解得 $C = \frac{1}{2}$，故特解为 $y=\frac{1}{2\ln x}\left(1+\ln^{2}x\right) = \frac{1}{2}\left(\frac{1}{\ln x}+\ln x\right)$。

## 003. 1992 数二

- 题目ID：`4498`
- 题号：`3`
- 题源：1992 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 一阶线性
- 选做：否

求微分方程 $(y-x^{3})dx-2x dy=0$ 的通解。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原方程化为 $y'-\frac{1}{2x}y=-\frac{x^{2}}{2}$，为一阶线性方程。通解为 $y=\mathrm{e}^{\int\frac{1}{2x}\mathrm{d}x}\left(\int\left(-\frac{x^{2}}{2}\right)\mathrm{e}^{\int-\frac{1}{2x}\mathrm{d}x}\mathrm{d}x+C\right) = \mathrm{e}^{\frac{\ln|x|}{2}}\left(-\frac{1}{2}\int x^{2} \cdot |x|^{-\frac{1}{2}} \mathrm{d}x + C\right)$。积分得通解为 $y = \sqrt{|x|}\left(-\frac{1}{2} \cdot \frac{2}{5}x^{\frac{5}{2}} + C\right) = -\frac{1}{5}x^{3} + C\sqrt{|x|}$，其中 $C$ 为任意常数。

## 004. 2004 数二

- 题目ID：`4499`
- 题号：`4`
- 题源：2004 数二
- 分类：高等数学 / 微分方程 / 解微分方程 / 一阶 / 有显著特征 / 框框 dx 框框 dy / 一阶线性
- 选做：否

微分方程 $(y+x^{3})dx-2x dy=0$ 满足 $y\big|_{x=1}=\frac{6}{5}$ 的特解为___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 第一步：确定微分方程的类型。由 $(y + x^3) \, \mathrm{d}x - 2x \, \mathrm{d}y = 0$，变形为 $\frac{\mathrm{d}y}{\mathrm{d}x} - \frac{1}{2x}y = \frac{1}{2}x^2$，这是一阶非齐次线性微分方程。第二步：解微分方程。由通解公式，得 $y=\mathrm{e}^{\int\frac{1}{2x}\mathrm{d}x}\left[\int\frac{1}{2}x^{2}\cdot\mathrm{e}^{\int-\frac{1}{2x}\mathrm{d}x}\mathrm{d}x+C\right]$。分情况讨论：① 当 $x > 0$ 时，$y=\sqrt{x}\left(\int\frac{1}{2}x^{\frac{3}{2}}\mathrm{d}x+C\right)=\sqrt{x}\left(\frac{1}{5}x^{\frac{5}{2}}+C\right)=\frac{1}{5}x^{3}+C\sqrt{x}$。② 当 $x < 0$ 时，$y=\sqrt{-x}\left(-\int\frac{1}{2}(-x)^{\frac{3}{2}}\mathrm{d}(-x)+C\right)=\sqrt{-x}\left(-\frac{1}{5}(-x)^{\frac{5}{2}}+C\right)=\frac{1}{5}x^{3}+C\sqrt{-x}$。综合得 $y = \frac{1}{5} x^{3} + C \sqrt{|x|}$。代入初始条件 $y|_{x=1}=\frac{6}{5}$，得 $\frac{1}{5}+C=\frac{6}{5}$，解得 $C = 1$。由于初始条件 $x=1>0$，故特解为 $y=\frac{1}{5}x^{3}+\sqrt{x}$。

^q-4499
