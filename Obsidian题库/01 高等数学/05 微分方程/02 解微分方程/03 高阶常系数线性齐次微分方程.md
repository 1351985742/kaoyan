## 001. 900 第六章数二 C 类 2

- 题目ID：`4522`
- 题号：`1`
- 题源：900 第六章数二 C 类 2
- 分类：高等数学 / 微分方程 / 解微分方程 / 高阶常系数线性齐次微分方程
- 选做：否

已知函数 $y(x)$ ($x > 0$, $y(x) > 0$) 满足微分方程 $y^{x}\left(\ln y + \frac{xy'}{y} + 1\right) = e^{-x}$，且 $y(1) = e^{-1}$，求 $y(x)$ 的表达式。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由方程 $y^{x}\left(\ln y + \frac{xy'}{y} + 1\right) = e^{-x}$，注意到 $\frac{d}{dx}(y^x) = y^x \ln y + x y^{x-1} y' = y^x \left(\ln y + \frac{xy'}{y}\right)$，因此原方程可写为 $\frac{d}{dx}(y^x) + y^x = e^{-x}$。令 $u = y^x$，则方程化为 $u' + u = e^{-x}$。解此一阶线性微分方程，通解为 $u = e^{-x}(x + C)$。由 $y(1) = e^{-1}$ 得 $u(1) = y(1)^1 = e^{-1}$，代入得 $e^{-1} = e^{-1}(1 + C)$，解得 $C = 0$。故 $u = x e^{-x}$，即 $y^x = x e^{-x}$，取对数得 $x \ln y = \ln x - x$，所以 $\ln y = \frac{\ln x}{x} - 1$，因此 $y(x) = e^{\frac{\ln x}{x} - 1} = \frac{x^{1/x}}{e}$。
