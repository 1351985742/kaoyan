## 001. 1990 数二

- 题目ID：`1623`
- 题号：`1`
- 题源：1990 数二
- 分类：高等数学 / 一元微分 / 导数应用 / 切法线 / 参数方程表示的曲线
- 选做：否

曲线 $\begin{cases}x=\cos^{3}t,\\y=\sin^{3}t\end{cases}$上对应于 $t=\frac{\pi}{6}$处的法线方程是___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 曲线上对应于 $t = \frac{\pi}{6}$ 的点的直角坐标为 $\left(\frac{3\sqrt{3}}{8},\ \frac{1}{8}\right)$。切线斜率 $k_{斜}=\frac{dy}{dx}=\frac{\frac{dy}{dt}}{\frac{dx}{dt}}=\frac{3\sin^{2}t\cos t}{-3\cos^{2}t\sin t} = -\tan t$，代入 $t = \frac{\pi}{6}$ 得 $k_{斜} = -\frac{1}{\sqrt{3}}$。法线斜率为 $\sqrt{3}$，故法线方程为 $y-\frac{1}{8}=\sqrt{3}\left(x-\frac{3\sqrt{3}}{8}\right)$，化简得 $y = \sqrt{3}x - 1$。

## 002. 1995 数二

曲线 $\begin{cases}x=1+t^{2},\\y=t^{3}\end{cases}$在t=2处的切线方程为___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 当 $t = 2$ 时， $x = 1 + t^2 = 5$， $y = t^3 = 8$。切线斜率 $\left.\frac{\mathrm{d}y}{\mathrm{d}x}\right|_{t=2} = \left.\frac{\frac{\mathrm{d}y}{\mathrm{d}t}}{\frac{\mathrm{d}x}{\mathrm{d}t}}\right|_{t=2} = \left.\frac{3t^{2}}{2t}\right|_{t=2} = 3$。因此，切线方程为 $y - 8 = 3(x - 5)$，即 $y = 3x - 7$.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 当 x = 0, y = 1 时，t = 0。切线斜率 $\left.\frac{dy}{dx}\right|_{t=0}=\left.\frac{\frac{dy}{dt}}{\frac{dx}{dt}}\right|_{t=0} = \left.\frac{\mathrm{e}^{t}\cos t-\mathrm{e}^{t}\sin t}{\mathrm{e}^{t}\sin2t+2\mathrm{e}^{t}\cos2t}\right|_{t=0} = \frac{1}{2}$。法线斜率为 -2，法线方程为 $y - 1 = -2x$，即 $y + 2x - 1 = 0$.

## 004. 2005 数二

- 题目ID：`1626`
- 题号：`4`
- 题源：2005 数二
- 分类：高等数学 / 一元微分 / 导数应用 / 切法线 / 参数方程表示的曲线
- 选做：否

设函数 $y = y(x)$ 由参数方程 $\begin{cases} x = t^{2} + 2t, \\ y = \ln(1 + t) \end{cases}$ 确定，则曲线 $y = y(x)$ 在 x = 3 处的法线与 x 轴交点的横坐标是（）。

### 选项

A. $\frac{1}{8}\ln2+3$
B. $-\frac{1}{8}\ln2+3$
C. $-8\ln2+3$
D. $8\ln2+3$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 当 x = 3 时，由 $t^{2} + 2t = 3$ 且 $1 + t > 0$ 得 t = 1，此时 $y = \ln 2$。导数 $y' = \frac{dy}{dx} = \frac{y'(t)}{x'(t)} = \frac{\frac{1}{1+t}}{2t+2} = \frac{1}{2(t+1)^{2}}$，故 $y'(3)=\left.\frac{1}{2(t+1)^{2}}\right|_{t=1}=\frac{1}{8}$。法线斜率为 -8，法线方程为 $y - \ln 2 = -8(x - 3)$，即 $y = -8x + 24 + \ln 2$。令 y = 0，解得 $x = \frac{24 + \ln 2}{8} = 3 + \frac{\ln 2}{8}$。

> **解析**

## 011. 900 第二章数二 A 类 54

- 题目ID：`1633`
- 题号：`11`
- 题源：900 第二章数二 A 类 54
- 分类：高等数学 / 一元微分 / 导数应用 / 切法线 / 参数方程表示的曲线
- 选做：否

设曲线 L 的参数方程为 $\begin{cases} x = \ln \tan \frac{t}{2} + \cos t, \\ y = \sin t, \end{cases}$ 其中 $\frac{\pi}{2} < t < \pi$，则曲线上一点 M 处的切线与 x 轴的交点 P 与点 M 之间的距离为 ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 计算 $\frac{dy}{dx} = \frac{\mathrm{d}y}{\mathrm{d}t}\bigg/\frac{\mathrm{d}x}{\mathrm{d}t}=\frac{\cos t}{\frac{1}{\tan\frac{t}{2}}\cdot\sec^{2}\frac{t}{2}\cdot\frac{1}{2}-\sin t}=\frac{\cos t}{\frac{1}{\sin t}-\sin t}=\tan t$。点 $M(x,y)$ 处的切线方程为 $Y-\sin t=\tan t\left[X-\left(\ln\tan\frac{t}{2}+\cos t\right)\right]$。令 $Y = 0$，得 $X = \ln \tan \frac{t}{2} + \cos t - \frac{\sin t}{\tan t} = \ln \tan \frac{t}{2}$。因此，$|P M| = \sqrt{\left(X-x\right)^{2}+y^{2}} = \sqrt{\left(-\cos t\right)^{2}+\sin^{2}t} = 1$。
