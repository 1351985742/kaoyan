## 001. 1987 数二

- 选做：否

曲线 $y = \arctan x$ 在横坐标为 1 的点处的切线方程是 ___；法线方程是 ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 已知曲线 $y = \arctan x$，则 $y' = \frac{1}{1 + x^{2}}$。故当 $x = 1$ 时，有： $y(1)=\arctan1=\frac{\pi}{4}$， $y'(1)=\frac{1}{1+1^{2}}=\frac{1}{2}$。则曲线 $y = \arctan x$ 在横坐标为 1 的点处的切线方程为： $y - \frac{\pi}{4} = \frac{1}{2}(x - 1)$。又由于在某点处的切线与法线是垂直的，即这两条线的斜率乘积为 -1 ，故 $x = 1$ 处的法线斜率为 -2 ，从而知法线方程为： $y - \frac{\pi}{4} = -2(x - 1)$。

## 002. 1988 数二

$f(x)=\frac{1}{3}x^{3}+\frac{1}{2}x^{2}+6x+1$ 的图形在点 $(0,1)$ 处的切线与 $x$ 轴交点坐标是（）

### 选项

A. $\left(-\frac{1}{6},0\right)$
B. $(-1,0)$
C. $\left(\frac{1}{6},0\right)$
D. $(1,0)$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 第一步：求切线方程。 $f(x) = \frac{1}{3}x^3 + \frac{1}{2}x^2 + 6x + 1$，则 $f'(x) = x^2 + x + 6$，故 $f'(0) = 6$。则 $f(x)$ 在点 $(0, 1)$ 处的切线方程为 $y - 1 = f'(0)(x - 0)$，即 $y - 1 = 6x$。第二步：得出结果。令 $y = 0$，则 $-1 = 6x$，解得 $x = -\frac{1}{6}$，所以此切线与 $x$ 轴的交点坐标为 $\left(-\frac{1}{6}, 0\right)$。故本题应选(A)。

## 005. 1991 数二

- 题目ID：`1605`

- 选做：否

若曲线 $y = x^{2} + ax + b$ 和 $2y = -1 + xy^{3}$ 在点 $(1, -1)$ 处相切，其中 a, b 是常数，则（）

### 选项

A. a=0,b=-2
B. a=1,b=-3
C. a=-3,b=1
D. a=-1,b=-1

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 对第一条曲线有 $y' = 2x + a$， $y'\big|_{x=1} = 2 + a$。对第二条曲线，利用隐函数求导： $2y' = y^3 + x \cdot 3y^2 \cdot y'$，解得 $y' = \frac{y^3}{2 - 3xy^2}$， $y'\big|_{x=1} = 1$。因为两曲线在该点处相切，故斜率相等，所以 $2 + a = 1$，解得 $a = -1$。同时，两曲线均经过点 $(1, -1)$，故 $-1 = 1 + a + b$，解得 $b = -1$。故 $a = -1$， $b = -1$。选 $(D)$。

## 006. 1991 数三

设曲线 $f(x)=x^{3}+ax$ 与 $g(x)=bx^{2}+c$ 都通过点 $(-1,0)$，且在点 $(-1,0)$ 有公共切线，则 $a=$ ___， $b=$ ___， $c=$ ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由 $f(x)=x^{3}+ax$ 与 $g(x)=bx^{2}+c$ 都通过点 $(-1,0)$ 知， $f(-1) = -1 - a = 0$， $g(-1) = b + c = 0$，解得 $a = -1$， $c = -b$。由 $f(x)$ 和 $g(x)$ 在点 $(-1, 0)$ 有公共切线知， $f'(-1) = g'(-1)$。又 $f'(x) = 3x^{2} + a$， $g'(x) = 2bx$，则 $f'(-1) = 3 + a = 3 - 1 = 2$， $g^{\prime}(-1)=-2b$。故 $-2b = 2$，解得 $b = -1$，则 $c = -b = 1$。综上，$a = -1, b = -1, c = 1$。

> 无
>
> **解析**
>

## 014. 900 第二章数二 B 类 29

- 题目ID：`1614`
- 题号：`14`
- 题源：900 第二章数二 B 类 29
- 分类：高等数学 / 一元微分 / 导数应用 / 切法线 / 普通曲线
- 选做：否

设函数 $f(x)=x\ln x+\frac{\mathrm{e}}{6}x^{3}-\frac{\mathrm{e}}{2}x^{2}+\left(\frac{\mathrm{e}}{2}-1\right)x-\frac{\mathrm{e}}{6}$，$g(x)=x(\ln x-1)+\mathrm{e}^{x}-\mathrm{e}x$。若曲线 $y = f(x)$ 与 $y = g(x)$ 相切于一点，则它们的公共切线的方程为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 分别对 $f(x)$，$g(x)$ 求导，得到 $f^{\prime}(x)=\ln x+\frac{\mathrm{e}}{2}x^{2}-\mathrm{e}x+\frac{\mathrm{e}}{2}=\ln x+\frac{\mathrm{e}}{2}(x-1)^{2}$，$g^{\prime}(x)=\ln x+\mathrm{e}^{x}-\mathrm{e}$。记 $h(x) = f'(x) - g'(x)$，则 $h(x) = \frac{\mathrm{e}}{2}(x-1)^{2} - \mathrm{e}^{x} + \mathrm{e}$。观察可知 $h(1) = 0$。此时 $f'(1) = g'(1) = 0$。并且，$h'(x) = \mathrm{e}(x-1) - \mathrm{e}^{x} = \mathrm{e}(x-1 - \mathrm{e}^{x-1}) < 0$，故 $h(x)$ 单调减少。于是 $h(x) = 0$ 当且仅当 $x = 1$ 时成立。由此可知，曲线 $y = f(x)$，$y = g(x)$ 在 $x = 1$ 处的切线斜率相等，且斜率均为 0。又因为 $f(1) = g(1) = -1$，所以 $y = f(x)$，$y = g(x)$ 在点 $(1, -1)$ 处有公共切线。因此，公共切线的方程为 $y = -1$。

>
> **解析**
>

> $$

> $$
