## 001. 880 第二章综合解答 25; 26 版 660 数二第 553 题

- 题目ID：`1640`
- 题号：`1`
- 题源：880 第二章综合解答 25; 26 版 660 数二第 553 题
- 分类：高等数学 / 一元微分 / 导数应用 / 切法线 / 切线在 x 轴上的截距
- 选做：否

设 $f(x)$ 有二阶连续导数， $f(0)=f'(0)=0,f''(0)>0,u=u(x)$ 是曲线 $y=f(x)$ 在点 $(x,f(x))$ 处的切线在 x 轴上的截距，求 $\lim_{x\to0}\frac{x}{u(x)}$

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设切线方程为 $Y - f(x) = f'(x)(X - x)$，令 $Y=0$，得 $u = X = x - \frac{f(x)}{f'(x)}$。则 $I = \lim\limits_{x\rightarrow0}\frac{x}{x-\frac{f(x)}{f'(x)}} = \lim\limits_{x\rightarrow0}\frac{1}{1-\frac{f(x)}{x f'(x)}}$。由泰勒展开，$f(x) = \frac{f''(0)}{2}x^{2}+o(x^{2})$，$f'(x) = f''(0)x+o(x)$，故 $\lim\limits_{x\rightarrow0}\frac{f(x)}{x f'(x)} = \lim\limits_{x\rightarrow0}\frac{\frac{f''(0)}{2}x^{2}+o(x^{2})}{x[f''(0)x+o(x)]} = \frac{1}{2}$。因此 $I = \frac{1}{1-\frac{1}{2}} = 2$。

## 002. 全国大学生 2012 年竞赛题

- 题目ID：`1641`
- 题号：`2`
- 题源：全国大学生 2012 年竞赛题
- 分类：高等数学 / 一元微分 / 导数应用 / 切法线 / 切线在 x 轴上的截距
- 选做：否

设 $f(x)$ 二阶可导，且 $f(0)=0,\quad f'(0)=0,\quad f''(x)>0$。若曲线 $y = f(x)$ 在点 $P(x, f(x))$ 处的切线在 x 轴上的截距为 u，求极限 $\lim_{x \to 0} \frac{x^3 f(u)}{f(x) \sin^3 u}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设切线方程为 $Y - f(x) = f'(x)(X - x)$，令 $Y = 0$，得 $u = X = x - \frac{f(x)}{f'(x)}$。由泰勒展开，$f(x) = \frac{f''(0)}{2}x^{2}+o(x^{2})$，$f'(x) = f''(0)x+o(x)$，可得 $\lim_{x\to0}\frac{u}{x}=1-\lim_{x\to0}\frac{f(x)}{xf'(x)}=1-\frac{1}{2}=\frac{1}{2}$。因此 $\lim_{x\to0}\frac{x^{3}f(u)}{f(x)\sin^{3}u} = \lim_{x\to0}\frac{x^{3}\left[\frac{f''(0)}{2}u^{2}+o(u^{2})\right]}{u^{3}\left[\frac{f''(0)}{2}x^{2}+o(x^{2})\right]} = \lim_{x\to0}\frac{x}{u} = 2$。

## 003. 26 版 ☀️ 1000 第五章强化 25

- 题目ID：`1642`
- 题号：`3`
- 题源：26 版 ☀️ 1000 第五章强化 25
- 分类：高等数学 / 一元微分 / 导数应用 / 切法线 / 切线在 x 轴上的截距
- 选做：否

设 $y = \tan^{n}x$ 在 $x = \frac{\pi}{4}$ 处的切线在 x 轴上的截距为 $x_{n}$，则 $\lim_{n \to \infty} y(x_{n}) =$ ___。

> [!success]- 答案解析
> **答案**
>
> $e^{-1}$
>
> **解析**
>
> 先求 $y = \tan^{n}x$ 在点 $M\left(\frac{\pi}{4}, 1\right)$ 处的切线方程。由 $y'\left(\frac{\pi}{4}\right)=n\tan^{n-1}x\cdot\sec^{2}x\bigg|_{x=\frac{\pi}{4}}=2n$，得切线方程 $y-1=2n\Big(x-\frac{\pi}{4}\Big)$。在 x 轴上的截距为 $x_{n}=\frac{\pi}{4}-\frac{1}{2n}$。故 $\lim_{n\to\infty}y(x_{n})=\lim_{n\to\infty}\tan^{n}\left(\frac{\pi}{4}-\frac{1}{2n}\right) \xlongequal{1^{\infty}}e^{A}$，其中 $A = \lim_{n\rightarrow\infty}\left[\tan\left(\frac{\pi}{4}-\frac{1}{2n}\right)-1\right] = \lim_{n\rightarrow\infty}\frac{\tan\left(\frac{\pi}{4}-\frac{1}{2n}\right)-\tan\frac{\pi}{4}}{\frac{1}{n}} = -\left.\frac{1}{2}(\tan x)'\right|_{x=\frac{\pi}{4}} = -\left.\frac{1}{2}\bullet\frac{1}{\cos^{2}x}\right|_{x=\frac{\pi}{4}} = -1$。因此极限为 $e^{-1}$。
