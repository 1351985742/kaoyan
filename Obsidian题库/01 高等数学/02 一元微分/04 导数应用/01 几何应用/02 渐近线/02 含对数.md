## 001. 25 版 660 数一二三第 48 题

- 题目ID：`1664`
- 题号：`1`
- 题源：25 版 660 数一二三第 48 题
- 分类：高等数学 / 一元微分 / 导数应用 / 渐近线 / 含对数
- 选做：否

曲线 $y = \sqrt{4x^{2} + x}\ln\left(2 + \frac{1}{x}\right)$ 的全部渐近线是 ___.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 定义域：$4x^{2}+x\geq0, x(4x+1)\geq0 \Rightarrow x\geq0$ 或 $x\leq-\frac{1}{4}$，且 $2+\frac{1}{x}>0\Rightarrow x>0$ 或 $x<-\frac{1}{2}$，综合得 $x>0$ 或 $x<-\frac{1}{2}$。\n无水平渐近线。\n垂直渐近线：$\lim\limits_{x\to(-\frac{1}{2})^{-}} f(x) = -\infty$，故 $x=-\frac{1}{2}$ 为垂直渐近线。\n斜渐近线：\n当 $x\to+\infty$ 时，$k = \lim\limits_{x\to+\infty} \frac{f(x)}{x} = \lim\limits_{x\to+\infty} \frac{\sqrt{4x^{2}+x}}{x} \ln\left(2+\frac{1}{x}\right) = 2\ln 2$，\n$b = \lim\limits_{x\to+\infty} [f(x) - kx] = \lim\limits_{x\to+\infty} \left[ \sqrt{4x^{2} + x} \ln\left(2+\frac{1}{x}\right) - 2\ln 2 \cdot x \right] = \frac{\ln 2}{4} + 1$，\n故右侧斜渐近线为 $y = 2\ln 2 \cdot x + \frac{\ln 2}{4} + 1$。\n由对称性或类似计算可得左侧斜渐近线为 $y = -2\ln 2 \cdot x - \frac{\ln 2}{4} - 1$。

## 002. 26 版 1000 第五章强化 18

- 题目ID：`1665`
- 题号：`2`
- 题源：26 版 1000 第五章强化 18
- 分类：高等数学 / 一元微分 / 导数应用 / 渐近线 / 含对数
- 选做：否

曲线 $y = x^2 \ln \left( \sin \frac{1}{x} + \cos \frac{1}{x} \right)$ 的斜渐近线为 ___.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设斜渐近线为 $y = ax + b$。\n$a = \lim\limits_{x\to\infty} \frac{f(x)}{x} = \lim\limits_{x\to\infty} \frac{x^2 \ln\left( \sin\frac{1}{x} + \cos\frac{1}{x} \right)}{x} = \lim\limits_{x\to\infty} x \ln\left( \sin\frac{1}{x} + \cos\frac{1}{x} \right) = \lim\limits_{x\to\infty} \ln\left( 1 + \sin\frac{2}{x} \right)^{\frac{x}{2}} = \ln e = 1$。\n$b = \lim\limits_{x\to\infty} [f(x) - ax] = \lim\limits_{x\to\infty} \left[ x^2 \ln\left( \sin\frac{1}{x} + \cos\frac{1}{x} \right) - x \right] = \lim\limits_{t\to0} \frac{\ln(\sin t + \cos t) - t}{t^2} = -1$。\n所以斜渐近线为 $y = x - 1$。

^q-1665
## 003. 900 第二章数二 A 类 23

- 题目ID：`1666`
- 题号：`3`
- 题源：900 第二章数二 A 类 23
- 分类：高等数学 / 一元微分 / 导数应用 / 渐近线 / 含对数
- 选做：否

曲线 $y = x \ln \frac{x}{x - 1} + \ln [x(x - 1)]$ 的渐近线的条数为()

### 选项

A. 0
B. 1
C. 2
D. 3

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 记 $f(x) = x \ln \frac{x}{x - 1} + \ln [x(x - 1)]$，定义域为 $(-\infty, 0) \cup (1, +\infty)$。\n垂直渐近线：$\lim\limits_{x\to0^{-}} f(x) = -\infty$，故 $x=0$ 为铅直渐近线。$\lim\limits_{x\to1^{+}} f(x) = 0$，故 $x=1$ 处无铅直渐近线。\n水平/斜渐近线：$\lim\limits_{x\to\infty} f(x) = \infty$，无水平渐近线。$\lim\limits_{x\to\infty} \frac{f(x)}{x} = 0$，故无斜渐近线。\n综上所述，曲线共有1条渐近线。

^q-1666
