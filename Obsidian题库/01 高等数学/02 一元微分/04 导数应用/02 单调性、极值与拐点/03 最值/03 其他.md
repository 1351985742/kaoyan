在第一象限内求曲线 $y = -x^{2} + 1$ 上的一点，使该点处的切线与所给曲线及两坐标轴所围成的图形面积为最小，并求此最小面积。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设切点横坐标为 $a$，则切点坐标为 $(a, -a^{2} + 1)$。曲线导数为 $y' = -2x$，切线斜率 $k = -2a$，切线方程为 $y-\left(1-a^{2}\right)=-2a(x-a)$。切线与坐标轴交点为 $(0, a^{2} + 1)$ 和 $\left(\frac{a^{2} + 1}{2a}, 0\right)$。所围图形面积 $s = \frac{1}{2}(a^{2} + 1)\frac{a^{2} + 1}{2a} - \int_{0}^{1}(-x^{2} + 1)dx = \frac{a^{3}}{4} + \frac{a}{2} + \frac{1}{4a} - \frac{2}{3}$。对 $s(a)$ 求导并令导数为零可求得使面积最小的 $a$ 值，进而求得最小面积。

## 003. 1993 数二

作半径为 $r$ 的球的外切正圆锥，问此圆锥的高 $h$ 为何值时，其体积 $V$ 最小，并求出该最小值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设圆锥底面圆半径为 $R$，如图所示。因 $\frac{BC}{SC} = \frac{OD}{SD}$，故 $\frac{R}{h} = \frac{r}{\sqrt{(h-r)^{2}-r^{2}}}$，从而 $R=\frac{rh}{\sqrt{h^{2}-2hr}}$。于是圆锥体积为 $V(h)=\frac{\pi}{3}R^{2}h=\frac{\pi r^{2}}{3}\frac{h^{2}}{h-2r}(2r<h<+\infty)$。因 $V'(h)=\frac{\pi r^{2}}{3}\frac{h^{2}-4rh}{(h-2r)^{2}}=\frac{\pi r^{2}}{3}\frac{h(h-4r)}{(h-2r)^{2}}$，故解 $V'(h)=0$ 得 $h=4r$，$h=0$ (舍去)。由于圆锥的最小体积一定存在，且 $h = 4r$ 是 $V(h)$ 在 $(2r, +\infty)$ 内的唯一驻点，所以当 $h = 4r$ 时，$V$ 取最小值 $V(4r) = \frac{\pi r^2}{3} \frac{(4r)^2}{(4r - 2r)} = \frac{8\pi r^3}{3}$。

## 004. 26版660数一二三第41题

- 题目ID：`1801`
- 题号：`4`
- 题源：26版660数一二三第41题
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 最值 / 其他
- 选做：否

过曲线 $y = 1 - x^{2}$ 上在第一象限内的点 $(\xi, \eta)$ 作该曲线的切线，交两坐标轴的正向构成三角形。要使此三角形的面积为最小，则该切点的坐标 $(\xi, \eta) =$ ___。

> [!success]- 答案解析
> **答案**
>
> $\left(\frac{1}{\sqrt{3}},\frac{2}{3}\right)$
>
> **解析**
>
> 设切点坐标 $(\xi,\eta)$，其中 $\xi>0,\eta=1-\xi^{2}$。切线方程为 $y-\eta=-2\xi(x-\xi)$。在两坐标轴上的截距分别为 $X=\frac{\eta}{2\xi}+\xi=\frac{1+\xi^{2}}{2\xi}$，$Y=\eta+2\xi^{2}=1+\xi^{2}$。三角形面积为 $A=\frac{1}{2}XY=\frac{(1+\xi^{2})^{2}}{2\xi}$，$0<\xi<1$。$\frac{\mathrm{d}A}{\mathrm{d}\xi}=\frac{(1+\xi^{2})(3\xi^{2}-1)}{2\xi^{2}}$。令 $\frac{dA}{d\xi}=0$，得 $\xi=\frac{1}{\sqrt{3}}$。当 $0<\xi<\frac{1}{\sqrt{3}}$时，$\frac{dA}{d\xi}<0$；当 $\xi>\frac{1}{\sqrt{3}}$时，$\frac{dA}{d\xi}>0$。所以当 $\xi=\frac{1}{\sqrt{3}}$时$A$取极小值。由于驻点唯一，故此时$A$也是最小值。相应地 $\eta=1-\xi^{2}=\frac{2}{3}$。

## 005. 900 第二章数二 A 类 72

- 题目ID：`1802`
- 题号：`5`
- 题源：900 第二章数二 A 类 72
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 最值 / 其他
- 选做：否

在椭圆 $\frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 (a > 0, b > 0, a \neq b)$ 位于第一象限的部分上求一点 $P$，使得该点处的法线与两坐标轴所围成的三角形面积最大。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 先求点 $(x,y)$处的切线斜率。对 $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1$两端关于$x$求导可得，$\frac{2x}{a^{2}}+\frac{2yy^{\prime}}{b^{2}}=0$。解得 $y^{\prime}=-\frac{b^{2}}{a^{2}}\cdot\frac{x}{y}$。由同一点处的切线与法线相互垂直，斜率乘积为$-1$可得，点 $(x,y)$处的法线斜率为 $-\frac{1}{y^{\prime}}=\frac{a^{2}}{b^{2}}\cdot\frac{y}{x}$。于是，点 $(x,y)$处的法线方程为 $Y=\frac{a^{2}y}{b^{2}x}(X-x)+y$。分别计算该法线在两坐标轴上的截距。在法线方程中令 $X = 0$，可得 $Y_{0} = \left(1 - \frac{a^{2}}{b^{2}}\right)y$。在法线方程中令 $Y = 0$，可得 $X_{0} = \left(1 - \frac{b^{2}}{a^{2}}\right)x$。由此可得，点 $(x, y)$ 处的法线与两坐标轴所围成三角形的面积 $S=\frac{1}{2}\mid X_{0}\mid\mid Y_{0}\mid=\frac{1}{2}\Bigm\vert\Bigm(1-\frac{a^{2}}{b^{2}}\Big)y\cdot\Bigm(1-\frac{b^{2}}{a^{2}}\Big)x\Bigm\vert=\frac{1}{2}\cdot\frac{(b^{2}-a^{2})^{2}}{a^{2}b^{2}}xy$。由 $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1$以及$y>0$可得，$y=b\sqrt{1-\frac{x^{2}}{a^{2}}}=\frac{b}{a}\sqrt{a^{2}-x^{2}}$。于是，$S=\frac{\left(b^{2}-a^{2}\right)^{2}}{2a^{3}b}x\sqrt{a^{2}-x^{2}}$。令 $f(x) = x \sqrt{a^{2} - x^{2}}, 0 < x < a$。$f^{\prime}(x)=\sqrt{a^{2}-x^{2}}+x\cdot\frac{-x}{\sqrt{a^{2}-x^{2}}}=\frac{a^{2}-2x^{2}}{\sqrt{a^{2}-x^{2}}}$。解 $f'(x)=0$ 可得 $x=\frac{a}{\sqrt{2}}$。当 $0<x<\frac{a}{\sqrt{2}}$ 时，$f'(x)>0$，$f(x)$ 单调增加；当 $\frac{a}{\sqrt{2}}<x<a$ 时，$f'(x)<0$，$f(x)$ 单调减少。因此，当 $x = \frac{a}{\sqrt{2}}$ 时，$f(x)$ 取得最大值，最大值为 $f\left(\frac{a}{\sqrt{2}}\right) = \frac{a}{\sqrt{2}} \cdot \sqrt{a^{2} - \frac{a^{2}}{2}} = \frac{a^{2}}{2}$，从而 $S$ 的最大值为 $\frac{(b^{2} - a^{2})^{2}}{2a^{3}b} \cdot \frac{a^{2}}{2} = \frac{(b^{2} - a^{2})^{2}}{4ab}$。

## 006. 26 版 660 数一二三第 157 题; 26 版 1000 第五章基础 13

- 题目ID：`1803`
- 题号：`6`
- 题源：26 版 660 数一二三第 157 题; 26 版 1000 第五章基础 13
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 最值 / 其他
- 选做：否

数列 $1,\sqrt{2},\sqrt[3]{3},\cdots,\sqrt[n]{n},\cdots$ 的最大项为

### 选项

A. $\sqrt{2}$
B. $\sqrt[3]{3}$
C. $\sqrt[4]{4}$
D. $\sqrt[5]{5}$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 考虑函数 $f(x)=x^{\frac{1}{x}}$，$x>0$。$\ln f(x) = \frac{\ln x}{x}$，求导得 $\frac{f'(x)}{f(x)} = \frac{1 - \ln x}{x^2}$。令 $f'(x)=0$，得 $x=e$。当 $0<x<e$ 时，$f'(x)>0$，$f(x)$ 单调递增；当 $x>e$ 时，$f'(x)<0$，$f(x)$ 单调递减。因此 $f(x)$ 在 $x=e$ 处取得最大值。比较数列项 $\sqrt[2]{2}$ 和 $\sqrt[3]{3}$：$2^{\frac{1}{2}}=2^{3\cdot\frac{1}{6}}=\sqrt[6]{8}$，$3^{\frac{1}{3}}=3^{2\cdot\frac{1}{6}}=\sqrt[6]{9}$，因为 $\sqrt[6]{9} > \sqrt[6]{8}$，所以 $\sqrt[3]{3} > \sqrt{2}$。又因为 $e \approx 2.718$，所以 $\sqrt[3]{3}$ 是数列的最大项。

## 007. 880 第二章综合解答 18

- 选做：否

求椭圆 $x^{2}-xy+y^{2}=3$ 上纵坐标最大和最小的点。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 椭圆方程 $x^{2}-xy+y^{2}=3$，两边同时对 $x$ 求导，得 $2x-y-xy'+2yy'=0$，解得 $y'=\frac{2x-y}{x-2y}$。令 $y' = 0$，有 $y = 2x$。$x = 2y$ 是 $y'$ 不存在的点。将 $y = 2x$ 代入原方程，得 $x = 1, y = 2$ 或 $x = -1, y = -2$；将 $x = 2y$ 代入原方程，得 $x = 2, y = 1$ 或 $x = -2, y = -1$。比较可得 $x=1$ 和 $x=-1$ 分别是 $y=y(x)$ 的最大值点和最小值点，且椭圆上纵坐标最大的点为 $(1,2)$，最小的点为 $(-1,-2)$。

## 008. 900 第二章数二 A 类

- 题目ID：`1805`
- 题号：`8`
- 题源：900 第二章数二 A 类
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 最值 / 其他
- 选做：否

设函数 $f(x)$ 和 $g(x)$ 在 $[0,1]$ 上的最大值分别为 a, b，则下列关于 $f(x)g(x)$ 在 $[0,1]$ 上的最大值 c 的说法中，正确的是（）

### 选项

A. c < ab
B. c > ab
C. c = ab
D. 以上都有可能

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 当 $f(x) = x, g(x) = 1 - x$ 时， $a = b = 1, f(x)g(x) = x - x^{2} = -\left(x - \frac{1}{2}\right)^{2} + \frac{1}{4}$. 当 $x = \frac{1}{2}$ 时， $f(x)g(x)$ 取得最大值 $\frac{1}{4}$，故 $c = \frac{1}{4}$. 此时，c < ab.\n当 $f(x)=x,g(x)=-x-1$时，a=1,b=-1， $f(x)g(x)=-x^{2}-x=-\left(x+\frac{1}{2}\right)^{2}+\frac{1}{4}$. $f(x)g(x)$ 在 $[0,1]$ 上单调减少，当 x=0 时， $f(x)g(x)$ 取得最大值 0，故 c=0. 此时，c>ab.\n当 $f(x)=0,g(x)=0$时，a=b=c=0.此时，c=ab.\n综上所述，应选D.

## 011. 880 第二章综合选择; 26 版 1000 第五章强化

- 题目ID：`1808`
- 题号：`11`
- 题源：880 第二章综合选择; 26 版 1000 第五章强化
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 最值 / 其他
- 选做：否

设 $f(x)$ 在 $[a,b]$ 上可导，且在点 x = a 处取最小值，在点 x = b 处取最大值，则（）.

### 选项

A. $f_{+}^{\prime}(a)\leqslant0,f_{-}^{\prime}(b)\leqslant0$
B. $f_{+}^{\prime}(a)\leqslant0,f_{-}^{\prime}(b)\geqslant0$
C. $f_{+}^{\prime}(a)\geqslant0,f_{-}^{\prime}(b)\leqslant0$
D. $f_{+}^{\prime}(a)\geqslant0,f_{-}^{\prime}(b)\geqslant0$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 因为 $f(a)$ 是最小值，所以 $f(x) \geqslant f(a), x \in (a, b]$，又 $f_{+}^{\prime}(a)$ 存在，故 $f_{+}^{\prime}(a)=\lim_{x\to a^{+}}\frac{f(x)-f(a)}{x-a}\geqslant0$.\n因为 $f(b)$ 是最大值，所以 $f(x) \leqslant f(b), x \in [a, b)$，又 $f_{-}^{\prime}(b)$ 存在，故 $f_{-}^{\prime}(b)=\lim_{x\to b^{-}}\frac{f(x)-f(b)}{x-b}\geqslant0$.

## 012. 880 第二章综合选择 11

- 题目ID：`1809`
- 题号：`12`
- 题源：880 第二章综合选择 11
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 最值 / 其他
- 选做：否

设 $f(x)$ 在 $[a,b]$ 上可导， $f(x)$ 在 x=a 处取得最小值，在 x=b 处取得最大值． $F(x)=\int_{0}^{x}f(t)dt,x\in[a,b]$，则（）.

### 选项

A. $F_{+}^{''}(a)>0$ 且 $F_{-}^{''}(b)<0$
B. $F_{+}^{''}(a)\geqslant0$ 且 $F_{-}^{''}(b)\geqslant0$
C. $F_{+}^{''}(a)<0$ 且 $F_{-}^{''}(b)<0$
D. $F_{+}^{''}(a)<0$ 且 $F_{-}^{''}(b)>0$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 由已知, $F'(x)=f(x)$在x=a处取得最小值,在x=b处取得最大值.\n用反证法. 若 $F_{+}^{\prime\prime}(a)<0$ , 则 $F_{+}^{\prime\prime}(a)=\lim_{x\to a^{+}}\frac{F^{\prime}(x)-F_{+}^{\prime}(a)}{x-a}=\lim_{x\to a^{+}}\frac{f(x)-f(a)}{x-a}<0$.\n由极限的保号性，知在 x = a 的某去心右邻域内 $f(x) < f(a)$. 这与 $f(x)$ 在 x = a 处取得最小值矛盾，故 $F_{+}^{\prime\prime}(a) \geqslant 0$. 同理，若 $F_{-}^{\prime\prime}(b) < 0$，则 $f(x)$ 在 x = b 处不可能取得最大值，所以 $F_{-}^{\prime\prime}(b) \geqslant 0$. 选项 B 正确.

设 $f'(x)$ 在区间 $[0,4]$ 上连续，曲线 $y = f'(x)$ 与直线 x = 0, x = 4, y = 0 围成如图所示的三个区域，其面积分别为 $S_{1} = 3$, $S_{2} = 4$, $S_{3} = 2$, 且 $f(0) = 1$，则 $f(x)$ 在 $[0,4]$ 上的最大值与最小值分别为（）.

### 选项

A. 2, -3
B. 4, -3
C. 2, -2
D. 4, -2

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 由面积关系及 $f(0)=1$，通过积分计算可得：$f(1) = f(0) + \int_{0}^{1} f'(t) dt = 1 - S_1 = -2$；$f(3) = f(1) + \int_{1}^{3} f'(t) dt = -2 + S_2 = 2$；$f(4) = f(3) + \int_{3}^{4} f'(t) dt = 2 - S_3 = 0$. 比较 $f(0)=1, f(1)=-2, f(3)=2, f(4)=0$，得最大值为2，最小值为-2.

## 010. 880 第二章综合选择

- 题目ID：`1807`
- 题号：`10`
- 题源：880 第二章综合选择
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 最值 / 其他
- 选做：否

设 $f'(x)$ 在 $[0,4]$ 上连续，曲线 $y = f'(x)$ 与 x = 0, y = 0, x = 4 围成如图 2-2 所示的三个区域，其面积 $S_{1}, S_{2}, S_{3}$ 满足 $S_{2} > S_{1} > S_{3}$，则下列选项中正确的是（）。

### 选项

A. $f(1) > f(3) > f(4)$
B. $f(4) > f(3) > f(1)$
C. $f(3) > f(4) > f(1)$
D. $f(4) > f(1) > f(3)$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 由已知，当 $x \in (0,1)$ 时， $f'(x) < 0$; 当 $x \in (1,3)$ 时， $f'(x) > 0$; 当 $x \in (3,4)$ 时， $f'(x) < 0$.\n由拉格朗日中值定理，有 $f(3)-f(1)=f^{\prime}(\xi_{1})(3-1)=2f^{\prime}(\xi_{1})>0,\xi_{1}\in(1,3)$， $f(4)-f(3)=f^{\prime}(\xi_{2})(4-3)=f^{\prime}(\xi_{2})<0,\xi_{2}\in(3,4)$，\n且由牛顿-莱布尼茨公式，有 $f(4)-f(1)=\int_{1}^{4}f^{\prime}(x)\mathrm{d}x=\int_{1}^{3}f^{\prime}(x)\mathrm{d}x+\int_{3}^{4}f^{\prime}(x)\mathrm{d}x=S_{2}-S_{3}>0$，\n故 $f(3) > f(4) > f(1)$. 选项 C 正确.
