## 001. 1996 数二

- 题目ID：`1769`
- 题号：`1`
- 题源：1996 数二
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 隐函数极值
- 选做：否

设函数 $y = y(x)$ 由方程 $2y^{3} - 2y^{2} + 2xy - x^{2} = 1$ 所确定，试求 $y = y(x)$ 的驻点，并判别它是否为极值点.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 对原方程两边求导得 $6y^{2}y' - 4yy' + 2y + 2xy' - 2x = 0$，整理得 $(3y^{2} - 2y + x)y' + y - x = 0$。令 $y' = 0$，得 $y = x$。代入原方程得 $2x^{3}-x^{2}-1=0$，因式分解为 $(x-1)(2x^{2}+x+1)=0$，由于 $2x^{2}+x+1>0$，故 $x=1$，对应 $y=1$，即驻点为 $x=1$。对求导后的式子再求导，并将 $x=1, y=1, y'=0$ 代入，得 $(3-2+1)y'' - 1 = 0$，解得 $y''|_{(1,1)} = \frac{1}{2} > 0$。故驻点 $x=1$ 是 $y=y(x)$ 的极小值点。

## 002. 2014 数一

- 题目ID：`1770`
- 题号：`2`
- 题源：2014 数一
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 隐函数极值
- 选做：否

设函数 $y = f(x)$ 由方程 $y^{3} + xy^{2} + x^{2}y + 6 = 0$ 确定，求 $f(x)$ 的极值.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 对方程 $y^{3} + xy^{2} + x^{2}y + 6 = 0$ 两端关于 x 求导，得 
>
> $$
> 3y^{2}y^{\prime}+y^{2}+2xyy^{\prime}+2xy+x^{2}y^{\prime}=0.
> $$
>
>  令 $y'=0$，则有 $y^{2}+2xy=0$，从而 $y=0$ 或 $y=-2x$。将 $y=0$ 代入原方程得到 $6=0$，矛盾，故 $y\neq0$，从而 $y=-2x$。将其代入到原方程得到 $6x^{3}=6$，解得 $x=1$，$y=-2$，于是 $f(1)=-2$， $f'(1)=0$。对(1)式两端关于x求导，整理得到 
>
> $$
> 6y(y^{\prime})^{2}+3y^{2}y^{\prime \prime}+4yy^{\prime}+2x(y^{\prime})^{2}+2xyy^{\prime \prime}+2y+4xy^{\prime}+x^{2}y^{\prime \prime}=0.
> $$
>
>  将 $x = 1$, $f(1) = -2$ 及 $f'(1) = 0$ 代入上式，得到 $f''(1) = \frac{4}{9} > 0$。因此 $x = 1$ 是 $f(x)$ 的极小值点，极小值为 $f(1) = -2$。

## 003. 2017 数一二

- 题目ID：`1771`
- 题号：`3`
- 题源：2017 数一二
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 隐函数极值
- 选做：否

已知函数 $y(x)$ 由方程 $x^{3} + y^{3} - 3x + 3y - 2 = 0$ 确定，求 $y(x)$ 的极值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 对方程两端关于 $x$ 求导，得 $3x^{2}+3y^{2}y^{\prime}-3+3y^{\prime}=0$。整理得 $(y^{2}+1)y^{\prime}=1-x^{2}$。由于 $y^{2}+1>0$，故 $y(x)$ 的全部驻点为 $x=1$ 和 $x=-1$。
> 将 $x = 1$ 代入原方程，得 $y^{3} + 3y - 4 = 0$。观察知 $y = 1$ 是一个根。由于 $\frac{\mathrm{d}(y^{3} + 3y - 4)}{\mathrm{d}y} = 3y^{2} + 3 > 0$，函数单调增加，故 $y = 1$ 是唯一实根，即 $y(1)=1$。
> 将 $x = -1$ 代入原方程，得 $y^{3} + 3y = 0$，即 $y(y^{2} + 3) = 0$。$y = 0$ 是该方程的唯一实根，即 $y(-1) = 0$。
> 判断极值点类型（法一）：对导数式 $(y^{2}+1)y^{\prime}=1-x^{2}$ 两端关于 $x$ 求导，得 $(y^{2}+1)y^{\prime \prime}+2y(y^{\prime})^{2}=-2x$。在驻点处 $y' = 0$，故当 $x = \pm 1$ 时，$(y^{2}+1)y^{\prime \prime}=-2x$。当 $x=1$ 时，$2y^{\prime\prime}(1)=-2$，得 $y^{\prime\prime}(1)=-1<0$；当 $x=-1$ 时，$y^{\prime\prime}(-1)=2>0$。因此，$y(1)=1$ 为极大值，$y(-1)=0$ 为极小值。
> （法二）：由 $y' = \frac{1 - x^{2}}{y^{2} + 1}$，因 $y^{2} + 1 > 0$，$y'(x)$ 的符号由 $1-x^{2}$ 决定。列表分析：$x \in (-\infty,-1)$ 时 $y'(x)<0$，$x=-1$ 时 $y'(x)=0$，$x \in (-1,1)$ 时 $y'(x)>0$，$x=1$ 时 $y'(x)=0$，$x \in (1,+\infty)$ 时 $y'(x)<0$。因此 $y(x)$ 在 $(-\infty,-1)$ 单调减少，在 $(-1,1)$ 单调增加，在 $(1,+\infty)$ 单调减少。故 $y(-1)=0$ 为极小值，$y(1)=1$ 为极大值。

## 004. 2023 数三

- 题目ID：`1772`
- 题号：`4`
- 题源：2023 数三
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 隐函数极值
- 选做：否

已知可导函数 $y = y(x)$ 满足 $ae^{x} + y^{2} + y - \ln(1 + x)\cos y + b = 0$，且 $y(0) = 0, y'(0) = 0$。
(1) 求 $a, b$ 的值；
(2) 判断 $x=0$ 是否为 $y(x)$ 的极值点。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> （Ⅰ）将 $y(0) = 0$ 代入方程 $ae^{x} + y^{2} + y - \ln(1 + x)\cos y + b = 0$ 中可得 $a + b = 0$。
> 对方程两端关于 $x$ 求导，得 $ae^{x}+2yy^{\prime}+y^{\prime}-\frac{\cos y}{1+x}+\ln(1+x)y^{\prime}\sin y=0$。
> 将 $y(0)=0, y'(0)=0$ 代入上式，得 $a-1=0$。
> 联立 $\begin{cases} a+b=0 \\ a-1=0 \end{cases}$，解得 $a=1, b=-1$。
> （Ⅱ）由 $y'(0) = 0$ 知 $x = 0$ 为驻点。为判断极值，求 $y''(0)$。
> 将 $a = 1$ 代入求导后的方程：$\mathrm{e}^{x}+2y y^{\prime}+y^{\prime}-\frac{\cos y}{1+x}+\ln(1+x)y^{\prime}\sin y=0$。
> 再次对 $x$ 求导：$\mathrm{e}^{x}+2(y^{\prime})^{2}+2y y^{\prime \prime}+y^{\prime \prime}+\frac{\cos y}{(1+x)^{2}}+\frac{2y^{\prime}\sin y}{1+x}+\ln(1+x)y^{\prime \prime}\sin y+\ln(1+x)(y^{\prime})^{2}\cos y=0$。
> 将 $y(0)=0, y'(0)=0$ 代入，得 $1 + y^{\prime\prime}(0) + 1 = 0$，即 $y^{\prime\prime}(0) = -2 < 0$。
> 由一元函数极值的第二充分条件可知，$x=0$ 是 $y(x)$ 的极大值点。

## 005. 26 版 660 数一二三第 38 题

- 题目ID：`1773`
- 题号：`5`
- 题源：26 版 660 数一二三第 38 题

设 $y = y(x)$ 是由方程 $2y^{3} - 2y^{2} + 2xy - x^{2} = 1$ 确定的，则 $y = y(x)$ 的极值点是

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 对方程 $2y^{3} - 2y^{2} + 2xy - x^{2} = 1$ 两端关于 $x$ 求导，得 $6y^{2}y^{\prime} - 4yy^{\prime} + 2y + 2xy^{\prime} - 2x = 0$。整理得 $(6y^{2} - 4y + 2x)y^{\prime} = 2x - 2y$。令 $y^{\prime}=0$，得 $2x - 2y = 0$，即 $x = y$。将 $x = y$ 代入原方程：$2x^{3} - 2x^{2} + 2x^{2} - x^{2} = 1$，化简为 $2x^{3} - x^{2} = 1$，即 $2x^{3} - x^{2} - 1 = 0$。观察知 $x = 1$ 是一个根，因 $2\cdot1^{3} - 1^{2} - 1 = 0$。对方程 $2x^{3} - x^{2} - 1 = 0$ 求导得 $6x^{2} - 2x = 2x(3x-1)$，在 $x=1$ 处导数为正，函数单调，故 $x=1$ 是唯一实根，对应 $y=1$。因此驻点为 $(x, y) = (1, 1)$。
> 为判断极值类型，求二阶导数。对一阶导数式再次求导，并代入 $x=y=1, y^{\prime}=0$，可得 $y^{\prime\prime}$ 的表达式。计算得 $y^{\prime\prime}(1) > 0$（具体过程略，根据解析提示结果为极小值）。故 $x=1$ 是 $y(x)$ 的极小值点。

## 006. 900 第二章数二 A 类

- 题目ID：`1774`
- 题号：`6`
- 题源：900 第二章数二 A 类
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 隐函数极值
- 选做：否

设函数 $y(x)$ 由方程 $27y^{3} + 2x^{3} - 3x^{2} - 12x + 20 = 0$ 所确定，求 $y = y(x)$ 的极值点，并判断它们是否为驻点。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由 $27y^{3}+2x^{3}-3x^{2}-12x+20=0$ 可得， $y = \sqrt[3]{\frac{-2x^{3}+3x^{2}+12x-20}{27}} = \frac{\sqrt[3]{-2x^{3}+3x^{2}+12x-20}}{3}$。记 $\varphi(x) = -2x^{3} + 3x^{2} + 12x - 20$，则 $y = \frac{\sqrt[3]{\varphi(x)}}{3}$， $y' = \frac{1}{3} \cdot \frac{1}{3}[\varphi(x)]^{-\frac{2}{3}}\varphi'(x)$。当 $\varphi(x) \neq 0$ 时， $y'(x)$ 与 $\varphi'(x)$ 同号，从而 $y(x)$ 与 $\varphi(x)$ 具有相同的单调性与极值点。计算可得 $\varphi'(x) = -6x^{2} + 6x + 12 = -6(x^{2} - x - 2)$。令 $\varphi'(x) = 0$，即 $x^{2} - x - 2 = 0$，解得 $x = -1$ 或 $x = 2$。当 $-1 < x < 2$ 时， $\varphi'(x) > 0$， $\varphi(x)$ 单调增加， $y(x)$ 单调增加；当 $x < -1$ 或 $x > 2$ 时， $\varphi'(x) < 0$， $\varphi(x)$ 单调减少， $y(x)$ 单调减少。因此，$x = -1$ 和 $x = 2$ 为 $y(x)$ 的极值点。当 $x = -1$ 时， $\varphi(-1) = -27$， $\varphi'(-1) = 0$，故 $y'(-1) = \frac{1}{3} \cdot \frac{1}{3} [\varphi(x)]^{-\frac{2}{3}} \varphi'(x) \bigg|_{x = -1} = 0$，$x = -1$ 是 $y(x)$ 的驻点。当 $x = 2$ 时， $\varphi(2) = 0$，此时 $[\varphi(x)]^{-\frac{2}{3}}$ 没有定义，故 $y'(2)$ 不存在，$x = 2$ 不是 $y(x)$ 的驻点。

## 007. 880 第二章基础填空26

- 题目ID：`1775`
- 题号：`7`
- 题源：880 第二章基础填空26
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 隐函数极值
- 选做：否

设函数 $y = y(x)$ 由方程 $\arctan\frac{x}{y} = \ln\sqrt{\frac{x^{2} + y^{2}}{2}} + \frac{\pi}{4} (x > 0, y > 0)$ 确定，则 $y(x)$ 的极大值为？

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 已知方程化为 $\arctan\frac{x}{y} = \frac{1}{2}\ln(x^{2}+y^{2}) - \frac{1}{2}\ln2 + \frac{\pi}{4}$。上式两边同时对 $x$ 求导，得 $\frac{1}{1+\left(\frac{x}{y}\right)^{2}} \cdot \frac{y - xy'}{y^{2}} = \frac{1}{2} \cdot \frac{2x + 2yy'}{x^{2}+y^{2}}$，即 $y' = \frac{-x + y}{x + y}$。令 $y' = 0$，得 $x = y$，代入原方程可求得 $x = 1$，$y = 1$，故 $y'(1) = 0$。方程 $y' = \frac{-x + y}{x + y}$，即 $(x + y)y' = -x + y$，两边同时对 $x$ 求导，得 $(1 + y')y' + (x + y)y'' = -1 + y'$。将 $x = 1$，$y = 1$，$y'(1) = 0$ 代入上式，得 $y''(1) = -\frac{1}{2} < 0$。故 $y(x)$ 的极大值为 $y(1) = 1$。

## 008. 26 版 ☀️ 1000 第五章强化13

- 题目ID：`1776`
- 题号：`8`
- 题源：26 版 ☀️ 1000 第五章强化13
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 隐函数极值
- 选做：否

由 $\int_{0}^{y} e^{-\frac{t^{2}}{2}} dt = \frac{1}{3} (\sqrt{x} - 2)^{2}$ 所确定的函数 $y = y(x)$ ()。

### 选项

A. 只有极大值点 $x = 4$，极大值为 $0$
B. 只有极小值点 $x = 4$，极小值为 $0$
C. 只有极大值点 $x = 0$，极大值为 $\frac{4}{3}$
D. 有极大值点和极小值点分别为 $x=0$，$x=4$，其值分别为 $\frac{4}{3}$，$0$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 等式两边对 $x$ 求导，有 $e^{-\frac{y^{2}}{2}} \cdot y' = \frac{2}{3}(\sqrt{x} - 2) \cdot \frac{1}{2\sqrt{x}}$，即 $y' = \frac{1}{3\sqrt{x}}(\sqrt{x} - 2)e^{\frac{y^{2}}{2}}$。令 $y' = 0$，得唯一驻点 $x = 4$。当 $0 < x < 4$ 时，$y' < 0$；当 $x > 4$ 时，$y' > 0$。故 $x = 4$ 为极小值点。当 $x = 4$ 时，由等式可知，$y(4) = 0$，故极小值为 $0$。由题易知 $x > 0$，故 $x = 0$ 为端点，因为在端点处不讨论是否为极值点，所以选项(C)，(D)均不对。
