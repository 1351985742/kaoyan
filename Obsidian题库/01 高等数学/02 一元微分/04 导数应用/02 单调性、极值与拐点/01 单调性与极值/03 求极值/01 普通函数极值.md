## 001. 1987 数一

- 题目ID：`1747`
- 题号：`1`
- 题源：1987 数一
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 普通函数极值
- 选做：否

当 $x=$___时,函数 $y=x2^{x}$取得极小值.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 第一步：求可疑点\n$y = x2^x$ 是连续函数，所以可疑点就是满足 $f'(x) = 0$ 的 $x$。\n对 $y = x2^x$ 求一阶导得，\n
>
> $$
> \begin{aligned}&y^{\prime}=2^{x}+x\cdot2^{x}\ln2=2^{x}(1+x\ln2),\end{aligned}
> $$
>
> \n令 $y' = 0$，则 $2^{x}(1 + x \ln 2) = 0$，又 $2^{x} > 0$，\n所以 $1 + x \ln 2 = 0$，则 $x = -\frac{1}{\ln 2}$。\n第二步：求解 $y''$，找到极小值点\n对 $y = x2^{x}$ 求二阶导得，\n
>
> $$
> \begin{aligned}&y^{\prime \prime}=\left[2^{x}(1+x\ln2)\right]^{\prime}\\&=2^{x}\ln2(1+x\ln2)+2^{x}\ln2\\&=2^{x}\ln2(2+x\ln2),\end{aligned}
> $$
>
> \n当 $x = -\frac{1}{\ln 2}$ 时，\n
>
> $$
> \begin{array}{l}y^{\prime\prime}\left(-\frac{1}{\ln2}\right)=2^{-\frac{1}{\ln2}}\ln2\left(2-\frac{1}{\ln2}\ln2\right)\\ =2^{-\frac{1}{\ln2}}\ln2>0,\end{array}
> $$
>
> \n根据极值的第二充分条件，\n则当 $x = -\frac{1}{\ln 2}$ 时，函数 $y = x2^{x}$ 取得极小值.

## 002. 1991 数三

- 题目ID：`1748`
- 题号：`2`
- 题源：1991 数三
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 普通函数极值
- 选做：否

设 $f(x)=xe^{x}$，则 $f^{(n)}(x)$ 在点 $x=$ ___ 处取极小值 ___.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 第一步：求解n阶导\n由 $f(x)=xe^{x}$\n
>
> $$
> \begin{aligned}&f^{\prime}(x)=\mathrm{e}^{x}+x\mathrm{e}^{x}=(1+x)\mathrm{e}^{x},\\&f^{\prime\prime}(x)=\mathrm{e}^{x}+(1+x)\mathrm{e}^{x}=(2+x)\mathrm{e}^{x},\\&\cdots\\&f^{(n)}(x)=(n+x)\mathrm{e}^{x}.\end{aligned}
> $$
>
> \n知 $f^{(n)}(x)=(n+x)\mathrm{e}^{x}$\n第二步：求解极值\n设函数 $g(x) = f^{(n)}(x)$，\n则 $g'(x) = (n + 1 + x)e^{x}$\n令 $g'(x)=0$ ，得驻点 $x=-(n+1)$\n
>
> $$
> g^{\prime \prime}(x)=(n+2+x)\mathrm{e}^{x}.
> $$
>
> \n由于 $g''[-(n+1)] = [n+2-(n+1)]e^{-(n+1)}$\n
>
> $$
> \begin{aligned}=\mathrm{e}^{-(n+1)}>0,\end{aligned}
> $$
>
> \n可见 $g(x)$ 在 $x = -(n + 1)$ 处取得极小值。\n综上所述，\n$f^{(n)}(x)$ 在点 $x = -(n + 1)$ 处取极小值 $-e^{-(n+1)}$.

## 003. 900 第二章数二 A 类 61

- 题目ID：`1749`
- 题号：`3`
- 题源：900 第二章数二 A 类 61
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 普通函数极值
- 选做：否

记函数 $f_{n}(x)=x^{n}\mathrm{e}^{-3x}(n>0,x>0)$的极值为 $a_{n}$，则数列 $\{a_{n}\}$的最小值为___.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 计算 $f_{n}^{\prime}(x)$ 可得，\n
>
> $$
> f_{n}^{\prime}(x)=nx^{n-1}\mathrm{e}^{-3x}-3\mathrm{e}^{-3x}x^{n}=\mathrm{e}^{-3x}x^{n-1}(n-3x).
> $$
>
> \n于是，当 $0 < x < \frac{n}{3}$ 时， $f_{n}^{\prime}(x) > 0, f_{n}(x)$ 在 $\left(0, \frac{n}{3}\right)$ 上单调增加，当 $x > \frac{n}{3}$ 时， $f_{n}^{\prime}(x) < 0, f_{n}(x)$ 在 $\left(\frac{n}{3}, +\infty\right)$ 上单调减少。从而， $x = \frac{n}{3}$ 为 $f_{n}(x)$ 唯一的极值点， $f_{n}(x)$ 在该点处取得极大值 $\left(\frac{n}{3}\right)^{n} e^{-3\frac{n}{3}} = \left(\frac{n}{3e}\right)^{n}$。\n由上可知 $a_{n}=\left(\frac{n}{3\mathrm{e}}\right)^{n}$. 记 $\varphi(x)=\left(\frac{x}{3\mathrm{e}}\right)^{x}=\mathrm{e}^{x\left[\ln x-\ln(3\mathrm{e})\right]}$，则\n
>
> $$
> \varphi^{\prime}(x)=\left[\mathrm{e}^{x(\ln x-1-\ln3)}\right]^{\prime}=\mathrm{e}^{x(\ln x-1-\ln3)}\left(\ln x-1-\ln3+x\cdot\frac{1}{x}\right)=\mathrm{e}^{x(\ln x-1-\ln3)}\left(\ln x-\ln3\right).
> $$
>
> \n当 $0 < x < 3$ 时， $\varphi'(x) < 0, \varphi(x)$ 单调减少；当 $x > 3$ 时， $\varphi'(x) > 0, \varphi(x)$ 单调增加。因此，\nx = 3 为 $\varphi(x)$ 的极小值点，也是最小值点，最小值为 $\varphi(3) = \left(\frac{3}{3e}\right)^{3} = e^{-3}$.

## 004. 2005 数三; 26 版 660 数二第 540 题

设 $f(x)=x\sin x+\cos x$ ，下列命题中正确的是（）

>

## 005. 26 版 1000 第五章强化 32

- 题目ID：`1751`
- 题号：`5`
- 题源：26 版 1000 第五章强化 32
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 普通函数极值
- 选做：否

函数 $y = x \cos x - \sin x \left( -\frac{\pi}{2} < x < 2\pi \right)$ 的极值点是 ( ).

### 选项

A. x = 0
B. $x = \pi$
C. $x = \frac{\pi}{2}$
D. $x = \frac{3}{2}\pi$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 由于 $y' = -x \sin x$，因此 $y'$ 在区间 $\left(-\frac{\pi}{2}, 2\pi\right)$ 内的零点为 0 和 $\pi$。当 $-\frac{\pi}{2} < x < 0$ 时， $y' < 0$；当 $0 < x < \pi$ 时， $y' < 0$；当 $\pi < x < 2\pi$ 时， $y' > 0$。所以 x = 0 不是函数的极值点， $x = \pi$ 是函数的极值点，选(B)。

## 006. 900 第二章数二 A 类

- 题目ID：`1752`
- 题号：`6`
- 题源：900 第二章数二 A 类
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 普通函数极值
- 选做：否

设函数 $f(x) = (x - 1) \left| \ln x \cdot \ln \left( x + \frac{1}{2} \right) \right|$，则下列关于 $f(x)$ 的说法中，正确的是（）

### 选项

A. x=1不是极值点，也不是驻点.
B. x=1是极值点，但不是驻点.
C. $x=\frac{1}{2}$既是极值点，又是驻点.
D. $x=\frac{1}{2}$是极值点，但不是驻点.

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 当 $x \in \left(0, \frac{1}{2}\right)$ 时， $f(x) < 0 = f\left(\frac{1}{2}\right)$; 当 $x \in \left(\frac{1}{2}, 1\right)$ 时， $f(x) < 0 = f\left(\frac{1}{2}\right) = f(1)$; 当 x > 1 时， $f(x) > 0 = f(1)$. 根据极值点的定义可知， $x = \frac{1}{2}$ 是极值点，x = 1 不是极值点. 另一方面，根据导数的定义， 
>
> $$
> f^{\prime}(1)=\lim_{x\to1}\frac{(x-1)\left|\ln x\cdot\ln\left(x+\frac{1}{2}\right)\right|}{x-1}=\lim_{x\to1}\left|\ln x\cdot\ln\left(x+\frac{1}{2}\right)\right|=0,
> $$
>
>  
>
> $$
> \begin{aligned}f_{-}^{\prime}\Big(\frac{1}{2}\Big)&=\lim_{x\rightarrow\frac{1}{2}^{-}}\frac{(x-1)\left|\ln x\cdot\ln\left(x+\frac{1}{2}\right)\right|}{x-\frac{1}{2}}=-\frac{1}{2}\ln2\lim_{x\rightarrow\frac{1}{2}^{-}}\frac{\left|\ln\left(1+x-\frac{1}{2}\right)\right|}{x-\frac{1}{2}}\\&=-\frac{1}{2}\ln2\lim_{x\rightarrow\frac{1}{2}^{-}}\frac{\left|x-\frac{1}{2}\right|}{x-\frac{1}{2}}=\frac{1}{2}\ln2,\end{aligned}
> $$
>
>  
>
> $$
> \begin{aligned}f_{+}^{\prime}\left(\frac{1}{2}\right)&=\lim_{x\rightarrow\frac{1}{2}^{+}}\frac{(x-1)\left|\ln x\cdot\ln\left(x+\frac{1}{2}\right)\right|}{x-\frac{1}{2}}=-\frac{1}{2}\ln2\lim_{x\rightarrow\frac{1}{2}^{+}}\frac{\left|\ln\left(1+x-\frac{1}{2}\right)\right|}{x-\frac{1}{2}}\\&=-\frac{1}{2}\ln2\lim_{x\rightarrow\frac{1}{2}^{+}}\frac{\left|x-\frac{1}{2}\right|}{x-\frac{1}{2}}=-\frac{1}{2}\ln2.\end{aligned}
> $$
>
>  由此可知， $f'(1)=0$， $f(x)$ 在 $x=\frac{1}{2}$ 处不可导. 因此，x = 1 是驻点，但不是极值点， $x = \frac{1}{2}$ 是极值点，但不是驻点。应选 D.

## 007. 880 第二章基础选择

- 题目ID：`1753`
- 题号：`7`
- 题源：880 第二章基础选择
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 普通函数极值
- 选做：否

设 $f'(x)=\frac{\left(x^{2}-1\right)(x+3)}{\sqrt{1+x^{2}}}$，则 $f(x)$ ___.

### 选项

A. 在 x = 1, x = -3 处取得极大值，在 x = -1 处取得极小值
B. 在 x = -1 处取得极大值，在 x = 1, x = -3 处取得极小值
C. 在 x = -1, x = 1, x = -3 处都取得极小值
D. 在 x = -1, x = -3, x = 1 处都取得极大值

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 利用在 x = -1, x = 1, x = -3 两侧导数符号的变化判别. $f'(x)$ 有 x = -1, x = 1, x = -3 三个零点，当从 x = -3 左侧到右侧时， $f'(x)$ 由负号变为正号，故 x = -3 是 $f(x)$ 的极小值点. 同理可得，x=-1 是 $f(x)$ 的极大值点，x=1 是 $f(x)$ 的极小值点，故选项 B 正确.

## 008. 880 第二章综合填空3

函数 $y = e^{-x}\left(1 + x + \frac{x^2}{2!} + \cdots + \frac{x^n}{n!}\right)$ （n 为正奇数）的极大值为 ___

> [!success]- 答案解析
> **答案**
>
> 1
>
> **解析**
>
> 由 
>
> $$
> y^{\prime}=\left[1+x+\frac{x^{2}}{2!}+\cdots+\frac{x^{n-1}}{(n-1)!}\right]\mathrm{e}^{-x}-\left(1+x+\frac{x^{2}}{2!}+\cdots+\frac{x^{n}}{n!}\right)\mathrm{e}^{-x}=-\frac{x^{n}}{n!}\mathrm{e}^{-x}=0,
> $$
>
>  得x=0.由于n为奇数，当x<0时， $y^{\prime}>0$;当x>0时， $y^{\prime}<0$,故 $f(0)=1$是极大值.
