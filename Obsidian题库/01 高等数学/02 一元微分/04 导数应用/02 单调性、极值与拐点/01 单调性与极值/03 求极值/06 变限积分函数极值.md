## 001. 2010 数一二

- 题目ID：`1777`
- 题号：`1`
- 题源：2010 数一二
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 变限积分函数极值
- 选做：否

求函数 $f(x) = \int_{1}^{x^{2}} (x^{2} - t)e^{-t^{2}} dt$ 的单调区间与极值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> $f(x) = x^{2}\int_{1}^{x^{2}} e^{-t^{2}} dt - \int_{1}^{x^{2}} t e^{-t^{2}} dt$。令 $f'(x) = 2x\int_{1}^{x^{2}} e^{-t^{2}} dt + x^{2}e^{-x^{4}} \cdot 2x - x^{2}e^{-x^{4}} \cdot 2x = 2x\int_{1}^{x^{2}} e^{-t^{2}} dt = 0$，得 $x = 0$ 或 $x = \pm 1$。当 $x < -1$ 时，$f'(x) < 0$；当 $-1 < x < 0$ 时，$f'(x) > 0$；当 $0 < x < 1$ 时，$f'(x) < 0$；当 $x > 1$ 时，$f'(x) > 0$。$f(0) = \int_{1}^{0} t e^{-t^{2}} dt = -\frac{1}{2}e^{-t^{2}}\bigg|_{0}^{1} = -\frac{1}{2}(e^{-1} - 1)$。

## 002. 26 版 ☀️ 1000 第五章强化8

- 题目ID：`1778`
- 题号：`2`
- 题源：26 版 ☀️ 1000 第五章强化8
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 极值 / 求极值 / 变限积分函数极值
- 选做：否

求函数 $f(x) = \int_{1}^{x} (x^{2} - t^{2})\ln(1 + t^{2}) dt$ 的极值。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 函数 $f(x)$ 的定义域为 $(-\infty, +\infty)$。$f(x) = x^{2}\int_{1}^{x} \ln(1 + t^{2}) dt - \int_{1}^{x} t^{2}\ln(1 + t^{2}) dt$，$f'(x) = 2x\int_{1}^{x} \ln(1 + t^{2}) dt + x^{2}\ln(1 + x^{2}) - x^{2}\ln(1 + x^{2}) = 2x\int_{1}^{x} \ln(1 + t^{2}) dt$，$f''(x) = 2\int_{1}^{x} \ln(1 + t^{2}) dt + 2x\ln(1 + x^{2})$。令 $f'(x) = 0$ 得 $x_{1} = 0$，$x_{2} = 1$。$f(0) = -\int_{1}^{0} t^{2}\ln(1 + t^{2}) dt = \int_{0}^{1} t^{2}\ln(1 + t^{2}) dt = \frac{1}{3}\int_{0}^{1} \ln(1 + t^{2}) d(t^{3}) = \frac{1}{3}\left[t^{3}\ln(1 + t^{2})\right]\Big|_{0}^{1} - \frac{2}{3}\int_{0}^{1} \frac{t^{4}}{1 + t^{2}} dt = \frac{1}{3}\ln2 - \frac{2}{3}\int_{0}^{1} \frac{(t^{4} - 1) + 1}{1 + t^{2}} dt = \frac{1}{3}\ln2 - \frac{2}{3}\int_{0}^{1} \left(t^{2} - 1 + \frac{1}{1 + t^{2}}\right) dt = \frac{1}{3}\ln2 - \frac{2}{3}\left(\frac{1}{3}t^{3} - t + \arctan t\right)\Big|_{0}^{1} = \frac{1}{3}\ln2 - \frac{2}{3}\left(\frac{\pi}{4} - \frac{2}{3}\right) = \frac{1}{3}\ln2 - \frac{\pi}{6} + \frac{4}{9}$。因为 $f''(1) = 2\ln2 > 0$，$f''(0) = 2\int_{1}^{0} \ln(1 + t^{2}) dt = -2\int_{0}^{1} \ln(1 + t^{2}) dt < 0$，所以 $f(1) = 0$ 为极小值，$f(0) = \frac{1}{3}\ln2 - \frac{\pi}{6} + \frac{4}{9}$ 为极大值。

^q-1778
