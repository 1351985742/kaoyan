## 001. 1990 数二

- 题目ID：`1823`
- 题号：`1`
- 题源：1990 数二

- 选做：否

求曲线 $y=\frac{1}{1+x^{2}}(x>0)$ 的拐点。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 第一步：求导。对 $y = \frac{1}{1 + x^{2}}$ 求导得 $y^{\prime}=-\frac{2x}{\left(1+x^{2}\right)^{2}}$， $y^{\prime \prime}=2\frac{3x^{2}-1}{\left(1+x^{2}\right)^{3}}$。第二步：求拐点。令 $y'' = 0$，则 $2\frac{3x^{2}-1}{(1+x^{2})^{3}} = 0$，解得 $x = \pm \frac{1}{\sqrt{3}}$。因 $x > 0$，故 $x = \frac{1}{\sqrt{3}}$。当 $0 < x < \frac{1}{\sqrt{3}}$ 时， $y'' < 0$；当 $x > \frac{1}{\sqrt{3}}$ 时， $y'' > 0$。在 $x = \frac{1}{\sqrt{3}}$ 的左右两侧 $y''$ 异号，故 $x = \frac{1}{\sqrt{3}}$ 是拐点的横坐标。代入函数得 $y = \frac{1}{1 + \left(\frac{1}{\sqrt{3}}\right)^2} = \frac{3}{4}$。所以曲线的拐点是 $\left(\frac{1}{\sqrt{3}}, \frac{3}{4}\right)$。

曲线 $y = x \sin x + 2 \cos x \left( -\frac{\pi}{2} < x < \frac{3\pi}{2} \right)$ 的拐点坐标为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 求导得 $y^{\prime}=\sin x+x\cos x-2\sin x = x\cos x-\sin x$， $y^{\prime \prime}=-x\sin x$。令 $y''=0$，得 $x=0$ 或 $x=\pi$。在区间 $\left( -\frac{\pi}{2}, \frac{3\pi}{2} \right)$ 内，当 $-\frac{\pi}{2}<x<0$ 时， $y''<0$；当 $0<x<\pi$ 时， $y''<0$；当 $\pi<x<\frac{3}{2}\pi$ 时， $y''>0$。故在 $x=\pi$ 两侧凹凸性发生变化， $(\pi,-2)$ 为拐点。

## 003. 2008 数二

- 选做：否

曲线 $y=(x-5)x^{\frac{2}{3}}$ 的拐点坐标为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 第一步：求导找疑似拐点。曲线 $y = x^{\frac{5}{3}} - 5x^{\frac{2}{3}}$ 处处连续。当 $x \neq 0$ 时， $y' = \frac{5}{3}x^{\frac{2}{3}} - \frac{10}{3}x^{-\frac{1}{3}}$；当 $x = 0$ 时， $y'(0)$ 不存在。 $y^{\prime\prime}=\frac{10}{9}x^{-\frac{1}{3}}+\frac{10}{9}x^{-\frac{4}{3}}=\frac{10}{9}x^{-\frac{4}{3}}(1+x)$。令 $y'' = 0$ 得 $x = -1$， $y(-1) = -6$，故 $(-1,-6)$ 是一个疑似拐点。在 $x = 0$ 处二阶导不存在， $(0, 0)$ 也是一个疑似拐点。第二步：确认拐点。 $y'' = \frac{10}{9}x^{-\frac{4}{3}}(1 + x)$。在 $x = 0$ 的邻域内， $y^{\prime\prime}$ 恒为正，凹凸性没有发生变化，故 $(0,\ 0)$ 不是拐点。当 $x > -1$ 时， $y'' > 0$；当 $x < -1$ 时， $y'' < 0$。在 $(-1, -6)$ 两侧凹凸性发生变化，故 $(-1,-6)$ 是曲线的拐点。

## 004. 900 第二章数二 A 类 19

- 题目ID：`1826`
- 题号：`4`
- 题源：900 第二章数二 A 类 19
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 求拐点（个数）
- 选做：否

曲线 $y = (x - 1)x^{\frac{4}{3}}$ 的拐点个数为()。

### 选项

A. 0
B. 1
C. 2
D. 3

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 求导得 $y^{\prime}=x^{\frac{4}{3}}+\frac{4}{3}x^{\frac{1}{3}}(x-1)=\frac{7}{3}x^{\frac{4}{3}}-\frac{4}{3}x^{\frac{1}{3}}$， $y^{\prime \prime}=\frac{28}{9}x^{\frac{1}{3}}-\frac{4}{9}x^{-\frac{2}{3}}=\frac{4}{9}x^{-\frac{2}{3}}(7x-1)$。 $y^{\prime\prime}(0)$ 不存在， $y^{\prime\prime}\left(\frac{1}{7}\right)=0$。分别考察 $y^{\prime\prime}$ 在 $x = 0$ 和 $x = \frac{1}{7}$ 两侧的符号。当 $x < 0$ 时， $y'' < 0$；当 $0 < x < \frac{1}{7}$ 时， $y'' < 0$，故 $y''$ 在 $x = 0$ 两侧不变号。当 $x > \frac{1}{7}$ 时， $y'' > 0$，故 $y''$ 在 $x = \frac{1}{7}$ 两侧变号。点 $\left(\frac{1}{7}, y\left(\frac{1}{7}\right)\right)$ 为曲线的拐点。因此，曲线的拐点个数为1，应选B。

## 006. 900 第二章数二 A 类 63

- 题目ID：`1828`

- 选做：否

曲线 $y = \sin x e^{-x}$ 在区间 $(0, \pi)$ 内的拐点坐标为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> $y(x)$ 在 $(0,\pi)$ 内二阶可导。计算 $y',y''$： $y^{\prime}=\cos x\mathrm{e}^{-x}+\sin x\left(-\mathrm{e}^{-x}\right)=\mathrm{e}^{-x}\left(\cos x-\sin x\right)$， $y^{\prime \prime}=-\mathrm{e}^{-x}\left(\cos x-\sin x\right)+\mathrm{e}^{-x}\left(-\sin x-\cos x\right)=-2\mathrm{e}^{-x}\cos x$。于是， $y''=0$ 在区间 $(0,\pi)$ 内的解为 $x=\frac{\pi}{2}$。当 $0 < x < \frac{\pi}{2}$ 时， $\cos x > 0, y'' < 0$；当 $\frac{\pi}{2} < x < \pi$ 时， $\cos x < 0, y'' > 0$。因此，曲线 $y = \sin x e^{-x}$ 在区间 $(0, \pi)$ 内的拐点坐标为 $\left(\frac{\pi}{2}, e^{-\frac{\pi}{2}}\right)$。

## 009. 26 版 1000 第八章强化 18

- 题目ID：`1831`
- 题号：`9`
- 题源：26 版 1000 第八章强化 18
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 求拐点（个数）
- 选做：否

设 $f(x)=\lim_{n\to\infty}\frac{x}{n}(\mathrm{e}^{-\frac{x^{2}}{n^{2}}}+\mathrm{e}^{-\frac{4x^{2}}{n^{2}}}+\cdots+\mathrm{e}^{-x^{2}})$，求：(1) $f(x)$ 的表达式; (2) 曲线 $y = e^{x^{2}} f(x)$ 的拐点.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> (1) 由定积分的定义可得 $f(x)=\int_{0}^{x}\mathrm{e}^{-t^{2}}\mathrm{d}t$。 (2) 由(1)可知，$y=\mathrm{e}^{x^{2}}f(x)=\mathrm{e}^{x^{2}}\int_{0}^{x}\mathrm{e}^{-t^{2}}\mathrm{d}t$，求导得 $y^{\prime\prime}=2[(1+2x^{2})\mathrm{e}^{x^{2}}\int_{0}^{x}\mathrm{e}^{-t^{2}}\mathrm{d}t+x]$。因为对任意的x，有 $1+2x^{2}>0,\quad e^{x^{2}}>0$，故当x<0时，$y^{\prime\prime}<0$；当x=0时，$y^{\prime\prime}=0$；当x>0时，$y^{\prime\prime}>0$。又 $y(0)=f(0)=0$，故 $(0,0)$是曲线 $y=e^{x^{2}}f(x)$的拐点。

^q-1831
