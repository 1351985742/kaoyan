## 001. 2000 数二

- 题目ID：`1839`
- 题号：`1`
- 题源：2000 数二
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 微分方程解的拐点
- 选做：否

设函数 $f(x)$ 满足关系式 $f''(x) + \left[f'(x)\right]^2 = x$，且 $f'(0) = 0$，则（）

### 选项

A. $f(0)$ 是 $f(x)$ 的极大值。
B. $f(0)$ 是 $f(x)$ 的极小值。
C. 点 $(0,f(0))$是曲线 $y=f(x)$的拐点。
D. $f(0)$ 不是 $f(x)$ 的极值, 点 $(0, f(0))$ 也不是曲线 $y = f(x)$ 的拐点。

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> $f'(0)=0,\quad f''(0)=0$， $f^{\prime\prime}(x)=(-[f^{\prime}(x)]^{2}+x)$， $f^{\prime\prime}(x)=-\left[f^{\prime}(x)\right]^{2}+x$ 两端对 $x$ 求导得 $f^{\prime\prime\prime}(x)=-2f'(x)\cdot f^{\prime\prime}(x)+1$，代入 $x=0$ 得 $f^{\prime\prime\prime}(0)=1$，故 $(0,f(0))$ 是拐点，一定不是极值点。

## 003. 姜晓千真题同源150例2.21

- 题目ID：`1841`
- 题号：`3`
- 题源：姜晓千真题同源150例2.21
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 微分方程解的拐点
- 选做：否

设 $f(x)$ 满足 $f''(x) + (1 - \cos x)f'(x) + xf(x) = \sin x$，且 $f(0) = 2$，则（）。

### 选项

A. x=0 是 $f(x)$ 的极小值点
B. x=0 是 $f(x)$ 的极大值点
C. 曲线 $y = f(x)$ 在点 $(0, f(0))$ 的左侧邻域内是凹函数，右侧邻域内是凸函数
D. 曲线 $y = f(x)$ 在点 $(0, f(0))$ 的左侧邻域内是凸函数，右侧邻域内是凹函数

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 由题设得 $f(0)=2,f''(0)=0$. 由 $f^{\prime\prime}(x)+\sin x\cdot f^{\prime}(x)+(1-\cos x)f^{\prime\prime}(x)+xf^{\prime}(x)+f(x)=\cos x$，得 $f^{\prime\prime\prime}(0)=-1$，故点 $(0,f(0))$ 为拐点。由于 $f''(0)=\lim_{x\to0}\frac{f''(x)-f''(0)}{x}=\lim_{x\to0}\frac{f''(x)}{x}=-1$，由极限保号性，存在 $\delta>0$，当 $0<|x|<\delta$ 时 $\frac{f''(x)}{x}<0$。当 $-\delta<x<0$ 时， $f^{\prime\prime}(x)>0$， $f(x)$ 为凹函数；当 $0 < x < \delta$ 时， $f''(x) < 0$， $f(x)$ 为凸函数，故应选 C。

## 004. 26版 § 1000 第五章基础 16

- 题目ID：`1842`
- 题号：`4`
- 题源：26版 § 1000 第五章基础 16
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 微分方程解的拐点
- 选做：否

设 $g(x)$ 在 $x=0$ 的某邻域内连续， $f(x)$ 具有一阶连续导数，且满足 $\lim_{x\to0}\frac{g(x)}{x} = -3$， $f'(x) = \ln(1 + x^2) - x \int_0^1 g(xt) \, dt$，则（ ）。

### 选项

A. $x=0$ 是 $f(x)$ 的极大值点
B. $x=0$ 是 $f(x)$ 的极小值点
C. $(0, f(0))$ 是曲线 $y=f(x)$ 的拐点
D. 以上结论均不正确

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> $f^{\prime}(x)=\ln(1+x^{2})-x\int_{0}^{1}g(xt)\mathrm{d}t=\ln(1+x^{2})-\int_{0}^{1}g(xt)\mathrm{d}(xt)\xlongequal{x t=u}\ln(1+x^{2})-\int_{0}^{x}g(u)\mathrm{d}u$， $f''(x)=\frac{2x}{1+x^{2}}-g(x)$，等式两边同除以 $x$ 并取极限，有 $\lim_{x\to0}\frac{f^{\prime \prime}(x)}{x}=\lim_{x\to0}\left[\frac{2}{1+x^{2}}-\frac{g(x)}{x}\right]=2+3=5$。由极限性质知 $f''(x)$ 在 x=0 处左右两侧改变符号，因此 $(0,f(0))$ 是拐点，故选(C)。

## 005. 900 第二章数二 B 类 17（重点）

- 题目ID：`1843`
- 题号：`5`
- 题源：900 第二章数二 B 类 17（重点）
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 微分方程解的拐点
- 选做：否

设函数 $f(x)$ 满足 $f''(x) + \ln(x + 1)f'(x) + \arctan xf(x) = \int_{0}^{x} f(t) \, dt$，则下列说法中，错误的是()

### 选项

A. 若 $f'(0) \neq 0$，则 x = 0 不是 $f(x)$ 的极值点.
B. 若 $f'(0) \neq 0$，则点 $(0, f(0))$ 是曲线 $y = f(x)$ 的拐点.
C. 若 x = 0 是 $f(x)$ 的极值点，则点 $(0, f(0))$ 是曲线 $y = f(x)$ 的拐点.
D. 若 x = 0 是 $f(x)$ 的极值点，则当 $x \to 0$ 时， $f'(x)$ 是 $x^{2}$ 的高阶无穷小.

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 将 x = 0 代入原方程可得， $f''(0) = 0$。由原方程可知 $f''(x)$ 二阶可导且 $f''(x)=\int_{0}^{x}f(t)dt-\ln(x+1)f'(x)-\arctan xf(x)$，该等式右端可导，故 $f''(x)$ 可导，即 $f(x)$ 三阶可导，从而 $f(x)$ 的一阶导数、二阶导数均连续。对原方程两端关于 x 求导可得 $f^{\prime \prime \prime}(x)+\ln(x+1)f^{\prime \prime}(x)+\frac{f^{\prime}(x)}{x+1}+\arctan x f^{\prime}(x)+\frac{1}{1+x^{2}}f(x)=f(x)$。令 x = 0 代入可得， $f'''(0) + f'(0) = 0$。
> 若 $f'(0)\neq0$，则由 $f'(x)$ 连续以及极限的局部保号性可知，存在 $\delta>0$，在 $(-\delta,\delta)$ 内， $f'(x)$ 与 $f'(0)$ 同号，从而在该邻域内， $f(x)$ 单调，x=0 不是 $f(x)$ 的极值点。选项 A 正确。
> 若 $f'(0)\neq0$，则 $f'''(0)=-f'(0)\neq0$，即 $f^{\prime \prime \prime}(0)=\lim_{x\to0}\frac{f^{\prime \prime}(x)-f^{\prime \prime}(0)}{x-0}\xlongequal{f^{\prime \prime}(0)=0}\lim_{x\to0}\frac{f^{\prime \prime}(x)}{x}\neq0$。由极限的局部保号性可知， $f''(x)$ 在 x=0 两侧异号，故点 $(0, f(0))$ 是曲线 $y = f(x)$ 的拐点。选项 B 正确。
> 若 x = 0 是 $f(x)$ 的极值点，则 $f'(x)$ 在 x = 0 的两侧异号，从而 x = 0 不是 $f'(x)$ 的极值点。此时，若点 $(0, f(0))$ 是曲线 $y = f(x)$ 的拐点，则 $f''(x)$ 在 x = 0 的两侧异号，从而 $f'(x)$ 在 x = 0 的一侧单调增加，另一侧单调减少，结合 $f'(x)$ 连续可知 x = 0 是 $f'(x)$ 的极值点，矛盾。因此，若 x = 0 是 $f(x)$ 的极值点，则点 $(0, f(0))$ 不可能是曲线 $y = f(x)$ 的拐点，选项 C 错误。
> 若 x = 0 是 $f(x)$ 的极值点，则由极值的必要条件可知， $f'(0) = 0$，从而 $\lim_{x \to 0} f'(x) = 0$。进一步， $\lim_{x\to0}\frac{f^{\prime}(x)}{x^{2}}\xlongequal{ 洛必达 }\lim_{x\to0}\frac{f^{\prime \prime}(x)}{2x}=\frac{1}{2}\lim_{x\to0}\frac{f^{\prime \prime}(x)-f^{\prime \prime}(0)}{x-0}=\frac{1}{2}f^{\prime \prime \prime}(0)=-\frac{1}{2}f^{\prime}(0)=0$。于是，当 $x\to0$ 时， $f'(x)$ 是 $x^{2}$ 的高阶无穷小。选项 D 正确。
> 综上所述，应选 C。

^q-1843
## 002. 26版660数二第555题

- 题目ID：`1840`
- 题号：`2`
- 题源：26版660数二第555题
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 微分方程解的拐点
- 选做：否

设 $y = y(x)$ 在 x = 0 邻域二阶连续可导且满足 $xy'' + y'^{2} = \arctan^{2}x$，则

### 选项

A. x=0 是 $y(x)$ 的极小值点。
B. x=0 是 $y(x)$ 的极大值点。
C. $(0,y(0))$ 点是 $y=y(x)$ 的拐点。
D. 以上均不对。

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> $x=0 \Rightarrow y'(0)=0$， $y^{\prime\prime}(0)=\lim_{x\to0}y^{\prime\prime}(x)=-\lim_{x\to0}\frac{y^{\prime2}}{x}+\lim_{x\to0}\frac{\arctan^{2}x}{x}=-\lim_{x\to0}y^{\prime}(0)\frac{y^{\prime}(x)-y^{\prime}(0)}{x}=-y^{\prime}(0)\cdot y^{\prime \prime}(0)=0$， $y^{\prime\prime\prime}(0) = \lim\limits_{x \to 0} \frac{y^{\prime\prime}(x) - y^{\prime\prime}(0)}{x} = -\lim\limits_{x \to 0} \frac{y^{\prime2}}{x^{2}} + \lim\limits_{x \to 0} \frac{\arctan^{2}x}{x^{2}} = -y^{\prime2}(0) + 1 = 1$，故 $(0,y(0))$ 是拐点。

^q-1840
