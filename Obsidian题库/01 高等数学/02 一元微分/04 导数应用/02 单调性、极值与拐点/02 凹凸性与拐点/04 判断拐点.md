## 001. 2004 数二三

- 题目ID：`1832`
- 题号：`1`
- 题源：2004 数二三
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 判断拐点
- 选做：否

设 $f(x)=\left|x(1-x)\right|$，则（）.

### 选项

A. x=0 是 $f(x)$ 的极值点, 但点 $(0,0)$ 不是曲线 $y=f(x)$ 的拐点
B. x=0 不是 $f(x)$ 的极值点,但点 $(0,0)$ 是曲线 $y=f(x)$ 的拐点
C. x=0 是 $f(x)$ 的极值点, 且点 $(0,0)$ 是曲线 $y=f(x)$ 的拐点
D. x=0 不是 $f(x)$ 的极值点, 点 $(0,0)$ 也不是曲线 $y=f(x)$ 的拐点

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 函数 $f(x) = |x(1 - x)|$ 的图像可由 $y = x(1 - x)$ 的图像将x轴以下部分翻折得到。在 $x = 0$ 的邻域内，$f(0)$ 为最小值；且在 $x \in (-\infty, 0)$ 时，$f(x)$ 为凹函数，在 $x = 0$ 的右邻域内，$f(x)$ 为凸函数。根据定义，$x = 0$ 是 $f(x)$ 的极值点，且 $(0, 0)$ 是曲线 $y = f(x)$ 的拐点。

## 002. 2025 数一二三

- 题目ID：`1833`
- 题号：`2`
- 题源：2025 数一二三
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 判断拐点
- 选做：否

已知函数 $f(x)=\int_{0}^{x}e^{t^{2}}\sin t\,dt$， $g(x)=\int_{0}^{x}e^{t^{2}}dt\cdot\sin^{2}x$，则

### 选项

A. x = 0 是 $f(x)$ 的极值点, 也是 $g(x)$ 的极值点
B. x = 0 是 $f(x)$ 的极值点， $(0,0)$ 是曲线 $y = g(x)$ 的拐点
C. x = 0 是 $f(x)$ 的极值点， $(0,0)$ 是曲线 $y = f(x)$ 的拐点
D. $(0,0)$ 是曲线 $y = f(x)$ 的拐点, 也是曲线 $y = g(x)$ 的拐点

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 对于 $f(x)$：$f^{\prime}\left(x\right)=\mathrm{e}^{x^{2}}\sin x\ ,f^{\prime\prime}(x)=2x\mathrm{e}^{x^{2}}\sin x+\mathrm{e}^{x^{2}}\cos x\$。因为 $f'(0) = 0, f''(0) = 1 > 0$，由极值第二充分条件可知 x = 0 是 $f(x)$ 的极值点。可导函数在同一点处不可能同时取得极值点和拐点，故 $(0,0)$ 不是 $y = f(x)$ 的拐点。\n对于 $g(x)$：求导得 $g^{\prime}\left(0\right)=0$，$g^{\prime \prime}\left(0\right)=0$，$g^{\prime \prime \prime}\left(0\right)=6\neq0$。由拐点第三充分条件可知 $(0,0)$ 是 $g(x)$ 的拐点。

## 003. 26版660数一二三第172题

- 题目ID：`1834`
- 题号：`3`
- 题源：26版660数一二三第172题
- 分类：高等数学 / 一元微分 / 导数应用 / 极最拐 / 拐点 / 判断拐点
- 选做：否

设 $f(x)=\left\{\begin{aligned}&2-\cos x,&x\leqslant0\\ &\sqrt{x}+1,&x>0\end{aligned}\right.$，则

### 选项

A. x=0 是 $f(x)$ 的极值点，但 $(0,1)$ 不是曲线 $y=f(x)$ 的拐点。
B. x=0 不是 $f(x)$ 的极值点，但 $(0,1)$ 是曲线 $y=f(x)$ 的拐点。
C. x=0 是 $f(x)$ 的极值点，且 $(0,1)$ 是曲线 $y=f(x)$ 的拐点。
D. x=0 不是 $f(x)$ 的极值点， $(0,1)$ 不是曲线 $y=f(x)$ 的拐点。

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> $f^{\prime}(x)=\left\{\begin{array}{l} \sin x, \\ \frac{1}{2\sqrt{x}}, \quad x>0 \end{array}\right. \Rightarrow x=0$ 为极小值点。

## 004. 26版660数二第539题

- 选做：否

设函数 $f(x)=\begin{cases}\ln x-x,&x\geqslant1\\x^{2}-2x,&x<1\end{cases}$，则

### 选项

A. x=1 是 $f(x)$ 的极小值点。
B. x=1 是 $f(x)$ 的极大值点。
C. $(1,f(1))$ 是 $y=f(x)$ 拐点。
D. $(1,f(1))$ 不是 $y=f(x)$ 拐点。

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> $x>1, f'(x)=\frac{1}{x}-1<0, f(x)=2, f''(x)=-\frac{1}{x^2}<0$. $x<1, f'(x)=2x-2<0, f(x)<2, f''(x)=2>0$.
