当 a 取下列哪个值时，函数 $f(x)=2x^{3}-9x^{2}+12x-a$ 恰好有两个不同的零点（）

### 选项

A. 2
B. 4
C. 6
D. 8

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> $f'(x)=6x^{2}-18x+12=6(x-1)(x-2)$。令 $f'(x)=0$，得 $x=1, x=2$。当 $x \in (-\infty, 1)$ 时， $f'(x) > 0$， $f(x)$ 单调增加；当 $x \in (1, 2)$ 时， $f'(x) < 0$， $f(x)$ 单调减少；当 $x \in (2, +\infty)$ 时， $f'(x) > 0$， $f(x)$ 单调增加。$f(1)=5-a$， $f(2)=4-a$。$\lim_{x\to-\infty}f(x)=-\infty$， $\lim_{x\to+\infty}f(x)=+\infty$。要使 $f(x)$ 恰好有两个不同的零点，需 $f(1)=0$ 且 $f(2)<0$，或 $f(2)=0$ 且 $f(1)>0$。前者得 $a=5$ (不在选项中)，后者得 $a=4$。结合选项，应选 $a=4$。

> **解析**
>

A. $0 < k < \frac{4}{\pi} - 1$
B. $\frac{4}{\pi} - 1 < k < \frac{4}{\pi}$
C. $1 < k < \frac{4}{\pi}$

> [!success]- 答案解析

>
> D
>
> **解析**
>

- 选做：否

确定常数 k 的取值范围，使方程 $x - \arctan x = kx^{3}$ 在 $(0,1]$ 内有实根。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 令 $f(x)=\frac{1}{x^{2}}-\frac{\arctan x}{x^{3}}$，则 $f^{\prime}(x)=-\frac{2}{x^{3}}-\frac{\frac{x}{1+x^{2}}-3\arctan x}{x^{4}}=\frac{3\arctan x-2x-\frac{x}{1+x^{2}}}{x^{4}}$。再令 $g(x) = 3 \arctan x - 2x - \frac{x}{1 + x^{2}}$，则 $g'(x) = \frac{-2x^{4}}{(1 + x^{2})^{2}} < 0 (x \neq 0)$。故 $g(x)$ 在 $[0, +\infty)$ 上单调减少，从而当 x > 0 时， $g(x) < g(0) = 0$，即 $f'(x) < 0$。由此可见， $f(x)$ 在 $(0, +\infty)$ 上单调减少。于是，当 $0<x\leqslant1$时， $f(1)\leqslant f(x)<f(0^{+})$。由于 $f(1)=1-\frac{\pi}{4}$， $f(0^{+})=\lim_{x\to0^{+}}\left(\frac{1}{x^{2}}-\frac{\arctan x}{x^{3}}\right)=\lim_{x\to0^{+}}\frac{x-\arctan x}{x^{3}}=\lim_{x\to0^{+}}\frac{1-\frac{1}{1+x^{2}}}{3x^{2}}=\frac{1}{3}$，故当 $0 < x \leqslant 1$ 时， $1 - \frac{\pi}{4} \leqslant f(x) < \frac{1}{3}$。由此可见，当且仅当 $1 - \frac{\pi}{4} \leqslant k < \frac{1}{3}$ 时，方程 $\frac{1}{x^{2}} - \frac{\arctan x}{x^{3}} = k$ 在 $(0, 1]$ 内有实根。由于在 $(0, 1]$ 内方程 $x - \arctan x = kx^{3}$ 有实根，即方程 $\frac{1}{x^{2}} - \frac{\arctan x}{x^{3}} = k$ 有实根，故所求常数 k 的取值范围为 $1 - \frac{\pi}{4} \leqslant k < \frac{1}{3}$。

## 011. 900 第二章数二 A 类 34

已知方程 $x^{4}-2x^{2}-k=0$ 有四个不同的实根，则 k 的取值范围是（）

### 选项

A. $(-\infty,0)$
B. $(-1,0)$
C. $(-1,1)$
D. $(1,+\infty)$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 构造辅助函数 $f(x) = x^{4} - 2x^{2}$，则 $f'(x) = 4x^{3} - 4x = 4x(x + 1)(x - 1)$。当 x < -1 或 0 < x < 1 时， $f'(x) < 0$， $f(x)$ 单调减少；当 -1 < x < 0 或 x > 1 时， $f'(x) > 0$， $f(x)$ 单调增加；当 x = 0， $\pm 1$ 时， $f'(x) = 0$。因此，x = -1 与 x = 1 是 $f(x)$ 的极小值点，极小值为 $f(-1) = f(1) = -1$，x = 0 是 $f(x)$ 的极大值点，极大值为 $f(0) = 0$。此外， $\lim_{x \to +\infty} f(x) = +\infty$。方程 $x^{4}-2x^{2}-k=0$ 有四个不同的实根等价于曲线 $y=f(x)$ 与 y=k 有四个交点。当 k < -1 时，曲线 $y = f(x)$ 与 y = k 没有交点；当 k = -1 时，曲线 $y = f(x)$ 与 y = k 有两个交点；当 -1 < k < 0 时，曲线 $y = f(x)$ 与 y = k 有四个交点；当 k = 0 时，曲线 $y = f(x)$ 与 y = k 有三个交点；当 k > 0 时，曲线 $y = f(x)$ 与 y = k 有两个交点。综上所述，当且仅当 $k\in(-1,0)$时， $x^{4}-2x^{2}-k=0$有四个不同的实根，应选B。

> **答案**

> **解析**
>

A. $(e, +\infty)$
B. $(0, e)$
C. $\left(0, \frac{1}{e}\right)$
D. $\left(\frac{1}{e}, +\infty\right)$

> [!success]- 答案解析
> **答案**

>
> **解析**
>
> 法一：$f(x)$ 的定义域为 $(0, +\infty)$。$f'(x) = a - \frac{b}{x}$。由于 $a > 0$，若 $b \leq 0$，则 $f'(x) > 0$，$f(x)$ 单调增加，不可能有 2 个零点。于是 $b > 0$。当 $x=\frac{b}{a}$ 时，$f'(x)=0$；当 $0<x<\frac{b}{a}$ 时，$f'(x)<0$，$f(x)$ 单调减少；当 $x>\frac{b}{a}$ 时，$f'(x)>0$，$f(x)$ 单调增加。$f\left(\frac{b}{a}\right)$ 为最小值。$f(x)$ 有 2 个零点等价于 $f\left(\frac{b}{a}\right) < 0$。计算得 $f\left(\frac{b}{a}\right)=b\left(1-\ln\frac{b}{a}\right)<0$，由 $b>0$ 得 $1 - \ln\frac{b}{a} < 0$，即 $\ln\frac{b}{a} > 1$，$\frac{b}{a} > e$。

> **解析**
