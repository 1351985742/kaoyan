## 先看目标，再选路径

| 可见信号 | 第一操作 → 中间状态 | 落地点 |
|---|---|---|
| 多因式在指定点求导 | 代入各因子找零点 → 提出零因子，只保留必要导数分配项 | 定点乘积公式或零点阶数 |
| 复合、绝对值、分段外函数 | 写取值链并判局部分支 → 补齐内外导数数据 | 链式法则或单侧导数定义 |
| 积商开方、底指同变 | 非零区间内对数化 → 相对导数变为和差 | 乘回原函数得到导数 |
| 隐式关系、反函数、参数方程 | 确定对应点与求导变量 → 求关系中的必要导数 | 隐式线性关系、反函数公式或参数算子 |
| 一点的高阶导 | 看中心奇偶、零点阶数、解析展开 → 筛出目标项 | 对称性或目标次系数乘阶乘 |
| 一般 n 阶导或导数等式 | 化为基本母函数或闭合关系 → 截断或递推 | 高阶导公式或经证明的通项 |
| 分段点、积分定义函数 | 查可导性或求导消积分 → 匹配两侧/补齐初值 | 差商定义或初值驱动的递推 |
