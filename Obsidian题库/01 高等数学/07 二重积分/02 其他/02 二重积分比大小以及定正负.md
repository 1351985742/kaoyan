## 005. 2019 数二

- 题目ID：`2957`
- 题号：`5`
- 题源：2019 数二
- 分类：高等数学 / 二重积分 / 其他 / 二重积分比大小以及定正负
- 选做：否

已知平面区域 $D=\left\{(x,y)\mid|x|+|y|\leqslant\frac{\pi}{2}\right\}$，记 $I_{1}=\iint_{D}\sqrt{x^{2}+y^{2}}dxdy$, $I_{2}=\iint_{D}\sin\sqrt{x^{2}+y^{2}}dxdy$, $I_{3}=\iint_{D}(1-\cos\sqrt{x^{2}+y^{2}})dxdy$, 则（）

### 选项

A. $I_{3}<I_{2}<I_{1}$
B. $I_{2}<I_{1}<I_{3}$
C. $I_{1}<I_{2}<I_{3}$
D. $I_{2}<I_{3}<I_{1}$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 本题主要考查二重积分比较大小。积分区域相同，故比较被积函数的大小。区域 D 包含于圆心在原点，半径为 $\frac{\pi}{2}$ 的圆盘区域 $\left\{(x,y)\mid x^{2}+y^{2}\leqslant\left(\frac{\pi}{2}\right)^{2}\right\}$。在区域 D 内，点 $(x,y)$ 满足 $0\leqslant\sqrt{x^{2}+y^{2}}\leqslant\frac{\pi}{2}$。令 $u = \sqrt{x^{2} + y^{2}}$。由于在 $\left(0, \frac{\pi}{2}\right)$ 内， $\sin u < u$，故对区域 D 内的点，均有 $\sin \sqrt{x^{2} + y^{2}} < \sqrt{x^{2} + y^{2}}$。由定积分的保号性可知， $I_{2} < I_{1}$。考虑 $1 - \cos u$ 与 $\sin u$ 的大小关系。令 $f(u) = \sin u + \cos u - 1$，则 $f'(u) = \cos u - \sin u$。当 $0 < u < \frac{\pi}{4}$ 时， $f'(u) > 0$， $f(u)$ 单调增加；当 $\frac{\pi}{4} < u < \frac{\pi}{2}$ 时， $f'(u) < 0$， $f(u)$ 单调减少。于是， $f(u)$ 在 $\left[0, \frac{\pi}{2}\right]$ 上的最大值为 $f\left(\frac{\pi}{4}\right) = \sqrt{2} - 1$，最小值为 $f(0) = f\left(\frac{\pi}{2}\right) = 0$。在 $\left[0, \frac{\pi}{2}\right]$ 上， $f(u) \geqslant 0$，即 $\sin u \geqslant 1 - \cos u$，且等号仅当 u = 0 和 $u = \frac{\pi}{2}$ 时取得。因此，对区域 D 内的点，均有 $\sin\sqrt{x^{2}+y^{2}}\geqslant1-\cos\sqrt{x^{2}+y^{2}}$。由定积分的保号性可知， $I_{3}<I_{2}$。综上所述， $I_{3}<I_{2}<I_{1}$。应选 A。

设 $I_{1}=\iint_{D}\cos\sqrt{x^{2}+y^{2}}d\sigma$, $I_{2}=\iint_{D}\cos(x^{2}+y^{2})d\sigma$, $I_{3}=\iint_{D}\cos(x^{2}+y^{2})^{2}d\sigma$,其中 $D=\{(x,y)|x^{2}+y^{2}\leq1\}$，则（）

### 选项

A. $I_{3}>I_{2}>I_{1}.$
B. $I_{1}>I_{2}>I_{3}.$
C. $I_{2}>I_{1}>I_{3}.$
D. $I_{3}>I_{1}>I_{2}.$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 在 $D:0 \leqslant x^{2} + y^{2} \leqslant 1$ 上，有 $\frac{\pi}{2}>1\geqslant\sqrt{x^{2}+y^{2}}\geqslant x^{2}+y^{2}\geqslant(x^{2}+y^{2})^{2}\geqslant0$，且 $\cos x$ 在 $\left[0,\frac{\pi}{2}\right)$ 上为单调减少函数，故 $0 \leqslant \cos \sqrt{x^{2} + y^{2}} \leqslant \cos(x^{2} + y^{2}) \leqslant \cos(x^{2} + y^{2})^{2}$，所以 $I_{1} < I_{2} < I_{3}$，B正确.

## 008. 880 基础选择 3

- 题目ID：`2960`
- 题号：`8`
- 题源：880 基础选择 3
- 分类：高等数学 / 二重积分 / 其他 / 二重积分比大小以及定正负
- 选做：否

设 D 是 xOy 平面上以 $A(1,1)$, $B(-1,1)$, $C(-1,-1)$ 为顶点的三角形区域， $D_{1}$ 是 D 在第一象限的部分，则 $I=\iint_{D}(xy+\cos x\sin y)dxdy=(\quad)$。

### 选项

A. 0
B. $2\iint_{D_{1}}xydxdy$
C. $2\iint_{D_{1}}\cos x\sin y\,dxdy$
D. $4\iint_{D_{1}}(xy+\cos x\sin y)\,dxdy$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 依题意， $I=\iint\limits_{D}(xy+\cos x\sin y)\mathrm{d}x\mathrm{d}y=\iint\limits_{D}xy\mathrm{d}x\mathrm{d}y+\iint\limits_{D}\cos x\sin y\mathrm{d}x\mathrm{d}y=I_{1}+I_{2}$。对于 $I_{1}, D_{1} \cup D_{2}$ 关于 y 轴对称，xy 关于 x 为奇函数，故 $\iint_{D_{1} \cup D_{2}} xy \, dx \, dy = 0$。同理 $\iint_{D_{1}\cup D_{2}}xy\,dx\,dy=0$，于是 $I_{1}=0$。对于 $I_{2}, D_{3} \cup D_{4}$ 关于 x 轴对称， $\cos x \sin y$ 关于 y 是奇函数，故 $\iint\limits_{D_{3}\cup D_{4}}\cos x\sin y\mathrm{d}x\mathrm{d}y=0$。 $D_{1}\cup D_{2}$ 关于 y 轴对称， $\cos x \sin y$ 关于 x 是偶函数，故 $\iint\limits_{D_{1}\cup D_{2}}\cos x\sin y\mathrm{d}x\mathrm{d}y=2\iint\limits_{D_{1}}\cos x\sin y\mathrm{d}x\mathrm{d}y$。故选项 C 正确。

## 011. 25 版 基础 3

设 $x \geqslant 0, y \geqslant 0$，曲线 $l_{1}: x^{2} + y^{2} - xy = 1, l_{2}: x^{2} + y^{2} - xy = 2$，直线 $l_{3}: y = \frac{\sqrt{3}}{3}x, l_{4}: y = \sqrt{3}x$。区域 $D_{1}$ 由 $l_{1}, l_{2}, x = 0, y = 0$ 围成， $D_{2}$ 由 $l_{1}, l_{2}, l_{3}, y = 0$ 围成， $D_{3}$ 由 $l_{1}, l_{2}, l_{4}, x = 0$ 围成，则对于 $I_{i} = \iint_{D_{i}} \sqrt[3]{y - x} \, \mathrm{d}\sigma (i = 1, 2, 3)$，有（）.

### 选项

A. $I_{1}<I_{2}<I_{3}$
B. $I_{3}<I_{1}<I_{2}$
C. $I_{2}<I_{3}<I_{1}$
D. $I_{2}<I_{1}<I_{3}$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 由于区域 $D_{1}$ 关于 $y = x$ 对称，由轮换对称性得 $I_{1}=\iint\limits_{D_{1}}\sqrt[3]{x-y}\mathrm{d}\sigma=\iint\limits_{D_{1}}\sqrt[3]{y-x}\mathrm{d}\sigma$，故 $I_{1}=0$。由于 $D_{2}$ 在 $y = x$ 的下侧，故 $y < x$，则 $\sqrt[3]{y - x} < 0$；由于 $D_{3}$ 在 $y = x$ 的上侧，故 $y > x$，则 $\sqrt[3]{y - x} > 0$。根据积分的保号性知， $I_{2} < 0, I_{3} > 0$。综上， $I_{2}<I_{1}<I_{3}$。

## 012. 900 第五章数二 A 类 4

- 题目ID：`2964`
- 题号：`12`
- 题源：900 第五章数二 A 类 4
- 分类：高等数学 / 二重积分 / 其他 / 二重积分比大小以及定正负
- 选做：否

设平面区域 $D = \left\{(x, y) \mid x^{\frac{2}{3}} + y^{\frac{2}{3}} \leqslant 1, x \geqslant 0, y \geqslant 0\right\}$。记 $I_{1} = \iint_{D} \sqrt[3]{x} - y \, dx \, dy$， $I_{2} = \iint_{D} (e^{x^2 + y^2} - 1) \, dx \, dy$， $I_{3} = \iint_{D} (x^2 + y^2) e^{x^2 + y^2} \, dx \, dy$，则（）.

### 选项

A. $I_{2}<I_{1}<I_{3}$
B. $I_{1}<I_{3}<I_{2}$
C. $I_{1}<I_{2}<I_{3}$
D. $I_{3}<I_{2}<I_{1}$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 由轮换对称性可知 $I_{1}=\iint\limits_{D}\sqrt[3]{x-y}\mathrm{d}x\mathrm{d}y=\iint\limits_{D}\sqrt[3]{y-x}\mathrm{d}x\mathrm{d}y=-\iint\limits_{D}\sqrt[3]{x-y}\mathrm{d}x\mathrm{d}y=-I_{1}$，从而 $I_{1}=0$。注意到 $I_{2},I_{3}$ 恒大于 $0$，故 $I_{2},I_{3}>I_{1}$。下面比较 $I_{2}, I_{3}$ 的大小。设 $f(t) = te^{t} - e^{t} + 1$。由于 $f'(t) = te^{t} > 0 (t > 0)$，故 $f(t)$ 单调增加，从而 $f(t) > f(0) = 0$。于是， $te^{t} > e^{t} - 1$。因此， $I_{3} > I_{2}$。应选 C。
