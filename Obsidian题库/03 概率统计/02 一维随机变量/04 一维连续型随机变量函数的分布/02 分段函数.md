## 001. 2013 数一

- 题目ID：`3146`
- 题号：`1`
- 题源：2013 数一
- 分类：概率统计 / 一维随机变量 / 一维连续型随机变量函数的分布 / 分段函数
- 选做：否

设随机变量的概率密度为 $f(x)=\left\{\begin{aligned}&\frac{1}{9}x^{2}&0<x<3\\ &0& 其他 \end{aligned}\right.$，令随机变量 $Y=\left\{\begin{aligned}&2,&X\leq1\\ &X,&1<X<2\\ &1,&X\geq2\end{aligned}\right.$。
(I) 求 Y 的分布函数。
(II) 求概率 $P\{X \leq Y\}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 对于 (I)：Y 的分布函数 $F_Y(y) = P(Y \leq y)$。
> 当 $y < 1$ 时，$F_Y(y) = 0$。
> 当 $y \geq 2$ 时，$F_Y(y) = 1$。
> 当 $1 \leq y < 2$ 时，$F_Y(y) = P(1 < X \leq y) + P(X \geq 2) = \int_{1}^{y}\frac{x^{2}}{9}dx + \int_{2}^{3}\frac{x^{2}}{9}dx = \frac{y^{3}}{27} + \frac{2}{3}$。
> 故 Y 的分布函数为混合型随机变量的分布函数。
> 对于 (II)：$P\{X \leq Y\} = P(0 < X < 2) = \int_{0}^{2}\frac{x^{2}}{9}dx = \frac{8}{27}$。

## 002. 姜晓千强化例题 例 2.15

- 题目ID：`3147`
- 题号：`2`
- 题源：姜晓千强化例题 例 2.15
- 分类：概率统计 / 一维随机变量 / 一维连续型随机变量函数的分布 / 分段函数
- 选做：否

设随机变量 $X \sim E(\lambda)$，则 $Y = \min\{X, 2\}$ 的分布函数【】

### 选项

A. 为连续函数
B. 为阶梯函数
C. 至少有两个间断点
D. 恰好有一个间断点

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 由于 $X \sim E(\lambda)$，其分布函数 $F_X(x) = 1 - e^{-\lambda x}$（$x \geq 0$）。$Y = \min\{X, 2\}$ 的分布函数为 $F_Y(y) = P(Y \leq y)$。当 $y < 2$ 时，$F_Y(y) = F_X(y)$；当 $y \geq 2$ 时，$F_Y(y) = 1$。在 $y=2$ 处，$F_Y(2^-) = F_X(2) = 1 - e^{-2\lambda} < 1 = F_Y(2)$，因此 $y=2$ 是一个跳跃间断点，且是唯一的间断点。
