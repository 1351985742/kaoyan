## 001. 1989 数一

- 题目ID：`3126`
- 题号：`1`
- 题源：1989 数一
- 分类：概率统计 / 一维随机变量 / 其他题型 / 求 X 取值的概率
- 选做：否

设随机变量 $X \sim U(1,6)$，则方程 $x^2 + Xx + 1 = 0$ 有实根的概率为 ___.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方程有实根的条件是判别式 $\Delta = X^2 - 4 \ge 0$，即 $X \ge 2$ 或 $X \le -2$。由于 $X \sim U(1,6)$，其概率密度函数为 $f(x) = \begin{cases} \frac{1}{5}, & 1 < x < 6 \\ 0, & \text{其他} \end{cases}$，因此 $P(\Delta \ge 0) = P(X \ge 2) = \int_{2}^{6} \frac{1}{5} dx = \frac{4}{5}$。

## 002. 1989 数三

- 题目ID：`3127`
- 题号：`2`
- 题源：1989 数三
- 分类：概率统计 / 一维随机变量 / 其他题型 / 求 X 取值的概率
- 选做：否

设随机变量 X 在 $[2,5]$ 上服从均匀分布，现在对 X 进行三次独立观测，试求至少有两次观测值大于 3 的概率。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设事件 A 为“观测值大于 3”，则 $P(A) = P(X > 3) = \int_{3}^{5} \frac{1}{3} dx = \frac{2}{3}$。令 Y 表示三次观测中事件 A 发生的次数，则 $Y \sim B(3, \frac{2}{3})$。所求概率为 $P(Y \ge 2) = P(Y=2) + P(Y=3) = C_3^2 (\frac{2}{3})^2 (\frac{1}{3}) + C_3^3 (\frac{2}{3})^3 = \frac{4}{9} + \frac{8}{27} = \frac{20}{27}$。

## 003. 1994 数三

- 题目ID：`3128`
- 题号：`3`
- 题源：1994 数三
- 分类：概率统计 / 一维随机变量 / 其他题型 / 求 X 取值的概率
- 选做：否

设随机变量X的概率密度为 $f(x)=\begin{cases} 2x, & 0<x<1 \\ 0, & \text{其他} \end{cases}$，以Y表示对X的三次独立重复观察中事件 $\{X \le \frac{1}{2}\}$ 出现的次数，则 $P\{Y=2\} =$ ___.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 首先计算事件 $\{X \le \frac{1}{2}\}$ 的概率：$p = P(X \le \frac{1}{2}) = \int_{0}^{\frac{1}{2}} 2x dx = x^2 \big|_{0}^{\frac{1}{2}} = \frac{1}{4}$。Y 服从二项分布 $B(3, \frac{1}{4})$，因此 $P(Y=2) = C_3^2 (\frac{1}{4})^2 (\frac{3}{4}) = 3 \times \frac{1}{16} \times \frac{3}{4} = \frac{9}{64}$。

## 004. 2000 数三

- 题目ID：`3129`

- 分类：概率统计 / 一维随机变量 / 其他题型 / 求 X 取值的概率

设随机变量 $X$ 的概率密度为 $f(x)=\begin{cases}\frac{1}{3}, & x\in[0,1] \\ \frac{2}{9}, & x\in[3,6], \text{若 } k \text{ 使得 } P\{X\geq k\}=\frac{2}{3}, \text{则 } k \text{ 的取值范围是 } \end{cases}$，其他为0。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由 $P\{X\geq k\}=\int_{k}^{+\infty}f(x)dx=\frac{2}{3}$，结合概率密度函数分段定义，可计算确定 $k$ 的取值范围。
