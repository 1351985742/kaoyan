## 001. 1995 数一

- 题目ID：`3133`
- 题号：`1`
- 题源：1995 数一
- 分类：概率统计 / 一维随机变量 / 其他题型 / 求最值函数取值的概率
- 选做：否

设 $X$ 和 $Y$ 为两个随机变量，且 $P\{X\geqslant0,Y\geqslant0\}=\frac{3}{7},P\{X\geqslant0\}=P\{Y\geqslant0\}=\frac{4}{7}$，则 $P\{\max\{X,Y\}\geq0\}=$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 最大值大于等于 0 即总有一项大于等于 0，因此 $\max(X,Y)\geqslant0\Leftrightarrow X\geqslant0$ 或 $Y\geqslant0$。$P\{\max(X,Y)\geqslant0\}=P\{X\geqslant0$ 或 $Y\geqslant0\}$。由加法公式，$P\{X\geqslant0$ 或 $Y\geqslant0\}=P\{X\geqslant0\}+P\{Y\geqslant0\}-P\{X\geqslant0,Y\geqslant0\}=\frac{4}{7}+\frac{4}{7}-\frac{3}{7}=\frac{5}{7}$。

## 002. 2006 数一三

- 题目ID：`3134`
- 题号：`2`
- 题源：2006 数一三
- 分类：概率统计 / 一维随机变量 / 其他题型 / 求最值函数取值的概率
- 选做：否

设随机变量 $X$ 与 $Y$ 相互独立，且均服从区间 $[0,3]$ 上的均匀分布，则 $P\{\max\{X,Y\} \leqslant 1\} =$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> $P\{\max\{X, Y\}\leq1\}=P\{X\leq1,\ Y\leq1\}$。因为 $X,Y$ 相互独立，故 $P\{X\leq1,Y\leq1\}=P\{X\leq1\}\cdot P\{Y\leq1\}$。$X$ 与 $Y$ 均服从区间 $[0,3]$ 上的均匀分布，故 $P\{X\leq1\}=P\{Y\leq1\}=\frac{1-0}{3-0}=\frac{1}{3}$。因此，$P\{\max\{X,Y\} \leqslant 1\}=P\{X\leq1\}\cdot P\{Y\leq1\}=\frac{1}{3}\times\frac{1}{3}=\frac{1}{9}$。

## 003. 姜晓千强化例题 例 2.12

- 题目ID：`3135`
- 题号：`3`
- 题源：姜晓千强化例题 例 2.12
- 分类：概率统计 / 一维随机变量 / 其他题型 / 求最值函数取值的概率
- 选做：否

设随机变量 $X$ 与 $Y$ 相互独立，均服从区间 $[0,3]$ 上的均匀分布，则 $P\left\{1 < \min\left\{X,Y\right\} < 2\right\} =$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原式 $=P\{\min\{X,Y\} \geq 1\} - P\{\min\{X,Y\} \geq 2\}=P\{X \geq 1, Y \geq 1\} - P\{X \geq 2, Y \geq 2\}$。因为 $X$ 与 $Y$ 相互独立，所以 $P\{X \geq 1, Y \geq 1\}=P\{X \geq 1\}P\{Y \geq 1\}$，$P\{X \geq 2, Y \geq 2\}=P\{X \geq 2\}P\{Y \geq 2\}$。$X$ 与 $Y$ 均服从区间 $[0,3]$ 上的均匀分布，故 $P\{X \geq 1\}=P\{Y \geq 1\}=\frac{2}{3}$，$P\{X \geq 2\}=P\{Y \geq 2\}=\frac{1}{3}$。因此，$P\left\{1 < \min\left\{X,Y\right\} < 2\right\} = \frac{2}{3} \times \frac{2}{3} - \frac{1}{3} \times \frac{1}{3} = \frac{1}{3}$。

## 004. 姜晓千强化例题 例 2.11

- 题目ID：`3136`
- 题号：`4`
- 题源：姜晓千强化例题 例 2.11
- 分类：概率统计 / 一维随机变量 / 其他题型 / 求最值函数取值的概率
- 选做：否

设随机变量 $X$ 与 $Y$ 相互独立，均服从参数为 1 的指数分布，则 $P\left\{1 < \max\left\{X, Y\right\} < 2\right\} =$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 原式 $=P\{\max\{x,y\} < 2\} - P\{\max\{x,y\} \leq 1\}=P\{x \leq 2, y \leq 2\} - P\{x \leq 1, y \leq 1\}$。因为 $X$ 与 $Y$ 相互独立，所以 $P\{x \leq 2, y \leq 2\}=P\{x \leq 2\} P\{y \leq 2\}$，$P\{x \leq 1, y \leq 1\}=P\{x \leq 1\} \cdot P\{y \leq 1\}$。$X$ 与 $Y$ 均服从参数为 1 的指数分布，其分布函数为 $F(t)=1-e^{-t}$（$t \geq 0$）。因此，$P\{x \leq 2\}=1-e^{-2}$，$P\{y \leq 2\}=1-e^{-2}$，$P\{x \leq 1\}=1-e^{-1}$，$P\{y \leq 1\}=1-e^{-1}$。所以，$P\left\{1 < \max\left\{X, Y\right\} < 2\right\} = (1-e^{-2})^{2} - (1 - e^{-1})^{2}$。
