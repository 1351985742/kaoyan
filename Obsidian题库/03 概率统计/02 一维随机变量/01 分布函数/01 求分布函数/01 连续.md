已知随机变量 $X$ 的概率密度 $f(x) = \frac{1}{2} e^{-|x|}, -\infty < x < +\infty$，则随机变量 $X$ 的概率分布函数 $F(x) =$

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由 $F(x) = P\{X \leqslant x\} = \int_{-\infty}^{x} f(t) dt$，分段计算：当 $x < 0$ 时，$F(x) = \int_{-\infty}^{x} \frac{1}{2} e^{t} dt = \frac{1}{2} e^{x}$；当 $x \geqslant 0$ 时，$F(x) = \int_{-\infty}^{0} \frac{1}{2} e^{t} dt + \int_{0}^{x} \frac{1}{2} e^{-t} dt = 1 - \frac{1}{2} e^{-x}$。因此 $F(x) = \begin{cases} \frac{1}{2} e^{x}, & x < 0 \\ 1 - \frac{1}{2} e^{-x}, & x \geqslant 0 \end{cases}$。

## 002. 姜晓千强化例题 例 2.2

- 题目ID：`3096`
- 题号：`2`
- 题源：姜晓千强化例题 例 2.2
- 分类：概率统计 / 一维随机变量 / 分布函数 / 求分布函数 / 连续
- 选做：否

设随机变量 $X$ 的概率密度为 $f(x) = \begin{cases} 1 - |x|, & |x| < 1 \\ 0, & \text{其他} \end{cases}$，则 $X$ 的分布函数 $F(x) =$___，$P\left\{-2 < X < \frac{1}{4}\right\} =$___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由 $f(x)$ 表达式，$F(x) = \int_{-\infty}^{x} f(t) dt$。当 $x \leqslant -1$ 时，$F(x) = 0$；当 $-1 < x \leqslant 0$ 时，$F(x) = \int_{-1}^{x} (1 + t) dt = \frac{1}{2} (x+1)^2$；当 $0 < x < 1$ 时，$F(x) = \frac{1}{2} + \int_{0}^{x} (1 - t) dt = -\frac{1}{2} x^2 + x + \frac{1}{2}$；当 $x \geqslant 1$ 时，$F(x) = 1$。故 $F(x) = \begin{cases} 0, & x \leqslant -1 \\ \frac{1}{2}(x+1)^2, & -1 < x \leqslant 0 \\ -\frac{1}{2}x^2 + x + \frac{1}{2}, & 0 < x < 1 \\ 1, & x \geqslant 1 \end{cases}$。$P\left\{-2 < X < \frac{1}{4}\right\} = F\left(\frac{1}{4}\right) - F(-2) = \left(-\frac{1}{2} \cdot \left(\frac{1}{4}\right)^2 + \frac{1}{4} + \frac{1}{2}\right) - 0 = \frac{23}{32}$。
