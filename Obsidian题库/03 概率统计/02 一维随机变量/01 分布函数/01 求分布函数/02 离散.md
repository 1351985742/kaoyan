## 001. 1987 数三

- 题目ID：`3097`
- 题号：`1`
- 题源：1987 数三
- 分类：概率统计 / 一维随机变量 / 分布函数 / 求分布函数 / 离散
- 选做：否

已知随机变量 $X$ 的概率分布为 $P\{X=1\}=0.2$, $P\{X=2\}=0.3$, $P\{X=3\}=0.5$，试写出 $X$ 的分布函数 $F(x)$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 因为 $F(x) = P\{X \leqslant x\}$，且 $P(X=1)=0.2$, $P(X=2)=0.3$, $P(X=3)=0.5$，所以当 $x<1$ 时，$F(x)=P\{X\leqslant x\}=0$；当 $1 \leqslant x < 2$ 时，$F(x) = P\{X \leqslant x\} = P\{X=1\}=0.2$；当 $2 \leqslant x < 3$ 时，$F(x) = P\{X = 1\} + P\{X = 2\} = 0.2+0.3=0.5$；当 $x \geqslant 3$ 时，$F(x) = P\{X \leqslant x\} = P\{X=1\}+P\{X=2\}+P\{X=3\}=1$。综上，$X$ 的分布函数为 $F(x)=\left\{\begin{array}{l}0,\ x<1\\0.2,\ 1\leqslant x<2\\0.5,\ 2\leqslant x<3\\1,\ x\geqslant3\end{array}\right.$。

## 002. 1991 数三

- 题目ID：`3098`
- 题号：`2`
- 题源：1991 数三
- 分类：概率统计 / 一维随机变量 / 分布函数 / 求分布函数 / 离散
- 选做：否

一汽车沿一街道行驶，需要通过三个均设有红绿信号灯的路口，每个信号灯为红或绿与其他信号灯为红或绿相互独立，且红绿两种信号显示的时间相等，以 $X$ 表示该汽车首次遇到红灯前已通过的路口的个数。求 $X$ 的概率分布。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设每个路口遇到绿灯的概率为 $\frac{1}{2}$，遇到红灯的概率为 $\frac{1}{2}$。$X$ 表示首次遇到红灯前已通过的路口数，则 $X$ 的可能取值为 $0,1,2,3$。$P\{X=0\} = \frac{1}{2}$（第一个路口遇到红灯）；$P\{X=1\} = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$（第一个路口绿灯，第二个路口红灯）；$P\{X=2\} = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$（前两个路口绿灯，第三个路口红灯）；$P\{X=3\} = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$（三个路口全绿灯，即未遇到红灯）。故 $X$ 的概率分布为 $\frac{x|0|1|2|3}{P|\frac{1}{2}|\frac{1}{4}|\frac{1}{8}|\frac{1}{8}}$。$X$ 的分布函数（右连续）为 $F(x)=P\{X \leq x\}=\begin{cases}0, & x < 0 \\ \frac{1}{2}, & 0 \leq x < 1 \\ \frac{3}{4}, & 1 \leq x < 2 \\ \frac{7}{8}, & 2 \leq x < 3 \\ 1, & x \geq 3 \end{cases}$。

## 003. 1997 数三

- 题目ID：`3099`
- 题号：`3`
- 题源：1997 数三
- 分类：概率统计 / 一维随机变量 / 分布函数 / 求分布函数 / 离散
- 选做：否

假设随机变量 $X$ 的绝对值不大于 $1$；$P\{X = -1\} = \frac{1}{8}$，$P\{X = 1\} = \frac{1}{4}$；在事件 $\{-1 < X < 1\}$ 出现的条件下，$X$ 在 $(-1,1)$ 内的任一子区间上取值的条件概率与该子区间长度成正比。试求 $X$ 的分布函数 $F(x) = P\{X \leq x\}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 因为 $|X|\leq1$，即 $-1\leq X\leq1$。则 $P\{-1<X<1\} = 1 - P\{X=-1\} - P\{X=1\} = 1 - \frac{1}{8} - \frac{1}{4} = \frac{5}{8}$。在事件 $\{-1<X<1\}$ 出现的条件下，$X$ 在 $(-1,1)$ 内的任一子区间上取值的条件概率与该子区间长度成正比，即 $P\{-1<X\leq x \mid -1<X<1\} = \frac{x - (-1)}{2} = \frac{x+1}{2}$。由条件概率公式，$P\{-1<X\leq x\} = P\{-1<X<1\} \cdot P\{-1<X\leq x \mid -1<X<1\} = \frac{5}{8} \cdot \frac{x+1}{2} = \frac{5x+5}{16}$。分布函数 $F(x)$：当 $x<-1$ 时，$F(x)=0$；$F(-1)=P\{X\leq -1\} = P\{X<-1\} + P\{X=-1\} = 0 + \frac{1}{8} = \frac{1}{8}$；当 $-1<x<1$ 时，$F(x)=P\{X\leq x\} = P\{X\leq -1\} + P\{-1<X\leq x\} = \frac{1}{8} + \frac{5x+5}{16} = \frac{5x+7}{16}$；当 $x \geqslant 1$ 时，$F(x) = 1$。
