## 001. 1991 数一

- 题目ID：`3115`
- 题号：`1`
- 题源：1991 数一
- 分类：概率统计 / 一维随机变量 / 正态分布 / 对称性
- 选做：否

设随机变量 $X \sim N(2, \sigma^2)$，且 $P\{2 < X < 4\} = 0.3$，则 $P\{X < 0\} =$ ___.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由正态分布的对称性，$P\{X < 0\} = P\{X > 4\} = 0.5 - P\{2 < X < 4\} = 0.5 - 0.3 = 0.2$.

## 002. 1993 数三

- 题目ID：`3116`
- 题号：`2`
- 题源：1993 数三
- 分类：概率统计 / 一维随机变量 / 正态分布 / 对称性
- 选做：否

设随机变量X的密度函数为 $\varphi(x)$，且 $\varphi(-x)=\varphi(x)$。 $F(x)$是X的分布函数，则对任意实数a，有（）

### 选项

A. $F(-a)=1-\int_{0}^{a}\varphi(x)dx$
B. $F(-a)=\frac{1}{2}-\int_{0}^{a}\varphi(x)dx$
C. $F(-a)=F(a)$
D. $F(-a)=2F(a)-1$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 由对称性，$F(-a) = P\{X \le -a\} = P\{X \ge a\} = 1 - P\{X < a\} = 1 - F(a) + P\{X = a\} = 1 - F(a)$。又 $F(a) = \frac{1}{2} + \int_{0}^{a} \varphi(x) dx$，代入得 $F(-a) = \frac{1}{2} - \int_{0}^{a} \varphi(x) dx$。

^q-3116

设随机变量X服从正态分布 $N\left(\mu,\sigma^{2}\right)\left(\sigma>0\right)$，且二次方程 $y^{2}+4y+X=0$无实根的概率为 $\frac{1}{2}$，则 $\mu=$

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 方程无实根的充要条件为 $4^{2}-4X<0$，即 $X > 4$。由题设 $P\{X>4\}=\frac{1}{2}$，根据正态分布的对称性，$\mu = 4$。

## 004. 2004 数一三

- 题目ID：`3118`
- 题号：`4`
- 题源：2004 数一三
- 分类：概率统计 / 一维随机变量 / 正态分布 / 对称性
- 选做：否

设随机变量X服从正态分布 $N(0,1)$，对给定的 $\alpha\in(0,1)$，数 $u_{\alpha}$满足 $P\{X>u_{\alpha}\}=\alpha$，若 $P\{|X|<x\}=\alpha$，则x等于

### 选项

A. $u_{\frac{\alpha}{2}}$
B. $u_{1-\frac{\alpha}{2}}$
C. $u_{1-\frac{\alpha}{2}}$
D. $u_{1-\alpha}$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> $P\{|X|<x\} = \alpha \Rightarrow P\{-x < X < x\} = \alpha$，由对称性 $P\{X > x\} = \frac{1-\alpha}{2}$，所以 $x = u_{\frac{1-\alpha}{2}}$，即 $u_{1-\frac{\alpha}{2}}$。

^q-3118

## 005. 2010 数一三

- 题目ID：`3119`
- 题号：`5`
- 题源：2010 数一三
- 分类：概率统计 / 一维随机变量 / 正态分布 / 对称性
- 选做：否

设 $f_{1}(x)$为标准正态分布的概率密度， $f_{2}(x)$为 $[-1,3]$上均匀分布的概率密度，若 $f(x)=\begin{cases}af_{1}(x),&x\leqslant0,\\bf_{2}(x),&x>0\end{cases}(a>0,b>0)$ 为概率密度,则a,b应满足（）

### 选项

A. $2a + 3b = 4$
B. $3a + 2b = 4$
C. $a + b = 1$
D. $a + b = 2$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 由概率密度性质 $\int_{-\infty}^{+\infty} f(x) dx = 1$，计算得 $\int_{-\infty}^{0} a f_{1}(x) dx + \int_{0}^{+\infty} b f_{2}(x) dx = a \cdot \frac{1}{2} + b \cdot \frac{3}{4} = 1$，整理得 $2a + 3b = 4$。

^q-3119

## 006. 2018 数一三

- 题目ID：`3120`
- 题号：`6`
- 题源：2018 数一三
- 分类：概率统计 / 一维随机变量 / 正态分布 / 对称性
- 选做：否

设随机变量X的概率密度 $f(x)$满足 $f(1+x)=f(1-x)$，且 $\int_{0}^{2}f(x)dx=0.6$，则 $P\{X<0\}=$（ ）

### 选项

A. 0.2
B. 0.3
C. 0.4
D. 0.5

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 由对称性 $f(x)$关于 $x=1$ 对称，所以 $P\{X<0\} = P\{X>2\} = 0.5 - P\{0 \le X \le 2\} = 0.5 - 0.6 = -0.1$，但概率非负，需调整：实际上 $P\{X<0\} = P\{X>2\} = \frac{1 - P\{0 \le X \le 2\}}{2} = \frac{1 - 0.6}{2} = 0.2$。

^q-3120
