## 001. 1987 数一

- 题目ID：`3079`
- 题号：`1`
- 题源：1987 数一
- 分类：概率统计 / 事件与概率 / 三大概型 / 伯努利概型
- 选做：否

设在一次试验中 $A$ 发生的概率为 $p$，现进行 $n$ 次独立试验，则 $A$ 至少发生一次的概率为 ___；而事件 $A$ 至多发生一次的概率为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设 $X = \{ \text{试验 } n \text{ 次事件 } A \text{ 发生的次数 } \}$，$X_i = \{ \text{试验第 } i \text{ 次事件 } A \text{ 是否发生 } \}$。在一次试验中，事件 $A$ 发生的概率为 $p$，故 $X_i \sim B(1, p)$。又 $X = X_1 + X_2 + \cdots + X_n$，且 $X_1, X_2, \cdots, X_n$ 相互独立，故 $X \sim B(n, p)$。
>
> 设 $\Omega_1 = \{ \text{事件 } A \text{ 至少发生一次 } \}$，则 $\overline{\Omega_1} = \{ \text{事件 } A \text{ 一次都不发生 } \}$，故 $P\{\Omega_1\} = 1 - P\{\overline{\Omega_1}\} = 1 - P\{X = 0\} = 1 - C_n^0 p^0(1 - p)^n = 1 - (1 - p)^n$。
>
> 设 $\Omega_2 = \{ \text{事件 } A \text{ 至多发生一次 } \}$，则 $P\{\Omega_2\} = P\{X = 0\} + P\{X = 1\} = C_n^0 p^0(1 - p)^n + C_n^1 p^1(1 - p)^{n-1} = (1 - p)^n + np(1 - p)^{n-1} = [1 + (n - 1)p](1 - p)^{n-1}$。

## 002. 1988 数一

- 题目ID：`3080`
- 题号：`2`
- 题源：1988 数一
- 分类：概率统计 / 事件与概率 / 三大概型 / 伯努利概型
- 选做：否

设三次独立试验中，事件 $A$ 出现的概率相等。若已知 $A$ 至少出现一次的概率等于 $\frac{19}{27}$，则事件 $A$ 在一次试验中出现的概率为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设 $A$ 在一次试验中出现的概率为 $p$。三次独立实验事件 $A$ 均不发生的概率为 $(1 - p)^3$，故依题意有 $\frac{19}{27} = 1 - (1 - p)^3$，解得 $p = \frac{1}{3}$。

^q-3080

## 003. 2007 数一三

- 题目ID：`3081`
- 题号：`3`
- 题源：2007 数一三
- 分类：概率统计 / 事件与概率 / 三大概型 / 伯努利概型
- 选做：否

某人向同一目标独立重复射击，每次射击命中目标的概率为 $p(0 < p < 1)$，则此人第 4 次射击恰好第 2 次命中目标的概率为（）。

### 选项

A. $3p(1-p)^{2}$
B. $6p(1-p)^{2}$
C. $3p^{2}(1-p)^{2}$
D. $6p^{2}(1-p)^{2}$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 第 4 次射击恰好第 2 次命中目标，意味着前 3 次射击中恰好命中 1 次，且第 4 次命中。前 3 次中恰好命中 1 次的概率为 $C_3^1 p (1-p)^2 = 3p(1-p)^2$，第 4 次命中的概率为 $p$。由于各次射击独立，所求概率为 $3p(1-p)^2 \cdot p = 3p^2(1-p)^2$。

^q-3081

## 004. 1990 数三

- 题目ID：`3082`
- 题号：`4`
- 题源：1990 数三
- 分类：概率统计 / 事件与概率 / 三大概型 / 伯努利概型
- 选做：否

一射手对同一目标独立地进行四次射击，若至少命中一次的概率为 $\frac{80}{81}$，则该射手的命中率为___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设该射手的命中率为 $p$。“至少命中一次”的对立事件为“四次射击都没有命中”，其概率为 $C_4^0 p^0 (1 - p)^4 = (1 - p)^4$。所以“至少命中一次”的概率为 $1 - (1 - p)^4 = \frac{80}{81}$，即 $(1 - p)^4 = \frac{1}{81}$，解得 $1 - p = \frac{1}{3}$ 或 $1 - p = -\frac{1}{3}$（舍去）。故 $p = \frac{2}{3}$。

^q-3082
