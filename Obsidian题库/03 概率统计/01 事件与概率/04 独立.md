## 001. 1994 数三

- 题目ID：`3088`
- 题号：`1`
- 题源：1994 数三
- 分类：概率统计 / 事件与概率 / 独立
- 选做：否

设 $0 < P(A) < 1, 0 < P(B) < 1, P(A \mid B) + P(\overline{A} \mid \overline{B}) = 1$，则（）

### 选项

A. 事件 A 和 B 互不相容
B. 事件 A 和 B 相互对立
C. 事件 A 和 B 互不独立
D. 事件 A 和 B 相互独立

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 由 $P(A \mid B) + P(\overline{A} \mid \overline{B}) = 1$ 知 $P(A \mid B) = 1 - P(\overline{A} \mid \overline{B}) = P(A \mid \overline{B})$。利用条件概率公式 $P(A \mid B) = \frac{P(AB)}{P(B)}$，即 $\frac{P(AB)}{P(B)} = \frac{P(A\overline{B})}{P(\overline{B})} = \frac{P(A) - P(AB)}{1 - P(B)}$。整理得 $P(AB) - P(AB)P(B) = P(A)P(B) - P(B)P(AB)$，即 $P(AB) = P(A)P(B)$，故 A 和 B 相互独立。

## 002. 1998 数一

- 题目ID：`3089`
- 题号：`2`
- 题源：1998 数一
- 分类：概率统计 / 事件与概率 / 独立
- 选做：否

设A,B是两个随机事件，且 $0<P(A)<1,P(B)>0,P(B\mid A)=P(B\mid\overline{A})$，则必有（）

### 选项

A. $P(A \mid B) = P(\overline{A} \mid B)$
B. $P(A \mid B) \neq P(\overline{A} \mid B)$
C. $P(AB) = P(A)P(B)$
D. $P(AB) \neq P(A)P(B)$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 由 $P(B \mid A) = P(B \mid \bar{A})$，知 $\frac{P(AB)}{P(A)} = \frac{P(\bar{A}B)}{P(\bar{A})}$。即 $P(AB)(1 - P(A)) = P(A)P(\bar{A}B) = P(A)(P(B) - P(AB))$。整理得 $P(AB) = P(A)P(B)$，故 A 和 B 相互独立。

## 003. 2003 数三

- 题目ID：`3090`
- 题号：`3`
- 题源：2003 数三
- 分类：概率统计 / 事件与概率 / 独立
- 选做：否

将一枚硬币独立地掷两次，引进事件： $A_{1}=\{$掷第一次出现正面$\}$， $A_{2}=\{$掷第二次出现正面$\}$， $A_{3}=\{$正、反面各出现一次$\}$， $A_{4}=\{$正面出现两次$\}$，则事件（）

### 选项

A. $A_{1},A_{2},A_{3}$相互独立
B. $A_{2},A_{3},A_{4}$相互独立
C. $A_{1}, A_{2}, A_{3}$ 两两独立
D. $A_{2}, A_{3}, A_{4}$ 两两独立

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 计算可知 $P(A_1)=P(A_2)=\frac{1}{2}$，$P(A_3)=\frac{1}{2}$，$P(A_4)=\frac{1}{4}$。$P(A_1A_2)=\frac{1}{4}=P(A_1)P(A_2)$，$P(A_1A_3)=\frac{1}{4}=P(A_1)P(A_3)$，$P(A_2A_3)=\frac{1}{4}=P(A_2)P(A_3)$，故 $A_1, A_2, A_3$ 两两独立。但 $P(A_1A_2A_3)=0 \neq P(A_1)P(A_2)P(A_3)$，故三者不相互独立。

## 004. 2017 数三

- 题目ID：`3091`
- 题号：`4`
- 题源：2017 数三
- 分类：概率统计 / 事件与概率 / 独立
- 选做：否

设 A, B, C 为三个随机事件，且 A 与 C 相互独立，B 与 C 相互独立，则 $A \cup B$ 与 C 相互独立的充分必要条件是（）

### 选项

A. A 与 B 相互独立
B. A 与 B 互不相容
C. AB 与 C 相互独立
D. AB 与 C 互不相容

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> $A \cup B$ 与 C 相互独立等价于 $P((A \cup B)C) = P(A \cup B)P(C)$。由已知 $P(AC)=P(A)P(C)$，$P(BC)=P(B)P(C)$，则 $P((A \cup B)C) = P(AC \cup BC) = P(AC) + P(BC) - P(ABC) = P(A)P(C) + P(B)P(C) - P(ABC)$。而 $P(A \cup B)P(C) = [P(A)+P(B)-P(AB)]P(C) = P(A)P(C)+P(B)P(C)-P(AB)P(C)$。两者相等当且仅当 $P(ABC) = P(AB)P(C)$，即 AB 与 C 相互独立。

## 005. 姜晓千强化例题

- 题目ID：`3092`
- 题号：`5`
- 题源：姜晓千强化例题
- 分类：概率统计 / 事件与概率 / 独立
- 选做：否

设 $A, B$ 为随机事件，且 $0 < P(A) < 1$，则【】

### 选项

A. 若 $A \supset B$，则 $A, B$ 一定不相互独立
B. 若 $B \supset A$，则 $A, B$ 一定不相互独立
C. 若 $AB = \varnothing$，则 $A, B$ 一定不相互独立
D. 若 $A = \overline{B}$，则 $A, B$ 一定不相互独立

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 若 $A = \overline{B}$，则 $P(AB)=0$，而 $P(A)P(B)=P(A)(1-P(A))$。由于 $0<P(A)<1$，有 $P(A)P(B)>0$，故 $P(AB) \neq P(A)P(B)$，即 A 与 B 一定不相互独立。其他选项不一定成立，例如当 $P(B)=0$ 或 $P(B)=1$ 时，包含关系或互斥关系下仍可能独立。

## 006. 姜晓千强化例题 例 1.13

- 题目ID：`3093`
- 题号：`6`
- 题源：姜晓千强化例题 例 1.13
- 分类：概率统计 / 事件与概率 / 独立
- 选做：否

设 $A, B, C$ 为随机事件，$A$ 与 $B$ 相互独立，且 $P(C) = 0$，则 $\overline{A}, \overline{B}, \overline{C}$

### 选项

A. 相互独立
B. 两两独立，但不一定相互独立
C. 不一定两两独立
D. 一定不两两独立

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 由 $P(C) = 0$ 可知 $C$ 是零概率事件，其对立事件 $\overline{C}$ 的概率为 $1$。对于任意事件 $D$，有 $P(D\overline{C}) = P(D)$，因此 $\overline{C}$ 与任何事件独立。又 $A$ 与 $B$ 独立，则 $\overline{A}$ 与 $\overline{B}$ 也独立。结合 $\overline{C}$ 的独立性，可得 $\overline{A}, \overline{B}, \overline{C}$ 相互独立。

^q-3093
