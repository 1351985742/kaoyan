## 001. 1996 数三

- 题目ID：`3040`
- 题号：`1`
- 题源：1996 数三
- 分类：概率统计 / 事件与概率 / 概率 / 概率性质 / 条件概率
- 选做：否

已知 $0 < P(B) < 1$ 且 $P\left[\left(A_{1} + A_{2}\right)B\right] = P\left(A_{1}B\right) + P\left(A_{2}B\right)$，则下列选项成立的是（）

### 选项

A. $P[\left(A_{1} + A_{2}\right)\left|\overline{B}\right] = P(A_{1}\left|\overline{B}\right) + P(A_{2}\left|\overline{B}\right)$
B. $P(A_1B + A_2B) = P(A_1B) + P(A_2B)$
C. $P(A_1 + A_2) = P(A_1 | B) + P(A_2 | B)$
D. $P(B) = P(A_1)P(B|A_1) + P(A_2)P(B|A_2)$

> [!success]- 答案解析
> **答案**
>
> B
>
> **解析**
>
> 由 $P\left[\left(A_{1}+A_{2}\right)\mid B\right]=P\left(A_{1}\mid B\right)+P\left(A_{2}\mid B\right)$，利用条件概率公式得 $P\left[\left(A_{1}+A_{2}\right)\mid B\right]=\frac{P\left[\left(A_{1}+A_{2}\right)B\right]}{P\left(B\right)}=\frac{P\left(A_{1}B+A_{2}B\right)}{P\left(B\right)}$；$P\left(A_{1}\mid B\right)=\frac{P\left(A_{1}B\right)}{P\left(B\right)}$；$P\left(A_{2}\mid B\right)=\frac{P\left(A_{2}B\right)}{P\left(B\right)}$。知 $\frac{P(A_{1}B+A_{2}B)}{P(B)}=\frac{P(A_{1}B)}{P(B)}+\frac{P(A_{2}B)}{P(B)}$，即 $P(A_{1}B + A_{2}B) = P(A_{1}B) + P(A_{2}B)$。故选(B)。

## 002. 2006 数一

- 题目ID：`3041`
- 题号：`2`
- 题源：2006 数一
- 分类：概率统计 / 事件与概率 / 概率 / 概率性质 / 条件概率
- 选做：否

设A,B为随机事件,且 $P(B)>0,P(A\mid B)=1$，则必有（）

### 选项

A. $P(A \cup B) > P(A)$
B. $P(A \cup B) > P(B)$
C. $P(A \cup B) = P(A)$
D. $P(A \cup B) = P(B)$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 由 $P(A\mid B)=1$ 可得 $P(AB)=P(B)$。因为 $P(A \cup B) = P(A) + P(B) - P(AB) = P(A) + P(B) - P(B) = P(A)$，所以 $P(A \cup B) = P(A)$。故选(C)。

## 003. 2016 数三

- 题目ID：`3042`
- 题号：`3`
- 题源：2016 数三
- 分类：概率统计 / 事件与概率 / 概率 / 概率性质 / 条件概率
- 选做：否

设A,B为两个随机事件，且 $0<P(A)<1,0<P(B)<1$，如果 $P(A|B)=1$，则（）

### 选项

A. $P(\overline{B}|\overline{A})=1$
B. $P(A|\overline{B})=0$
C. $P(A\cup B)=1$
D. $P(B|A)=1$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 由 $P(A\mid B)=\frac{P(AB)}{P(B)}=1$ 得 $P(AB)=P(B)$。计算 $P(\overline{B}|\overline{A})=1-P(B|\overline{A})=1-\frac{P(B\overline{A})}{P(\overline{A})}=1-\frac{P(B)-P(AB)}{P(\overline{A})}=1-\frac{P(B)-P(B)}{P(\overline{A})}=1$。故选项(A)成立。

## 004. 2021 数一三

- 题目ID：`3043`
- 题号：`4`
- 题源：2021 数一三
- 分类：概率统计 / 事件与概率 / 概率 / 概率性质 / 条件概率
- 选做：否

设 A, B 为随机事件, 且 $0 < P(B) < 1$，下列命题中为假命题的是（）

### 选项

A. 若 $P(A \mid B) = P(A)$，则 $P(A \mid \overline{B}) = P(A)$
B. 若 $P(A \mid B) > P(A)$，则 $P(\overline{A} \mid \overline{B}) > P(\overline{A})$
C. 若 $P(A \mid B) > P(A \mid \overline{B})$，则 $P(A \mid B) > P(A)$
D. 若 $P(A \mid A \cup B) > P(\overline{A} \mid A \cup B)$，则 $P(A) > P(B)$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 考虑选项 D。$P(A\mid A\cup B)=\frac{P(A)}{P(A)+P(B)-P(AB)}$，$P(\overline{A}\mid A\cup B)=\frac{P(B)-P(AB)}{P(A)+P(B)-P(AB)}$。若 $P(A \mid A \cup B) > P(\overline{A} \mid A \cup B)$，则 $P(A) > P(B) - P(AB)$，但这并不能保证 $P(A) > P(B)$。反例：取 $A = B$，则 $P(A \mid A \cup B) = 1 > 0 = P(\overline{A} \mid A \cup B)$，但 $P(A) = P(B)$。因此选项 D 是假命题。选项 A、B、C 均为真命题。
