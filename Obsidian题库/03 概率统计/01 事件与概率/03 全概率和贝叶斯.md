## 001. 1987 数一

- 题目ID：`3084`
- 题号：`1`
- 题源：1987 数一
- 分类：概率统计 / 事件与概率 / 全概率和贝叶斯
- 选做：否

三个箱子，第一个箱子中有4个黑球1个白球，第二个箱子中有3个黑球3个白球，第三个箱子中有3个黑球5个白球。现随机地取一个箱子，再从这个箱子中取出1个球，求：(1) 这个球为白球的概率；(2) 已知取出的球是白球，此球属于第二个箱子的概率。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 记$A=\{取到白球\}$，$B_i=\{取到第i个箱子\}$，$i=1,2,3$。则$P(B_1)=P(B_2)=P(B_3)=\frac{1}{3}$，$P(A \mid B_1)=\frac{1}{5}$，$P(A \mid B_2)=\frac{1}{2}$，$P(A \mid B_3)=\frac{5}{8}$。
> (1) 由全概率公式：$P(A)=\sum_{i=1}^{3} P(B_i)P(A \mid B_i)=\frac{1}{3} \cdot \frac{1}{5} + \frac{1}{3} \cdot \frac{1}{2} + \frac{1}{3} \cdot \frac{5}{8} = \frac{53}{120}$。
> (2) 由贝叶斯公式：$P(B_2 \mid A)=\frac{P(B_2)P(A \mid B_2)}{P(A)}=\frac{\frac{1}{3} \cdot \frac{1}{2}}{\frac{53}{120}} = \frac{20}{53}$。

## 002. 1996 数一

- 题目ID：`3085`
- 题号：`2`
- 题源：1996 数一
- 分类：概率统计 / 事件与概率 / 全概率和贝叶斯
- 选做：否

设工厂A和工厂B的产品的次品率分别为1%和2%，现从由A厂和B厂的产品分别占60%和40%的一批产品中随机抽取一件，发现是次品，则该次品是A厂生产的概率是？

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 设事件$A=\{抽取的产品是A厂生产的\}$，$B=\{抽取的产品是B厂生产的\}$，$C=\{抽取的产品是次品\}$。则$P(A)=0.6$，$P(B)=0.4$，$P(C \mid A)=0.01$，$P(C \mid B)=0.02$。由贝叶斯公式：$P(A \mid C)=\frac{P(A)P(C \mid A)}{P(A)P(C \mid A)+P(B)P(C \mid B)}=\frac{0.6 \times 0.01}{0.6 \times 0.01 + 0.4 \times 0.02}=\frac{0.006}{0.006+0.008}=\frac{3}{7}$。

## 003. 2003 数一

- 题目ID：`3086`
- 题号：`3`
- 题源：2003 数一
- 分类：概率统计 / 事件与概率 / 全概率和贝叶斯
- 选做：否

已知甲、乙两箱中装有同种产品，其中甲箱中装有3件合格品和3件次品，乙箱中仅装有3件合格品。从甲箱中任取3件产品放入乙箱后，求：(Ⅰ) 乙箱中次品件数X的数学期望；(Ⅱ) 从乙箱中任取一件产品是次品的概率。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 从甲箱取3件产品，其中次品数$k$服从超几何分布：$P\{X=k\}=\frac{C_3^k C_3^{3-k}}{C_6^3}$，$k=0,1,2,3$。计算得：$P\{X=0\}=\frac{1}{20}$，$P\{X=1\}=\frac{9}{20}$，$P\{X=2\}=\frac{9}{20}$，$P\{X=3\}=\frac{1}{20}$。
> (Ⅰ) $EX = 0 \times \frac{1}{20} + 1 \times \frac{9}{20} + 2 \times \frac{9}{20} + 3 \times \frac{1}{20} = \frac{3}{2}$。
> (Ⅱ) 设$A=\{从乙箱取一件是次品\}$，由全概率公式：$P(A)=\sum_{k=0}^{3} P\{X=k\} P\{A \mid X=k\} = \frac{1}{20} \times 0 + \frac{9}{20} \times \frac{1}{6} + \frac{9}{20} \times \frac{2}{6} + \frac{1}{20} \times \frac{3}{6} = \frac{1}{4}$。

## 004. 2005 数一/数三

- 题目ID：`3087`
- 题号：`4`
- 题源：2005 数一/数三
- 分类：概率统计 / 事件与概率 / 全概率和贝叶斯
- 选做：否

从数1,2,3,4中任取一个数，记为X，再从1,$\cdots$,X中任取一个数，记为Y，则$P\{Y=2\}=$？

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由全概率公式：$P\{Y=2\} = \sum_{x=1}^{4} P\{X=x\} P\{Y=2 \mid X=x\}$。其中$P\{X=x\}=\frac{1}{4}$，$x=1,2,3,4$。当$X=1$时，$P\{Y=2 \mid X=1\}=0$；当$X=2$时，$P\{Y=2 \mid X=2\}=\frac{1}{2}$；当$X=3$或$4$时，$P\{Y=2 \mid X=3\}=P\{Y=2 \mid X=4\}=\frac{1}{x}$。故$P\{Y=2\} = \frac{1}{4} \times 0 + \frac{1}{4} \times \frac{1}{2} + \frac{1}{4} \times \frac{1}{3} + \frac{1}{4} \times \frac{1}{4} = \frac{13}{48}$。

## 005. 姜晓千基础例题 1.10

- 题目ID：`3094`
- 题号：`5`
- 题源：姜晓千基础例题 1.10
- 分类：概率统计 / 事件与概率 / 全概率和贝叶斯
- 选做：否

设 10 件产品中有 2 件次品，8 件正品，每次从中任取一件，取后不放回。求下列事件的概率：\n\n（1）前两次均取到正品；\n\n（2）第二次取到次品；\n\n（3）若已知第二次取到次品，则第一次也取到次品。

> [!success]- 答案解析
> **答案**
>
> (1) $\\dfrac{28}{45}$；(2) $\\dfrac{1}{5}$；(3) $\\dfrac{1}{9}$
>
> **解析**
>
> 设 $A_i$ 为第 $i$ 次取到次品。\n\n(1) $P(\\bar{A}_1 \\cap \\bar{A}_2) = \\dfrac{8}{10} \\cdot \\dfrac{7}{9} = \\dfrac{28}{45}$。\n\n(2) $P(A_2) = P(A_1)P(A_2|A_1) + P(\\bar{A}_1)P(A_2|\\bar{A}_1) = \\dfrac{2}{10} \\cdot \\dfrac{1}{9} + \\dfrac{8}{10} \\cdot \\dfrac{2}{9} = \\dfrac{1}{5}$。\n\n(3) $P(A_1|A_2) = \\dfrac{P(A_1 \\cap A_2)}{P(A_2)} = \\dfrac{\\frac{2}{10} \\cdot \\frac{1}{9}}{\\frac{1}{5}} = \\dfrac{1}{9}$。

^q-3094
