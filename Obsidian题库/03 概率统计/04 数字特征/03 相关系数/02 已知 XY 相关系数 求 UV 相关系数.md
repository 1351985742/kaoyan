## 001. 2003 数三

- 题目ID：`3268`
- 题号：`1`
- 题源：2003 数三
- 分类：概率统计 / 数字特征 / 相关系数 / 已知 XY 相关系数 求 UV 相关系数
- 选做：否

设随机变量 $X$ 和 $Y$ 的相关系数为 $0.9$，若 $Z = X - 0.4$，则 $Y$ 与 $Z$ 的相关系数为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 相关系数在随机变量线性变换下保持不变（除非缩放因子为负）。$Z = X - 0.4$ 是 $X$ 的线性变换（平移），不改变 $X$ 与 $Y$ 的相关系数。因此，$\rho_{YZ} = \rho_{YX} = \rho_{XY} = 0.9$。计算过程：$\rho_{YZ} = \frac{\text{Cov}(Y, Z)}{\sqrt{DY}\sqrt{DZ}} = \frac{\text{Cov}(Y, X-0.4)}{\sqrt{DY}\sqrt{D(X-0.4)}} = \frac{\text{Cov}(Y, X)}{\sqrt{DY}\sqrt{DX}} = \rho_{YX} = \rho_{XY} = 0.9$。
