## 001. 1987 数三

- 题目ID：`3240`
- 题号：`1`
- 题源：1987 数三
- 分类：概率统计 / 数字特征 / 期望与方差 / 伽马/凑正态
- 选做：否

已知随机变量Y的概率密度为 $f(y)=\left\{\begin{aligned}&\frac{y}{a^{2}}\mathrm{e}^{-\frac{y^{2}}{2a^{2}}},&y>0,\\&0,&y\leqslant0,\end{aligned}\right.$，求随机变量 $Z=\frac{1}{Y}$的数学期望 $E(Z)$.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 代入 $Z = \frac{1}{Y}$，有 $E\left(\frac{1}{Y}\right) = \int_{-\infty}^{+\infty} \frac{1}{y} f(y) \, dy$。代入 $f(y) = \frac{y}{a^2} e^{-\frac{y^2}{2a^2}}$，注意当 $y \leq 0$ 时 $f(y) = 0$，所以积分下限从0开始：$= \int_0^{+\infty} \frac{1}{y} \cdot \frac{y}{a^2} e^{-\frac{y^2}{2a^2}} \, dy = \int_0^{+\infty} \frac{1}{a^2} e^{-\frac{y^2}{2a^2}} \, dy$。通过凑正态分布：$= \frac{\sqrt{2\pi}}{a} \int_0^{+\infty} \frac{1}{\sqrt{2\pi} a} e^{-\frac{y^2}{2a^2}} \, dy$，其中 $\frac{1}{\sqrt{2\pi} a} e^{-\frac{y^2}{2a^2}}$ 是正态分布 $N(0, a^2)$ 的概率密度，所以 $\int_0^{+\infty} \frac{1}{\sqrt{2\pi} a} e^{-\frac{y^2}{2a^2}} \, dy = \frac{1}{2}$。因此 $E(Z) = \frac{\sqrt{2\pi}}{2a}$。

## 002. 1992 数一

- 题目ID：`3241`
- 题号：`2`
- 题源：1992 数一
- 分类：概率统计 / 数字特征 / 期望与方差 / 伽马/凑正态
- 选做：否

设随机变量 X 服从参数为 1 的指数分布，则 $E(X + e^{-2X}) =$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> X 服从参数为 1 的指数分布，其密度函数为 $f(x)=\left\{\begin{array}{l}\mathrm{e}^{-x},\ x>0\\ 0,\ x\leq0\end{array}\right.$。计算：$E\left(X+\mathrm{e}^{-2X}\right)=E(X)+E\left(\mathrm{e}^{-2X}\right) = \int_{-\infty}^{+\infty}x f(x)\mathrm{d}x+\int_{-\infty}^{+\infty}\mathrm{e}^{-2x}f(x)\mathrm{d}x$。代入 $f(x)$：$= \int_{0}^{+\infty}x\mathrm{e}^{-x}\mathrm{~d}x+\int_{0}^{+\infty}\mathrm{e}^{-2x}\mathrm{e}^{-x}\mathrm{~d}x$。已知 $\int_{0}^{+\infty}x\mathrm{e}^{-x}\mathrm{d}x = \Gamma(2) = 1! = 1$。第二项：$\int_{0}^{+\infty}\mathrm{e}^{-3x}\mathrm{d}x = \left. -\frac{1}{3}\mathrm{e}^{-3x} \right|_{0}^{+\infty} = \frac{1}{3}$。所以 $E(X + e^{-2X}) = 1 + \frac{1}{3} = \frac{4}{3}$。

## 003. 2013 数三

- 题目ID：`3242`
- 题号：`3`
- 题源：2013 数三
- 分类：概率统计 / 数字特征 / 期望与方差 / 伽马/凑正态
- 选做：否

设随机变量 X 服从标准正态分布 $N(0,1)$，则 $E(X\mathrm{e}^{2X})=$ ___

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> X 服从标准正态分布 $N(0,1)$，其概率密度为 $\phi(x) = \frac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}$。计算 $E(X e^{2X}) = \int_{-\infty}^{+\infty} x e^{2x} \phi(x) \, dx = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{+\infty} x e^{2x - \frac{x^2}{2}} \, dx$。配方指数：$2x - \frac{x^2}{2} = -\frac{1}{2}(x^2 - 4x) = -\frac{1}{2}[(x-2)^2 - 4] = -\frac{1}{2}(x-2)^2 + 2$。所以 $E(X e^{2X}) = \frac{1}{\sqrt{2\pi}} e^{2} \int_{-\infty}^{+\infty} x e^{-\frac{1}{2}(x-2)^2} \, dx$。令 $y = x-2$，则 $x = y+2$，积分变为 $\int_{-\infty}^{+\infty} (y+2) e^{-\frac{y^2}{2}} \, dy = \int_{-\infty}^{+\infty} y e^{-\frac{y^2}{2}} \, dy + 2\int_{-\infty}^{+\infty} e^{-\frac{y^2}{2}} \, dy$。第一项被积函数为奇函数，在对称区间积分为0；第二项 $2\int_{-\infty}^{+\infty} e^{-\frac{y^2}{2}} \, dy = 2 \sqrt{2\pi}$。因此 $E(X e^{2X}) = \frac{1}{\sqrt{2\pi}} e^{2} \cdot 2\sqrt{2\pi} = 2e^{2}$。
