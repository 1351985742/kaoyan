## 001. 2004 数一

- 题目ID：`3252`
- 题号：`1`
- 题源：2004 数一
- 分类：概率统计 / 数字特征 / 协方差 / 分配
- 选做：否

设随机变量 $X_{1}, X_{2}, \cdots, X_{n} (n > 1)$ 独立同分布，且其方差为 $\sigma^{2} > 0$。令 $Y = \frac{1}{n} \sum_{i=1}^{n} X_{i}$，则（）

### 选项

A. $\mathrm{Cov}\left(X_{1},Y\right)=\frac{\sigma^{2}}{n}$
B. $\mathrm{Cov}\left(X_{1},Y\right)=\sigma^{2}$
C. $D(X_{1}+Y)=\frac{n+2}{n}\sigma^{2}$
D. $D(X_{1}-Y)=\frac{n+1}{n}\sigma^{2}$

> [!success]- 答案解析
> **答案**
>
> A
>
> **解析**
>
> 由于 $X_i$ 独立同分布，$\mathrm{Cov}(X_i, X_j)=0$（$i \neq j$），$\mathrm{Cov}(X_i, X_i)=D(X_i)=\sigma^{2}$。
> $\mathrm{Cov}(X_1, Y) = \mathrm{Cov}\left(X_1, \frac{1}{n}\sum_{i=1}^{n} X_i\right) = \frac{1}{n} \sum_{i=1}^{n} \mathrm{Cov}(X_1, X_i) = \frac{1}{n} \mathrm{Cov}(X_1, X_1) = \frac{\sigma^{2}}{n}$，故 (A) 正确。
>
> 计算 $D(Y) = D\left(\frac{1}{n}\sum_{i=1}^{n} X_i\right) = \frac{1}{n^{2}} \sum_{i=1}^{n} D(X_i) = \frac{1}{n^{2}} \cdot n \sigma^{2} = \frac{\sigma^{2}}{n}$。
> $D(X_1+Y) = D(X_1) + D(Y) + 2\mathrm{Cov}(X_1, Y) = \sigma^{2} + \frac{\sigma^{2}}{n} + 2 \cdot \frac{\sigma^{2}}{n} = \frac{n+3}{n}\sigma^{2}$，故 (C) 错误。
> $D(X_1-Y) = D(X_1) + D(Y) - 2\mathrm{Cov}(X_1, Y) = \sigma^{2} + \frac{\sigma^{2}}{n} - 2 \cdot \frac{\sigma^{2}}{n} = \frac{n-1}{n}\sigma^{2}$，故 (D) 错误。

## 002. 2005 数一/数三

- 题目ID：`3253`
- 题号：`2`
- 题源：2005 数一/数三
- 分类：概率统计 / 数字特征 / 协方差 / 分配
- 选做：否

设 $X_{1}, X_{2}, \cdots, X_{n} (n > 2)$ 为来自总体 $N(0, \sigma^{2})$ 的简单随机样本，$\bar{X}$ 为样本均值，记 $Y_{i} = X_{i} - \bar{X}, i = 1, 2, \cdots, n$。
求：(I) $Y_{i}$ 的方差 $DY_{i}, i=1,2,\cdots,n$；
(II) $Y_{1}$ 与 $Y_{n}$ 的协方差 $\text{Cov}(Y_{1}, Y_{n})$；
(III) 若 $c(Y_{1}+Y_{n})^{2}$ 是 $\sigma^{2}$ 的无偏估计量，求常数 $c$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> (I) $Y_i = X_i - \bar{X}$，其中 $\bar{X} = \frac{1}{n}\sum_{j=1}^{n} X_j$。
> $D(Y_i) = D(X_i - \bar{X}) = D(X_i) + D(\bar{X}) - 2\mathrm{Cov}(X_i, \bar{X})$。
> 已知 $D(X_i)=\sigma^{2}$，$D(\bar{X})=\frac{\sigma^{2}}{n}$。
> $\mathrm{Cov}(X_i, \bar{X}) = \mathrm{Cov}\left(X_i, \frac{1}{n}\sum_{j=1}^{n} X_j\right) = \frac{1}{n}\mathrm{Cov}(X_i, X_i) = \frac{\sigma^{2}}{n}$。
> 故 $D(Y_i) = \sigma^{2} + \frac{\sigma^{2}}{n} - 2 \cdot \frac{\sigma^{2}}{n} = \frac{n-1}{n}\sigma^{2}$。
>
> (II) $\mathrm{Cov}(Y_1, Y_n) = \mathrm{Cov}(X_1 - \bar{X}, X_n - \bar{X}) = \mathrm{Cov}(X_1, X_n) - \mathrm{Cov}(X_1, \bar{X}) - \mathrm{Cov}(X_n, \bar{X}) + D(\bar{X})$。
> 由于 $X_1$ 与 $X_n$ 独立，$\mathrm{Cov}(X_1, X_n)=0$。
> $\mathrm{Cov}(X_1, \bar{X}) = \frac{\sigma^{2}}{n}$，$\mathrm{Cov}(X_n, \bar{X}) = \frac{\sigma^{2}}{n}$，$D(\bar{X})=\frac{\sigma^{2}}{n}$。
> 故 $\mathrm{Cov}(Y_1, Y_n) = 0 - \frac{\sigma^{2}}{n} - \frac{\sigma^{2}}{n} + \frac{\sigma^{2}}{n} = -\frac{\sigma^{2}}{n}$。
>
> (III) 要使 $c(Y_1+Y_n)^{2}$ 是 $\sigma^{2}$ 的无偏估计，即 $E[c(Y_1+Y_n)^{2}] = \sigma^{2}$。
> $Y_1+Y_n = (X_1 - \bar{X}) + (X_n - \bar{X}) = X_1 + X_n - 2\bar{X}$。
> 由于 $X_i \sim N(0,\sigma^{2})$，且 $\bar{X} \sim N(0, \frac{\sigma^{2}}{n})$，$Y_1+Y_n$ 服从正态分布，其均值为 $0$。
> $D(Y_1+Y_n) = D(X_1+X_n - 2\bar{X}) = D(X_1+X_n) + 4D(\bar{X}) - 4\mathrm{Cov}(X_1+X_n, \bar{X})$。
> $D(X_1+X_n)=2\sigma^{2}$，$D(\bar{X})=\frac{\sigma^{2}}{n}$。
> $\mathrm{Cov}(X_1+X_n, \bar{X}) = \mathrm{Cov}(X_1, \bar{X}) + \mathrm{Cov}(X_n, \bar{X}) = \frac{\sigma^{2}}{n} + \frac{\sigma^{2}}{n} = \frac{2\sigma^{2}}{n}$。
> 故 $D(Y_1+Y_n) = 2\sigma^{2} + 4\cdot\frac{\sigma^{2}}{n} - 4\cdot\frac{2\sigma^{2}}{n} = 2\sigma^{2} - \frac{4\sigma^{2}}{n} = \frac{2(n-2)}{n}\sigma^{2}$。
> 因此，$E[(Y_1+Y_n)^{2}] = D(Y_1+Y_n) = \frac{2(n-2)}{n}\sigma^{2}$。
> 由 $c \cdot \frac{2(n-2)}{n}\sigma^{2} = \sigma^{2}$，解得 $c = \frac{n}{2(n-2)}$。

## 003. 姜晓千强化例题 例4.11

- 题目ID：`3254`
- 题号：`3`
- 题源：姜晓千强化例题 例4.11
- 分类：概率统计 / 数字特征 / 协方差 / 分配
- 选做：否

设 $X_{1}, X_{2}, \cdots, X_{n}$ 为来自总体 $X$ 的简单随机样本。若 $DX = 4$，正整数 $s \leq n$，$t \leq n$，则 $\mathrm{Cov}\left(\frac{1}{s}\sum_{i=1}^{s} X_{i}, \frac{1}{t}\sum_{j=1}^{t} X_{j}\right) =$ 【】

### 选项

A. $4\max\{s,t\}$
B. $4\min\{s,t\}$
C. $\frac{4}{\max\{s,t\}}$
D. $\frac{4}{\min\{s,t\}}$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 当 $s \leq t$ 时，$\mathrm{Cov}\left(\frac{1}{s}\sum_{i=1}^{s} X_{i}, \frac{1}{t}\sum_{j=1}^{t} X_{j}\right) = \frac{1}{st} \cdot s \cdot 4 = \frac{4}{t}$。同理，当 $t \leq s$ 时，结果为 $\frac{4}{s}$。综合可得结果为 $\frac{4}{\max\{s,t\}}$。

^q-3254
