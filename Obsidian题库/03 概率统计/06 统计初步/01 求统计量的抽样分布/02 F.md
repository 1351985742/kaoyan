## 001. 1997 数三

- 题目ID：`3290`
- 题号：`1`
- 题源：1997 数三
- 分类：概率统计 / 统计初步 / 求统计量的抽样分布 / F
- 选做：否

设随机变量 $X$ 和 $Y$ 相互独立且都服从正态分布 $N(0,3^{2})$，而 $X_{1},\cdots,X_{9}$ 和 $Y_{1},\cdots,Y_{9}$ 分别是来自总体 $X$ 和 $Y$ 的简单随机样本，则统计量 $U=\frac{X_{1}+\cdots+X_{9}}{\sqrt{Y_{1}^{2}+\cdots+Y_{9}^{2}}}$ 服从 ___ 分布，参数为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由于 $X_{i} \sim N(0, 3^{2})$，则 $X_{1}+\cdots+X_{9} \sim N(0, 9^{2})$，故 $\frac{1}{9}(X_{1}+\cdots+X_{9}) \sim N(0,1)$。同理，$\frac{1}{3}Y_{i} \sim N(0,1)$，于是 $\left(\frac{1}{3}Y_{1}\right)^{2}+\cdots+\left(\frac{1}{3}Y_{9}\right)^{2} \sim \chi^{2}(9)$，即 $\frac{1}{9}(Y_{1}^{2}+\cdots+Y_{9}^{2}) \sim \chi^{2}(9)$。对原统计量转化：$U = \frac{\frac{1}{9}(X_{1}+\cdots+X_{9})}{\sqrt{\frac{1}{81}(Y_{1}^{2}+\cdots+Y_{9}^{2})}}$。根据 $t$ 分布定义，$U \sim t(9)$。因此统计量 $U$ 服从 $t$ 分布，参数为 $9$。

## 002. 1998 数三

- 题目ID：`3291`
- 题号：`2`
- 题源：1998 数三
- 分类：概率统计 / 统计初步 / 求统计量的抽样分布 / F
- 选做：否

设 $X_{1},X_{2},X_{3},X_{4}$ 是来自正态总体 $N(0,2^{2})$ 的简单随机样本，$X = a(X_{1} - 2X_{2})^{2} + b(3X_{3} - 4X_{4})^{2}$，其中 $a,b \neq 0$。则当 $a = \_\_\_\_\_$，$b = \_\_\_\_\_$ 时，统计量 $X$ 服从 $\chi^{2}$ 分布，其自由度为 \_\_\_\_\_。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 因样本 $X_{1}, X_{2}, X_{3}, X_{4}$ 与总体 $N(0, 2^{2})$ 同分布且相互独立，故 $X_{1} - 2X_{2} \sim N(0, 20)$，$3X_{3} - 4X_{4} \sim N(0, 100)$。标准化得 $\frac{X_{1} - 2X_{2}}{\sqrt{20}} \sim N(0,1)$，$\frac{3X_{3} - 4X_{4}}{\sqrt{100}} \sim N(0,1)$。由 $\chi^{2}$ 分布的产生模式，$\left[\frac{X_{1} - 2X_{2}}{\sqrt{20}}\right]^{2} + \left[\frac{3X_{3} - 4X_{4}}{\sqrt{100}}\right]^{2} \sim \chi^{2}(2)$。于是 $a = \frac{1}{20}$，$b = \frac{1}{100}$，自由度为 $2$。

## 003. 2001 数三

- 题目ID：`3292`
- 题号：`3`
- 题源：2001 数三
- 分类：概率统计 / 统计初步 / 求统计量的抽样分布 / F
- 选做：否

设总体 $X$ 服从正态分布 $N(0,2^{2})$，而 $X_{1}, X_{2}, \cdots, X_{15}$ 是来自总体 $X$ 的简单随机样本，则随机变量 $Y = \frac{X_{1}^{2} + \cdots + X_{10}^{2}}{2(X_{11}^{2} + \cdots + X_{15}^{2})}$ 服从 ___ 分布，参数为 ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由于 $X_{i} \sim N(0, 2^{2})$，则 $\frac{X_{i}}{2} \sim N(0,1)$。于是 $\left(\frac{X_{1}}{2}\right)^{2} + \cdots + \left(\frac{X_{10}}{2}\right)^{2} \sim \chi^{2}(10)$，$\left(\frac{X_{11}}{2}\right)^{2} + \cdots + \left(\frac{X_{15}}{2}\right)^{2} \sim \chi^{2}(5)$。因此 $Y = \frac{X_{1}^{2} + \cdots + X_{10}^{2}}{2(X_{11}^{2} + \cdots + X_{15}^{2})} = \frac{\left[\left(\frac{X_{1}}{2}\right)^{2} + \cdots + \left(\frac{X_{10}}{2}\right)^{2}\right]/10}{\left[\left(\frac{X_{11}}{2}\right)^{2} + \cdots + \left(\frac{X_{15}}{2}\right)^{2}\right]/5} \sim F(10,5)$。故 $Y$ 服从 $F$ 分布，参数为 $(10,5)$。

## 004. 2023 数一三

- 题目ID：`3293`
- 题号：`4`
- 题源：2023 数一三
- 分类：概率统计 / 统计初步 / 求统计量的抽样分布 / F
- 选做：否

设 $X_{1}, X_{2}, \cdots, X_{n}$ 为来自总体 $N\left(\mu_{1}, \sigma^{2}\right)$ 的简单随机样本， $Y_{1}, Y_{2}, \cdots, Y_{m}$ 为来自总体 $N\left(\mu_{2}, 2\sigma^{2}\right)$ 的简单随机样本，且两样本相互独立。记 $\bar{X} = \frac{1}{n} \sum_{i=1}^{n} X_{i}, \bar{Y} = \frac{1}{m} \sum_{i=1}^{m} Y_{i}, S_{1}^{2} = \frac{1}{n-1} \sum_{i=1}^{n} \left(X_{i} - \bar{X}\right)^{2}, S_{2}^{2} = \frac{1}{m-1} \sum_{i=1}^{m} \left(Y_{i} - \bar{Y}\right)^{2}$，则

### 选项

A. $\frac{S_{1}^{2}}{S_{2}^{2}} \sim F(n, m)$
B. $\frac{S_{1}^{2}}{S_{2}^{2}} \sim F(n-1, m-1)$
C. $\frac{2S_{1}^{2}}{S_{2}^{2}} \sim F(n, m)$
D. $\frac{2S_{1}^{2}}{S_{2}^{2}} \sim F(n-1, m-1)$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 由两样本方差比与F分布的关系，有 $\frac{S_{1}^{2}/\sigma^{2}}{S_{2}^{2}/(2\sigma^{2})} = \frac{2S_{1}^{2}}{S_{2}^{2}} \sim F(n-1, m-1)$。
