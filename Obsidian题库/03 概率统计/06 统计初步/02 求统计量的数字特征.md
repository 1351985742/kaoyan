## 001. 2001 数一

- 题目ID：`3303`
- 题号：`1`
- 题源：2001 数一
- 分类：概率统计 / 统计初步 / 求统计量的数字特征
- 选做：否

设总体 $X$ 服从正态分布 $N(\mu, \sigma^{2}) (\sigma > 0)$，从该总体中抽取简单随机样本 $X_{1}, X_{2}, \cdots, X_{2n} (n \geqslant 2)$，其样本均值为 $\bar{X} = \frac{1}{2n} \sum_{i=1}^{2n} X_{i}$，求统计量 $Y = \sum_{i=1}^{n} \left( X_{i} + X_{n+i} - 2\bar{X} \right)^{2}$ 的数学期望 $EY$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由于 $X_i (i = 1, 2, \cdots, 2n)$ 独立同分布于 $N(\mu, \sigma^{2})$，则 $(X_i + X_{n+i}) \sim N(2\mu, 2\sigma^{2})$。定义 $Z_i = X_i + X_{n+i}$，则 $Z_1, Z_2, \cdots, Z_n$ 独立同分布于 $N(2\mu, 2\sigma^{2})$。其样本均值为 $\bar{Z} = \frac{1}{n}\sum_{i=1}^{n} Z_i = 2\bar{X}$。统计量 $Y = \sum_{i=1}^{n} (Z_i - \bar{Z})^2$ 即为 $Z$ 的样本离差平方和。样本方差 $S_Z^2 = \frac{1}{n-1}Y$，且 $E(S_Z^2) = D(Z_i) = 2\sigma^{2}$。因此，$E\left(\frac{1}{n-1}Y\right) = 2\sigma^{2}$，解得 $EY = 2(n-1)\sigma^{2}$。

> **解析**

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> (1) $E(T) = E(\overline{X}^2) - \frac{1}{n}E(S^2)$。由于 $\overline{X} \sim N(\mu, \frac{\sigma^2}{n})$，故 $E(\overline{X}^2) = D(\overline{X}) + [E(\overline{X})]^2 = \frac{\sigma^2}{n} + \mu^2$。又 $E(S^2) = \sigma^2$。因此，$E(T) = (\frac{\sigma^2}{n} + \mu^2) - \frac{1}{n}\sigma^2 = \mu^2$，即 $T$ 是 $\mu^2$ 的无偏估计。\n(2) 当 $\mu=0, \sigma=1$ 时，$T = \overline{X}^2 - \frac{1}{n}S^2$。由于 $\overline{X}$ 与 $S^2$ 独立（正态总体下样本均值与样本方差独立），故 $D(T) = D(\overline{X}^2) + \frac{1}{n^2}D(S^2)$。已知 $\sqrt{n}\overline{X} \sim N(0,1)$，则 $n\overline{X}^2 \sim \chi^2(1)$，$D(n\overline{X}^2)=2$，所以 $D(\overline{X}^2) = \frac{2}{n^2}$。又 $(n-1)S^2 \sim \chi^2(n-1)$，$D[(n-1)S^2] = 2(n-1)$，故 $D(S^2) = \frac{2}{n-1}$。因此，$D(T) = \frac{2}{n^2} + \frac{1}{n^2} \cdot \frac{2}{n-1} = \frac{2}{n^2}\left(1 + \frac{1}{n-1}\right) = \frac{2}{n^2} \cdot \frac{n}{n-1} = \frac{2}{n(n-1)}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> 由题意，$N_1 \sim B(n, 1-\theta)$，$N_2 \sim B(n, \theta-\theta^2)$，$N_3 \sim B(n, \theta^2)$，且 $N_1+N_2+N_3=n$。
>
> $E(T) = a_1 E(N_1) + a_2 E(N_2) + a_3 E(N_3) = a_1 n(1-\theta) + a_2 n(\theta-\theta^2) + a_3 n\theta^2 = n[a_1 + (a_2 - a_1)\theta + (a_3 - a_2)\theta^2]$。
>
> 要求 $T$ 为 $\theta$ 的无偏估计，即 $E(T) = \theta$，故有：
> $n a_1 = 0$，$n(a_2 - a_1) = 1$，$n(a_3 - a_2) = 0$。
> 解得：$a_1 = 0$，$a_2 = \frac{1}{n}$，$a_3 = \frac{1}{n}$。
> 因此 $T = \frac{1}{n}(N_2 + N_3)$。
>
> 由于 $N_1 + N_2 + N_3 = n$，故 $N_2 + N_3 = n - N_1$，所以 $T = \frac{1}{n}(n - N_1) = 1 - \frac{N_1}{n}$。
> $D(T) = D\left(1 - \frac{N_1}{n}\right) = \frac{1}{n^2} D(N_1) = \frac{1}{n^2} \cdot n(1-\theta)\theta = \frac{\theta(1-\theta)}{n}$。

设总体 $X$ 服从参数为 $\lambda(\lambda > 0)$ 的泊松分布，$X_{1}, X_{2}, \cdots, X_{n} (n \geqslant 2)$ 为来自该总体的简单随机样本，则对于统计量 $T_{1} = \frac{1}{n} \sum_{i=1}^{n} X_{i}$ 和 $T_{2} = \frac{1}{n-1} \sum_{i=1}^{n-1} X_{i} + \frac{1}{n} X_{n}$，有（）

### 选项

A. $E(T_{1}) > E(T_{2}), D(T_{1}) > D(T_{2})$
B. $E(T_{1}) > E(T_{2}), D(T_{1}) < D(T_{2})$
C. $E(T_{1}) < E(T_{2}), D(T_{1}) > D(T_{2})$
D. $E(T_{1}) < E(T_{2}), D(T_{1}) < D(T_{2})$

> [!success]- 答案解析
> **答案**
>
> D
>
> **解析**
>
> 由于 $X_i$ 独立同分布于 $P(\lambda)$，$E(X_i) = \lambda$，$D(X_i) = \lambda$。
>
> $E(T_1) = \frac{1}{n} \sum_{i=1}^{n} E(X_i) = \frac{1}{n} \cdot n \lambda = \lambda$。
>
> $E(T_2) = \frac{1}{n-1} \sum_{i=1}^{n-1} E(X_i) + \frac{1}{n} E(X_n) = \frac{1}{n-1} \cdot (n-1)\lambda + \frac{1}{n} \lambda = \lambda + \frac{\lambda}{n}$。
> 故 $E(T_2) > E(T_1)$。
>
> $D(T_1) = D\left(\frac{1}{n} \sum_{i=1}^{n} X_i\right) = \frac{1}{n^2} \sum_{i=1}^{n} D(X_i) = \frac{1}{n^2} \cdot n \lambda = \frac{\lambda}{n}$。
>
> $D(T_2) = D\left(\frac{1}{n-1} \sum_{i=1}^{n-1} X_i + \frac{1}{n} X_n\right) = \frac{1}{(n-1)^2} \sum_{i=1}^{n-1} D(X_i) + \frac{1}{n^2} D(X_n) = \frac{1}{(n-1)^2} \cdot (n-1)\lambda + \frac{1}{n^2} \lambda = \frac{\lambda}{n-1} + \frac{\lambda}{n^2}$。
> 由于 $\frac{1}{n-1} > \frac{1}{n}$，故 $D(T_2) > \frac{\lambda}{n} = D(T_1)$。
> 因此 $E(T_1) < E(T_2)$，$D(T_1) < D(T_2)$，应选 D。

### 选项

A. $\hat{\theta}$ 是 $\theta$ 的无偏估计， $D(\hat{\theta})=\frac{\sigma_{1}^{2}+\sigma_{2}^{2}}{n}$
B. $\hat{\theta}$ 不是 $\theta$ 的无偏估计， $D(\hat{\theta})=\frac{\sigma_{1}^{2}+\sigma_{2}^{2}}{n}$
C. $\hat{\theta}$ 是 $\theta$ 的无偏估计， $D(\hat{\theta})=\frac{\sigma_{1}^{2}+\sigma_{2}^{2}-2\rho\sigma_{1}\sigma_{2}}{n}$
D. $\hat{\theta}$ 不是 $\theta$ 的无偏估计， $D(\hat{\theta})=\frac{\sigma_{1}^{2}+\sigma_{2}^{2}-2\rho\sigma_{1}\sigma_{2}}{n}$

>
> **解析**
>
> 由于总体 $(X,Y)$ 服从 $N(\mu_{1},\mu_{2};\sigma_{1}^{2},\sigma_{2}^{2};\rho)$，故 $X\sim N(\mu_{1},\sigma_{1}^{2})$， $Y\sim N(\mu_{2},\sigma_{2}^{2})$，从而 $\bar{X}\sim N\left(\mu_{1},\frac{\sigma_{1}^{2}}{n}\right)$， $\bar{Y}\sim N\left(\mu_{2},\frac{\sigma_{2}^{2}}{n}\right)$。计算 $E(\hat{\theta})$： 
>
> $$
> E(\widehat{\theta})=E(\overline{X}-\overline{Y})=E(\overline{X})-E(\overline{Y})=\mu_{1}-\mu_{2}=\theta.
> $$
>
>  计算 $D(\hat{\theta})$： 
>
> $$
> D(\widehat{\theta})=D(\overline{X}-\overline{Y})=D(\overline{X})+D(\overline{Y})-2\operatorname{Cov}(\overline{X},\overline{Y})=\frac{\sigma_{1}^{2}}{n}+\frac{\sigma_{2}^{2}}{n}-2\operatorname{Cov}(\overline{X},\overline{Y}).
> $$
>
>  由于 $(X_{1},Y_{1}),(X_{2},Y_{2}),\cdots,(X_{n},Y_{n})$ 为简单随机样本，故它们相互独立，从而当 $i\neq j$ 时， $X_{i}$ 与 $Y_{j}$ 独立。于是， $\operatorname{Cov}(X_{i},Y_{i})=\operatorname{Cov}(X,Y),\operatorname{Cov}(X_{i},Y_{j})=0(i\neq j)$。

> $$

>
>  因此， 
>
> $$
> D(\hat{\theta})=\frac{\sigma_{1}^{2}}{n}+\frac{\sigma_{2}^{2}}{n}-2\operatorname{Cov}(\overline{X},\overline{Y})=\frac{\sigma_{1}^{2}}{n}+\frac{\sigma_{2}^{2}}{n}-\frac{2}{n}\operatorname{Cov}(X,Y)=\frac{\sigma_{1}^{2}+\sigma_{2}^{2}-2\rho\sigma_{1}\sigma_{2}}{n}.
> $$
>
>  应选 B。

设总体 $X$ 的均匀分布为 $F(x)$，$X_{1}$，$X_{2}$，$\cdots$，$X_{n}$ 为来自总体 $X$ 的简单随机样本，样本的经验分布函数为 $F_{n}(x)$，对于给定的 $x (0 < F(x) < 1)$，$D\left[F_{n}(x)\right] =$

### 选项

A. $F(x)(1-F(x))$

>
