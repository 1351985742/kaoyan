## 001. 1995 数三

- 题目ID：`3150`
- 题号：`1`
- 题源：1995 数三
- 分类：概率统计 / 二维随机变量 / 联合分布函数
- 选做：否

已知随机变量 X 和 Y 的联合概率密度为 

$$
\varphi(x,y)=\left\{\begin{aligned}4xy,0&\le x\le1,0\le y\le1\\ 0,\quad& 其他 .\end{aligned}\right.
$$

 求 X 和 Y 联合分布函数 $F(x,y)$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> $$
> F(x, y)=\left\{\begin{array}{ll}0,&x<0 \text{ 或 } y<0,\\x^{2}y^{2},&0\le x\le1,\ 0\le y\le1,\\x^{2},&y>1,\ 0\le x\le1,\\y^{2},&x>1,\ 0\le y\le1,\\1,&x>1,\ y>1.\end{array}\right.
> $$

## 002. 姜晓千基础例题

- 题目ID：`3151`
- 题号：`2`
- 题源：姜晓千基础例题
- 分类：概率统计 / 二维随机变量 / 联合分布函数
- 选做：否

下列四个函数哪个不能作为联合分布函数？

### 选项

A. $F_{1}(x,y)=\left\{\begin{aligned}(1-e^{-x})(1-e^{-y}),&0<x<+\infty,0<y<+\infty\\ 0,& 其他 \end{aligned}\right.$
B. $F_{2}(x,y)=\frac{1}{\pi^{2}}\Bigg(\frac{\pi}{2}+\arctan\frac{x}{2}\Bigg)\Bigg(\frac{\pi}{2}+\arctan\frac{y}{3}\Bigg)$
C. $F_{3}(x,y)=\begin{cases}1,x+2y\ge1\\ 0,x+2y<1\end{cases}$
D. $F_{4}(x,y)=\left\{\begin{aligned}&1-2^{-x}-2^{-y}+2^{-x-y},0<x<+\infty,0<y<+\infty\\ &0,\quad 其他 \end{aligned}\right.$

> [!success]- 答案解析
> **答案**
>
> C
>
> **解析**
>
> 对于 $F_3$，取 $x=1, y=0$，则 $P\{0<X\le1,0<Y\le1\} = F(1,1)-F(0,1)-F(1,0)+F(0,0) = 1 - 1 - 1 + 0 = -1 < 0$，不满足概率的非负性，故 $F_3$ 不能作为联合分布函数。

## 003. 姜晓千强化例题

- 题目ID：`3152`
- 题号：`3`
- 题源：姜晓千强化例题
- 分类：概率统计 / 二维随机变量 / 联合分布函数
- 选做：否

设随机变量 X 与 Y 相互独立， $X \sim B(1, p)$， $Y \sim E(\lambda)$，则 $(X, Y)$ 的联合分布函数 $F(x, y) =$ ___。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> X的边缘分布函数为 $F_X(x)=\begin{cases}0,&x\le0\\ 1-p,&0<x<1\\ 1,&x\ge1\end{cases}$，Y的边缘分布函数为 $F_Y(y)=\begin{cases}1-e^{-\lambda y},&y>0\\0,&y\le0\end{cases}$。由于X与Y独立，联合分布函数 $F(x,y)=F_X(x)F_Y(y)$，即 
>
> $$
> F(x,y)=\left\{\begin{array}{ll}(1-p)(1-e^{-\lambda y}),&0\le x<1,\ y>0\\1-e^{-\lambda y},&x\ge1,\ y>0\\0,& \text{其他}\end{array}\right.
> $$

## 004. 姜晓千基础例题

- 题目ID：`3153`
- 题号：`4`
- 题源：姜晓千基础例题
- 分类：概率统计 / 二维随机变量 / 联合分布函数
- 选做：否

设随机变量 $(X,Y)$的联合概率密度为 

$$
f(x,y)=\left\{\begin{aligned}Ce^{-(3x+4y)},&x>0,y>0\\ 0,& 其他 \end{aligned}\right.
$$

 求：(1) 常数C；(2) 联合分布函数 $F(x, y)$；(3) $P\{0 < X \le 1, 0 < Y \le 2\}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> (1) 由归一性：
>
> $$
> 1 = \int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x,y) \, dx dy = C \int_{0}^{+\infty} e^{-3x} dx \int_{0}^{+\infty} e^{-4y} dy = C \cdot \frac{1}{3} \cdot \frac{1}{4}
> $$
>
>  得 $C = 12$。
> (2) 联合分布函数：
>
> $$
> F(x,y)=\int_{-\infty}^{x} \int_{-\infty}^{y} f(u,v) \, du dv = \left\{\begin{array}{ll} 12 \int_{0}^{x} e^{-3u} du \int_{0}^{y} e^{-4v} dv = (1-e^{-3x})(1-e^{-4y}), & x>0,\ y>0 \\ 0, & \text{其他} \end{array}\right.
> $$
>
>  
> (3) 法一（用联合分布函数）：
>
> $$
> P\{0 < X \le 1, 0 < Y \le 2\} = F(1,2)-F(0,2)-F(1,0)+F(0,0) = (1-e^{-3})(1-e^{-8})
> $$
>
>  法二（用联合概率密度）：
>
> $$
> 原式 = 12 \int_{0}^{1} e^{-3x} dx \int_{0}^{2} e^{-4y} dy = (1-e^{-3})(1-e^{-8})
> $$

## 005. 姜晓千强化例题

- 题目ID：`3154`
- 题号：`5`
- 题源：姜晓千强化例题
- 分类：概率统计 / 二维随机变量 / 联合分布函数
- 选做：否

设二维随机变量 $(X,Y)$ 的联合概率密度为 $f(x,y)=\begin{cases}1, & 0<x<1,0<y<2x \\ 0, & \text{其他} \end{cases}$，求：
(I) $(X,Y)$ 的联合分布函数 $F(x,y)$;
(II) $(X,Y)$ 的边缘概率密度 $f_X(x), f_Y(y)$;
(III) 条件概率密度 $f_{X|Y}(x|y), f_{Y|X}(y|x)$;
(IV) $P\left\{Y \leq \frac{1}{2} \mid X \leq \frac{1}{2}\right\}$, $P\left\{Y \leq \frac{1}{2} \mid X = \frac{1}{2}\right\}$;
(V) $Z = 2X - Y$ 的概率密度 $f_Z(z)$.

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> (I) 联合分布函数 $F(x,y)$:
> 当 $0 \leq x \leq 1, 0 \leq y \leq 2x$ 时，$F(x,y) = xy - \frac{y^2}{4}$;
> 当 $x \geq 1, 0 < y < 2$ 时，$F(x,y) = y - \frac{y^2}{4}$;
> 当 $0 < x < 1, y \geq 2x$ 时，$F(x,y) = x^2$;
> 当 $x \geq 1, y \geq 2$ 时，$F(x,y) = 1$;
> 其他情况 $F(x,y) = 0$.
>
> (II) 边缘概率密度:
> $f_X(x) = \int_{-\infty}^{+\infty} f(x,y) dy = \begin{cases} 2x, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$
> $f_Y(y) = \int_{-\infty}^{+\infty} f(x,y) dx = \begin{cases} 1 - \frac{y}{2}, & 0 < y < 2 \\ 0, & \text{其他} \end{cases}$
>
> (III) 条件概率密度:
> 当 $0 < x < 1$ 时，$f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)} = \begin{cases} \frac{1}{2x}, & 0 < y < 2x \\ 0, & \text{其他} \end{cases}$
> 当 $0 < y < 2$ 时，$f_{X|Y}(x|y) = \frac{f(x,y)}{f_Y(y)} = \begin{cases} \frac{1}{1 - \frac{y}{2}}, & \frac{y}{2} < x < 1 \\ 0, & \text{其他} \end{cases}$
>
> (IV) 条件概率:
> $P\left\{X \leq \frac{1}{2}\right\} = \int_0^{\frac{1}{2}} 2x dx = \frac{1}{4}$
> $P\left\{X \leq \frac{1}{2}, Y \leq \frac{1}{2}\right\} = \int_0^{\frac{1}{2}} dy \int_{\frac{y}{2}}^{\frac{1}{2}} dx = \int_0^{\frac{1}{2}} \left(\frac{1}{2} - \frac{y}{2}\right) dy = \frac{3}{16}$
> $P\left\{Y \leq \frac{1}{2} \mid X \leq \frac{1}{2}\right\} = \frac{P\left\{X \leq \frac{1}{2}, Y \leq \frac{1}{2}\right\}}{P\left\{X \leq \frac{1}{2}\right\}} = \frac{3/16}{1/4} = \frac{3}{4}$
> $P\left\{Y \leq \frac{1}{2} \mid X = \frac{1}{2}\right\} = \int_{-\infty}^{\frac{1}{2}} f_{Y|X}(y|\frac{1}{2}) dy = \int_0^{\frac{1}{2}} 1 dy = \frac{1}{2}$
>
> (V) $Z = 2X - Y$ 的概率密度:
> $f_Z(z) = \begin{cases} 1 - \frac{z}{2}, & 0 < z < 2 \\ 0, & \text{其他} \end{cases}$
