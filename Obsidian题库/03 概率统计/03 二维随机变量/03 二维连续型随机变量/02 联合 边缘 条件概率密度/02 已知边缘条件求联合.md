## 001. 姜晓千强化例题

- 题目ID：`3181`
- 题号：`1`
- 题源：姜晓千强化例题
- 分类：概率统计 / 二维随机变量 / 二维连续型随机变量 / 联合 边缘 条件概率密度 / 已知边缘条件求联合
- 选做：否

设随机变量 $X \sim U(0,1)$，在 $X = x (0 < x < 1)$ 的条件下，随机变量 $Y \sim U(x,1)$。
(I) 求 $(X,Y)$ 的联合概率密度；
(II) 求 $(X,Y)$ 关于 $Y$ 的边缘概率密度 $f_{Y}(y)$；
(III) 求 $P\{X + Y > 1\}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> X的边缘概率密度为 $f_X(x) = \begin{cases} 1, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$。在 $X = x$ 条件下，$Y$ 的条件概率密度为 $f_{Y|X}(y|x) = \begin{cases} \frac{1}{1-x}, & x < y < 1 \\ 0, & \text{其他} \end{cases}$。
> (I) 联合概率密度 $f(x,y) = f_X(x) \cdot f_{Y|X}(y|x) = \begin{cases} \frac{1}{1-x}, & 0 < x < 1, x < y < 1 \\ 0, & \text{其他} \end{cases}$。
> (II) $Y$ 的边缘概率密度 $f_Y(y) = \int_{-\infty}^{\infty} f(x,y) dx = \int_{0}^{y} \frac{1}{1-x} dx = -\ln(1-y), \quad 0 < y < 1$，其他为0。
> (III) $P\{X + Y > 1\} = \iint_{x+y>1} f(x,y) dxdy = \int_{0}^{1} \int_{\max(x,1-x)}^{1} \frac{1}{1-x} dy dx = \int_{0}^{1/2} \int_{1-x}^{1} \frac{1}{1-x} dy dx + \int_{1/2}^{1} \int_{x}^{1} \frac{1}{1-x} dy dx = \int_{0}^{1/2} \frac{x}{1-x} dx + \int_{1/2}^{1} 1 dx = \frac{1}{2} + \ln 2$。

## 002. 2013 数三

- 题目ID：`3182`
- 题号：`2`
- 题源：2013 数三
- 分类：概率统计 / 二维随机变量 / 二维连续型随机变量 / 联合 边缘 条件概率密度 / 已知边缘条件求联合
- 选做：否

设 $(X,Y)$ 是二维随机变量，$X$ 的边缘概率密度为 $f_X(x) = \begin{cases} 3x^2, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$，在给定 $X = x (0 < x < 1)$ 的条件下，$Y$ 的条件概率密度为 $f_{Y|X}(y|x) = \begin{cases} \frac{3y^2}{x^3}, & 0 < y < x \\ 0, & \text{其他} \end{cases}$。
(I) 求 $(X,Y)$ 的概率密度 $f(x,y)$；
(II) 求 $Y$ 的边缘概率密度 $f_Y(y)$；
(III) 求 $P\{X > 2Y\}$。

> [!success]- 答案解析
> **答案**
>
> 无
>
> **解析**
>
> (I) $f(x,y) = f_X(x) \cdot f_{Y|X}(y|x) = \begin{cases} 3x^2 \cdot \frac{3y^2}{x^3} = \frac{9y^2}{x}, & 0 < y < x < 1 \\ 0, & \text{其他} \end{cases}$。
> (II) $f_Y(y) = \int_{-\infty}^{\infty} f(x,y) dx = \int_{y}^{1} \frac{9y^2}{x} dx = 9y^2 \ln x \big|_{y}^{1} = -9y^2 \ln y, \quad 0 < y < 1$，其他为0。
> (III) $P\{X > 2Y\} = \iint_{x > 2y} f(x,y) dxdy = \int_{0}^{1/2} \int_{2y}^{1} \frac{9y^2}{x} dx dy = \int_{0}^{1/2} 9y^2 (\ln 1 - \ln(2y)) dy = -9 \int_{0}^{1/2} y^2 \ln(2y) dy = \frac{1}{4} - \frac{3}{8} \ln 2$。

^q-3182
