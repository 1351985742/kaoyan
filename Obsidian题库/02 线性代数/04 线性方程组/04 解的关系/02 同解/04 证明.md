## 001. 姜晓千基础例题

- 题目ID：`570`
- 题号：`1`
- 题源：姜晓千基础例题
- 分类：线性代数 / 线性方程组 / 解的关系 / 同解 / 证明
- 选做：是

设 A为 $m \times n$ 矩阵。证明： (I)线性方程组 $A^T A x=0$ 与 $Ax=0$ 同解； (II) $r(A^T A) = r(A)$。

> [!success]- 答案解析
> **答案**
>
> 见解析。
>
> **解析**
>
> (I) **证同解**：
> - 充分性：若 $Ax = 0$，则 $A^T A x = A^T (Ax) = A^T 0 = 0$；
> - 必要性：若 $A^T A x = 0$，左乘 $x^T$ 得：
>   $$x^T A^T A x = (Ax)^T (Ax) = \|Ax\|^2 = 0 \implies Ax = 0$$
> 故 $A^T A x = 0$ 与 $Ax = 0$ 同解。
>
> (II) **证秩相等**：
> $A$ 与 $A^T A$ 的列数均为 $n$，齐次方程组未知数个数均为 $n$。
> 两方程组同解 $\implies$ 基础解系所含向量个数（解空间维数）相同：
> $$n - r(A^T A) = n - r(A) \implies r(A^T A) = r(A)$$

## 002. 姜晓千基础例题

- 题目ID：`571`
- 题号：`2`
- 题源：姜晓千基础例题
- 分类：线性代数 / 线性方程组 / 解的关系 / 同解 / 证明
- 选做：是

设 $A$ 为 $m \times n$ 矩阵，$B$ 为 $n \times s$ 阶矩阵，且 $r(A)=n$。证明： (I)线性方程组 $ABx=0$ 与 $Bx=0$ 同解； (II) $r(AB) = r(B)$。

> [!success]- 答案解析
> **答案**
>
> 见解析。
>
> **解析**
>
> (I) **证同解**：
> - 充分性：若 $Bx = 0$，则 $ABx = A(Bx) = A 0 = 0$；
> - 必要性：若 $ABx = 0$，记 $y = Bx$（为 $n$ 维列向量），则 $Ay = 0$。
>   因为 $A$ 为 $m \times n$ 矩阵且 $r(A) = n$（列满秩），齐次方程组 $Ay = 0$ 只有零解，故必有 $y = 0$，即 $Bx = 0$。
> 故 $ABx = 0$ 与 $Bx = 0$ 同解。
>
> (II) **证秩相等**：
> 两方程组未知数个数均为 $s$（$B$ 的列数）。
> 同解 $\implies$ 解空间维数相等：
> $$s - r(AB) = s - r(B) \implies r(AB) = r(B)$$

## 003. 姜晓千真题同源 150

- 题目ID：`572`
- 题号：`3`
- 题源：姜晓千真题同源 150
- 分类：线性代数 / 线性方程组 / 解的关系 / 同解 / 证明
- 选做：是

设 $A$ 为 $n$ 阶矩阵，$\boldsymbol{\alpha}$ 为 n维列向量。证明： (I)若存在正整数 $m$，使得 $A^m \boldsymbol{\alpha} \neq \mathbf{0}$，$A^{m+1}\boldsymbol{\alpha} = \mathbf{0}$，则向量组 $\boldsymbol{\alpha}, A\boldsymbol{\alpha}, \dots, A^m\boldsymbol{\alpha}$ 线性无关； (II)线性方程组 $A^nx=0$ 与 $A^{n+1}x=0$ 同解； (III) $r(A^n) = r(A^{n+1})$。

> [!success]- 答案解析
> **答案**
>
> 见解析。
>
> **解析**
>
> (I) **逼零法证无关**：
> 设 $k_0 \boldsymbol{\alpha} + k_1 A\boldsymbol{\alpha} + \dots + k_m A^m \boldsymbol{\alpha} = \mathbf{0}$。
> 两边左乘 $A^m$：
> $$k_0 A^m \boldsymbol{\alpha} + k_1 A^{m+1}\boldsymbol{\alpha} + \dots + k_m A^{2m}\boldsymbol{\alpha} = \mathbf{0}$$
> 因为 $A^{m+1}\boldsymbol{\alpha} = \mathbf{0}$，后面各项全为 $\mathbf{0}$，故 $k_0 A^m \boldsymbol{\alpha} = \mathbf{0}$。
> 又 $A^m \boldsymbol{\alpha} \neq \mathbf{0}$，必有 $k_0 = 0$。
> 依次在原式两端左乘 $A^{m-1}, A^{m-2}, \dots, A$，逐项递推可得 $k_1 = k_2 = \dots = k_m = 0$。
> 故向量组 $\boldsymbol{\alpha}, A\boldsymbol{\alpha}, \dots, A^m\boldsymbol{\alpha}$ 线性无关。
>
> (II) **维度天花板反证法**：
> - 显然若 $A^n x = 0$，则 $A^{n+1} x = A(A^n x) = \mathbf{0}$，即 $A^n x = 0$ 的解必是 $A^{n+1} x = 0$ 的解。
> - 反之，假设存在 $x_0$ 满足 $A^{n+1} x_0 = \mathbf{0}$，但 $A^n x_0 \neq \mathbf{0}$。
>   此时令向量 $\boldsymbol{\alpha} = x_0$，$m = n$。由 (I) 的结论，向量组：
>   $$x_0, A x_0, A^2 x_0, \dots, A^n x_0$$
>   线性无关。
>   但这包含了 $n+1$ 个 $n$ 维列向量！在 $n$ 维向量空间 $\mathbb{R}^n$ 中，任意 $n+1$ 个向量必线性相关，矛盾！
>   故不存在这样的 $x_0$，即 $A^{n+1} x = 0 \implies A^n x = 0$。
> 故线性方程组 $A^n x = 0$ 与 $A^{n+1} x = 0$ 同解。
>
> (III) **解空间维数定秩**：
> 未知数个数均为 $n$。由同解得解空间维数相同：
> $$n - r(A^n) = n - r(A^{n+1}) \implies r(A^n) = r(A^{n+1})$$

^q-572
