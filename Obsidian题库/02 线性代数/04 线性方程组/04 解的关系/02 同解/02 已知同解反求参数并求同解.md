## 002. 900 题数二第四章 A 类 21

- 题目ID：`566`
- 题号：`2`
- 题源：900 题数二第四章 A 类 21
- 分类：线性代数 / 线性方程组 / 解的关系 / 同解 / 已知同解反求参数并求同解
- 选做：否

已知齐次线性方程组(i)$\begin{cases} x_1+2x_2+3x_3=0,\\ 2x_1+3x_2+5x_3=0,\\ x_1+ax_2+bx_3=0 \end{cases}$ 和 (ii)$\begin{cases} x_1+x_2+cx_3=0,\\ 2x_1+b^2x_2+(c+1)x_3=0 \end{cases}$ 同解,求 $a, b, c$ 的值。

> [!success]- 答案解析
> **答案**
>
> $a = 0, b = 1, c = 2$ 或 $a = -2, b = -1, c = 2$；同解为 $x = k(1, 1, -1)^T$ ($k \in \mathbb{R}$)。
>
> **解析**
>
> 1. **定秩**：(i) 的前两行系数矩阵 $\begin{pmatrix} 1 & 2 & 3 \\ 2 & 3 & 5 \end{pmatrix}$ 秩为 2。若 $r(i)=3$，则 (i) 只有零解，但 (ii) 仅 2 个方程 3 个未知数必有非零解，矛盾。故 $r(i)=2$。
> 2. **求基础解系与约束**：由 (i) 前两式得基础解系 $\xi = (1, 1, -1)^T$。第三式必满足 $1 + a - b = 0 \implies b = a + 1$。
> 3. **代入 (ii) 反求参数**：将 $\xi$ 代入 (ii)：
>    - 第 1 式：$1 + 1 - c = 0 \implies c = 2$；
>    - 第 2 式：$2 + b^2 - 3 = 0 \implies b^2 = 1 \implies b = \pm 1$。
> 4. **核对秩**：
>    - 当 $b=1$ 时，$a=0$，(ii) 矩阵两行不成比例，$r(ii)=2$，同解；
>    - 当 $b=-1$ 时，$a=-2$，(ii) 矩阵两行不成比例，$r(ii)=2$，同解。
>
> 综上，$(a, b, c) = (0, 1, 2)$ 或 $(-2, -1, 2)$。

## 004. 25 版 880 方程组基础解答 5

- 题目ID：`568`
- 题号：`4`
- 题源：25 版 880 方程组基础解答 5
- 分类：线性代数 / 线性方程组 / 解的关系 / 同解 / 已知同解反求参数并求同解
- 选做：否

设有方程组①$\begin{cases} x_1 - x_4 = -2,\\ x_2 - x_4 = -4,\\ -4x_2 - x_3 + 6x_4 = 21, \end{cases}$ ②$\begin{cases} x_1 + ax_2 - x_3 - x_4 = -5,\\ bx_2 - x_3 - 2x_4 = -11,\\ x_3 - 2x_4 = -c+1. \end{cases}$ (I) 求方程组①的通解； (II) 当 $a,b,c$ 为何值时，方程组①与②同解。

> [!success]- 答案解析
> **答案**
>
> (I) 方程组 ① 的通解为 $x = \begin{pmatrix} -2 \\ -4 \\ -5 \\ 0 \end{pmatrix} + k \begin{pmatrix} 1 \\ 1 \\ 2 \\ 1 \end{pmatrix}$ ($k \in \mathbb{R}$)。
> (II) 当 $a = 2, b = 4, c = 6$ 时，方程组 ① 与 ② 同解。
>
> **解析**
>
> 1. **求方程组 ① 的通解**：
>    增广矩阵或直接回代：
>    - $x_1 = x_4 - 2$
>    - $x_2 = x_4 - 4$
>    - $-4(x_4 - 4) - x_3 + 6x_4 = 21 \implies -x_3 + 2x_4 + 16 = 21 \implies x_3 = 2x_4 - 5$
>    令自由未知量 $x_4 = k$，得特解 $\eta = (-2, -4, -5, 0)^T$，导出组基础解系 $\xi = (1, 1, 2, 1)^T$。通解为 $x = \eta + k\xi$。
> 2. **代入 ② 反求参数**：
>    同解要求 ① 的任意解均为 ② 的解。
>    - 将特解 $\eta = (-2, -4, -5, 0)^T$ 代入 ②：
>      - 式 3：$-5 - 0 = -c + 1 \implies c = 6$；
>      - 式 2：$-4b - (-5) - 0 = -11 \implies -4b = -16 \implies b = 4$；
>      - 式 1：$-2 + a(-4) - (-5) - 0 = -5 \implies 3 - 4a = -5 \implies a = 2$。
>    - 将导出组基础解系 $\xi = (1, 1, 2, 1)^T$ 代入 ② 的导出组验证：全部恒等成立。
>    - 此时 ② 系数矩阵秩为 3，解空间维数 $4 - 3 = 1$，与 ① 维数相同且解集包含，故两方程组同解。
> 
> 综上，$a = 2, b = 4, c = 6$。
