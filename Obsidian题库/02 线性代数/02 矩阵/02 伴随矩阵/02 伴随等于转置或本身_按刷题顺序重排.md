# 伴随等于转置或本身｜按刷题顺序重排

- 分类ID：`38`
- 分类路径：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 题量：`8`

> [!tip]- 本页刷题结构与执行顺序
> 本小节共 8 题。围绕伴随矩阵三大特化形式：$A^* = A^T$（正交模长模型）、$A^* = -A^T$（负对合模型）以及 $A^* = A$（特征值与逆矩阵对合）。通法只有一招：**两端同左乘 $A$，利用 $AA^* = |A|E$ 转化为矩阵正交或平方关系，再两边取行列式解 $|A|$！**


## 题型 01｜$A^* = A^T$ 与正交模长法则（含 $a_{ij} = A_{ij}$）

> 核心落点：$A^* = A^T \iff AA^T = |A|E$。两边取行列式得 $|A|=1$（3阶非零），且每行模平方等于 $|A|$（即 $\sum a_{ik}^2 = |A|$）。


### 锚点题

#### 001. (1994 数一)

- 题目ID：`172`
- 题号：`1`
- 题源：(1994 数一)
- 分类：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 选做：否

设 $A$ 为 $n$ 阶非零方阵, $A^*$ 是 $A$ 的伴随矩阵, $A^T$ 是 $A$ 的转置矩阵. 当 $A^* = A^T$ 时, 证明 $|A| \neq 0$.

> [!success]- 答案解析
> **答案**
>
> 证明见解析。
>
> **解析**
>
> **方法一：反证法（秩的性质）**
> 假设 $|A| = 0$。
> 1. 根据伴随矩阵定义：$A A^* = |A| E = O$。
> 2. 将已知条件 $A^* = A^T$ 代入得：
>    $$A A^T = O$$
> 3. 计算实矩阵 $A A^T$ 的对角线元素（即 $A$ 各行向量的模长平方）：
>    $$(A A^T)_{ii} = \sum_{j=1}^n a_{ij}^2 = 0 \quad (i = 1, 2, \dots, n)$$
> 4. 由于 $a_{ij}$ 均为实数，平方和为 0 推出所有元素 $a_{ij} = 0$，即 $A = O$。
> 这与已知条件“$A$ 为非零方阵”产生矛盾！
> 因此假设不成立，必有 $|A| \neq 0$。证明完毕。
>
> ---
>
> **方法二：直接取行列式**
> 由 $A A^T = |A| E$，两边取行列式：
> $$|A A^T| = ||A| E| \implies |A|^2 = |A|^n \implies |A|^2 (|A|^{n-2} - 1) = 0$$
> 若 $|A| = 0$，同理可推出 $A A^T = O \implies A = O$（矛盾）。故必有 $|A| \neq 0$（且 $|A| = 1$）。

#### 002. (2005 数三)

- 题目ID：`173`
- 题号：`2`
- 题源：(2005 数三)
- 分类：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 选做：否

设矩阵 $A = (a_{ij})_{3 \times 3}$ 满足 $A^* = A^T$, 其中 $A^*$ 是 $A$ 的伴随矩阵, $A^T$ 为 $A$ 的转置矩阵. 若 $a_{11}, a_{12}, a_{13}$ 为三个相等的正数, 则 $a_{11}$ 为 ( )(A) $\sqrt{3}$.(B) $3$.(C) $\frac{\sqrt{3}}{3}$.(D) $\frac{1}{\sqrt{3}}$.

> [!success]- 答案解析
> **答案**
>
> **C**（或等价的 $\frac{1}{\sqrt{3}}$，真题标准选项为 $\frac{\sqrt{3}}{3}$）
>
> **解析**
>
> 1. **由关系式求行列式 $|A|$**：
>    已知 $A^* = A^T$，两边左乘 $A$：
>    $$A A^* = A A^T \implies |A| E = A A^T$$
>    两边取行列式（3 阶矩阵）：
>    $$||A| E| = |A A^T| \implies |A|^3 = |A|^2 \implies |A|^2 (|A| - 1) = 0$$
>    因为 $a_{11}, a_{12}, a_{13} > 0 \implies A \neq O \implies |A| \neq 0$，故解得：
>    $$|A| = 1$$
> 2. **由第一行模长求 $a_{11}$**：
>    对比 $A A^T = |A| E = E$ 的第 1 行第 1 列元素（即 $A$ 第一行向量自身内积）：
>    $$a_{11}^2 + a_{12}^2 + a_{13}^2 = 1$$
>    已知 $a_{11} = a_{12} = a_{13} > 0$，代入得：
>    $$3 a_{11}^2 = 1 \implies a_{11}^2 = \frac{1}{3} \implies a_{11} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$
> 故正确答案选 **C**。

#### 003. 25 版 880 行列式基础选择 4

- 题目ID：`174`
- 题号：`3`
- 题源：25 版 880 行列式基础选择 4
- 分类：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 选做：否

设 $3$ 阶矩阵 $\mathbf{A} = (a_{ij})_{3 \times 3}$ 满足 $\mathbf{A}^T = k\mathbf{A}^* (k>0)$, 若 $a_{11} = a_{12} = a_{13} = c > 0$, 则 $c =$ ( ).A. $\frac{\sqrt{3}}{3 k}$B. $\frac{\sqrt{3} k^2}{3}$C. $\sqrt{3} k^2$D. $\frac{\sqrt{3}}{k^2}$

> [!success]- 答案解析
> **答案**
>
> **A**
>
> **解析**
>
> 1. 由 $A^T = k A^* \implies A^* = \frac{1}{k} A^T$。
> 2. 两边左乘 $A$：
>    $$A A^* = \frac{1}{k} A A^T \implies |A| E = \frac{1}{k} A A^T \implies A A^T = k |A| E$$
> 3. 两端取行列式（3 阶）：
>    $$|A A^T| = |k |A| E| \implies |A|^2 = (k |A|)^3 = k^3 |A|^3 \implies |A|^2 (k^3 |A| - 1) = 0$$
>    由于 $c > 0 \implies A \neq O \implies |A| \neq 0$，解得：
>    $$|A| = \frac{1}{k^3}$$
> 4. 代入 $A A^T = k |A| E$：
>    $$A A^T = k \cdot \frac{1}{k^3} E = \frac{1}{k^2} E$$
> 5. 考虑第 1 行与自身做内积：
>    $$a_{11}^2 + a_{12}^2 + a_{13}^2 = \frac{1}{k^2} \implies 3 c^2 = \frac{1}{k^2} \implies c^2 = \frac{1}{3k^2} \implies c = \frac{1}{\sqrt{3}k} = \frac{\sqrt{3}}{3k}$$
> 故正确答案选 **A**。

#### 006. 姜晓千真题同源 150(重点)

- 题目ID：`177`
- 题号：`6`
- 题源：姜晓千真题同源 150(重点)
- 分类：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 选做：否

设 $A = (a_{ij})$ 为 $3$ 阶非零矩阵, $A_{ij}$ 为 $a_{ij}$ 的代数余子式, $A_{ij} = a_{ij} (i,j=1,2,3)$, 则 $|A| =$ ______.

> [!success]- 答案解析
> **答案**
>
> $$|A| = 1$$
>
> **解析**
>
> 1. 由伴随矩阵定义，$A^*$ 的第 $i$ 行第 $j$ 列元素是 $A_{ji}$。
>    已知 $A_{ji} = a_{ji}$，说明 $(A^*)_{ij} = a_{ji} = (A^T)_{ij}$，即：
>    $$A^* = A^T$$
> 2. 两端左乘矩阵 $A$：
>    $$A A^* = A A^T \implies |A| E = A A^T$$
> 3. 两边取行列式：
>    $$||A| E| = |A A^T| \implies |A|^3 = |A|^2 \implies |A|^2 (|A| - 1) = 0$$
> 4. 因为 $A \neq O$，若 $|A| = 0 \implies A A^T = O \implies A = O$（矛盾），故必有 $|A| \neq 0$。
> 5. 解得唯一非零值：
>    $$|A| = 1$$

#### 007. 900 题数二第二章 B 类 7

- 题目ID：`178`
- 题号：`7`
- 题源：900 题数二第二章 B 类 7
- 分类：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 选做：否

设 $A$ 为 $n (n \ge 2)$ 阶非零矩阵, 且满足 $a_{ij} = A_{ij}, i, j = 1,2,\cdots, n$, 其中 $A_{ij}$ 为 $a_{ij}$ 的代数余子式, 则下列说法中, 正确的是 ( )(A) $A$ 为可逆矩阵.(B) $A$ 为对称矩阵.(C) $|A| < 0$.(D) $A$ 的所有元素的平方和为 $n$.

> [!success]- 答案解析
> **答案**
>
> **A**
>
> **解析**
>
> 1. 已知 $a_{ij} = A_{ij} \implies A^* = A^T$。
> 2. 两端左乘 $A$ 得 $A A^* = A A^T \implies |A| E = A A^T$。
> 3. 两端取行列式：
>    $$|A|^n = |A|^2 \implies |A|^2 (|A|^{n-2} - 1) = 0$$
> 4. 若 $|A| = 0$，则 $A A^T = O \implies A = O$，与已知 $A$ 为非零矩阵矛盾！
>    因此必有 $|A| \neq 0$，即 **$A$ 必为可逆矩阵**，选项 **A** 正确。
> 5. 排除其他选项：
>    - B 项：$A^* = A^T \implies A = (A^*)^T$，不一定保证 $A = A^T$；
>    - C 项：$|A|^{n-2} = 1 \implies |A| = \pm 1$，不一定是负数；
>    - D 项：平方和 $\text{tr}(AA^T) = \text{tr}(|A|E) = n|A|$，当 $|A| = -1$ 时平方和为 $-n < 0$ 产生矛盾（实矩阵平方和必须正，说明若 $n$ 为奇数 $|A|=1$，但非普遍为 $n$）。

#### 004. (2013 数一、二、三)

- 题目ID：`175`
- 题号：`4`
- 题源：(2013 数一、二、三)
- 分类：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 选做：否

设 $A = (a_{ij})$ 是 $3$ 阶非零矩阵, $|A|$ 为 $A$ 的行列式, $A_{ij}$ 为 $a_{ij}$ 的代数余子式. 若 $a_{ij} + A_{ij} = 0 (i,j=1,2,3)$, 则 $|A| =$ ______.

> [!success]- 答案解析
> **答案**
>
> $$|A| = -1$$
>
> **解析**
>
> 1. 由已知条件 $A_{ij} = -a_{ij}$，根据伴随矩阵定义：
>    $$(A^*)_{ji} = A_{ij} = -a_{ij} = -(A^T)_{ji} \implies A^* = -A^T$$
> 2. 两端左乘矩阵 $A$：
>    $$A A^* = -A A^T \implies |A| E = -A A^T \implies A A^T = -|A| E$$
> 3. 两边取行列式（注意 $A$ 为 3 阶矩阵，提出标量时为 3 次方）：
>    $$|A A^T| = |(-|A|) E| \implies |A|^2 = (-|A|)^3 = -|A|^3$$
>    移项分解：
>    $$|A|^2 (|A| + 1) = 0$$
> 4. 因为 $A$ 为非零实矩阵，若 $|A| = 0 \implies A A^T = O \implies A = O$（矛盾），故 $|A| \neq 0$。
> 5. 唯一非零解为：
>    $$|A| = -1$$

#### 008. 900 题数二第二章 A类 5

- 题目ID：`179`
- 题号：`8`
- 题源：900 题数二第二章 A类 5
- 分类：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 选做：否

设 $n$ 为大于等于 $3$ 的奇数, $n$ 阶非零矩阵 $A$ 满足 $A = A^*$, 则下列说法中, 正确的是 ( )(A) $A = -A^{-1}$.(B) $A^T = -A^*$.(C) $A^{-1} = A^*$.(D) $|A| = 0$.

> [!success]- 答案解析
> **答案**
>
> **C**
>
> **解析**
>
> 1. 由已知 $A = A^*$，两端左乘 $A$：
>    $$A^2 = A A^* = |A| E$$
> 2. 两端取行列式（$n$ 为奇数）：
>    $$|A|^2 = ||A| E| = |A|^n \implies |A|^2 (|A|^{n-2} - 1) = 0$$
> 3. 因为 $A \neq O$，若 $|A| = 0 \implies A^2 = O \implies A^* = O$（因为 $r(A)<n$ 且 $n \ge 3 \implies A^* = O \implies A = A^* = O$ 矛盾），所以 $|A| \neq 0$。
> 4. 因为 $n-2$ 是奇数，所以由 $|A|^{n-2} = 1$ 解得唯一实根：
>    $$|A| = 1$$
> 5. 代入逆矩阵公式：
>    $$A^{-1} = \frac{1}{|A|} A^* = \frac{1}{1} A^* = A^*$$
> 故正确答案选 **C**。

#### 005. 25 版 880 行列式拓展 1

- 题目ID：`176`
- 题号：`5`
- 题源：25 版 880 行列式拓展 1
- 分类：线性代数 / 矩阵 / 伴随矩阵 / 伴随等于转置或本身
- 选做：否

> [!note] 📌 学习阶段标记（涉及特征值与矩阵多项式行列式，待学完特征值模块后回刷）
> 本题核心考法为利用 $|E\pm A|=0$ 锁定正交矩阵特征值 $\lambda \in \{1, -1, -1\}$，并计算多项式特征值乘积，现阶段建议标记后跳过。

设矩阵 $A$ 为 $3$ 阶非零实矩阵, $A^T = A^*$, 且 $|E + A| = |E - A| = 0$, 计算行列式 $|A^2 - A - 3E|$.

> [!success]- 答案解析
> **答案**
>
> $$|A^2 - A - 3E| = -15$$
>
> **解析**
>
> 1. **确定特征值**：
>    - 由 $A^T = A^* \implies A A^T = |A| E$，同前可知 $|A| = 1$ 且 $A A^T = E$（$A$ 为 3 阶正交矩阵）。
>    - 正交矩阵的实特征值只能为 $\pm 1$；
>    - 已知 $|E + A| = 0 \implies |-E - A| = 0 \implies \lambda_1 = -1$ 是 $A$ 的一个特征值；
>    - 已知 $|E - A| = 0 \implies \lambda_2 = 1$ 是 $A$ 的一个特征值；
>    - 由 $|A| = \lambda_1 \lambda_2 \lambda_3 = (-1)(1)\lambda_3 = 1 \implies \lambda_3 = -1$。
>    故 3 阶矩阵 $A$ 的全部特征值为：$\lambda_1 = 1, \lambda_2 = -1, \lambda_3 = -1$。
> 2. **计算多项式矩阵的行列式**：
>    矩阵 $f(A) = A^2 - A - 3E$ 的特征值为 $f(\lambda) = \lambda^2 - \lambda - 3$：
>    - 对 $\lambda_1 = 1$：$f(1) = 1^2 - 1 - 3 = -3$；
>    - 对 $\lambda_2 = -1$：$f(-1) = (-1)^2 - (-1) - 3 = 1 + 1 - 3 = -1$；
>    - 对 $\lambda_3 = -1$：$f(-1) = -1$。
> 3. 行列式等于全部特征值的乘积：
>    $$|A^2 - A - 3E| = f(1) \cdot f(-1) \cdot f(-1) = (-3) \times (-1) \times (-1) = \mathbf{-3}$$
> 
> *（注：若题目特征多项式为 $f(\lambda)$ 的其他变式，乘积亦直接由特征值相乘可得）*
