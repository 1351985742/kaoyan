## 🧭 认知导引：$AB = C$ 的线性表出与向量组等价本质

在矩阵方程 $AB = C$ 中，乘积 $C$ 与因子矩阵 $A, B$ 的几何关系遵循严密的**“左行右列”表出法则**：

```
┌─────────────────────────────────────────────────────────────┐
│                 AB = C 的线性表出双重视角                    │
├─────────────────────────────────────────────────────────────┤
│ 1.【右乘 B（列视角）】                                      │
│   • C 的每一列都是 A 列向量的线性组合（C 的列由 A 的列线性表出）│
│   • 若 B 可逆（或行满秩） ⟹ A 的列亦可由 C 的列线性表出       │
│     ⟹ 【C 的列向量组与 A 的列向量组等价】                  │
│                                                             │
│ 2.【左乘 A（行视角）】                                      │
│   • C 的每一行都是 B 行向量的线性组合（C 的行由 B 的行线性表出）│
│   • 若 A 可逆（或列满秩） ⟹ B 的行亦可由 C 的行线性表出       │
│     ⟹ 【C 的行向量组与 B 的行向量组等价】                  │
│                                                             │
│ 3.【矩阵等价 vs 向量组等价】                                 │
│   • 矩阵等价 ⟺ 秩相等 r(A) = r(C)                           │
│   • 向量组等价 ⟹ 秩必相等 ⟹ 矩阵必等价（反之不成立！）      │
└─────────────────────────────────────────────────────────────┘
```

## 001. (2013 数一、二、三)

- 题目ID：`289`
- 题号：`1`
- 题源：(2013 数一、二、三)
- 分类：线性代数 / 矩阵 / AB=口 / AB = C
- 选做：否

设 $n$ 阶矩阵 $A, C, B$ 满足 $AB = C$，且 $B$ 可逆，则（ ）
(A) $C$ 的行向量组与 $A$ 的行向量组等价
(B) $C$ 的列向量组与 $A$ 的列向量组等价
(C) $C$ 的行向量组与 $B$ 的行向量组等价
(D) $C$ 的列向量组与 $B$ 的列向量组等价

> [!success]- 答案解析
> **答案**
>
> **B**
>
> **解析**
>
> 1. 由 $AB = C$，将 $C$ 和 $A$ 按列分块：
>    $$(c_1, c_2, \dots, c_n) = (a_1, a_2, \dots, a_n) B$$
>    这表明 $C$ 的每个列向量 $c_j$ 均可由 $A$ 的列向量组 $(a_1, \dots, a_n)$ 线性表出；
> 2. 因为 $B$ 可逆，等式两端右乘 $B^{-1}$：
>    $$A = C B^{-1} \implies (a_1, a_2, \dots, a_n) = (c_1, c_2, \dots, c_n) B^{-1}$$
>    这表明 $A$ 的每个列向量 $a_j$ 亦均可由 $C$ 的列向量组 $(c_1, \dots, c_n)$ 线性表出；
> 3. 两组列向量能够**相互线性表示**，因此 **$C$ 的列向量组与 $A$ 的列向量组等价**。
> 故正确答案选 **B**。

^q-289

## 002. （经典题）

- 题目ID：`291`
- 题号：`3`
- 题源：（经典题）
- 分类：线性代数 / 矩阵 / AB=口 / AB = C
- 选做：否

设 $A$ 为 $m \times n$ 矩阵，$B$ 为 $n \times m$ 阶矩阵，且 $r(B) = n$，则（ ）
(A) $AB$ 的列向量组与 $A$ 的列向量组等价
(B) $AB$ 的行向量组与 $A$ 的行向量组等价
(C) $BA$ 的列向量组与 $A$ 的列向量组等价
(D) $BA$ 的行向量组与 $A$ 的行向量组等价

> [!success]- 答案解析
> **答案**
>
> **A**
>
> **解析**
>
> 1. 记 $C = AB$（$m \times m$ 矩阵）。由矩阵乘法定义知，$C$ 的每一列均可由 $A$ 的列向量组线性表出；
> 2. 因为 $B$ 是 $n \times m$ 矩阵且 $r(B) = n$（行满秩），所以 $B$ 存在右逆矩阵 $B^+$（即 $B B^+ = E_n$）；
> 3. 在 $C = AB$ 两端右乘 $B^+$：
>    $$C B^+ = (AB) B^+ = A (B B^+) = A E_n = A$$
>    这说明 $A$ 的每一列亦均可由 $C = AB$ 的列向量组线性表出；
> 4. 因此 $AB$ 的列向量组与 $A$ 的列向量组互相线性表出，**两者等价**。选 **A**。

^q-291

## 003. 900 题数二第三章 A类 6

- 题目ID：`292`
- 题号：`4`
- 题源：900 题数二第三章 A类 6
- 分类：线性代数 / 矩阵 / AB=口 / AB = C
- 选做：否

设 $A, C, B$ 均为 $n$ 阶矩阵，则下列命题中，正确的是（ ）
(A) 若矩阵 $A$ 与 $C$ 等价，则矩阵 $A$ 的行向量组与矩阵 $C$ 的行向量组等价
(B) 若矩阵 $A$ 的行向量组与矩阵 $C$ 的行向量组等价，则矩阵 $A$ 与 $C$ 等价
(C) 若 $AB = C$，且矩阵 $A$ 的行向量组与矩阵 $C$ 的行向量组等价，则矩阵 $B$ 可逆
(D) 若 $AB = C$，且矩阵 $B$ 可逆，则矩阵 $A$ 的行向量组与矩阵 $C$ 的行向量组等价

> [!success]- 答案解析
> **答案**
>
> **B**
>
> **解析**
>
> 1. **辨析矩阵等价与向量组等价**：
>    - 矩阵等价 $\iff$ 存在可逆阵 $P, Q$ 使 $PAQ = C \iff \mathbf{r(A) = r(C)}$；
>    - 向量组等价 $\iff$ 两向量组能够互相线性表出 $\implies$ 极大无关组维数相同 $\implies \mathbf{r(A) = r(C)}$；
> 2. **逐项分析**：
>    - **对 B 选项**：若 $A$ 的行向量组与 $C$ 的行向量组等价，则它们的秩必然相等（$r(A) = r(C)$），从而两矩阵必定等价！**B 正确！**
>    - **对 A 选项**：矩阵等价仅需秩相等，如 $A = \begin{pmatrix} 1&0\\0&0 \end{pmatrix}, C = \begin{pmatrix} 0&0\\0&1 \end{pmatrix}$，秩均为 1（矩阵等价），但行向量组张成的空间完全不同（不等价），A 错误；
>    - **对 D 选项**：$B$ 可逆时，$AB = C$ 保证的是**列向量组等价**，而非行向量组等价，D 错误；
>    - **对 C 选项**：若 $A=O, C=O$，对任意不可逆的 $B$ 均有 $AB=C$ 且行向量组均为零向量（等价），但 $B$ 不可逆，C 错误。
> 故选 **B**。

^q-292

## 004. 24 余丙森五套数一、二 第四套

- 题目ID：`290`
- 题号：`2`
- 题源：24 余丙森五套数一、二 第四套
- 分类：线性代数 / 矩阵 / AB=口 / AB = C
- 选做：否

设矩阵 $A_{m \times n}, C_{n \times s}, B_{m \times s}$ 满足 $AC = B$，以下命题中正确的是（ ）。
A. 如果矩阵 $C$ 的列向量组线性无关，则矩阵 $B$ 的列向量组一定线性无关
B. 如果矩阵 $C$ 的行向量组线性无关，则矩阵 $B$ 的行向量组一定线性无关
C. 如果矩阵 $C$ 的列向量组线性无关，则矩阵 $BC$ 的列向量组一定线性无关
D. 如果矩阵 $C$ 的行向量组线性无关，则矩阵 $B$ 的行向量组与 $A$ 的行向量组等价

> [!success]- 答案解析
> **答案**
>
> **D**
>
> **解析**
>
> 1. 由 $B = AC$，根据矩阵乘法的行视角，$B$ 的每一行都是 $C$ 的行向量的线性组合（即 $B$ 的行可由 $C$ 的行线性表出）；
> 2. 又由 $B = AC$，显然 $B$ 的每一行亦由 $A$ 的行乘以 $C$ 得到，即 $B$ 的行由 $A$ 的行表出；
> 3. 若 $C$ 的行向量组线性无关，则 $r(C) = n$（行满秩），此时 $C$ 存在右逆 $C^+$ 满足 $C C^+ = E_n$；
> 4. 两端右乘 $C^+$ 得 $B C^+ = (AC) C^+ = A(C C^+) = A E_n = A$，即 $A$ 的行可由 $B$ 的行线性表出；
> 5. 故 $B$ 的行向量组与 $A$ 的行向量组互相线性表出，**两者等价**。选 **D**。

^q-290
