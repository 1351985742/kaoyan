# 大观园题库导出说明

本目录按照网站原有分类树导出，适合直接作为 Obsidian Vault 中的题库目录使用。

## 组织规则

- 根目录保留四个一级学科：`高等数学`、`线性代数`、`概率统计`、`套卷精刷`
- 每一级目录都按网站分类层级建立文件夹
- 不生成 `目录.md` 这类导航文档，目录导航交给 Obsidian 文件树
- 有题目的分类节点会直接生成同名 Markdown 文件，例如 `01 函数/01 求函数表达式.md`
- 若某个分类节点既有题目又有子分类，会同时保留同名文件夹承载子分类，并在父目录下生成同名题册文件

## 文件含义

- 题册 Markdown 文件：题干、选项、题源、题号、分类、视频链接等元信息
- 每道题下方有默认收起的 `答案解析` 折叠块
- `_meta/categories.json`：原始分类树
- `_meta/manifest.json`：实际导出的题册节点清单
- `_meta/summary.json`：导出统计摘要

## 折叠答案

- 单题展开：点击 `答案解析` callout 左侧折叠箭头
- 默认状态：`> [!success]- 答案解析` 中的 `-` 表示默认收起
- 批量展开：Obsidian 原生没有稳定的“只展开所有 callout”格式语法；可用命令面板中的展开/折叠命令，或安装支持 callout 批量展开的插件

## Obsidian 公式渲染

- 题目来自网站 API 原始数据，不是网页渲染层 OCR
- 数学公式已规范为 Obsidian 友好的 `$...$` 与 `$$...$$` 形式
- 若仍显示源码，请切到阅读视图或实时预览，并确认没有处于纯源码模式
