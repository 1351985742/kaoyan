# 关键中间步骤的选择与验证

## 选择依据

优先找相对该题型通用流程不常见、容易被常规套路漏掉的中间处理，且它对结果或路径有实质影响；通常跨题型可复用，如条件边界、特定结构的变量变化、消项后精度改变。不能仅因某步影响结果、题目比较复杂、没有展示、出现特殊函数，或属于一般流程中的必经步骤，就标成关键处理。也不能只因为外形新奇就标记：写清相对常规处理多了什么，以及漏掉会怎样。已知用户明确不熟的基础处理可作为个人薄弱点单独记录，但须注明是个人证据，不冒称它在一般场景下非常规。

后台做通题目，把“整理得、代入化简、同理、解方程得”等省略展开，识别：

| 转换 | 需要核验的实际动作 |
| --- | --- |
| 原式变成可操作形式 | 拆分、配项、变量选择、展开阶数、余项控制 |
| 表示变化 | 换元后变量/微分/端点统一，区域/积分限转换，函数与导数表达式衔接 |
| 条件变成约束 | 方程保留、自由变量、分段点、非零前提、合法消去 |
| 局部结果接回目标 | 列向量顺序、系数读取、变量信息保留、适用范围和符号 |

对候选片段问：

1. 是否需要实质选择，还是纯粹重复抄写？
2. 错误是否会破坏后续推理，即使这步只有一行？
3. “然后化简/求特征向量/换元”是否能掩盖它？

优先关键转换。再按学生实际旧错、本轮省略、缺少近期执行证据、跨路径复用价值和当前预算取舍。预标只是候选；学生改走有效路线时重新评价该路线的关键环节。

### 出题前识别需要选择的处理

不必等学生出错。后台展开实际解法，区分确定的常规运算与必须由目标、阶数或条件决定的操作：

- 同一个对象在不同位置承担不同作用，不能统一替换；例如相减中的指数项与已乘 x 的指数项需要保留不同精度。
- 熟悉的简化可能丢掉决定结果的信息：消去首项后还需更高阶、非一一映射后反推、提前固定后续要变化的变量。
- 存在看起来相似的处理选择，选择错误会改变极限、符号、定义域或可解性。

检查“如果学生把这一步简写成最熟悉的处理，结果是否仍成立”。若某个具体、可预见的误处理会改变结果，而同类执行尚无可靠证据，应在首次出题就选择少量高价值片段，中性标记“本题写关键过程”，只写到足以继续推进的形式。历史上明确不熟且当前输入结构、条件和复杂度相近时优先安排；有关联但不相同的操作写明差别，不能直接推断不会。不能为了制造风险枚举任意不合理错误，也不能把所有非多项式题或所有省略都升级为手算。

### 必须落实的逐题判定

每次出题前，对每道入选题完成以下简短后台决定，并将结果写入出题台账的 `fragment_decisions`：

1. 真实做通题目，对照该题型常规流程找非常规且有实质影响的具体转换；写明其不同点、合理误处理导致的后果，或确认无须单列。单纯遗漏、重要或较难不够；不编造学生错误。
2. 对照近期证据：实际已验证、明确困难、相关但不等同、无证据，记录来源及可迁移的条件；无证据本身不等于需要即时手算。
3. 选择 `思路回顾`、`写关键过程` 或 `完整作答`，记录理由。需要验证但本轮时间不足时写明具体回访安排，不能只写“待验证”。
4. 若决定写关键过程或完整作答，将对应中性要求直接附在本次题组的题目上；不得暴露关键动作、目标公式或旧错。所有题一次发齐、集中反馈。
5. 反馈后对照决定记录学生是否能预测关键处理、是否实际计算、使用提示和结果。学生清楚口述关键处理并连接前后步骤时，思路回顾可通过；实际手算另记未验证，并不自动补算。确有必要检验执行时，结合风险、用户意愿和时间安排集中补验或回访；用户拒绝或无条件时尊重并记录，不把 Agent 推演记成学生计算。

`fragment_decisions` 是教学计划，不是学生能力证据。每项至少含 `question_id`、`decision`、`fragment`、`rationale`、`evidence_basis`、`followup`；普通回顾的 fragment 可填“无须指定”，followup 可填“无”。具体结果仍记录在 `questions` 或 `fragments` 中。

例如 N(x)=1-e^x+ax e^x、分母为 x 时：1-e^x 需保留一阶差，ax e^x 只需 e^x 的常数精度；统一将 e^x 换成 1 会漏掉 -x。这里只需检验精度选择的一小段，不要求整题从头验算。数学任务改变时重新判断，不把“指数项危险”当口诀。单纯多项式运算通常可回顾，但有消项、参数退化或分母阶数变化时也可能需要判断。

## 记录验证缺口

- 实际展示且正确：记录具体输入、条件、产出、独立性和证据。
- 有旧错或本次明确错误：记录断点，不用“粗心”替代具体原因。
- 本次省略但未见错误：记待验证，不声称不会，也不自动要求补写。口述路线合理时可完成本题回顾，Agent 简短核验关键结果，学生执行能力仍保留证据局限。
- 旧记录已验证：只有结构、条件和复杂度相近时才复用，保留原证据来源与局限。

例如“简单常系数消元成功”不能推出“含参消元稳定”；“单段换元成功”不能推出“跨符号区间的根式换元稳定”。不让学生自行承担发现全部盲点的责任。

## 片段怎样截取

保留当前数学对象、必要条件、足以继续推进的局部任务。不要截成失去上下文的一行，也不要默认要求重算整题。

- **识别与选择验证**：保留原情境，不点名操作、目标中间公式或旧错提醒。
- **执行验证**：已确认会选择后，可以说明局部目标，检查实际变形是否完整、合法、可衔接。成功只证明给定任务下执行通过。

首次题组可在确有风险的少量题上中性要求展示关键过程；评价后只对实际错误、明确犹豫、同类反复不稳或高风险衔接集中补验。候选片段不等于必验任务，“没写过程”本身不足以要求即时补写。不设置每个片段一个确认关口，不把正常复习变成每题验算；Agent 自己的推演不能记成学生独立完成。

## 何时需要完整作答

根据风险选择，不固定每路径一题或全组必做：

- 多个局部步骤都能完成，但衔接尚无证据。
- 条件、变量、分段或上下限跨步骤传递，单片段不足以暴露问题。
- 路线描述合理但实际耗时未知，而时间控制是当前目标。
- 看过旧答案、接受提示或局部模板后成功，尚缺独立完成证据。

片段练习不能代替全部整题验证；也不能因为缺整题证据就将所有回顾题全部重算。预算不足时如实留待办。

## 评价示例（不直接作为作答前提示）

- 知道求特征向量，却未核对目标矩阵要求的列关系：检查选列及后续方程可解性，不能只验证某向量是特征向量。
- 知道用换元：分别看代换选择证据与变量、微分、端点统一的执行证据。
- 知道判断可微：检查候选线性主部和余项，不能无条件套用净阶数口诀。
- 知道消元：相减替换一条方程时，核对是否保留仍有信息的原约束。

题目或解析存在歧义、错误时先独立核验，记录来源问题，不归责于学生。
